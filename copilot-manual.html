Microsoft Copilot Manual

Independent self-study guide for Copilot on Windows, the web, mobile devices, and Microsoft 365.

All manuals Table of contents Website practice procedures Copilot lessons

Windows, Web, Mobile, Microsoft 365, Screen Readers, Privacy, and Responsible Use

Purpose: This manual teaches Microsoft Copilot from the beginning. It explains how to open Copilot, chat effectively, upload files, use current creation and voice features, verify results, manage privacy, use Copilot with screen readers, and understand how personal and work/school accounts differ.

Current reference: This guide is written for the current Microsoft Copilot experience available in September 2026. Microsoft released an updated Copilot app for web, desktop, and mobile on August 18, 2026, so some older tutorials and screenshots may not match the current interface.

Important account distinction: Copilot signed in with a personal Microsoft account and Copilot signed in with a work or school Microsoft Entra account have different data protections, settings, licensing, and features. Always identify which account you are using before entering sensitive information.

AI accuracy warning: Copilot is generative AI. Microsoft states that answers may not always be accurate. Verify important facts before making decisions or taking action.

How to Use This Manual

  • Work through Parts 1 through 8 before using Copilot for important tasks.

  • Use Tab and Shift+Tab to move among controls in the Windows/web Copilot interface; use Arrow keys inside lists and menus.

  • When using a screen reader, identify whether focus is in the navigation pane, chat pane, message edit field, or a generated response before typing.

  • Use low-risk practice prompts first. Do not begin by uploading confidential work, medical, financial, school, or client information.

  • Ask Copilot for sources when facts matter, then open the sources and verify that they support the answer.

  • If a feature such as Vision, Agents, Create, Search, Notebooks, or a Microsoft 365 integration is missing, your account, subscription, region, rollout stage, or organization policy may not include it.

  • For work/school accounts, follow organizational policy even if a personal Copilot account offers a feature that seems more convenient.

Part 1 - What Microsoft Copilot Is

Microsoft Copilot is Microsoft's AI assistant. Depending on the account and product, it can answer questions, draft and rewrite text, search for current information, analyze uploaded files, generate images, hold voice conversations, work with Microsoft 365 content, and use specialized agents or connected experiences.

  • Copilot chat: conversational AI in the Copilot app or web experience.

  • Microsoft 365 integration: Copilot features inside apps such as Word, Excel, PowerPoint, Outlook, OneNote, and Teams when included in your plan/account.

  • Work or school Copilot: can be grounded in organizational data you already have permission to access, subject to licensing and policy.

  • Personal Copilot: uses a personal Microsoft account and has consumer privacy/data controls that differ from enterprise data protection.

  • Copilot does not guarantee that generated facts, calculations, citations, interpretations, or recommendations are correct.

Part 2 - Personal vs Work or School Copilot

Account context Why it matters
Personal Microsoft account Examples: outlook.com, hotmail.com, live.com or another Microsoft account used personally. Consumer privacy controls apply.
Work/school Microsoft Entra account Organizational account. Enterprise data protection applies to Copilot Chat prompts/responses and organizational data according to Microsoft 365 protections.
Microsoft 365 home apps Copilot inside Word/Excel/PowerPoint/Outlook/OneNote with eligible personal Microsoft 365 subscriptions has separate Microsoft 365-home privacy rules.
Feature availability Can differ by subscription, license, region, device, rollout, and administrator policy.

2.1 Identify Your Account Before You Work

What you will learn: Know which privacy and data rules apply.

Before you begin: Open Copilot.

Exactly how to do it

  1. Find your profile/account control using Tab or the navigation menu.
  2. Open the profile/account menu.
  3. Read the signed-in email address and organization name if shown.
  4. Decide whether it is a personal Microsoft account or a work/school organizational account.
  5. If you are about to use employer/school data, verify that the organizational account and approved Copilot experience are active.

What should happen: You know which identity is currently controlling the Copilot session.

If that does not happen: If the account is unclear, sign out and sign in deliberately with the intended identity before entering sensitive information.

Practice: Practice switching only if you have two non-sensitive test accounts.

Part 3 - Open Copilot on Windows and the Web

3.1 Open the Copilot App in Windows

What you will learn: Start Copilot without using a mouse.

Before you begin: Copilot is installed or available from Microsoft Store.

Exactly how to do it

  1. Press the Windows key.
  2. Type Microsoft Copilot.
  3. Press Enter.
  4. Wait for the Copilot app to open.
  5. If using a screen reader, listen for focus in the message/chat area.

What should happen: The Copilot app opens.

If that does not happen: If Copilot is not installed, use Microsoft Store or the web version at copilot.com. Organization-managed PCs may restrict installation.

Practice: Open and close Copilot twice.

3.2 Open Copilot on the Web

What you will learn: Use Copilot from a browser.

Before you begin: Use a current browser and internet connection.

Exactly how to do it

  1. Open your browser.
  2. Press Ctrl+L or Alt+D to focus the address bar.
  3. Type copilot.com.
  4. Press Enter.
  5. Use Tab to reach sign-in or the message field.
  6. Sign in with the intended account if needed.

What should happen: Copilot opens in the browser.

If that does not happen: If the site is blocked, use an approved organizational method or contact IT rather than bypassing policy.

Practice: Open Copilot on the web and identify the message field.

Part 4 - Understand the Copilot Interface

The current Copilot interface changes depending on account type and feature availability. In Microsoft's work/school screen-reader documentation, the navigation pane can include items such as Search, Library, Create, Agents, Notebooks, and Apps. The chat area contains the message field, generated responses, and related controls.

Task What to do
Message Copilot edit field Type the prompt here, then press Enter.
New chat Starts a separate conversation.
Navigation pane Contains available experiences such as Search, Library, Create, Agents, Notebooks, and Apps in supported work/school versions.
Copilot chats and more / Settings Opens settings, history/recent pages, personalization, and other options depending on account.

Screen-reader navigation: Microsoft documents Tab/Shift+Tab for moving among the navigation pane, chat pane, and other sections, with Arrow keys used inside navigation choices.

Part 5 - Start a Chat

5.1 Ask Your First Question

What you will learn: Send a basic text prompt.

Before you begin: Focus is in the Message Copilot field.

Exactly how to do it

  1. Type a harmless question such as: Explain the difference between a file and a folder in Windows 11.
  2. Press Enter.
  3. Wait for the response.
  4. Use your screen reader reading commands or Arrow keys to review the answer.
  5. Press Tab through nearby response controls such as copy, feedback, sources, or follow-up actions when available.

What should happen: Copilot generates a response and keeps the conversation open for follow-up.

If that does not happen: If Enter creates a new line instead of sending, use the visible Send button or the keyboard behavior documented by your current client.

Practice: Ask three low-risk questions.

5.2 Start a New Chat

What you will learn: Keep unrelated topics from becoming mixed together.

Before you begin: You already have an active conversation.

Exactly how to do it

  1. Press Tab until you find Start a new chat / New chat.
  2. Press Enter.
  3. Confirm that the message field is empty and the old conversation is no longer the active thread.
  4. Type the new topic and press Enter.

What should happen: A separate conversation begins.

If that does not happen: If the prior conversation remains active, use the chat-history/sidebar navigation and choose New chat explicitly.

Practice: Start a new chat for a different subject.

Part 6 - Write Better Prompts

A strong prompt usually includes a goal, context, requirements, output format, and verification request.

Task What to do
Goal What you want Copilot to do.
Context Background Copilot needs to understand the task.
Requirements Length, audience, tone, exclusions, constraints, and required details.
Output format Paragraphs, headings, numbered steps, table, checklist, email draft, etc.
Verification Ask for sources, uncertainty, assumptions, or current-document grounding when appropriate.

6.1 Turn a Weak Prompt into a Strong Prompt

What you will learn: Get more useful and testable output.

Before you begin: Choose a harmless topic.

Exactly how to do it

  1. Start with a vague prompt such as: Help me with Excel.
  2. Identify what is missing: task, audience, version, data, output, or constraints.
  3. Rewrite it: I use Excel for Microsoft 365 on Windows with NVDA. Explain exactly how to create a table from A1:D20 using only the keyboard. Include expected screen-reader feedback and troubleshooting.
  4. Send the improved prompt.
  5. Compare the two responses.

What should happen: The second response should be more specific and actionable.

If that does not happen: If Copilot still gives visual-only directions, explicitly ask for exact keyboard/screen-reader steps.

Practice: Improve three vague prompts.

Part 7 - Follow-Up Questions and Iteration

  • Ask Copilot to explain one step in more detail.

  • Ask for alternatives and tradeoffs rather than one answer.

  • Ask which assumptions it made.

  • Ask which claims need verification.

  • Ask it to reformat an answer for a screen reader: headings, numbered procedures, fewer decorative symbols, descriptive links.

  • Ask it to shorten or expand the answer without changing the factual meaning.

Important: Repeatedly asking the same model does not create independent evidence. Use external sources when accuracy matters.

Part 8 - Verify Answers and Sources

8.1 Verify a Copilot Answer

What you will learn: Treat important claims as unverified until checked.

Before you begin: Choose a factual Copilot response.

Exactly how to do it

  1. Identify the claims that matter.
  2. Ask Copilot for sources or open the source citations it provides.
  3. Read the original source rather than only the Copilot summary.
  4. Check the publication or update date.
  5. Confirm that the source actually supports the claim.
  6. For important matters, compare another trustworthy source or primary source.

What should happen: You know which claims are supported and which are uncertain.

If that does not happen: If Copilot provides no usable source, do not repeat the claim as established fact.

Practice: Verify three current claims.

Part 9 - Web Search and Current Information

Copilot can use web search in supported experiences. Work/school versions may also have a Work/Web choice. Current information should be checked against recent sources, especially for news, prices, software, policies, laws, schedules, public figures, and product features.

9.1 Ask for Current Information Safely

What you will learn: Use web-grounded information without assuming it is correct.

Before you begin: Use a low-risk current topic.

Exactly how to do it

  1. Ask Copilot to search for the current information and cite sources.
  2. Open at least one primary or authoritative source.
  3. Check the date.
  4. Compare the event date with the publication date.
  5. If sources disagree, ask Copilot to summarize the disagreement rather than choosing a side without evidence.

What should happen: The answer is tied to current sources you can inspect.

If that does not happen: If Copilot appears to answer from memory without current sources, restate that current verification is required.

Practice: Verify a current Microsoft feature announcement.

Part 10 - Upload Files and Images

Microsoft currently documents file upload in personal Copilot for PDF, DOCX, XLSX, PPTX, PNG, JPEG/JFIF/PJP, TXT/TEXT, JSON, CSV, and Markdown. Microsoft says up to 20 files can be uploaded in one conversation in the current personal Copilot experience.

10.1 Upload a File

What you will learn: Ask Copilot about content you provide.

Before you begin: Use a non-sensitive practice file.

Exactly how to do it

  1. Focus the message composer.
  2. Press Tab until you find the Open/Add/plus control for files or images.
  3. Press Enter.
  4. Choose Add images or files.
  5. Use the file picker to select the practice file.
  6. Confirm the filename is attached.
  7. Type a prompt such as: Summarize this document in five bullets and list anything that appears ambiguous.
  8. Press Enter.

What should happen: Copilot analyzes the uploaded file and responds about its content.

If that does not happen: If upload is unavailable, your account/client/policy may not support it. Do not move sensitive files to a personal account just to gain the feature.

Practice: Upload a simple TXT or DOCX practice file.

Personal-account privacy: Microsoft currently states that files uploaded to personal Copilot are stored securely for no longer than 18 months and that uploaded file contents are not used for model training. Review current privacy controls before relying on this for sensitive material.

Part 11 - Work with PDFs, Word, Excel, and PowerPoint Files

  • PDF: ask for summary, headings, key facts, table extraction, or questions about the text. Scanned/image-only PDFs may require OCR and can produce errors.

  • DOCX: ask for summary, outline, rewrite suggestions, comparison, or accessibility improvements.

  • XLSX/CSV: ask for trends or explanations, but verify calculations/formulas independently.

  • PPTX: ask for slide outline, speaker-note summary, accessibility review, or missing-context questions.

  • Never assume Copilot interpreted a complex table, chart, footnote, scanned page, or hidden worksheet perfectly.

11.1 Check Copilot Against the Source File

What you will learn: Prevent a summary from replacing the document.

Before you begin: Use a practice document you know well.

Exactly how to do it

  1. Upload the document.
  2. Ask for a concise summary.
  3. Ask Copilot to identify where in the document each important claim came from.
  4. Open the original file and locate those sections yourself.
  5. Correct any mismatch.

What should happen: You know whether Copilot preserved the source meaning.

If that does not happen: If Copilot cannot identify supporting locations, treat the summary as a draft aid only.

Practice: Compare five claims with the source.

Part 12 - Generate and Edit Images

Microsoft Copilot can generate images from text prompts and can edit an uploaded image in supported versions.

12.1 Generate an Image

What you will learn: Create a new image from a text description.

Before you begin: Do not include a real person or private information in the practice prompt.

Exactly how to do it

  1. Type a descriptive prompt beginning with Create an image of...
  2. Include subject, setting, style, mood, orientation, and important details.
  3. Send the prompt.
  4. Wait for the generated result.
  5. If using a screen reader, ask Copilot to describe the resulting image in text and verify critical details when possible.

What should happen: Copilot produces one or more images or a creation result.

If that does not happen: If image generation is unavailable or capacity-limited, use a text task and try later through an eligible experience.

Practice: Generate a simple diagram-like or decorative practice image.

12.2 Edit an Image

What you will learn: Describe a requested change to an image you have the right to use.

Before you begin: Use your own practice image.

Exactly how to do it

  1. Use the plus/Open control.
  2. Choose Add images or files.
  3. Select the image.
  4. Type a change request such as: Remove the plain background and replace it with a neutral office wall.
  5. Send the prompt.
  6. Review the result and ask for further changes if needed.

What should happen: Copilot creates an edited result based on the request.

If that does not happen: Microsoft instructs users to upload images they own or have rights to use and to respect other people's privacy and rights.

Practice: Edit a non-sensitive image you own.

Part 13 - Copilot Voice

Current Copilot voice features include dictation, read aloud, and voice chat in supported experiences/languages. Voice chat lets you speak conversationally and hear spoken Copilot responses.

13.1 Start a Voice Conversation

What you will learn: Use Copilot hands-free.

Before you begin: A microphone is connected and microphone access is permitted.

Exactly how to do it

  1. Open Copilot.
  2. Move to the microphone/voice control near the composer.
  3. Activate it.
  4. Grant microphone permission if prompted and you agree.
  5. Speak a simple question.
  6. Listen to the spoken response.
  7. End the voice conversation using the available stop/end control.

What should happen: Copilot responds aloud and a text transcript is available after the conversation.

If that does not happen: If Copilot cannot hear you, check the selected microphone and browser/Windows microphone permission.

Practice: Have a one-minute low-risk voice conversation.

Voice privacy: Microsoft currently states that normal Copilot Voice audio is not stored after processing; text transcripts are managed like text conversations. Feedback-related audio retention can have separate temporary rules, so review current settings before discussing sensitive topics.

Part 14 - Copilot Vision

Copilot Vision can analyze a screen, webpage/app, or mobile camera feed that you deliberately share and answer questions about what it sees. Availability depends on the current Copilot plan/account and rollout. Vision is guidance: Microsoft states that it does not directly manipulate items on your device.

14.1 Use Vision as an Accessibility Aid

What you will learn: Ask Copilot about visual content you choose to share.

Before you begin: Use only non-sensitive visual content and confirm Vision is available to your account.

Exactly how to do it

  1. Start a Copilot Voice conversation when required by the current client.
  2. Activate the Vision/share-screen or camera control.
  3. Choose only the screen, app, page, or camera view you intend to share.
  4. Ask a specific question such as: Describe the layout and tell me the text of the main heading.
  5. Ask follow-up questions about individual controls or visual elements.
  6. End Vision when finished.

What should happen: Copilot describes or reasons about the shared visual content.

If that does not happen: Do not rely on Vision alone for safety-critical visual information such as medication identity, traffic, hazards, financial amounts, or identity verification.

Practice: Use Vision on a harmless settings screen if available.

Vision privacy: Microsoft states that Vision is user-initiated and session-bound. Current retention and subscription details vary between personal and organizational Copilot experiences; review the privacy notice displayed by your current client.

Part 15 - Conversation History

When signed in, Copilot can save conversation history so you can reopen past chats. Microsoft currently states that personal Copilot keeps the last 18 months of conversation history by default, with controls to delete individual conversations or history.

15.1 Reopen a Previous Conversation

What you will learn: Continue a prior topic without retyping context.

Before you begin: You are signed in and history is enabled.

Exactly how to do it

  1. Open the sidebar/navigation pane.
  2. Move through conversation history/recent chats.
  3. Select a conversation by title/date.
  4. Press Enter.
  5. Read enough of the prior conversation to confirm it is the correct one before continuing.

What should happen: The prior thread opens.

If that does not happen: If the conversation is missing, it may have been deleted, created in temporary chat, or history may be disabled/unavailable.

Practice: Open one harmless prior conversation.

Part 16 - Memory, Personalization, and Temporary Chat

Current Copilot versions can remember preferences and details for personalization. Microsoft provides controls to view/delete saved memories and turn memory/personalization off. Temporary chat is designed for conversations that do not use or add personalized memory and do not appear in normal chat history in supported experiences.

16.1 Review Copilot Memory

What you will learn: See what Copilot may remember about you.

Before you begin: Sign in to a Copilot version with memory controls.

Exactly how to do it

  1. Open Settings / Chat settings.
  2. Open Personalization or Memory.
  3. Choose Manage saved memories.
  4. Review each memory.
  5. Delete anything you do not want remembered.
  6. Turn saved memory/personalization off if that better fits your privacy preference.

What should happen: You know what personalization data is being retained in the feature.

If that does not happen: Turning off memory may not automatically delete every already-saved item; use the delete controls as well.

Practice: Review memory without adding new private information.

16.2 Start a Temporary Chat

What you will learn: Discuss something without using normal personalization/history when the feature is available.

Before you begin: Temporary chat is offered in your version.

Exactly how to do it

  1. Find Temporary chat near the new-chat controls.
  2. Activate it.
  3. Confirm the interface indicates Temporary chat.
  4. Ask a harmless question.
  5. Close the temporary conversation and verify it is not available as a normal history item.

What should happen: The temporary conversation is separated from normal history/personalization.

If that does not happen: Do not treat Temporary chat as permission to share confidential information; service and organizational rules still apply.

Practice: Use one harmless temporary chat.

Part 17 - Search, Library, and Create in the Work/School Copilot App

Microsoft's current screen-reader guidance for organizational Copilot describes Search, Library, Create, Agents, Notebooks, and Apps in the navigation pane. Availability depends on account and organization settings.

17.1 Use Search with a Screen Reader

What you will learn: Find organizational files and content you already have permission to access.

Before you begin: Signed in with a supported work/school account.

Exactly how to do it

  1. Press Tab until you reach the side navigation panel and expand it if necessary.
  2. Move to Search using the navigation list and Down Arrow.
  3. Press Enter.
  4. Type a keyword/query.
  5. Press Enter.
  6. Use Tab and Arrow keys through results and Quick access tabs such as Recent, Shared, and Favorites when available.
  7. Press Enter on the intended file.

What should happen: Search returns content available to your account.

If that does not happen: Search does not grant new permissions; if a file is unavailable, request access through normal organizational channels rather than trying to bypass permissions.

Practice: Search for one known non-sensitive work/school file.

17.2 Use Library and Create

What you will learn: Open existing content or start an AI-created artifact.

Before you begin: The navigation items are available.

Exactly how to do it

  1. Open the side navigation panel.
  2. Move to Library and press Enter to browse saved/recent items.
  3. Return to navigation.
  4. Move to Create and press Enter.
  5. Use Arrow keys through creation options such as image, video, infographic, story, poster, or edit image when those options are available.
  6. Choose a harmless practice creation option and enter a prompt.

What should happen: You can reach both existing content and creation tools without a mouse.

If that does not happen: If items are not present, your license/organization may not include them.

Practice: Open Library and Create without generating confidential content.

Part 18 - Agents and Specialized Experiences

Current organizational Copilot experiences may include specialized agents such as Researcher, Analyst, Files, Writing Coach, Prompt Coach, Idea Coach, and organization-specific agents. Availability varies by license and administrator settings.

  • An agent is specialized for a task or data source; it is not automatically more accurate.

  • Check what data and permissions the agent can access.

  • Use the same verification rules for an agent's factual output.

  • Do not create an agent with broader organizational permissions than its job requires.

  • Use least privilege and human confirmation for actions that affect files, people, money, external communications, or records.

18.1 Open an Agent with a Screen Reader

What you will learn: Use a specialized agent without losing navigation context.

Before you begin: Agents are available in your organizational Copilot.

Exactly how to do it

  1. Expand the navigation pane.
  2. Move to Agents and press Enter.
  3. Use Down Arrow through available agents.
  4. Press Enter on the desired agent.
  5. Read its description before giving it information.
  6. Send a low-risk test prompt.

What should happen: The specialized agent opens in a chat-like workspace.

If that does not happen: If you do not recognize an agent or its data access, ask your organization/IT before using sensitive information.

Practice: Try Prompt Coach or Writing Coach if available.

Part 19 - Copilot in Word

  • Draft: generate a starting draft from a prompt or referenced content when available.

  • Rewrite: improve selected text, tone, clarity, or length.

  • Summarize: produce a summary of document content.

  • Ask about document: query information grounded in the open file.

  • Always review generated text for factual accuracy, tone, citations, accessibility, and organization policy before accepting it.

Screen-reader workflow: Use Word's normal keyboard navigation to position focus/selection, then open Copilot through the current Ribbon/Copilot control. Microsoft publishes separate screen-reader instructions for Copilot in Word because commands and pane structure can change.

Part 20 - Copilot in Excel

  • Ask Copilot to explain data, trends, formulas, or possible visualizations when supported.

  • Keep data in a clean table/range with meaningful headers for better analysis.

  • Verify every generated formula by checking cell references and testing with known values.

  • Do not rely on Copilot alone for financial, statistical, compliance, or scientific calculations.

  • Ask it to explain how it reached a result rather than accepting the number alone.

Part 21 - Copilot in PowerPoint

  • Use Copilot for presentation outlines, draft slides, summaries, and rewriting.

  • Check slide order, factual claims, speaker notes, citations, alt text, reading order, and color/contrast.

  • Do not assume an AI-generated visual is accessible to blind/low-vision users.

  • Run PowerPoint Accessibility Checker before sharing important presentations.

Part 22 - Copilot in Outlook

  • Summarize long email threads when supported, then read critical messages yourself before acting.

  • Draft/rewrite email, but verify recipient, tone, promises, dates, attachments, and confidential content.

  • Do not let a summary hide a disagreement, exception, deadline, or legal/compliance language.

  • For work/school use, organizational data protection and policy govern what Copilot can use and what you may send.

Part 23 - Copilot in OneNote and Teams

23.1 OneNote

  • Use Copilot to summarize notes, generate task lists, reorganize ideas, or explain selected content when available.

  • Check notebook/section/page privacy before asking Copilot to act on shared notes.

  • Keep source notes available so you can verify the generated summary.

23.2 Teams

  • Copilot can summarize meetings/chats and help identify decisions or action items when the required licensing/policy is enabled.

  • Verify names, assignments, dates, and decisions against the actual meeting/chat record before sending follow-up.

  • Respect meeting recording, transcription, retention, and organizational privacy policies.

Part 24 - Accessibility with Narrator, NVDA, and JAWS

24.1 Navigate the Copilot App with a Windows Screen Reader

What you will learn: Move predictably among chat and navigation areas.

Before you begin: Narrator, NVDA, or JAWS is running.

Exactly how to do it

  1. Press Windows, type Microsoft Copilot, and press Enter.
  2. Listen for focus in the Message Copilot edit field/chat area.
  3. Press Tab and Shift+Tab to move among major regions and controls.
  4. When focus reaches the navigation pane/list, use Down/Up Arrow through options.
  5. Press Enter to activate the selected option.
  6. Return to the message field with Tab/Shift+Tab and type a prompt.
  7. After the response arrives, use screen-reader reading/navigation commands to review it before moving to action buttons.

What should happen: You can reach chat, navigation, settings, and feature areas without a mouse.

If that does not happen: If your screen reader begins reading the whole window rather than interacting with controls, confirm whether its browse/scan mode needs to be changed for the current control. Use the screen reader's help rather than guessing.

Practice: Navigate New chat, Settings, and one navigation item.

Part 25 - VoiceOver, TalkBack, and Braille

25.1 VoiceOver and TalkBack

  • Use standard swipe/navigation gestures through labeled buttons, the composer, history, settings, and generated responses.

  • Double-tap the focused control to activate it.

  • Use rotor/reading controls to move by headings or form controls where exposed.

  • When using Copilot Voice or Vision, confirm microphone/camera/screen-sharing state before discussing private content.

  • Mobile UI can roll out independently from Windows/web, so rely on control labels rather than memorized screen coordinates.

25.2 Refreshable Braille

  • Braille follows the active screen reader: Narrator, NVDA, JAWS, VoiceOver, or TalkBack.

  • Test three functions: braille output from Copilot, braille input into the message field, and routing within editable text.

  • Long AI responses may be easier to navigate with headings, lists, or shortened output; explicitly ask Copilot for that format.

  • Protect privacy: Copilot can display account, work, email, and uploaded-document content on the braille display.

Part 26 - Privacy for Personal Microsoft Accounts

Microsoft's current personal-account privacy controls include conversation history, personalization/memory, model-training choices, and other consumer privacy settings. Microsoft released updated privacy documentation with the August 18, 2026 Copilot app.

  • Review Settings > privacy/personalization controls in the current app.

  • Microsoft currently lets personal users control whether conversation activity is used to train generative AI models.

  • Personal Copilot conversation history is retained for a limited period (currently documented as 18 months by default) unless deleted sooner.

  • You can delete individual conversations or history.

  • Uploaded files and images have their own current retention rules; verify them before uploading sensitive information.

  • Vision has separate session-bound privacy rules from ordinary uploaded files/images.

Rule: A personal Copilot account is not an employer-approved secure workspace just because it is a Microsoft product.

Part 27 - Enterprise Data Protection for Work or School

Microsoft states that Copilot Chat for work/school processes prompts and responses within the Microsoft 365 service boundary with enterprise data protection. Microsoft also states that Microsoft 365 Copilot prompts, responses, and Microsoft Graph data are not used to train foundation LLMs.

  • Copilot can only ground in organizational content the signed-in user is permitted to access.

  • Existing Microsoft 365 security, privacy, and compliance controls continue to apply.

  • Organization administrators can restrict features, connected experiences, agents, Vision, and other capabilities.

  • Enterprise protection does not mean every use is allowed; organizational policy still governs what employees/students may submit and what actions they may take.

27.1 Check Before Using Organizational Data

What you will learn: Avoid accidentally putting work/school data into the wrong Copilot context.

Before you begin: You are about to use nonpublic organizational information.

Exactly how to do it

  1. Confirm the signed-in account is your organizational account.
  2. Confirm the Copilot experience shows the expected organizational/work context.
  3. Check whether your organization has an AI/Copilot policy for this data category.
  4. Use only the minimum data required.
  5. Review the response before sharing it outside the organization.

What should happen: Organizational information stays within the approved workflow.

If that does not happen: If you cannot determine whether the Copilot session is covered by your organization, stop and ask IT/security rather than using a personal session.

Practice: Practice with a non-sensitive internal document only if policy permits.

Part 28 - Responsible Use and High-Stakes Tasks

  • Copilot can be wrong even when the answer sounds confident.

  • Do not use Copilot alone to make medical, legal, financial, employment, safety, disciplinary, or other high-stakes decisions.

  • Verify facts with authoritative current sources and qualified professionals when needed.

  • Do not upload other people's sensitive personal information merely because Copilot can analyze it.

  • Review AI-generated images and text for bias, inappropriate assumptions, accessibility, copyright/rights issues, and disclosure requirements.

  • Keep a human responsible for external messages, files, purchases, deletions, security changes, and decisions that affect other people.

Microsoft guidance: Microsoft's Copilot voice FAQ explicitly warns that generative AI answers may not always be accurate and recommends double-checking facts before decisions or actions.

Part 29 - Troubleshooting

29.1 Copilot Gives an Incorrect or Invented Answer

What you will learn: Recover without arguing with the model.

Before you begin: You suspect the answer is wrong.

Exactly how to do it

  1. Ask Copilot to separate verified facts from assumptions.
  2. Ask for current primary sources.
  3. Open those sources yourself.
  4. Remove unsupported claims from your work.
  5. Start a new chat if the conversation contains conflicting assumptions.
  6. For high-stakes topics, use qualified human guidance.

What should happen: The unsupported content is isolated and corrected.

If that does not happen: Do not keep prompting until Copilot produces the answer you hoped to hear.

Practice: Verify one deliberately testable claim.

29.2 Copilot Cannot See a File or Work Item

What you will learn: Check account, permission, and attachment state.

Before you begin: A file exists but Copilot cannot use it.

Exactly how to do it

  1. Confirm the correct account is signed in.
  2. For uploads, confirm the file is actually attached to the current chat.
  3. For organizational Search/Library, confirm you personally have permission to open the file outside Copilot.
  4. Check whether the file format/size is supported by the current client.
  5. Ask IT/owner for normal file access if required.

What should happen: You identify upload, account, permission, or feature support as the cause.

If that does not happen: Copilot must not be used to bypass access control.

Practice: Diagnose a harmless test file.

29.3 Voice Does Not Hear You

What you will learn: Restore microphone access methodically.

Before you begin: Copilot Voice is open.

Exactly how to do it

  1. Check that the correct microphone is connected and unmuted.
  2. Check Windows/browser microphone permission for Copilot.
  3. Reduce background noise.
  4. End and restart the voice session.
  5. Test the microphone in another trusted app.

What should happen: Voice input works or the microphone/permission problem is isolated.

If that does not happen: Do not repeatedly reinstall Copilot until the basic microphone test is done.

Practice: Run a microphone test.

29.4 Copilot Screen Reader Focus Is Confusing

What you will learn: Reestablish the region before changing screen-reader settings.

Before you begin: Copilot is open with Narrator/NVDA/JAWS.

Exactly how to do it

  1. Press Escape to close menus/dialogs.
  2. Use Tab/Shift+Tab to identify the focused control.
  3. Move to the navigation pane or message field deliberately.
  4. Use the screen reader's focus-repeat command to confirm location.
  5. Only toggle browse/scan/focus mode if the current control requires it.

What should happen: You regain predictable keyboard focus.

If that does not happen: If the UI changed after an update, use Microsoft's current screen-reader article instead of old memorized positions.

Practice: Recover from navigation pane to message field.

29.5 A Feature Is Missing

What you will learn: Determine whether it is a rollout/license/policy issue.

Before you begin: You saw a feature in documentation or another user's account.

Exactly how to do it

  1. Check whether you are using personal or work/school Copilot.
  2. Check Copilot/app updates.
  3. Check subscription/license requirements in Microsoft Support.
  4. Check organization policy/admin restrictions.
  5. Check region/language/device requirements.
  6. Use an alternative supported workflow instead of trying to circumvent restrictions.

What should happen: You understand why the UI differs or know what to check next.

If that does not happen: Copilot features roll out and change frequently; a missing feature is not automatically a malfunction.

Practice: Compare the navigation items available in your account with the manual.

Exactly how to do it

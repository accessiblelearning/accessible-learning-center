How to Use This Manual

  • Students can skip the teacher-only parts; teachers can use both sections to understand the student experience.

  • Use heading, landmark, button, link, and form-field navigation in Classroom.

  • Verify that you are signed into the correct school/personal account before joining or creating a class.

  • Open attached Docs/Sheets/Forms in their own tabs and use each app’s screen-reader workflow.

  • Use the assignment status and due-date information, not memory alone, to confirm completion.

Part 1 - What Google Classroom Is

  • Classroom organizes classes, assignments, announcements, materials, communication, grades, and linked Google Workspace files.

  • Students join classes and submit work.

  • Teachers create classes, distribute work, grade, and return submissions.

  • Availability and advanced features depend on Google Workspace for Education edition and administrator settings.

Part 2 - Recommended Screen Readers and Browsers

Task Command / Method
Windows NVDA or JAWS with Chrome or Firefox
ChromeOS ChromeVox
Mac VoiceOver with Chrome
Mobile VoiceOver on iOS/iPadOS or TalkBack on Android

Navigation model: Classroom is a structured web application. Use headings, buttons, links, and tabs; unlike Gmail/Drive, many Classroom tasks work well with ordinary screen-reader web navigation.

Part 3 - Classroom Homepage

  • View Switcher may let users switch among Enrolled/Student, Teaching, and Admin views when their account has multiple roles.

  • Due soon can show upcoming assignments.

  • Classes module contains class cards and quick actions.

  • Teacher dashboards may include Recently due, analytics/insights, and feature cards depending on edition.

  • Learn with Gemini and class learning tools may appear when enabled by the administrator.

Part 4 - Join a Class - Student

4.1 Join with a Class Code

What you will learn: Enroll in a class using a code from the teacher.

Keyboard command: Universal: Tab/Shift+Tab to controls and Enter to activate. JAWS/NVDA: B/Shift+B can move by buttons and E/Shift+E by edit fields in browse mode; press Enter to activate. On the Join class button press Enter, type the code, then press Enter again.

Before you begin: Use the school account intended for the class.

Exactly how to do it

  1. Open classroom.google.com.
  2. Verify the Google account in the banner.
  3. Use Tab/Shift+Tab or your screen reader button command to move to Join class / + Add Class.
  4. Press Enter to activate it.
  5. Press Tab to the Class code edit field if focus is not already there, then type the code.
  6. Press Enter, or Tab to Join and press Enter.

What should happen: The class opens on the Stream page.

If that does not happen: If the code is rejected, confirm exact characters and the intended school account with the teacher.

Practice: Join only a real class with permission.

Invitation alternative: If a teacher invited you directly, activate the Join control on that class card instead of entering a code.

Part 5 - Open a Class

5.1 Open a Class

What you will learn: Enter a class and identify its navigation tabs.

Keyboard command: On the Classes page use screen-reader heading/link navigation (JAWS/NVDA H or K where applicable) or Tab/Shift+Tab to the class link; press Enter. Use Tab/Shift+Tab or link navigation to Stream/Classwork/People and press Enter.

Before you begin: You are enrolled.

Exactly how to do it

  1. Use Tab/Shift+Tab or screen-reader heading/link navigation to the class name link.
  2. Press Enter.
  3. Use Tab/Shift+Tab or link navigation to identify Stream, Classwork, People, and any other available tabs.
  4. Move to Classwork and press Enter.
  5. Move to Stream and press Enter.

What should happen: You can move among the class’s main pages.

If that does not happen: If the class is missing, verify account and enrollment.

Practice: Open every class tab once.

Part 6 - Stream, Classwork, People, Grades

  • Stream: announcements and class conversation, depending on settings.

  • Classwork: assignments, questions, materials, topics, and due dates.

  • People: teachers and classmates according to role/permissions.

  • Grades: teacher gradebook; students use returned work/grade views rather than a teacher Grades tab.

Part 7 - Upcoming Work and To-do

  • Use Due soon and To-do/Classwork views to identify deadlines.

  • Read assignment name, class, due date/time, and submission status.

  • Use Google Calendar integration when enabled, but confirm the Classroom assignment itself before assuming a calendar event proves submission.

Part 8 - Complete an Assignment - Student

8.1 Open and Complete an Assignment

What you will learn: Finish work without losing track of submission status.

Keyboard command: Use Tab/Shift+Tab or screen-reader link/heading navigation to Classwork and the assignment; press Enter to open each. After completing attached work, return to the Classroom tab with Ctrl+Tab/Shift+Ctrl+Tab (browser tab navigation), navigate to Turn in, and press Enter.

Before you begin: Use a practice or real assigned item.

Exactly how to do it

  1. Use Tab/link navigation to the class name and press Enter.
  2. Use Tab/link navigation to Classwork and press Enter.
  3. Use heading/link navigation or Tab to the assignment title; press Enter. If the item is collapsed, press Enter and then navigate to View instructions/details and press Enter.
  4. Read instructions, due date, points, and attachments.
  5. Open the assigned file/link in its new tab if needed.
  6. Complete the work using the appropriate Google app workflow.
  7. Press Ctrl+Tab or Ctrl+Shift+Tab to return to the Classroom browser tab if the work opened in another tab.
  8. Review Your work/attachments.
  9. Use Tab/button navigation to Turn in and press Enter only when ready; press Enter again if a confirmation dialog appears.

What should happen: Classroom records the work as turned in/submitted.

If that does not happen: If Turn in is unavailable, check whether a required attachment/question is incomplete or whether the due item uses another submission workflow.

Practice: Practice with a teacher-provided test assignment when available.

Part 9 - Turn In, Unsubmit, and Resubmit

  • Turn in changes assignment status; saving a Doc alone is not the same as submitting it.

  • Unsubmit may be available before grading/locking and can change status back to assigned.

  • After changing work, turn it in again.

  • Always read the final status before leaving the assignment.

Part 10 - Questions and Quizzes

  • Questions may be short-answer or multiple choice.

  • Quiz assignments commonly open Google Forms.

  • Complete the Form using normal Forms respondent navigation and submit there, then verify Classroom status.

  • Practice sets can expose an Enable accessibility control in supported environments; Google currently documents this particularly for ChromeOS practice sets.

Part 11 - Communicate with Teacher/Class

  • Use private comments for assignment-specific teacher communication when available.

  • Use class comments/Stream only for information appropriate to the class audience.

  • Do not post passwords, private grades, or sensitive student information in public class comments.

Part 12 - Check Grades and Returned Work

12.1 Review Returned Work

What you will learn: Find teacher feedback and grade.

Keyboard command: Use Tab/Shift+Tab or screen-reader navigation to Classwork/Your work; press Enter. Navigate to the returned assignment with headings/links, press Enter, then use Tab/Shift+Tab through grade, feedback, and attachment controls.

Before you begin: An assignment has been returned.

Exactly how to do it

  1. Open the class and Classwork.
  2. Open the assignment.
  3. Read the grade/status.
  4. Open the returned file or feedback/comments.
  5. Review teacher comments.
  6. If revision is allowed, make changes and follow the teacher’s resubmission instructions.

What should happen: You know the current grade and feedback.

If that does not happen: If a grade appears missing, confirm the work was submitted and returned, then ask the teacher through the approved channel.

Practice: Review one returned practice assignment.

Part 13 - Join a Class Video Meeting

  • A class may expose a Google Meet link in Stream/Classwork/banner depending on teacher settings.

  • Activate the meeting link, then use the Google Meet screen-reader workflow for mic, camera, captions, chat, people, and leaving.

  • Verify that you joined the correct class meeting and account.

Part 14 - Teacher: Create a Class

14.1 Create a Class

What you will learn: Set up a course shell.

Keyboard command: Use Tab/Shift+Tab or screen-reader button navigation to + Add Class; press Enter. Use Arrow keys to Create class and press Enter. Tab through fields, type the details, then Tab to Create and press Enter.

Before you begin: Use an account allowed to teach/create classes.

Exactly how to do it

  1. Open classroom.google.com.
  2. Navigate to the Classes module.
  3. Use Tab/Shift+Tab or button navigation to + Add Class.
  4. Press Enter.
  5. Use Up/Down Arrow to Create class and press Enter.
  6. Use Tab/Shift+Tab through Class name, Section, Subject, Room, and Class level fields; type each value as needed.
  7. Tab to Create and press Enter.

What should happen: The new class opens on Stream.

If that does not happen: If Create class is missing, the Workspace administrator or account type may not permit it.

Practice: Create only a real or authorized practice class.

Part 15 - Teacher: Invite Students and Co-teachers

  • Use People to invite students and co-teachers through approved school accounts.

  • A class code can be shared with students who are allowed to enroll.

  • Verify names/email domains before inviting.

  • Co-teachers have substantial access; invite only authorized staff.

Part 16 - Teacher: Create Assignments and Materials

16.1 Create an Assignment

What you will learn: Publish a clear, accessible assignment.

Keyboard command: Open Classwork with Tab/link navigation and Enter. Navigate to Create and press Enter; use Arrow keys to Assignment and press Enter. Tab/Shift+Tab through Title, Instructions, attachments, students, points, due date, topic, and Assign/Schedule/Save draft controls.

Before you begin: Open the correct class.

Exactly how to do it

  1. Navigate to Classwork with Tab/link navigation and press Enter.
  2. Use Tab/Shift+Tab or button navigation to Create.
  3. Press Enter on Create, use Up/Down Arrow to Assignment, and press Enter.
  4. In the Title edit field, type a descriptive title; press Tab to move onward.
  5. Enter instructions that do not depend on visual layout/color alone.
  6. Attach Drive files, links, YouTube, or create Google files as needed.
  7. Set students/classes, points, due date/time, topic, rubric/category where applicable.
  8. Use Tab/Shift+Tab to Assign/Schedule/Save draft, press Enter, and confirm any menu/dialog choice with Arrow keys and Enter.

What should happen: Students receive a structured assignment with clear requirements.

If that does not happen: If a file-copy option is wrong, cancel/edit before students begin because changing distributed files later can be disruptive.

Practice: Create a draft practice assignment.

Part 17 - Teacher: Questions and Quiz Assignments

  • Question supports short answer or multiple choice.

  • Quiz assignment can create/attach Google Forms quiz.

  • Review accessibility of the Form before assigning.

  • Use due dates, points, and instructions consistently.

Part 18 - Teacher: Review, Grade, and Return Work

18.1 Grade One Submission

What you will learn: Open work, enter grade, and return it.

Keyboard command: In the gradebook use Arrow keys in view mode, Enter to save a draft and move down, Shift+Enter to move up, Tab/Shift+Tab across cells, Ctrl+Shift+\ to open a cell menu, Ctrl+Alt+V to view submission, Ctrl+Alt+R to return the assignment, and Esc to return from edit mode to view mode.

Before you begin: Students have submitted work.

Exactly how to do it

  1. Open the assignment.
  2. Navigate to student work/submissions.
  3. Choose the student.
  4. Open the submission.
  5. Review work and comments.
  6. In the gradebook, use Arrow keys to the grade cell; type the grade. Press Enter to save the draft and move down, or Shift+Enter to save and move up.
  7. Add private feedback if needed.
  8. Press Ctrl+Alt+R on Windows/ChromeOS (Command+Option+R on Mac) when the gradebook shortcut applies, or navigate to Return and press Enter.
  9. Confirm when prompted.

What should happen: The student can view the returned grade and feedback.

If that does not happen: If the grade remains a draft, confirm Return was completed.

Practice: Grade a practice submission in a test class if available.

Part 20 - Gemini and Learning Tools in Classroom

  • Current Classroom can show Learn with Gemini for assignments when enabled.

  • Student tools may include guided help, study guides, quizzes, flashcards, Gemini Notebooks, or Gems distributed by teachers.

  • Teacher feature cards may include Gemini in Classroom, student Gems, or Gemini Notebook study guides depending on edition/admin enablement.

  • AI-generated learning material should still be checked against course materials and teacher instructions.

Part 21 - Workspace Integration

  • Drive stores class folders and attachments.

  • Docs/Sheets/Slides provide assignment files.

  • Forms provides quizzes/surveys.

  • Calendar can show due dates.

  • Meet provides video meetings.

  • Use each application’s own accessibility/manual workflow after the link opens.

Part 22 - Mobile Use

  • Classroom apps are available on Android and iOS.

  • VoiceOver/TalkBack can navigate class cards, assignments, comments, and attachments.

  • Complex grading and multi-file assignment creation are usually easier on desktop.

Part 23 - Braille and Accessibility

  • Braille works through the active screen reader.

  • Use routing/input inside Classroom text fields and then switch to the attached Docs/Forms app’s braille workflow when it opens.

  • Teachers should test linked materials, not only the Classroom assignment shell.

Part 24 - Privacy, Student Data, and Security

  • Use school-approved accounts and sharing settings.

  • Do not expose one student’s work/grade to other students.

  • Verify class membership and file permissions.

  • Do not post sensitive data in Stream/class comments.

  • Follow school policy for AI/Gemini tools and student data.

Part 25 - Troubleshooting

Class is missing

  1. Verify Google account.
  2. Check invitation/class code.
  3. Ask teacher/admin if enrollment changed.

Assignment says missing after work was done

  1. Open the assignment.
  2. Read submission status.
  3. Turn in/resubmit if needed.

Attachment cannot be edited

  1. Check whether teacher set View, Edit, or Make a copy for each student.
  2. Verify correct account.

Teacher cannot create class

  1. Check account role/admin policy.
  2. Press Escape.
  3. Use heading/landmark navigation.
  4. Return to class/page tabs.

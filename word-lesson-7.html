Microsoft Word Lesson 7

Creating Accessible Tables

Goal

Learn to create and navigate a simple table with a header row.

Instructions

  1. Create a blank Word document.
  2. Type the heading: Training Schedule
  3. Apply Heading 1.
  4. Insert a table with 3 columns and 4 rows.
  5. Use these column headings in the first row: Topic, Date, Status.
  6. Enter Microsoft Word, Monday, Complete in the second row.
  7. Enter Excel, Tuesday, In Progress in the third row.
  8. Enter PowerPoint, Wednesday, Not Started in the fourth row.
  9. Make the first row the table's Header Row.
  10. Use Tab and Shift+Tab to move through the cells.
  11. Avoid merged or split cells.
  12. Save the file as Word-Lesson-7.docx.

Your Assignment

Submit Word-Lesson-7.docx.

Before Submitting

  • The table should contain 3 columns and 4 rows.
  • The first row should contain Topic, Date, and Status.
  • The first row should be designated as a Header Row.
  • The table should not contain merged cells.

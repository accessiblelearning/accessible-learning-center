JAWS Lesson 3

Windows Desktop, Start Menu, Taskbar, and App Switching

JAWS manual All JAWS lessons My progress

Goal

Navigate common Windows 11 areas and move efficiently among workplace applications.

Skills practiced

  • Move to the desktop and Start menu.
  • Search for and launch an application.
  • Use the taskbar and system tray.
  • Switch among open applications and close only the intended window.

Step-by-step instructions

  1. Press Windows+D to move focus to the desktop. Use Arrow keys to review desktop items.
  2. Press the Windows key, type Notepad, and press Enter to open it.
  3. Type: Daily task list, followed by three fictional work tasks on separate lines.
  4. Press Windows+E to open File Explorer.
  5. Press Alt+Tab repeatedly to move between File Explorer and Notepad. Release Alt when the desired application is announced.
  6. Press Windows+T to move through taskbar buttons. Press Escape when finished.
  7. Press Insert+F10 to open the JAWS Window List. Review open windows and press Escape.
  8. Press Insert+F11 to review system tray icons. Press Escape without changing anything.
  9. Return to Notepad, save the file as JAWS-Lesson-3.txt, and confirm the location in the Save As dialog.
  10. Use Alt+F4 to close Notepad only. Confirm other windows remain open.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Your assignment

Create a daily task list and add a short paragraph describing how Alt+Tab, Windows+T, and the JAWS Window List differ.

Save the finished assignment as JAWS-Lesson-3.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • The file includes three workplace tasks.
  • The explanation covers all three switching methods.
  • The student closed only the intended application.
  • The file is named JAWS-Lesson-3.txt.

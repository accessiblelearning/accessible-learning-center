Screen Readers Lesson 3

Read by Character, Word, Line, Paragraph, and Continuously

Screen Readers manualAll Screen Readers lessonsMy progress

Choose your screen reader

Complete this lesson with JAWS, Windows Narrator, or NVDA. Use one primary screen reader at a time. Follow the column for your selection whenever commands differ.

Goal

Read and review text at several levels with the chosen screen reader.

Shared practice steps

  1. Open an instructor-provided text document and move to the beginning with Ctrl+Home.
  2. Use Left and Right Arrow to review characters in editable text.
  3. Use Ctrl+Left Arrow and Ctrl+Right Arrow to move by word.
  4. Use Up and Down Arrow to move by line or paragraph as supported by the application.
  5. Use the screen reader’s continuous-reading command.
  6. Stop speech with Ctrl and summarize the passage.

Command note: JAWS key, Narrator key, and NVDA key each mean that screen reader’s modifier key. Commands can vary by keyboard layout, software version, application, and user settings. Confirm differences in the official references linked from the manual.

How to Use This Manual

This manual is designed for independent learning. Each section explains what you will learn, what to do before beginning, the exact steps to complete the task, what should happen, what to do if something goes wrong, and a practice activity.

The manual is written primarily for Microsoft Word for Microsoft 365 on Windows. Many commands also work in Word 2024, Word 2021, Word 2019, and Word 2016.

Part 1: What Microsoft Word Is

Microsoft Word is a word-processing program used to create, edit, format, save, print, and share documents.

Part 2: Opening Word and Creating Documents

Use this section to learn how to open Microsoft Word, create a blank document, and begin working.

Part 3: The Word Window and Ribbon

Press Alt to activate Ribbon KeyTips. Use Tab and Shift+Tab to move through controls. Press F6 to move between major areas of the Word window.

Part 4: Typing, Moving, Selecting, and Editing Text

This section covers typing, cursor movement, selecting text, copying, cutting, pasting, undoing, and redoing.

Part 5: Saving, Opening, and Closing Files

Press Ctrl+S to save a document. Use Ctrl+O to open a document and Ctrl+W to close the current document.

Part 6: Find and Replace

Use Ctrl+F to find text and Ctrl+H to open Find and Replace.

Part 7: Formatting Text and Paragraphs

Learn how to apply bold, italics, underline, alignment, spacing, fonts, and other formatting.

Part 8: Headings, Styles, and the Navigation Pane

Use built-in heading styles whenever possible. They improve navigation, organization, and accessibility.

Part 9: Lists

Learn how to create bulleted and numbered lists using Word's built-in list tools.

Part 10: Tables

Learn how to insert, navigate, edit, and format tables accessibly.

Part 11: Links, Pictures, Alt Text, Headers, and Footers

This section covers inserting hyperlinks, adding images, writing alt text, and working with headers and footers.

Part 12: Spelling, Grammar, and Editor

Press F7 to review spelling and grammar. Microsoft Editor can also help identify writing issues.

Part 13: Comments

Learn how to add, review, reply to, and remove comments.

Part 14: Track Changes

Learn how to turn Track Changes on and off and review edits made to a document.

Part 15: Accessibility Checker and Accessible Design

Use Word's Accessibility Checker and good document structure to make files easier for everyone to use.

Part 16: Printing, PDF, and Sharing

Learn how to print documents, create PDFs, and share files.

Part 17: Using Word with Narrator

This section covers Word-specific strategies and commands for Microsoft Narrator.

Part 18: Using Word with NVDA

This section covers Word-specific strategies and commands for NVDA.

Part 19: Using Word with JAWS

This section covers Word-specific strategies and commands for JAWS.

Part 20: Working with Long Documents

Learn strategies for navigating and organizing longer Word documents efficiently.

Part 21: Using Braille with Word

This section covers considerations for using refreshable Braille displays with Microsoft Word.

Part 22: Word Online

Learn the differences and accessibility considerations when using Word in a web browser.

Part 23: Troubleshooting

This section provides solutions for common problems encountered while using Word with screen readers.

Part 24: Practice Course

Practice activities will help you apply the skills taught throughout this manual.

Part 25: Quick Reference

Common Word Commands

  • Ctrl+N: New document
  • Ctrl+O: Open document
  • Ctrl+S: Save
  • Ctrl+P: Print
  • Ctrl+W: Close document
  • Ctrl+Z: Undo
  • Ctrl+Y: Redo
  • Ctrl+F: Find
  • Ctrl+H: Replace
  • Ctrl+A: Select all
  • Ctrl+C: Copy
  • Ctrl+X: Cut
  • Ctrl+V: Paste
  • Ctrl+B: Bold
  • Ctrl+I: Italic
  • Ctrl+U: Underline
  • Ctrl+Alt+1: Heading 1
  • Ctrl+Alt+2: Heading 2
  • Ctrl+Alt+3: Heading 3
  • Ctrl+Shift+N: Normal style
  • Ctrl+Shift+L: Bulleted list
  • Ctrl+K: Insert hyperlink
  • Ctrl+Alt+M: Insert comment
  • Ctrl+Shift+E: Track Changes
  • F7: Spelling and grammar
  • F6: Move to next major area
  • Shift+F6: Move to previous major area

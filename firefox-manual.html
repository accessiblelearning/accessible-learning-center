Navigate pages, manage tabs, save bookmarks, locate downloads, and adjust readability.

Before you begin

Choose one practice task at a time. Have your usual accessibility tools running and a way to record which steps helped. Use a familiar, non-sensitive document or book for the first exercise.

Keyboard directions

A plus sign means hold the first key while tapping the final key, then release both. For three-key combinations, hold both modifiers while tapping the last key. Do not type the plus sign. “Then” means release the first command before pressing the next key.

Tab moves forward through controls; Shift+Tab moves backward. Enter activates a focused link or button; Space commonly operates buttons and checkboxes. Arrow keys move within menus and lists. Pause after each step to check where focus went. For screen-reader reading and interaction modes, see the Screen Readers manual. Phone gestures are covered in the iPhone and iPad VoiceOver and Android TalkBack manuals.

1. Open a page and find text

What you will learn: Separate the address bar from page content.

Exactly how to do it

  1. In Firefox on Windows, press Ctrl+L. Type accessiblelearningcenter.org and press Enter.
  2. Use Tab to explore links. Activate Manuals with Enter.
  3. Press Ctrl+F, type Thunderbird, then press Escape to close Find.

What should happen: The manual title is located on the page.

If that does not happen: If you typed into the wrong control, return to the address bar and identify the page before retrying.

Practice: Find a topic you know. Explain the difference between searching this page and searching the entire web.

Source: Mozilla keyboard shortcuts.

2. Work with two tabs

What you will learn: Keep your instructions available while opening another page.

Exactly how to do it

  1. Press Ctrl+T and open a second familiar website.
  2. Use Ctrl+Page Up or Ctrl+Page Down to move between adjacent tabs.
  3. Close the practice tab with Ctrl+W. Reopen it with Ctrl+Shift+T.

What should happen: You can return to both pages.

If that does not happen: Confirm the active tab before closing it; closing the final tab may close the window.

Practice: Describe which page you expect before switching, then verify the title.

Source: Mozilla tab shortcuts.

3. Save a useful page

What you will learn: Create a bookmark you can identify later.

Exactly how to do it

  1. Open the page you want to keep. Press Ctrl+D.
  2. If the bookmark editor appears, review its name and location. Give the bookmark a meaningful name and activate Save.
  3. Press Ctrl+Shift+O for the bookmark Library. Find your saved item and open it.

What should happen: The saved link returns to the intended page.

If that does not happen: If the editor did not appear, the page may already be saved or the editor preference may be off. Check the Library before creating another bookmark.

Practice: Save two manuals with distinct names. Later, return to each without typing its full address.

Source: Mozilla bookmarks.

Source: Bookmark keyboard shortcut.

4. Locate a downloaded file

What you will learn: Distinguish a saved file from its download-history entry.

Exactly how to do it

  1. Download a harmless practice document from a source you recognize.
  2. Press Ctrl+J to open Downloads. Select the expected filename and read its status.
  3. Use the entry’s available folder action to locate the file on disk. Open only the file you intended to download.

What should happen: You know the filename and where it was saved.

If that does not happen: An unfinished or failed download is not ready to use. Read the status; do not bypass an unsafe-download warning just to finish an exercise.

Practice: Record the filename and folder. Close the browser and find that file through File Explorer.

Source: Mozilla downloads.

Source: Downloads shortcut.

5. Make a page easier to see

What you will learn: Adjust page size without changing every Windows application.

Exactly how to do it

  1. Press Ctrl+Plus to enlarge the page. Press Ctrl+Minus to reduce it.
  2. Press Ctrl+0 to return to the normal zoom level.
  3. For text-only zoom, open the View menu with the keyboard, find Zoom, and select Zoom Text Only. Compare the result on a familiar page.

What should happen: You can choose a readable size and return to the baseline.

If that does not happen: A very large setting may change the layout. Reduce it one step and check whether content becomes easier to follow.

Practice: Compare one heading, one paragraph, and one button at two sizes. Choose the size that helps you complete the task, not simply the largest one.

Source: Mozilla accessibility features.

6. Recover when navigation feels wrong

What you will learn: Identify focus before changing browser settings.

Exactly how to do it

  1. Name the problem: wrong page, wrong tab, wrong field, or unexpected reading behavior.
  2. If an unwanted Find bar is active, close it with Escape. If you closed the wrong tab, reopen it using the command above.
  3. If arrow keys move a text cursor through the page, check whether Caret Browsing was enabled with F7. Read its prompt before changing it.

What should happen: You can explain what changed and take one targeted recovery step.

If that does not happen: Check your screen reader’s current mode. Do not reset the browser or delete your profile to solve an unidentified focus problem.

Practice: Ask an instructor to move focus to the address bar. Identify the change before entering any text.

Source: Mozilla Caret Browsing guidance.

Independent practice

Choose any activity; there is no required order or passing score.

  1. Open the Manuals page and find a named topic.
  2. Keep two manuals in separate tabs and switch between them.
  3. Bookmark one manual, close its tab, and return using the bookmark.
  4. Find a downloaded practice file on your computer.
  5. Explain whether an access problem belongs to the browser, the website, or your screen-reader mode.

After each task, record whether you completed it independently, needed a prompt, or want another attempt. Repeat the difficult step instead of restarting everything.

First-time learner: how to follow a task

Read the task title and its starting location before pressing anything. A keyboard command acts on the active application and focused control. Merely having these instructions visible does not make the other application active.

  1. Keep these instructions available. Open the application separately. On Windows, hold Alt, tap Tab to choose its window, and release Alt. Check the window title before continuing.
  2. Focus is the place receiving your next keystroke. A screen reader announces its name and role; a visible border or highlight may mark it. Tab selects the next keyboard-accessible control. Shift+Tab reverses that movement. Neither command means “activate.”
  3. At a button or link, press Enter to activate. A checkbox is an on/off choice: Space changes it. Listen for checked or not checked. In an open menu, use arrows to select an item, then Enter. Escape usually closes that menu; it does not universally return to the previous page.
  4. At a text field, enter only the requested information. Ctrl+A selects all text in that field; typing then replaces it. Confirm focus before doing this. Use Left and Right to review a small correction, or Backspace to remove the character before the cursor.
  5. After opening a dialog, listen to its title, read its instructions, and Tab through its controls. Use Cancel if you are unsure. Do not repeatedly activate a button while a page or file is loading.
  6. At the result checkpoint, stop. Say what changed. If the result is different, use that task’s recovery paragraph before attempting the next task.

With a screen reader, arrow-key reading and text editing can use different modes. If letters become navigation commands instead of text, confirm you reached an editable field and consult your reader’s forms/focus-mode instructions in the Screen Readers manual. Do not turn the reader off to solve an unidentified focus problem.

When a task says to locate a named control, start with Tab or Shift+Tab and listen to each complete label and role. Tab skips ordinary paragraphs. If the page itself needs to be read, use your screen reader’s reading commands. If you pass the same controls twice without finding the requested one, stop and check the application, page, account, and open dialogs. A fixed number of Tab presses is unreliable because layouts change.

Recording progress: Write down the task, your starting location, the result, and one step to practice again. These activities are optional and repeatable; they are not a sequence of locked lessons.

Before you begin

Choose one practice task at a time. Have your usual accessibility tools running and a way to record which steps helped. Use a familiar, non-sensitive document or book for the first exercise.

Keyboard directions

A plus sign means hold the first key while tapping the final key, then release both. For three-key combinations, hold both modifiers while tapping the last key. Do not type the plus sign. “Then” means release the first command before pressing the next key.

Tab moves forward through controls; Shift+Tab moves backward. Enter activates a focused link or button; Space commonly operates buttons and checkboxes. Arrow keys move within menus and lists. Pause after each step to check where focus went. For screen-reader reading and interaction modes, see the Screen Readers manual. Phone gestures are covered in the iPhone and iPad VoiceOver and Android TalkBack manuals.

Understand the browser before navigating

Browser and website
Firefox is the application. A website is content it displays. The Firefox menu changes browser behavior; a website’s menu changes that website.
Window and tab
A window can contain several tabs. Only one tab is active in that window. Closing a tab is different from going back a page.
Address bar and page search
The address bar opens an address or performs a web search. Find searches words in the current page. A website’s search field searches that site’s own collection.
Download and bookmark
A download saves a file. A bookmark saves a way to return to a page; it does not normally save a readable offline copy.
Browser zoom and screen magnification
Browser zoom changes page layout and size. A screen magnifier enlarges the computer’s display, including browser controls. You may use both, but change one at a time while learning.

Open Firefox and establish your starting point

Start here: Windows, with Firefox installed. If needed, obtain it through Firefox’s official website and follow the installer; a managed computer may need administrator help.

Step-by-step instructions

  1. Press the Windows key, type Firefox, check the application name in the results, and press Enter. If a first-run screen appears, read each choice before accepting it; account sign-in is separate from simply browsing.
  2. Confirm the active window is Firefox. Press Ctrl+L and enter https://accessiblelearningcenter.org/manuals.html, then Enter. Wait for the page to load.
  3. Read the page heading using your usual reading method. Tab through its interactive controls. Notice that pressing Tab does not read every paragraph.
  4. Keep this page in one tab while using a separate tab for exercises. Before entering a command, name which tab should receive it.

Check your result

You know which application and page are active and can return to a familiar starting address.

If something goes wrong

If you land in a web-search results page, check the address you entered. If another browser opens, return to the Windows application search and explicitly choose Firefox.

Try it yourself

Open the Manuals page twice from a blank tab, then explain how you verified the destination.

Documentation: Firefox on Windows installation.

1. Open a page and find text

What you will learn: Separate the address bar from page content.

Exactly how to do it

  1. In Firefox on Windows, press Ctrl+L. Type accessiblelearningcenter.org and press Enter.
  2. Use Tab to explore links. Activate Manuals with Enter.
  3. Press Ctrl+F, type Thunderbird, then press Escape to close Find.

What should happen: The manual title is located on the page.

If that does not happen: If you typed into the wrong control, return to the address bar and identify the page before retrying.

Practice: Find a topic you know. Explain the difference between searching this page and searching the entire web.

Source: Mozilla keyboard shortcuts.

2. Work with two tabs

What you will learn: Keep your instructions available while opening another page.

Exactly how to do it

  1. Press Ctrl+T and open a second familiar website.
  2. Use Ctrl+Page Up or Ctrl+Page Down to move between adjacent tabs.
  3. Close the practice tab with Ctrl+W. Reopen it with Ctrl+Shift+T.

What should happen: You can return to both pages.

If that does not happen: Confirm the active tab before closing it; closing the final tab may close the window.

Practice: Describe which page you expect before switching, then verify the title.

Source: Mozilla tab shortcuts.

3. Save and return to a useful page

Start here: The page you want to keep, open in Firefox.

Step-by-step instructions

  1. Press Ctrl+D. If a bookmark editor appears, Tab through its controls and locate the Name field. Give the bookmark a recognizable name such as “Learning Center — Firefox.”
  2. Review the folder/location choice. Choose a location you will recognize, then activate Save. If the page was already bookmarked, the editor may offer editing instead of a new save.
  3. Open the bookmark Library with Ctrl+Shift+O. Tab to its Search Bookmarks field, enter part of your saved name, and move to the matching results.
  4. Select the intended bookmark with arrow keys and press Enter to open it. Confirm the page heading or address matches what you saved.
  5. To rename or remove a practice bookmark, select it in the Library and use Shift+F10 to explore its context menu. Read the selected action before activating it. Removing a bookmark removes your saved link, not the website.

Check your result

You can close the original tab and still return through the saved bookmark.

If something goes wrong

If there is no match, clear the search and check its spelling and saved location. A website’s own search box is not the bookmark Library search.

Try it yourself

Save two pages with distinct names, close their original tabs, and reopen each through the Library.

Documentation: Mozilla bookmarks.

4. Download a file and find the saved copy

Start here: A page offering a harmless document you recognize. Know whether you want to save it or only view it.

Step-by-step instructions

  1. Tab to the document’s download link and activate it. Some document links first open a viewer; if so, locate that viewer’s labeled download control.
  2. If a Save dialog appears, read its current folder and File name. Choose a destination you can find, such as Downloads, and keep a meaningful filename. Activate Save. If no dialog appears, the browser may use its configured default folder.
  3. Open the Downloads list with Ctrl+J. Select the expected item and check whether it is complete, still transferring, or failed.
  4. For a completed item, explore its available actions with Tab or its context menu. Use the action that opens the containing folder to see the saved file in File Explorer.
  5. Check the filename and extension before opening it. If Windows asks which application to use, identify the file type rather than selecting an unrelated program.
  6. Close the file and return to its folder independently. Explain where the local copy is stored. Clearing a browser download-history entry is different from deleting that file.

Check your result

You can locate the completed file after leaving its original web page.

If something goes wrong

Do not repeatedly download while an existing transfer is still in progress. A failed or blocked transfer needs its status examined. If a duplicate filename has a number added, verify which copy is the one you intend to use.

Try it yourself

Record the destination folder and filename, then locate the file without using the original website.

Documentation: Mozilla downloads and file actions.

5. Make a page easier to see

What you will learn: Adjust page size without changing every Windows application.

Exactly how to do it

  1. Press Ctrl+Plus to enlarge the page. Press Ctrl+Minus to reduce it.
  2. Press Ctrl+0 to return to the normal zoom level.
  3. For text-only zoom, open the View menu with the keyboard, find Zoom, and select Zoom Text Only. Compare the result on a familiar page.

What should happen: You can choose a readable size and return to the baseline.

If that does not happen: A very large setting may change the layout. Reduce it one step and check whether content becomes easier to follow.

Practice: Compare one heading, one paragraph, and one button at two sizes. Choose the size that helps you complete the task, not simply the largest one.

Source: Mozilla accessibility features.

6. Recover when navigation feels wrong

What you will learn: Identify focus before changing browser settings.

Exactly how to do it

  1. Name the problem: wrong page, wrong tab, wrong field, or unexpected reading behavior.
  2. If an unwanted Find bar is active, close it with Escape. If you closed the wrong tab, reopen it using the command above.
  3. If arrow keys move a text cursor through the page, check whether Caret Browsing was enabled with F7. Read its prompt before changing it.

What should happen: You can explain what changed and take one targeted recovery step.

If that does not happen: Check your screen reader’s current mode. Do not reset the browser or delete your profile to solve an unidentified focus problem.

Practice: Ask an instructor to move focus to the address bar. Identify the change before entering any text.

Source: Mozilla Caret Browsing guidance.

Fill in a web form without losing your place

Start here: A familiar website with a harmless search form. Do not practice with a checkout or application that submits real information.

Step-by-step instructions

  1. Read the form’s heading and instructions first. Use Tab to reach its search edit field. Listen for the field’s label and whether it is required.
  2. Type a distinctive topic such as Firefox. If existing text needs replacing, confirm focus remains inside the edit field, press Ctrl+A, and type the replacement.
  3. Tab to the Search button and press Enter. Some forms submit when you press Enter in a text field, so use the labeled button when you are learning the layout.
  4. On a form with a checkbox, listen to its current checked state, then use Space only if you intend to change it. For a list of options, use its arrow-key choices and confirm the selected value before leaving it.
  5. After submitting, read the new heading, result count, or validation error. If a field is rejected, return to that labeled field and correct only the indicated value.
  6. When finished, leave the form through its ordinary navigation. Do not assume Escape undoes a submission or that the browser Back command will preserve unsaved text.

Check your result

The intended form action occurs once, and you can identify its result or error message.

If something goes wrong

If a single letter moves to a heading instead of appearing in the field, your screen reader may still be reading the page. Re-identify the editable field and use your reader’s interaction instructions. If audio or a dialog interrupts you, identify it before continuing.

Try it yourself

Search for a manual, replace the search word with another topic, and describe which field changed.

Documentation: Firefox accessibility.

Read an article in Reader View

Start here: A text-heavy article in Firefox on Windows. Reader View is not available for every page.

Step-by-step instructions

  1. Press F9 to request Reader View. If your laptop assigns another action to its function keys, use the keyboard’s appropriate function-key mode or use Firefox’s View menu and its Reader View command.
  2. Read the simplified page heading and a paragraph. Tab to the Reader View controls to explore its appearance options.
  3. Adjust one text or appearance setting, then return to the article and compare the result. Choose a size that lets you track a full line comfortably.
  4. Use the Reader View exit control or return to the original page. Check that you are back at the website before trying its ordinary navigation.

Check your result

On a supported article, you get a simpler reading presentation and can return to the original.

If something goes wrong

If Reader View is unavailable, use ordinary page zoom and your screen reader’s reading navigation. Do not expect account forms, dashboards, or every PDF to convert into an article.

Try it yourself

Compare the same paragraph in the original page and Reader View. Explain which presentation makes it easier to follow.

Documentation: Mozilla Reader View.

Understand saved passwords and sign-in

Start here: Firefox on your own trusted device. Use a practice account if you are learning password controls.

Step-by-step instructions

  1. Open Firefox’s application menu and activate Passwords, or type about:logins in the address bar and press Enter. This opens Firefox’s saved-login manager, not a website’s password-reset page.
  2. Tab to its search field and search for a site you recognize. Select the matching entry and review its website and username.
  3. Do not reveal or copy a password merely to identify the entry. If you intentionally request a protected action, Windows may ask you to authenticate.
  4. If you edit a saved entry, understand that you are changing Firefox’s stored copy. To change the actual account password, follow that website’s own account-recovery or security process, then update the saved copy as appropriate.
  5. Close the login-manager tab when finished. On shared devices, follow the device owner’s sign-in and password-storage policy.

Check your result

You can distinguish a stored credential from the website account itself.

If something goes wrong

A rejected login may be an old saved password, a different account, or a site-specific access problem. Verify the website address and username before requesting recovery. Do not repeatedly guess passwords.

Try it yourself

Identify the manager’s search field and website field without displaying or sharing any secret.

Documentation: Mozilla saved-login manager.

Troubleshooting by symptom

The wrong page opened.
Read its address and title. Return to the known starting address if necessary. A similar-looking search result is not proof that it is the official site.
The page looks cut off after zooming.
Reduce browser zoom one step and check whether a menu has collapsed into a menu button. If screen magnification is also active, identify which zoom you changed.
My text vanished.
Check the active tab and focused field before retyping. A form may have navigated away. Use its saved-draft feature where provided; browser history is not a reliable backup of form text.
A keyboard command does nothing.
Check for an open menu, dialog, screen-reader command conflict, or laptop function-key behavior. Return focus to the intended control and try once. Record the command and what happened if the problem continues.
I hear two voices.
Identify whether the website or a media player is speaking alongside your screen reader. Pause that player through its controls before changing the screen reader you rely on for navigation.

Independent practice

Choose any activity; there is no required order or passing score.

  1. Open the Manuals page and find a named topic.
  2. Keep two manuals in separate tabs and switch between them.
  3. Bookmark one manual, close its tab, and return using the bookmark.
  4. Find a downloaded practice file on your computer.
  5. Explain whether an access problem belongs to the browser, the website, or your screen-reader mode.

After each task, record whether you completed it independently, needed a prompt, or want another attempt. Repeat the difficult step instead of restarting everything.

Practice this topic in Mission Control

Choose Command Practice or choose Topic Missions, then select Firefox. These are simulated exercises; they do not operate the actual app or account.

Topic Missions presents a troubleshooting problem. Command Practice explains and checks one keyboard action at a time. Use Settings to choose speech and sound feedback. Escape returns to the topic list during a session.

When a simulator prompt says protected practice, release the modifier before the final key as instructed. In the real application, use the held keyboard combination in this manual. Completing a simulation does not confirm that the real application received or performed a command.

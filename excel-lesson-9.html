Excel Lesson 9

Data Validation, Consistent Entry, and Review

Excel manual All Excel lessons My progress

Goal

Create a reliable data-entry sheet with controlled choices and check it for common accessibility problems.

Skills practiced

  • Create a drop-down list with Data Validation.
  • Use consistent data types.
  • Find blanks and errors.
  • Document instructions inside the workbook.

Step-by-step instructions

  1. Create a blank workbook with the headers Request ID, Request Type, Priority, Assigned To, and Status.
  2. Enter five fictional requests.
  3. In a separate area, list the allowed Status values: New, In Progress, Waiting, and Closed.
  4. Select the Status entry cells.
  5. Press Alt+Q, type Data Validation, and choose the command.
  6. Choose List and set the source to the cells containing the allowed Status values.
  7. Use Alt+Down Arrow in a validated Status cell to open its choices, then select a value.
  8. Apply a similar list to Priority using Low, Medium, and High.
  9. Add an Instructions worksheet explaining what each column contains and which values are allowed.
  10. Use Ctrl+F to search for blank required fields and review the used range with Ctrl+End.
  11. Run Check Accessibility and correct merged cells, unclear sheet names, or missing object descriptions.
  12. Save the workbook as Excel-Lesson-9.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Microsoft screen reader support for OneDrive

Purpose: This manual teaches OneDrive from the beginning to a person using a screen reader. It explains where OneDrive appears, what to press, what should receive focus, what the screen reader should announce, and how to recover when the result is different.

Reference platform: The main workflows are OneDrive on Windows 11 and OneDrive on the web. Work/school and personal accounts are both discussed because labels and sharing rules can differ.

Key distinction: OneDrive on the web is a browser application. Synced OneDrive in Windows behaves like a normal File Explorer location. Learn both because the same cloud file can be reached in either place.

How to Use This Manual

  • Work through Parts 1-12 first if OneDrive is new to you.

  • In OneDrive for the web, use Ctrl+F6/F6 to move between browser and OneDrive regions, then Tab and Arrow keys within regions.

  • In the OneDrive web content grid, Arrow keys move between items, Spacebar toggles selection, Enter opens, F2 renames, Delete deletes, S shares, and I toggles the Details pane in supported OneDrive for work or school contexts.

  • In Windows File Explorer, OneDrive files use normal Windows commands such as Arrow keys, Enter, F2, Delete, Ctrl+C, Ctrl+V, and Alt+Up Arrow.

  • Files On-Demand means some files may be cloud-only until opened or marked available offline.

  • Before deleting, moving, or renaming a synced file, remember the change can sync to the cloud and other devices.

  • Before sharing, verify the recipient, permission, and whether the link is restricted or broadly accessible.

  • Save important work before experimenting with sync, move, or delete commands.

Part 1 - What OneDrive Is

OneDrive is Microsoft cloud storage. A file stored in OneDrive can be available through OneDrive.com and, when sync is configured, through a OneDrive folder in Windows File Explorer. Changes made in one location can synchronize to the other.

  • OneDrive folder: the synced cloud-storage location in File Explorer.

  • My files: the main file area in OneDrive on the web.

  • Shared: items other people shared with you or that you shared, depending on view.

  • Recent: recently opened or changed items.

  • Recycle bin: deleted cloud items that have not yet been permanently removed.

  • Files On-Demand: controls whether a file is cloud-only, locally cached, or always available on the computer.

  • Sync: keeps cloud and local versions aligned when online.

Part 2 - Personal vs Work or School OneDrive

  • Personal OneDrive uses a Microsoft account.

  • OneDrive for work or school uses an organization account and may be governed by administrator policies.

  • Work/school sharing, retention, external access, storage, and sync options can be restricted by the organization.

  • The Windows File Explorer name may appear as OneDrive - Personal or OneDrive - Organization Name.

Practical rule: Before changing a file, identify which OneDrive account/location contains it. The same filename can exist in personal and work OneDrive at the same time.

Part 3 - Find OneDrive in Windows 11

3.1 Open the OneDrive Folder in File Explorer

What you will learn: Reach synced OneDrive files using normal Windows navigation.

Before you begin: OneDrive must be signed in and configured on the computer.

Exactly how to do it

  1. Press Windows+E to open File Explorer.

  2. Press F6 or Shift+F6 until the Navigation pane is announced.

  3. Use Up/Down Arrow through locations.

  4. Stop on OneDrive, OneDrive - Personal, or OneDrive - your organization name.

  5. Press Enter.

  6. Press F6 until the file list is announced.

  7. Use Arrow keys through files and folders.

What should happen: The OneDrive file list opens in File Explorer.

If that does not happen: If OneDrive is missing, the app may not be signed in, running, or configured. Open the OneDrive app from Windows Search and sign in.

Practice: Open OneDrive and identify three items.

Part 4 - OneDrive Status and Sync Icons

OneDrive uses status information to indicate whether files are cloud-only, available locally, always available, syncing, or experiencing an error. A screen reader may announce the status in File Explorer depending on the current view and column information.

  • Cloud-only: stored in OneDrive and downloaded when opened.

  • Locally available: downloaded to the computer after use and may be removable by Windows/OneDrive when space is needed.

  • Always available: intentionally kept on the computer for offline access.

  • Syncing: changes are being uploaded/downloaded.

  • Error/attention needed: OneDrive could not complete a sync action.

4.1 Review a File's OneDrive Status

What you will learn: Determine whether a file is available offline.

Before you begin: Open the OneDrive folder in File Explorer.

Exactly how to do it

  1. Move to a file.

  2. Use Shift+F10 to open its context menu.

  3. Listen for OneDrive commands such as Always keep on this device or Free up space.

  4. If Always keep on this device is offered, the file can be marked for offline availability.

  5. If Free up space is offered, a local copy may currently exist.

What should happen: The available OneDrive command helps identify the file state.

If that does not happen: If OneDrive commands are absent, verify the item is actually inside a synced OneDrive location.

Practice: Inspect three files without changing their status.

Part 6 - Create, Rename, Copy, Move, and Delete Files

6.1 Create a New Folder

What you will learn: Create a folder that will sync to OneDrive.

Before you begin: Open the intended OneDrive location in File Explorer.

Exactly how to do it

  1. Press Ctrl+Shift+N.

  2. Type a clear folder name.

  3. Press Enter.

  4. Wait briefly for OneDrive to sync the new folder.

What should happen: The folder appears locally and then in OneDrive online.

If that does not happen: If the folder cannot be created, check permission and storage/sync status.

Practice: Create a folder named OneDrive Practice.

6.2 Rename a Synced Item

What you will learn: Rename a cloud-synced file safely.

Before you begin: Use a disposable practice item.

Exactly how to do it

  1. Focus the item.

  2. Press F2.

  3. Type the new name.

  4. Press Enter.

  5. Wait for OneDrive to sync the rename.

What should happen: The new name propagates to the cloud.

If that does not happen: If another user or policy blocks the rename, OneDrive may report an error.

Practice: Rename a practice file and rename it back.

6.3 Delete and Restore Awareness

What you will learn: Understand that deleting a synced item is a cloud action.

Before you begin: Use a disposable practice item.

Exactly how to do it

  1. Focus the item.

  2. Press Delete.

  3. Confirm only if prompted and intended.

  4. Remember that the deletion can sync to OneDrive online and other devices.

  5. Use the OneDrive Recycle bin workflow later in this manual to restore it.

What should happen: The item leaves the current OneDrive folder and syncs as deleted.

If that does not happen: If you deleted the wrong file, stop other changes and restore it from Recycle bin as soon as possible.

Practice: Delete only a disposable test file.

Part 7 - Files On-Demand and Offline Access

7.1 Keep a File Always Available Offline

What you will learn: Download and retain a local copy.

Before you begin: The file is inside synced OneDrive.

Exactly how to do it

  1. Focus the file.

  2. Press Shift+F10.

  3. Choose Always keep on this device.

  4. Wait for OneDrive to download/sync the file.

  5. Review its status again.

What should happen: The file remains available when the computer is offline, subject to storage and policy.

If that does not happen: If the command is missing, Files On-Demand may be disabled or managed by your organization.

Practice: Mark one harmless file always available, then restore your preferred state.

7.2 Free Local Disk Space

What you will learn: Remove the local cached copy while keeping the cloud file.

Before you begin: Confirm the file is safely synchronized and can be downloaded later.

Exactly how to do it

  1. Focus the file.

  2. Press Shift+F10.

  3. Choose Free up space.

  4. Wait for the status to change to cloud-only.

What should happen: The cloud file remains in OneDrive but the local cached copy is removed.

If that does not happen: Do not use this before travel/offline work unless you are certain the file is not needed offline.

Practice: Review the command on a practice file.

8.1 Open OneDrive.com

What you will learn: Reach the cloud view directly.

Before you begin: Use a supported browser.

Exactly how to do it

  1. Open Microsoft Edge or Chrome.

  2. Press Ctrl+L.

  3. Type onedrive.com.

Practice: Open OneDrive and identify the account.

What you will learn: Navigate the cloud file list.

Before you begin: OneDrive for the web is open.

Exactly how to do it

Part 10 - Upload and Download

10.1 Upload a File on the Web

What you will learn: Copy a local file to OneDrive.

Before you begin: Open the destination folder on OneDrive.com.

Exactly how to do it

  1. Move to the command bar with Tab/Ctrl+F6.

  2. Move to Upload.

  3. Press Enter.

  4. Choose Files.

  5. When File Explorer opens, navigate to the file.

  6. Press Enter/Open.

  7. Wait for the OneDrive upload confirmation.

What should happen: The file appears in the current cloud folder.

If that does not happen: If upload fails, check network, storage quota, file restrictions, and permissions.

Practice: Upload one harmless practice file.

10.2 Download a File on the Web

What you will learn: Save a OneDrive file to the computer.

Before you begin: Select/focus a file.

Exactly how to do it

  1. Open the context menu with Shift+F10.

  2. Move to Download.

  3. Press Enter.

  4. Open the browser Downloads list with Ctrl+J if needed.

  5. Confirm the filename and status before opening it.

What should happen: The file downloads to the browser-configured location.

If that does not happen: If the file is suspicious or unexpected, do not open it.

Practice: Download one practice file.

Part 11 - Search

11.1 Search for a File or Folder

What you will learn: Find content without browsing many folders.

Before you begin: Know part of the filename or another clue.

Exactly how to do it

  1. Move to OneDrive Search with Tab or the page controls.

  2. Type the search term.

  3. Press Enter.

  4. Use Up/Down Arrow through results.

  5. Press Enter on the intended file/folder.

What should happen: OneDrive displays matching results.

If that does not happen: If search is too broad, add more of the filename or filter by file type/location when available.

Practice: Find one known file by name.

Part 12 - Share Files and Folders

12.1 Share with a Specific Person

What you will learn: Give access to an exact recipient.

Before you begin: Select the file/folder and know the recipient email address.

Exactly how to do it

  1. Open Share using the command bar, context menu, or S in supported work/school web contexts.

  2. Wait for the Send link/Share dialog.

  3. Type the exact email address.

  4. Select the correct person.

  5. Review the permission such as Can edit or Can view.

  6. Change it if needed.

  7. Review the recipient and permission again.

  8. Send only when correct.

What should happen: The recipient receives the intended access.

If that does not happen: If external sharing is blocked, the organization may restrict it.

Practice: Open Share on a practice file and inspect controls without sending.

Folder warning: Sharing a folder can expose everything inside it, including files added later, depending on permissions. Share the smallest appropriate scope.

Part 13 - Link Permissions and Access Safety

13.1 Review Link Settings Before Copying a Link

What you will learn: Understand who can use the sharing link.

Before you begin: The Share dialog is open.

Exactly how to do it

  1. Move to the link/settings control.

  2. Listen for choices such as specific people, people in your organization, or anyone with the link, depending on account policy.

  3. Choose the narrowest audience that meets the need.

  4. Choose Can view instead of Can edit unless editing is required.

  5. Apply/save the permission.

  6. Only then copy the link.

What should happen: The copied link has the intended access scope.

If that does not happen: If the organization blocks a setting, do not work around the policy by moving confidential content elsewhere.

Practice: Inspect link settings on a non-sensitive file.

Security rule: A broadly accessible link can function like a credential. Treat it as sensitive and avoid posting it publicly unless that is intentional.

Part 14 - Version History

OneDrive and Microsoft 365 can preserve earlier versions for supported files. Exact availability depends on file type, account, and organizational retention settings.

14.1 Review Version History

What you will learn: Inspect earlier versions before restoring one.

Before you begin: Use a file with more than one saved version.

Exactly how to do it

  1. Open the file context menu on the web or in supported File Explorer/Office workflows.

  2. Choose Version history.

  3. Move through versions and listen for date/time and author when available.

  4. Open a version for review if supported.

  5. Restore only after confirming it is the correct version.

What should happen: Earlier versions can be inspected or restored where available.

If that does not happen: If Version history is missing, the file/account may not support it or you may lack permission.

Practice: Open version history and exit without restoring.

Part 15 - Recycle Bin and Restore

15.1 Restore a Deleted File from OneDrive Web

What you will learn: Recover a recently deleted cloud item.

Before you begin: The file was deleted from OneDrive and has not been permanently removed.

Exactly how to do it

  1. Open OneDrive.com.

  2. Navigate to Recycle bin.

  3. Move through deleted items with Arrow keys.

  4. Select the intended item with Spacebar if needed.

  5. Activate Restore.

  6. Return to My files and search for the restored item.

What should happen: The item returns to its original or supported restore location.

If that does not happen: If it is not in Recycle bin, it may have been permanently deleted or retention may have expired.

Practice: Restore the disposable practice file from Part 6.

Permanent deletion: Emptying the Recycle bin or permanently deleting an item can remove normal self-service recovery. Use those commands only when you are certain.

Part 16 - Sync Setup and Sync Problems

16.1 Open the OneDrive Sync App

What you will learn: Reach sync status and settings from Windows.

Before you begin: OneDrive is installed.

Exactly how to do it

  1. Press the Windows key.

  2. Type OneDrive.

  3. Press Enter.

  4. If OneDrive is not signed in, enter the intended Microsoft/work account.

  5. Use the OneDrive notification-area icon or app window to review sync status/settings.

What should happen: OneDrive begins or continues synchronizing configured folders.

If that does not happen: If multiple accounts are configured, verify which account/folder is being shown.

Practice: Open OneDrive settings and identify the signed-in account.

16.2 Investigate a Sync Error

What you will learn: Use OneDrive's own error information before changing files.

Before you begin: OneDrive reports a sync issue.

Exactly how to do it

  1. Open the OneDrive status/activity window.

  2. Move through errors with Tab/Arrow keys.

  3. Listen for the filename and error reason.

  4. Follow the specific fix, such as closing an open file, renaming an invalid filename, restoring network access, or resolving storage limits.

  5. After correction, wait for OneDrive to retry sync.

What should happen: The problem item either syncs or reports a more specific remaining issue.

If that does not happen: Do not delete/recreate important files as a first troubleshooting step.

Practice: Review sync status even when no error is present.

Microsoft screen-reader behavior: Microsoft documents that OneDrive can announce the affected filename, the sync error, and suggested resolution through supported screen readers.

Part 17 - Folder Backup

Personal OneDrive can back up supported Windows folders such as Desktop, Documents, and Pictures through OneDrive folder backup. Availability differs for work/school accounts and administrator policy.

17.1 Review Folder Backup Settings

What you will learn: Understand which Windows folders are being redirected/backed up.

Before you begin: OneDrive personal account is configured where supported.

Exactly how to do it

  1. Open OneDrive Settings.

  2. Find Sync and backup or Manage backup.

  3. Review Desktop, Documents, Pictures, and any other offered folders.

  4. Do not turn a backup off/on casually if those folders contain important work.

  5. Close Settings without changing anything until you understand the current configuration.

What should happen: You know which important Windows folders are stored in OneDrive.

If that does not happen: If backup controls are unavailable, the account/policy may not support them.

Practice: Review backup state only.

Part 19 - Narrator with OneDrive

  5. Press Enter to open.

What should happen: Narrator supports both direct application interaction and normal webpage review.

If that does not happen: If letters/Arrows move webpage structure instead of OneDrive items, verify the current Scan Mode state.

Practice: Select and open a practice folder.

Part 25 - Security and Privacy

  • Verify whether you are in personal or work OneDrive before uploading confidential information.

  • Use the least-powerful sharing permission that meets the need.

  • Avoid broad anonymous/anyone links for sensitive files.

  • Do not open unexpected shared files until you verify the sender.

  • Remember that synced deletion/rename/move actions propagate to other devices.

  • Do not free up local space on files you need while offline.

  • Organization OneDrive can be subject to retention, auditing, legal hold, and administrator access policies.

  • Treat browser downloads from OneDrive like any downloaded file: verify filename, type, and source before opening.

25.1 Review an Unexpected Shared File

What you will learn: Verify ownership before opening suspicious content.

Before you begin: A file was shared unexpectedly.

Exactly how to do it

  1. Open OneDrive Shared view.

  2. Read the filename and owner.

  3. Open Details instead of opening the file when possible.

  4. Verify the sender through a trusted channel.

  5. Do not download or open risky file types until verified.

What should happen: You decide whether to trust the file before opening it.

If that does not happen: If the sender cannot be verified, leave the file unopened and report/block through available organizational processes.

Practice: Inspect one safe shared item.

Part 26 - Troubleshooting

26.1 OneDrive Is Missing from File Explorer

What you will learn: Restore sync access without assuming files are gone.

Before you begin: Windows is running.

Exactly how to do it

  1. Press Windows key and type OneDrive.

  2. Open OneDrive.

  3. Sign in if prompted.

  4. Open OneDrive Settings and confirm the intended account.

  5. Open File Explorer again and check the Navigation pane.

What should happen: The OneDrive location reappears when setup is valid.

If that does not happen: If the organization disabled sync, use OneDrive on the web instead.

Practice: Locate the OneDrive app and account.

26.2 A File Is Visible but Will Not Open Offline

What you will learn: Check Files On-Demand status.

Before you begin: You are offline or have unstable internet.

Exactly how to do it

  1. Open the file context menu.

  2. Look for Always keep on this device.

  3. If the file is cloud-only and you have internet again, choose Always keep on this device and wait for download.

  4. Do not assume cloud-only files are corrupt merely because they cannot open offline.

What should happen: The file becomes available locally once downloaded.

If that does not happen: If download fails, resolve sync/network issues first.

Practice: Identify one file suitable for offline access.

26.3 A File Change Does Not Appear on Another Device

What you will learn: Check sync completion before making duplicate edits.

Before you begin: The same OneDrive account is used on both devices.

Exactly how to do it

  1. Open OneDrive sync status on the first device.

  2. Confirm the file finished syncing.

  3. Check network connectivity.

  4. On the second device, allow time for sync and refresh/reopen the folder.

  5. Confirm both devices are signed in to the same OneDrive account/location.

What should happen: The same file version appears after sync.

If that does not happen: If conflicts exist, preserve both copies until you know which version contains needed changes.

Practice: Review current sync status.

26.4 You Deleted the Wrong File

What you will learn: Use Recycle bin before trying to recreate the file.

Before you begin: The file was recently deleted from OneDrive.

Exactly how to do it

  1. Open OneDrive.com.

  2. Open Recycle bin.

  3. Find the file.

  4. Select it.

  5. Activate Restore.

  6. Search My files for the restored file.

What should happen: The file is restored if still retained.

If that does not happen: If permanently deleted or past retention, contact your organization/admin promptly when applicable.

Practice: Restore the practice deletion.

26.5 OneDrive Web Keyboard Commands Behave Like Browser Commands

What you will learn: Identify web focus and mode.

Before you begin: OneDrive.com is open.

Exactly how to do it

  1. Press Escape to close dialogs.

  2. Use Ctrl+F6/F6 to move into OneDrive.

  3. Narrator: turn Scan Mode off when direct interaction is needed.

  4. NVDA: enter Focus Mode.

  5. JAWS: turn Virtual PC Cursor off.

  6. Try Arrow/Space/Enter in the files grid.

What should happen: OneDrive receives its own interaction keys.

If that does not happen: If Ctrl+O or another shortcut opens browser UI, remember that some shortcuts belong to the browser in OneDrive web.

Practice: Practice moving between browser and OneDrive.

Chrome Lesson 1

Chrome Layout, Address Bar, and Basic Navigation

Chrome manualAll Chrome lessonsMy progress

Goal

Navigate Chrome’s main controls, enter a web address, and move safely through page history.

Step-by-step instructions

  1. Open Chrome and press Ctrl+L to focus the address bar.
  2. Type https://accessiblelearning.github.io/accessible-learning-center/ and press Enter.
  3. Press Alt+Left Arrow to go back and Alt+Right Arrow to go forward.
  4. Press Alt+Home to open the configured home page, then return to the learning site.
  5. Press Ctrl+R to reload the current page.
  6. Press Esc to stop a page that is still loading or dismiss an open browser control.
  7. Press F6 repeatedly to move among the webpage, address bar, toolbar, and tab strip.
  8. With JAWS, press Insert+T to confirm the window and Insert+Tab to identify focus.
  9. Record each command and the browser area it controls.
  10. Save as Chrome-Lesson-1.txt.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

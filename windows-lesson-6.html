Windows 11 Lesson 6

Settings and Built-in Accessibility Features

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Navigate Windows Settings and identify accessibility options without disrupting an established assistive-technology setup.

Skills practiced

  • Open and search Settings.
  • Find Accessibility categories.
  • Review Magnifier, contrast themes, text size, audio, and keyboard options.
  • Exit without changing unfamiliar workplace settings.

Step-by-step instructions

  1. Press Windows+I to open Settings.
  2. Use the Settings search field to search for Accessibility.
  3. Open Accessibility and review the Vision, Hearing, and Interaction groups.
  4. Open Text size and review the current value. Press Escape or Back without applying a change.
  5. Review Magnifier. Windows+Plus starts Magnifier and Windows+Escape closes it; use the commands only if appropriate for the learner.
  6. Review Contrast themes without applying one on a shared computer.
  7. Review Audio options such as mono audio and visual notifications without changing workplace policy settings.
  8. Review Keyboard accessibility options. Do not turn on Sticky Keys, Filter Keys, or Toggle Keys unless the learner intentionally wants them.
  9. Use Alt+Left Arrow to return through Settings and Alt+F4 to close it.
  10. Create Windows-Lesson-6.txt listing five accessibility options, who each may help, and which changes require permission on a shared computer.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

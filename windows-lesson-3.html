Windows 11 Lesson 3

File Explorer Basics and Location Awareness

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Open File Explorer, understand its major areas, and keep track of the current folder.

Skills practiced

  • Open and navigate File Explorer.
  • Move among panes and controls.
  • Identify the current location.
  • Open folders and return to prior locations.

Step-by-step instructions

  1. Press Windows+E to open File Explorer.
  2. Press Ctrl+L to move to the address bar. Listen to or read the current location, then press Escape.
  3. Press F6 repeatedly to move among the content pane, navigation pane, address bar, and command controls.
  4. Use Tab and Shift+Tab to inspect controls within the current area.
  5. Move to the navigation pane and choose Documents without opening unfamiliar cloud or network locations.
  6. In the content pane, use Arrow keys to review items. Press Enter only on a familiar folder.
  7. Press Alt+Left Arrow to return to the previous location and Alt+Right Arrow to go forward.
  8. Press Alt+Up Arrow to move to the folder containing the current folder.
  9. Press Ctrl+L, type %USERPROFILE%\Documents, and press Enter to return to Documents.
  10. Create Windows-Lesson-3.txt explaining the address bar, navigation pane, content pane, and history commands.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

I’m new to computers or screen readers

Use this recommended beginner order to build one skill at a time. JAWS, Windows Narrator, and NVDA are taught together so you can follow the instructions for your screen reader.

  1. Create or enter an anonymous Student ID if you want the website to remember completed lessons.
  2. Begin Screen Readers Lesson 1 to choose, start, and stop JAWS, Narrator, or NVDA.
  3. Continue with Windows 11 Lesson 1 to learn the desktop, Start menu, search, and taskbar.
  4. Continue with Microsoft Word Lesson 1 to create and save your first document.

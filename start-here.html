Choose a guided learning path

Pick the path that best matches your goal. You can create or enter an anonymous Student ID first if you want the website to remember your completed lessons.

  1. New to computers

    Learn the Windows desktop, Start menu, search, File Explorer, folders, and files before moving into other programs.

    Recommended order: Windows, Screen Readers, then Microsoft Word.

    Start Windows Lesson 1

  2. New to screen readers

    Learn the core commands for JAWS, Windows Narrator, and NVDA with safe, guided practice.

    Recommended order: Screen Readers, Windows, then Command Practice.

    Start Screen Readers Lesson 1

  3. Workplace skills

    Build practical skills for writing documents, working with spreadsheets, email, and online teamwork.

    Recommended order: Word, Excel, Outlook, then Teams.

    Start Microsoft Word Lesson 1

  4. Google skills

    Learn to browse the web and work with Google documents, cloud files, email, and meetings.

    Recommended order: Chrome, Docs, Drive, then Gmail.

    Start Google Chrome Lesson 1

  5. Braille technology

    Learn how to use refreshable braille displays and eReaders for navigation, reading, and writing.

    Choose your device: Focus 40 Blue, Mantis Q40, or NLS Braille eReader.

    Start Focus 40 Blue Lesson 1 or choose another braille device.

  6. AI skills

    Learn AI basics, responsible use, effective prompts, and accessible tools for everyday tasks.

    Recommended order: AI Fundamentals, ChatGPT, Copilot, then Gemini.

    Start AI Fundamentals Lesson 1

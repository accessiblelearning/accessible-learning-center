JAWS Lesson 5

Web Navigation with the Virtual Cursor

JAWS manual All JAWS lessons My progress

Goal

Read and navigate structured web pages with the Virtual Cursor and Navigation Quick Keys.

Skills practiced

  • Understand the Virtual Cursor.
  • Move by heading, link, paragraph, list, and region.
  • Open element lists for headings and links.
  • Return to the top and find text on a page.

Step-by-step instructions

  1. Open Chrome or Edge and visit the Accessible Learning Center home page.
  2. Press Insert+Z and listen to the Virtual Cursor status. Turn it back on if it was turned off.
  3. Press Ctrl+Home to move to the top of the page.
  4. Press H and Shift+H to move forward and backward by heading.
  5. Press P and Shift+P to move by paragraph. Press L to move to the next list.
  6. Press Tab and Shift+Tab to move among focusable links and controls.
  7. Press Insert+F6 to open the Headings List. Choose a heading and press Enter.
  8. Press Insert+F7 to open the Links List. Type the first letters of a link, then press Enter or Escape.
  9. Press Ctrl+F to use the browser’s visual Find command, then compare it with JAWS Find using Insert+Ctrl+F.
  10. Create JAWS-Lesson-5.txt and record the page visited, the commands practiced, and one accessibility feature that made navigation easier.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Your assignment

Write a web-navigation report comparing headings, links, Tab navigation, and JAWS Find.

Save the finished assignment as JAWS-Lesson-5.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • The report names the page tested.
  • At least six web-navigation commands are documented.
  • One helpful and one difficult page feature are identified.
  • The file is named JAWS-Lesson-5.txt.

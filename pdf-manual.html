Adobe Acrobat Reader accessibility features

Purpose: This manual teaches how to read, navigate, complete, save, print, and evaluate PDFs with a screen reader, and how to recognize when a PDF needs OCR or accessibility remediation.

Reader versus Acrobat Pro: Adobe Acrobat Reader is primarily for reading, forms, comments, and everyday PDF use. Acrobat Pro adds authoring and remediation tools such as accessibility checking, automatic tagging, Reading Order, and advanced tag repair.

Reference platform: Main procedures focus on current Acrobat/Acrobat Reader on Windows. Separate sections cover macOS/VoiceOver and braille.

How to Use This Manual

  • A screen reader can only read what the PDF exposes as text and structure.

  • A tagged PDF is usually easier to navigate than an untagged PDF.

  • An image-only scanned PDF may contain no readable text until OCR is performed.

  • Use Ctrl+F for text search, Ctrl+0/1/2/3/4/5 for common view/reflow commands as supported, and Ctrl+Shift+5 for current-document reading settings.

  • Do not confuse Adobe Read Out Loud with your screen reader; Read Out Loud is Adobe text-to-speech, not a substitute for accessible tagging.

  • For long untagged PDFs, Reader may take time to analyze reading order.

  • When a PDF reads badly, test whether the problem is the document before changing global screen-reader settings.

Part 1 - What a PDF Is

PDF means Portable Document Format. A PDF can preserve page appearance, but visual appearance does not guarantee accessibility.

  • Text PDF: contains selectable/extractable text.

  • Tagged PDF: contains a logical structure tree identifying headings, paragraphs, lists, tables, figures, links, and reading order.

  • Untagged PDF: may contain real text but little or no structural information.

  • Scanned/image-only PDF: may be only pictures of pages until OCR adds a text layer.

  • Form PDF: can contain interactive text fields, checkboxes, radio buttons, buttons, and signatures.

Part 2 - Acrobat Reader vs Acrobat Pro

Product Typical accessibility role
Acrobat Reader Read PDFs, use forms, comments, accessibility preferences, Read Out Loud, save/print common PDFs.
Acrobat Pro Includes Reader functions plus accessibility checking, tagging/remediation, Reading Order, OCR and advanced document repair.

Rule of thumb: If you only need to consume a PDF, Reader may be enough. If you must repair or certify PDF accessibility, Acrobat Pro is normally required.

Part 3 - Open a PDF and Learn the Window

3.1 Open a Local PDF

What you will learn: Open a known file in Acrobat/Reader.

Before you begin: Know the PDF location.

Exactly how to do it

  1. Press Ctrl+O.

  2. Navigate the Windows Open dialog to the PDF.

  3. Press Enter.

  4. Wait for the document to load.

  5. Press Tab and Shift+Tab slowly to identify toolbar and document controls.

  6. Use your screen reader reading command in the document area.

What should happen: The PDF opens and accessible content is exposed to the screen reader.

If that does not happen: If the screen reader announces only image, blank, or very little content, the PDF may be scanned or poorly structured.

Practice: Open one known accessible PDF.

Browser PDFs: PDFs may open in Chrome or Edge instead of Acrobat. Download/open the file in Acrobat when you need Adobe-specific accessibility preferences or Pro remediation tools.

Part 4 - Page Navigation

Task Command
Next page Page Down or Ctrl+Page Down depending view/context
Previous page Page Up or Ctrl+Page Up depending view/context
First page Home/Ctrl+Home depending focus
Last page End/Ctrl+End depending focus
Go to page Use page-number field or navigation control; Ctrl+Shift+N is commonly used in Acrobat for Go to Page

4.1 Go to a Specific Page

What you will learn: Reach a page without reading every page before it.

Before you begin: Open a multi-page PDF.

Exactly how to do it

  1. Move to the page-number control in the toolbar, or invoke the Go to Page command available in your Acrobat version.

  2. Type the page number.

  3. Press Enter.

  4. Use the screen reader to verify the page heading/text.

What should happen: The requested page becomes active.

If that does not happen: If the printed page number differs from the PDF page index, use bookmarks/headings/search for better orientation.

Practice: Jump to three different pages.

Part 5 - Text Reading and Selection

5.1 Read PDF Text with Your Screen Reader

What you will learn: Read text using the screen reader rather than Acrobat TTS.

Before you begin: The PDF exposes selectable text.

Exactly how to do it

  1. Move focus into the document pane.

  2. Use your screen reader Say All/read commands.

  3. Use line, word, heading, link, and table commands when the PDF is tagged.

  4. Stop speech with the screen reader stop-speech command when needed.

What should happen: The screen reader follows the PDF text and document structure.

If that does not happen: If reading order jumps unpredictably, the PDF may be untagged or incorrectly tagged.

Practice: Read one page continuously, then navigate by structure.

5.2 Select and Copy Text

What you will learn: Copy a short accessible passage.

Before you begin: Use a PDF that allows copying.

Exactly how to do it

  1. Move the screen reader/caret to the desired text.

  2. Select with Shift plus navigation keys or the screen reader selection mechanism.

  3. Press Ctrl+C.

  4. Paste into a harmless text editor with Ctrl+V to confirm.

What should happen: The selected text copies in a sensible order.

If that does not happen: If copied text is scrambled or unavailable, the PDF may use inaccessible encoding, permissions, or image-only pages.

Practice: Copy one sentence.

Part 6 - Search

6.1 Find Text

What you will learn: Locate a word in a long PDF.

Before you begin: PDF contains searchable text.

Exactly how to do it

  1. Press Ctrl+F.

  2. Type a word or phrase.

  3. Press Enter.

  4. Use the Find next/previous controls or Enter/Shift+Enter as available.

  5. Press Escape when finished.

What should happen: Acrobat moves to matching text.

If that does not happen: If a visible word cannot be found, the page may be image-only or text extraction may be broken.

Practice: Search for three terms.

Part 7 - Links and Bookmarks

7.1 Use PDF Bookmarks

What you will learn: Navigate a structured long document.

Before you begin: The PDF contains bookmarks.

Exactly how to do it

  1. Open the Bookmarks side panel with the Acrobat navigation-pane controls.

  2. Use Arrow keys through bookmarks.

  3. Press Enter on the desired bookmark.

  4. Return to the document pane and read from the new location.

What should happen: The PDF jumps to the bookmarked section.

If that does not happen: If no bookmarks exist, use headings/search/page navigation.

Practice: Navigate to three bookmarks.

7.2 Activate a Link

What you will learn: Open a link deliberately.

Before you begin: Focus a link in the PDF.

Exactly how to do it

  1. Listen to the link text and destination information if your screen reader provides it.

  2. Press Enter only when you trust the destination.

  3. Use Alt+Tab/Ctrl+Tab to return if the link opens a browser.

What should happen: The linked destination opens.

If that does not happen: If the link text is vague, inspect surrounding context or destination before activating it.

Practice: Open one trusted link.

Part 8 - Forms

8.1 Fill an Accessible PDF Form

What you will learn: Complete text, checkbox, radio, and list fields.

Before you begin: Use a trusted form that permits filling.

Exactly how to do it

  1. Press Tab to move to the first form field.

  2. Type in text fields.

  3. Use Spacebar for checkboxes.

  4. Use Arrow keys in radio-button groups.

  5. Use Alt+Down Arrow/Arrow keys in combo boxes when needed.

  6. Press Tab to continue.

  7. Review every field before saving or submitting.

What should happen: Focus moves in a logical tab order and labels are announced.

If that does not happen: If fields are unlabeled or Tab order is illogical, the form itself has accessibility problems.

Practice: Complete a non-sensitive practice form.

Form command behavior: Adobe documents Tab/Shift+Tab for moving between fields, arrow keys for radio buttons, Escape for rejecting/deselecting a field, and Enter for accepting single-line text entry.

Part 9 - Comments and Annotations

9.1 Add a Comment

What you will learn: Annotate a PDF without editing its original text.

Before you begin: Comments are permitted.

Exactly how to do it

  1. Open the Comment tool or toolbar.

  2. Choose a text comment/sticky note/highlight as appropriate.

  3. Anchor it to the intended text/location.

  4. Type the comment.

  5. Save the PDF.

What should happen: The comment is attached to the PDF.

If that does not happen: If commenting is disabled, document security or workflow restrictions may prevent annotations.

Practice: Add and remove one practice comment.

Part 10 - Saving, Printing, and Exporting

Task Command
Save Ctrl+S
Save As Ctrl+Shift+S in common Acrobat contexts
Print Ctrl+P

10.1 Save a Filled/Annotated PDF

What you will learn: Preserve your work.

Before you begin: You changed a form or comment.

Exactly how to do it

  1. Press Ctrl+S.

  2. If Save As appears, choose a location and filename.

  3. Do not overwrite the original when you need to preserve a clean copy.

  4. Reopen the saved file and verify the changes.

What should happen: Your changes remain in the saved PDF.

If that does not happen: If the PDF is read-only or protected, save a permitted copy or follow the document owner's process.

Practice: Save a practice PDF under a new name.

Part 11 - Tagged vs Untagged PDFs

  • Tags provide structure used by assistive technology.

  • A tagged PDF can identify headings, paragraphs, lists, tables, figures, links, and logical reading order.

  • An untagged PDF forces Acrobat/screen readers to infer order, which can be slow or inaccurate.

  • A PDF can be tagged but still be badly tagged.

  • Acrobat Pro can inspect and repair tags; the source document should be fixed whenever possible.

11.1 Recognize a Suspected Untagged PDF

What you will learn: Identify structural warning signs.

Before you begin: Open a PDF.

Exactly how to do it

  1. Try heading navigation with the screen reader.

  2. Try table/list navigation.

  3. Listen for logical reading order across columns.

  4. Search for text.

  5. If using Acrobat Pro, inspect Document Properties/Tags or run Accessibility Check.

What should happen: You form a reasonable diagnosis of whether structure is missing or poor.

If that does not happen: Do not assume every screen-reader problem is caused by your screen reader. Test another known-good PDF.

Practice: Compare a tagged and untagged PDF.

Part 12 - Scanned/Image-Only PDFs and OCR

12.1 Recognize an Image-Only PDF

What you will learn: Determine whether OCR is needed.

Before you begin: Open a scanned PDF.

Exactly how to do it

  1. Press Ctrl+F and search for a clearly visible word.

  2. Try selecting/copying text.

  3. Use screen-reader reading commands.

  4. If text cannot be found, selected, or read, treat the page as likely image-only.

What should happen: You identify the need for OCR or an accessible alternate copy.

If that does not happen: Some PDFs have partial OCR; test several pages.

Practice: Test one scanned page.

12.2 Run OCR in Acrobat Pro

What you will learn: Add a text layer to scanned pages.

Before you begin: You have Acrobat Pro and permission to alter the PDF.

Exactly how to do it

  1. Open All tools.

  2. Open Scan & OCR or the current OCR tool.

  3. Choose Recognize Text.

  4. Choose the relevant pages and language.

  5. Run recognition.

  6. Save a new copy.

  7. Re-read the PDF with the screen reader and run Accessibility Check.

What should happen: The scanned image gains machine-readable text.

If that does not happen: OCR does not automatically create correct headings, lists, tables, or reading order; remediation may still be required.

Practice: OCR a non-sensitive one-page scan.

Part 13 - Reading Order and Document Structure

Core concept: Visual position and screen-reader reading order are separate. Two-column pages, sidebars, captions, tables, and floating graphics can read incorrectly when tags/order are wrong.

13.1 Test Logical Reading Order

What you will learn: Determine whether content is encountered sensibly.

Before you begin: Use a multi-column or visually complex PDF.

Exactly how to do it

  1. Read continuously from the top of a page.

  2. Listen for whether columns are interleaved or skipped.

  3. Navigate headings and links.

  4. Compare the spoken sequence with the visible/logical document order.

What should happen: Content is read in a human-logical sequence.

If that does not happen: If not, remediation is needed in the source file or Acrobat Pro Reading Order/Tags tools.

Practice: Test a two-column page.

Part 14 - Reflow and Reading Settings

Task Command
Change reading settings for current document Ctrl+Shift+5
Reflow tagged PDF / return to normal Ctrl+4

14.1 Use Reflow

What you will learn: Simplify visual layout and support magnification/small-window reading.

Before you begin: Use a tagged PDF.

Exactly how to do it

  1. Press Ctrl+4.

  2. Read/navigate the reflowed document.

  3. Press Ctrl+4 again to return to normal view.

What should happen: Tagged content reflows into a simpler sequence.

If that does not happen: If reflow is unavailable or nonsensical, the PDF may be untagged or poorly structured.

Practice: Reflow one tagged PDF.

14.2 Change Reading Settings for One Document

What you will learn: Adjust how Acrobat presents the current PDF to assistive technology.

Before you begin: A difficult PDF is open.

Exactly how to do it

  1. Press Ctrl+Shift+5.

  2. Review the reading-order and page-delivery options.

  3. Prefer document tags for a well-tagged PDF.

  4. Use inference only when tags are absent or broken.

  5. For very long untagged PDFs, consider delivering only visible pages to reduce analysis delay.

  6. Apply the setting and test.

What should happen: The current document becomes more manageable.

If that does not happen: Do not globally override good tags just because one bad PDF needs special treatment.

Practice: Change and restore a document-specific reading setting.

Part 15 - Accessibility Setup Assistant

15.1 Run the Accessibility Setup Assistant

What you will learn: Configure Acrobat/Reader for screen-reader use.

Before you begin: Acrobat/Reader is open.

Exactly how to do it

  1. Open the menu path for Accessibility > Setup Assistant (Adobe documents Edit > Accessibility > Setup Assistant in Reader).

  2. Choose the screen-reader setup path.

  3. Review document-reading order, page delivery, color, and other accessibility preferences.

  4. Finish the assistant.

  5. Open a known-good PDF and test.

What should happen: Acrobat preferences are configured for assistive technology.

If that does not happen: If settings make good PDFs worse, rerun the assistant or restore recommended defaults.

Practice: Run the assistant once and record the options you choose.

Part 17 - Creating and Checking Accessible PDFs in Acrobat Pro

17.1 Run Accessibility Check

What you will learn: Find common PDF accessibility problems.

Before you begin: Use Acrobat Pro and a copy of the PDF.

Exactly how to do it

  1. Open All tools > Prepare for accessibility.

  2. Choose Check for accessibility.

  3. Select the checks you need.

  4. Run the check.

  5. Move through the results.

  6. Use Fix where appropriate and manually verify items such as logical reading order.

  7. Save a new copy.

What should happen: Acrobat reports pass/fail/manual-check results.

If that does not happen: Passing the automated checker does not guarantee full accessibility; manually test reading order, links, forms, and tables.

Practice: Run the checker on one practice PDF.

Source-first rule: Adobe recommends fixing the original authoring file when possible, then recreating the PDF. Repeatedly repairing every new PDF export is less reliable.

Part 18 - Fixing Reading Order in Acrobat Pro

18.1 Use the Reading Order Tool

What you will learn: Repair basic reading-order/tagging problems.

Before you begin: Save a backup copy first.

Exactly how to do it

  1. Open All tools > Prepare for accessibility.

  2. Open Reading Order / Fix reading order.

  3. Enable page-content/order overlays.

  4. Inspect the numbered content regions.

  5. Use the Order panel to move regions into logical sequence.

  6. Mark figures/tables/text appropriately as needed.

  7. Save and test with a screen reader.

What should happen: The assistive-technology reading sequence improves without changing the visual page appearance.

If that does not happen: Reading Order is not ideal for every advanced repair. Use the Tags panel for complex tag-tree work.

Practice: Repair one simple two-column page.

Backup warning: Adobe notes that undo/redo is not supported for every Reading Order operation. Save a copy before remediation.

Part 19 - Tables, Lists, Headings, Language, and Alt Text

  • Headings must be tagged as headings at correct levels.

  • Lists should use proper List/List Item structure.

  • Tables need table, row, and header/data-cell structure.

  • Figures/images need meaningful alt text unless decorative.

  • The PDF primary language should be set so screen readers can choose appropriate pronunciation.

  • Link text should be meaningful.

  • Form fields need accessible names/tooltips and logical tab order.

19.1 Verify Document Language in Acrobat Pro

What you will learn: Help the screen reader pronounce text correctly.

Before you begin: Use a PDF you can edit.

Exactly how to do it

  1. Open Document Properties.

  2. Open the relevant Advanced/Reading Options area.

  3. Find Language/Reading Language.

  4. Choose the document primary language.

  5. Save and retest with the screen reader.

What should happen: The PDF declares its primary language.

If that does not happen: Mixed-language documents may require more advanced language tagging at element level.

Practice: Set language on a practice PDF.

Part 20 - Narrator

20.1 Read a PDF with Narrator

What you will learn: Use Narrator with Acrobat document content.

Before you begin: Narrator is on.

Exactly how to do it

  1. Open a known tagged PDF.

  2. Move focus into the document pane.

  3. Use Narrator reading commands to read.

  4. Use Tab through links/forms.

  5. Use Acrobat Ctrl+F for document search.

  6. Use Acrobat page/bookmark controls for long-document navigation.

What should happen: Narrator reads text and interactive controls exposed by the PDF.

If that does not happen: If Narrator reads toolbar controls instead of the document, move focus back into the document pane.

Practice: Read a tagged PDF and complete one form field.

Part 21 - NVDA

21.1 Read Tagged PDFs with NVDA

What you will learn: Use NVDA browse/document navigation.

Before you begin: NVDA is running.

Exactly how to do it

  1. Open a tagged PDF in Acrobat/Reader.

  2. Move focus into document content.

  3. Use NVDA heading, link, list, and table navigation when structure is exposed.

  4. Use NVDA+F for formatting information if useful.

  5. Use Ctrl+F for Acrobat text search.

What should happen: NVDA uses the PDF structure for navigation.

If that does not happen: If heading/list/table commands find nothing, the PDF may lack correct tags.

Practice: Navigate one PDF by headings and links.

MathML: Adobe currently documents MathML reading in tagged PDFs with NVDA 2026.1.x or later, with built-in math support; earlier NVDA versions may require MathCAT.

Part 22 - JAWS

22.1 Read a PDF with JAWS

What you will learn: Use JAWS Virtual Cursor/document navigation in Acrobat.

Before you begin: JAWS is running.

Exactly how to do it

  1. Open a tagged PDF.

  2. Move into the document pane.

  3. Use H/Shift+H for headings when tags are correct.

  4. Use Insert+F7 for links when appropriate.

  5. Use table/list navigation commands where structure exists.

  6. Tab through form fields and interactive controls.

What should happen: JAWS exposes the PDF as a structured document when tags are correct.

If that does not happen: If Virtual Cursor navigation is erratic, compare with a known-good tagged PDF before changing JAWS settings.

Practice: Navigate headings, links, and a form.

Part 23 - VoiceOver

23.1 Read a PDF on macOS

What you will learn: Use VoiceOver with Acrobat or Preview as appropriate.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Open the PDF.

  2. Use VO navigation to reach the document content.

  3. Interact with the document area when required.

  4. Use VO reading/navigation commands through text and controls.

  5. Use Acrobat document search and page controls for navigation.

What should happen: VoiceOver reads accessible PDF content and controls.

If that does not happen: If one PDF is poor while others are good, suspect the document structure rather than VoiceOver.

Practice: Read one tagged PDF and one form.

Part 24 - Braille Displays

24.1 Test PDF Braille Output

What you will learn: Verify text, links, fields, and routing.

Before you begin: Connect/configure your braille display through the screen reader.

Exactly how to do it

  1. Open a tagged PDF.

  2. Read several paragraphs in braille.

  3. Navigate to a link and form field.

  4. Enter harmless text in a form field using braille input if supported.

  5. Use routing keys within editable fields if supported.

What should happen: Braille follows the PDF accessibility information exposed by the screen reader.

If that does not happen: If braille works in other apps but not the PDF, test another known-good PDF and inspect tags/OCR.

Practice: Test output, input, and routing.

Braille printing/export: Adobe accessibility features include saving as accessible text for braille printers and assistive devices where supported.

Part 25 - PDF Security and Signatures

  • A PDF can restrict copying, editing, printing, commenting, or form filling.

  • A digital signature can validate document integrity/identity but does not make the PDF accessible.

  • Do not bypass security restrictions you are not authorized to change.

  • Before signing, review every field and the document you are agreeing to.

  • Do not assume a signed PDF is safe or accessible merely because it is signed.

25.1 Review Before Signing

What you will learn: Avoid signing the wrong or unreadable document.

Before you begin: Use a trusted signing workflow.

Exactly how to do it

  1. Read the complete document or obtain an accessible equivalent.

  2. Review signer fields and intent.

  3. Verify the source/recipient.

  4. Only activate the signature control after you understand the document.

  5. Save/download the completed copy as needed.

What should happen: You sign deliberately with informed access to the document.

If that does not happen: If the PDF is not accessible enough to review, request an accessible version before signing.

Practice: Practice locating signature controls on a non-binding test PDF.

Part 26 - Troubleshooting

26.1 Screen Reader Says Blank or Image

What you will learn: Diagnose image-only pages.

Before you begin: Open the problem PDF.

Exactly how to do it

  1. Try Ctrl+F for visible words.

  2. Try selecting/copying text.

  3. Test another page.

  4. If no text is exposed, use OCR or request an accessible copy.

What should happen: You identify a likely scan/image-only PDF.

If that does not happen: Do not repeatedly change screen-reader settings for a document with no text layer.

26.2 Reading Order Jumps Around

What you will learn: Identify structural/tagging problems.

Before you begin: Open the problem PDF.

Exactly how to do it

  1. Read continuously through one page.

  2. Test heading/link navigation.

  3. Compare with visual/logical order.

  4. If using Pro, inspect tags/Reading Order.

  5. Fix source or remediate a copy.

What should happen: You identify the document as the likely cause.

If that does not happen: For a single bad PDF, avoid overriding global reading preferences for every PDF.

26.3 Long PDF Takes a Long Time to Open to the Screen Reader

What you will learn: Reduce analysis work for untagged documents.

Before you begin: Open the problem PDF.

Exactly how to do it

  1. Press Ctrl+Shift+5.

  2. Review Page vs Document delivery.

  3. Choose visible-page delivery for very large untagged documents when appropriate.

  4. Apply and test.

What should happen: The screen reader becomes responsive sooner.

If that does not happen: This is a workaround; proper tags are the better fix.

26.4 Tab Skips Form Fields

What you will learn: Diagnose bad form tab order.

Before you begin: Open the problem PDF.

Exactly how to do it

  1. Tab through the form.

  2. Note missing/misordered fields.

  3. Use screen-reader form lists if available.

  4. If using Pro, run Accessibility Check and inspect Tab Order/form labels.

What should happen: You determine whether the form itself needs repair.

If that does not happen: Do not submit a form when you cannot reliably identify fields.

26.5 Text Copies as Gibberish

What you will learn: Identify encoding/extraction problems.

Before you begin: Open the problem PDF.

Exactly how to do it

  1. Copy a short sentence.

  2. Paste into a text editor.

  3. Try another page.

  4. If extraction is broken, request a better source PDF or remediate from the source.

What should happen: You confirm whether text extraction is trustworthy.

If that does not happen: Visual text can still be inaccessible when font-to-Unicode mapping is broken.

Final Independence Checklist

☐ I can distinguish a text PDF, tagged PDF, untagged PDF, and image-only scan.

☐ I can open and navigate PDFs by page, search, bookmarks, headings, and links when available.

☐ I can fill accessible PDF forms.

☐ I can save and print PDFs safely.

☐ I can use document-specific reading settings and Reflow.

☐ I understand Accessibility Setup Assistant and Read Out Loud.

☐ I can recognize when OCR is needed.

☐ I understand why tags and reading order matter.

☐ I can run Accessibility Check in Acrobat Pro.

☐ I can perform basic Reading Order remediation in Acrobat Pro.

☐ I understand headings, lists, tables, alt text, language, and form tab order.

☐ I can use PDFs with Narrator, NVDA, JAWS, or VoiceOver.

☐ I can use a braille display with PDFs.

☐ I can diagnose whether a problem belongs to the PDF or the screen reader.

☐ I understand PDF security and signature cautions.

Most important habit: When a PDF is difficult, ask in this order: Does it contain real text? Is it tagged? Is the reading order logical? Are interactive controls labeled? Only after checking the document should you change global screen-reader or Acrobat settings.

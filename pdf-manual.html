Purpose and setup

This manual supports independent practice with Adobe Acrobat and Accessible PDFs on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Basic and advanced how-tos

Open and identify a PDF

Keyboard commands: Ctrl+O opens a file in Acrobat. Ctrl+Shift+S opens Save As. Ctrl+F finds text.

  1. Press Ctrl+O and choose the PDF.
  2. Confirm the filename and page count.
  3. Use Ctrl+F to search for a known word.
  4. Navigate by headings, links, lists, tables, and fields when available.
  5. Save a working copy before changing anything.

If that does not happen: The PDF may be image-only, untagged, protected, or still loading.

Recognize an image-only PDF with OCR

  1. Test whether Ctrl+F finds visible words.
  2. Save a copy of the original.
  3. Open Scan & OCR and choose Recognize Text in this file.
  4. Select the page range and language.
  5. Run recognition and reread every page.
  6. Correct names, numbers, headings, columns, and tables against the source.

If that does not happen: Request the original accessible document or human help for critical information.

Complete and save a PDF form

Keyboard commands: Tab and Shift+Tab move through fields. Space changes checkboxes. Arrow keys choose radio buttons. Alt+Down Arrow opens many combo boxes.

  1. Save a blank copy.
  2. Hear each field’s label, type, required state, and instructions.
  3. Enter fictional or authorized information.
  4. Review checkboxes, radio buttons, dates, and signature requirements.
  5. Press Ctrl+S, close, reopen, and confirm the responses remained.

If that does not happen: Stop before submitting; the document may lack real fields.

Check tags and reading order

  1. Work on a copy.
  2. Run Acrobat Pro’s accessibility checker.
  3. Inspect title, language, headings, lists, links, table headers, alternative text, and reading order.
  4. Correct the source when possible and export a fresh tagged PDF.
  5. Test by keyboard and screen reader.

If that does not happen: Automated checking cannot prove full accessibility; complex files need trained remediation.

Create a better PDF from Word

  1. Use real headings, lists, table headers, descriptive links, and alternative text in Word.
  2. Set the title and run Word’s Accessibility Checker.
  3. Save the editable Word original.
  4. Export a tagged PDF rather than printing an image-only PDF.
  5. Test headings, reading order, links, tables, and selectable text.

If that does not happen: Correct the Word source and export again.

Ten-lesson learning path

  1. Lesson 1: Open, Read, and Identify a PDF — Report the title, page count, and whether a public practice PDF is readable.
  2. Lesson 2: Navigate Pages, Headings, and Search — Create a navigation log for a public accessible PDF.
  3. Lesson 3: Links, Bookmarks, Lists, and Tables — Evaluate structure in a public PDF without changing it.
  4. Lesson 4: Complete Accessible PDF Forms — Describe the accessibility of a practice form and save a local copy if allowed.
  5. Lesson 5: Comments and Review Tools — Submit a review summary with three constructive comments.
  6. Lesson 6: Tags, Reading Order, and Document Properties — Write an accessibility inventory for a public or instructor-provided PDF.
  7. Lesson 7: Scanned PDFs and OCR — Compare a scanned page before and after OCR, or describe the required workflow.
  8. Lesson 8: Accessibility Checker and Common Fixes — Create a prioritized remediation report for a practice PDF.
  9. Lesson 9: Export, Print, and Document Security — Write a file-handling plan for a fictional PDF workflow.
  10. Lesson 10: Final Accessible PDF Evaluation — Submit a complete accessible-PDF evaluation report.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Save the requested practice file locally with the exact filename given in the lesson. Assignment uploads are currently paused.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

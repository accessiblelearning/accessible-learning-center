First-time setup and success checks

Lesson goal in plain language: Combine Chrome, JAWS, research, tabs, bookmarks, forms, and file-safety skills.

Prepare before step 1

  1. Open the correct application, website, or device screen and wait for its name to be announced.
  2. Open Chrome manual and review the matching procedure if any command or term is unfamiliar.
  3. Use only fictional, public, disposable, or instructor-provided practice information. Make a copy before changing an important file.
  4. Read all numbered instructions once before performing them so you know the intended final result.

Commands used or referenced

Insert+T, Insert+Tab, Insert+1

For a plus-sign command, hold the modifier key, press and release the final key, then release the modifier. For a sequence, press and release each key in order. Stop after every command and listen for the result.

Work and verify

  1. Perform one numbered instruction and stop. Identify the active window, focused control, selected item, cell, slide, message, field, or device area before continuing.
  2. Compare the result with the lesson goal. A sound alone is not enough; verify the name, state, value, location, permission, or content.
  3. If the result is wrong, press Escape once to leave an unexpected menu, identify focus again, and use Undo only when the change is safely reversible.
  4. Save or synchronize at natural stopping points. Confirm the filename and location before closing.
  5. Complete the “Before submitting” checklist from top to bottom. Correct missing items before marking the lesson complete.
  6. Close and reopen the practice item, or return to it from the product’s main screen, to prove you can locate and verify the result independently.

Success standard: Explain what each major command did, show the finished result, and recover from one harmless focus or navigation error without another person naming the next key.

Goal

Combine Chrome, JAWS, research, tabs, bookmarks, forms, and file-safety skills.

Step-by-step instructions

  1. Choose a fictional workplace question that can be answered from public information.
  2. Search for two authoritative sources and open them in separate tabs.
  3. Use headings, links, lists, and Find to locate relevant information.
  4. Record each page title, organization, address, and publication or update date.
  5. Compare one fact across both sources.
  6. Bookmark the strongest source with a meaningful name.
  7. Locate one form and identify its fields without submitting private information.
  8. Locate one downloadable file and record its name and type without opening it if unnecessary.
  9. Write the answer, commands used, accessibility observations, and safety decisions.
  10. Review with JAWS Say All and save as Chrome-Lesson-10.txt.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

Your assignment

Create the report described above using fictional or public information only.

Save it as Chrome-Lesson-10.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • Two authoritative sources are documented.
  • At least eight Chrome or JAWS commands are recorded.
  • A bookmark, form, and potential download are evaluated.
  • No private information is submitted.
  • The file is Chrome-Lesson-10.txt.

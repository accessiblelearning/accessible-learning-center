Purpose and setup

This manual supports independent practice with NLS Braille eReader on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Identify your model before using commands

  • Zoomax: has six display keys labeled D1 through D6, four system keys labeled S1 through S4, and five navigation keys. S1 opens the Main Menu.
  • HumanWare: uses four thumb keys for menu movement and does not use the Zoomax S1 through S4 arrangement.

Important: Both models have 20 braille cells and Perkins-style keys, but their navigation and file commands are not interchangeable.

HumanWare model: Basic and advanced how-tos

Keyboard commands: HumanWare eReader commands use braille chords, thumb keys, Enter, and Backspace as described in each task.

Return to the Main Menu and open a book

Device commands: Space with M, dots 1-3-4, opens the Main Menu. Up and Down thumb keys move through items. Enter opens the selected item.

  1. Press Space with M.
  2. Move to Book Reader and press Enter.
  3. Open Book List.
  4. Use the thumb keys to find the intended title.
  5. Press Enter and use the panning keys to read.

You should feel: The selected title followed by its opening text.

If that does not happen: Press Space with M once and confirm whether Book Reader stopped or another message is displayed.

Navigate, search, and identify your position

Device commands: Space+Dot 1 or Space+Dot 4 moves by paragraph; Space+Dot 2 or Space+Dot 5 moves by page; Space+F, dots 1-2-4, searches; Space with the W-H sign, dots 1-5-6, gives Where am I.

  1. Open a practice book.
  2. Move forward and backward by paragraph, then by page.
  3. Press Space+F, type a word, and press Enter.
  4. Use Space+N for the next result or Space+P for the previous result.
  5. Press Space with dots 1-5-6 to confirm the location.

If that does not happen: Check spelling and whether the search started after the current position.

Insert and return to a bookmark

Device commands: Enter+B, dots 1-2, inserts a quick bookmark. Enter+J, dots 2-4-5, opens the bookmark list.

  1. Move to a passage you want to save.
  2. Press Enter+B and note the bookmark confirmation.
  3. Move several pages away.
  4. Press Enter+J, enter the bookmark number if requested, and press Enter.
  5. Use Where am I to verify the restored position.

If that does not happen: Open the Bookmark Menu with Enter+M and inspect saved bookmark numbers.

Find and download a BARD title

  1. Connect to a trusted Wi-Fi network.
  2. Press Space+M and open Online Services, then NLS BARD.
  3. Open Search collection, enter a title, author, or keyword, and press Enter.
  4. Move through results and press Enter for title information.
  5. Choose Download or Download Then Open.
  6. Wait for completion, return to Book Reader, and confirm the title in Book List.

If that does not happen: Check the Wi-Fi and BARD status. Never include BARD credentials in a lesson file.

Manage a file without losing it

Device commands: Space+D selects a drive; Space+I gives information; Backspace+C copies; Backspace+X cuts; Backspace+V pastes.

  1. Open File Manager and press Space+D to select the drive.
  2. Use thumb keys to select the file and press Space+I to confirm its name and location.
  3. Use Backspace+C to preserve the original or Backspace+X only when moving it.
  4. Open the verified destination and press Backspace+V.
  5. Confirm both source and destination before deleting anything.

If that does not happen: Preserve every copy and check available storage with Space+I.

Zoomax model: Basic and advanced how-tos

Return to the Main Menu and open a book

Device commands: S1 or Space with M, dots 1-3-4, opens the Main Menu. Navigate up or down with N-Up, N-Down, D1, D3, D4, or D6. Dot 8, N-Center, or a cursor router activates the selected item.

  1. Press S1.
  2. Move to Book Reader and press Enter.
  3. Open Book List.
  4. Move through titles until the intended book is displayed.
  5. Press Enter and use D2 or the left panning key to pan left; use D5 or the right panning key to pan right.

You should feel: The selected title followed by its opening text.

If that does not happen: Press S1 once and check for a startup, storage, or error message before reopening Book Reader.

Navigate and identify your reading position

Device commands: Dot 1 moves to the previous paragraph and Dot 4 to the next paragraph. Dot 2 moves to the previous page and Dot 5 to the next page. Space with the W-H sign, dots 1-5-6, gives the current position.

  1. Open a practice book.
  2. Move forward and backward by paragraph.
  3. Move forward and backward by page.
  4. Press Space with dots 1-5-6.
  5. Read the reported page, volume, and position information.

If that does not happen: Confirm that focus is inside the open book rather than Book List or a menu.

Search for text

Device commands: Space with F, dots 1-2-4, opens Find. Space with N, dots 1-3-4-5, finds the next occurrence; Space with P, dots 1-2-3-4, finds the previous occurrence.

  1. Move to a known point in the book.
  2. Press Space+F, type the search term, and press Enter.
  3. Read the surrounding line to confirm the match.
  4. Press Space+N for the next match or Space+P to move backward.
  5. Use Where am I to record the result’s location.

If that does not happen: Check spelling, braille grade, and whether the search begins from the current position.

Create and return to a bookmark

Device approach: Press S3 for the Context Menu, then select the bookmark command shown for the current book.

  1. Move to the passage you want to save.
  2. Press S3 and find Set Bookmark.
  3. Activate it and confirm the bookmark message.
  4. Move several pages away.
  5. Open the Context Menu again, choose Go to Bookmark, select the bookmark, and press Enter.
  6. Use Where am I to verify the restored position.

If that does not happen: Confirm that the book supports bookmarks and that the bookmark was created in the current title.

Find and download a BARD title

Device command: Space with A, dot 1, opens BARD from anywhere after the device is configured.

  1. Connect to trusted Wi-Fi and press Space+A.
  2. Choose a title, author, subject, or keyword search.
  3. Enter the search text and press Enter.
  4. Move through results, open the intended title, and review its information.
  5. Choose Download or the current download-and-open option.
  6. Wait for completion, then open Book List and verify the title.

If that does not happen: Check Wi-Fi and BARD sign-in status without putting credentials in a lesson file.

Use File Manager safely

Device commands: Space with F, dots 1-2-4, opens File Manager. S2 opens the application menu; S3 opens the context menu.

  1. Press Space+F and identify the current drive and folder.
  2. Move to the file and confirm its complete name.
  3. Press S3 and choose Copy when the original must remain, or Move only when relocation is intended.
  4. Navigate to the destination folder and use its context or application menu to paste.
  5. Verify both locations before deleting anything.

If that does not happen: Preserve every copy and check available storage before repeating the operation.

Connect the Zoomax eReader as a braille display

Device commands: Space with T, dots 2-3-4-5, toggles Bluetooth. The Power On quick menu also offers Bluetooth and USB modes.

  1. Save current reading position and work.
  2. Choose Bluetooth or USB mode on the eReader.
  3. On the computer or mobile device, open the screen reader’s braille-display settings.
  4. Select the NLS eReader Zoomax and complete pairing or USB setup.
  5. Move focus on the host device and verify matching braille.

If that does not happen: Confirm the selected mode, cable or Bluetooth state, screen-reader display choice, and paired device before restarting.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Save the requested practice file locally with the exact filename given in the lesson. Assignment uploads are currently paused.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

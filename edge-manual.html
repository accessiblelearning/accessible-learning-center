Microsoft Edge accessibility features

Purpose: This manual teaches Microsoft Edge from the beginning to a person using a screen reader. It explains exactly what to press, what browser region or webpage element should receive focus, what your screen reader should announce, and how to recover when the result is different.

Reference platform: This manual focuses on current Microsoft Edge on Windows 11.

Screen readers: Core Edge keyboard commands are taught first. Narrator, NVDA, and JAWS are covered separately so browser commands and screen-reader commands are not mixed together.

How to Use This Manual

  • Learn the browser itself before memorizing screen-reader-specific web commands.

  • Ctrl+L or Alt+D moves directly to the address bar.

  • Ctrl+T opens a new tab. Ctrl+W closes the current tab. Ctrl+Shift+T reopens the last closed tab.

  • F6 moves focus among major Edge panes. Shift+F6 moves backward.

  • Ctrl+F6 moves directly to the web content pane.

  • Tab and Shift+Tab move among focusable page controls and browser controls.

  • Screen-reader browse/scan modes control how you move through webpage structure.

  • Do not type passwords into pages you reached from suspicious email links.

  • Use Ctrl+S only when you intentionally want to save a webpage or file.

  • Use Ctrl+J to review downloads and Ctrl+H to review history.

Part 1 - What Microsoft Edge Is

Microsoft Edge is the web browser built into Windows 11. It displays webpages, web applications, PDFs, downloads, settings, favorites, history, and browser extensions.

  • Address bar: where you type a website address or search query.

  • Tab: one open webpage or browser task.

  • Toolbar: browser controls such as Back, Refresh, Favorites, profile, and Settings and more.

  • Web content pane: the current webpage.

  • Favorites: saved website shortcuts.

  • History: previously visited pages.

  • Downloads: files downloaded through Edge.

  • Profile: optional Microsoft account sign-in and sync settings.

Part 2 - Open Edge and Learn the Window

2.1 Open Microsoft Edge

What you will learn: Start the browser without using a mouse.

Before you begin: Be at the Windows keyboard.

Exactly how to do it

  1. Press the Windows key.

  2. Type Edge.

  3. Press Enter on Microsoft Edge.

  4. Wait for the browser window.

  5. Press F6 once.

  6. Listen to the region announced.

  7. Press F6 several more times to hear different Edge panes.

  8. Press Ctrl+F6 to move to the web content pane.

What should happen: Edge opens and keyboard focus can move among the browser's major regions.

If that does not happen: If F6 seems trapped in one area, press Escape to close any open popup/menu and try again.

Practice: Open Edge, cycle through panes, and return to web content.

Part 3 - Address Bar and Web Search

Task Command
Address bar Ctrl+L or Alt+D
Search from address bar Ctrl+E
Open typed address/search in new tab Alt+Enter

3.1 Open a Website by Address

What you will learn: Navigate directly to a known website.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Ctrl+L.

  2. Type the full website address, for example microsoft.com.

  3. Press Enter.

  4. Wait for the page to load.

  5. Use your screen reader to read the page title or first heading.

What should happen: The requested website opens in the current tab.

If that does not happen: If search results appear instead, check whether the address was typed correctly.

Practice: Open two known websites by address.

3.2 Search the Web from the Address Bar

What you will learn: Perform a web search without opening a search engine first.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Ctrl+L.

  2. Type a search phrase such as accessible PDF keyboard navigation.

  3. Press Enter.

  4. Wait for search results.

  5. Use your screen reader's heading/link commands to review results.

What should happen: Search results appear in the current tab.

If that does not happen: If a previous address remains, Ctrl+L should select it automatically; typing replaces it.

Practice: Search for three topics.

Part 4 - Tabs and Windows

4.1 Open and Switch Tabs

What you will learn: Work with more than one webpage.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Ctrl+T.

  2. Type a search or address.

  3. Press Enter.

  4. Press Ctrl+T again and open another page.

  5. Press Ctrl+Tab to move to the next tab.

  6. Press Ctrl+Shift+Tab to move back.

  7. Listen to the page title after each switch.

What should happen: You can keep multiple webpages open and identify which tab is active.

If that does not happen: If Ctrl+Tab appears to do nothing, only one tab may be open.

Practice: Open three tabs and cycle through them.

4.2 Recover a Closed Tab

What you will learn: Restore a tab closed by mistake.

Before you begin: Close a non-important tab with Ctrl+W.

Exactly how to do it

  1. Press Ctrl+Shift+T.

  2. Wait for the tab to reopen.

  3. Listen for the restored page title.

What should happen: The most recently closed tab reopens.

If that does not happen: If a different tab opens, repeated Ctrl+Shift+T can restore earlier closed tabs.

Practice: Close and restore two practice tabs.

Part 5 - Back, Forward, Reload, and Home

Task Command
Back Alt+Left Arrow
Forward Alt+Right Arrow
Reload Ctrl+R or F5
Hard reload/ignore cached content Ctrl+Shift+R or Shift+F5
Home page Alt+Home

5.1 Move Back and Forward

What you will learn: Return to recently visited pages within one tab.

Before you begin: Open one page, then follow a link to another.

Exactly how to do it

  1. Press Alt+Left Arrow.

  2. Listen for the previous page title.

  3. Press Alt+Right Arrow.

  4. Listen for the newer page title.

What should happen: Edge moves backward and forward through that tab's history.

If that does not happen: If nothing happens, there may be no previous/forward page in that tab.

Practice: Navigate through three pages and use Back/Forward.

Part 6 - Webpage Keyboard Navigation

Screen readers add structural webpage navigation, while Edge itself provides focus navigation with Tab and Shift+Tab.

6.1 Move Through Focusable Controls

What you will learn: Navigate links, buttons, and form fields without using screen-reader quick keys.

Before you begin: Open a webpage with several controls.

Exactly how to do it

  1. Press Ctrl+F6 to ensure focus is in web content.

  2. Press Tab.

  3. Listen for the link, button, field, or other control.

  4. Press Tab again.

  5. Press Shift+Tab to move backward.

  6. Press Enter on a link/button when you intentionally want to activate it.

  7. Use Spacebar on many checkboxes and buttons.

What should happen: Focus moves among interactive page elements.

If that does not happen: If Tab moves through browser controls rather than the page, press Ctrl+F6 first.

Practice: Move through ten controls without activating them.

Part 7 - Find on Page

Task Command
Find on page Ctrl+F
Next result Ctrl+G
Previous result Ctrl+Shift+G

7.1 Search Within the Current Webpage

What you will learn: Find visible page text without reading the whole page.

Before you begin: Open a long webpage.

Exactly how to do it

  1. Press Ctrl+F.

  2. Type a word that appears on the page.

  3. Press Enter if needed.

  4. Press Ctrl+G for the next occurrence.

  5. Press Ctrl+Shift+G for the previous occurrence.

  6. Press Escape to close Find.

What should happen: Edge moves through matching page text.

If that does not happen: If no results are found, check spelling or try a shorter phrase.

Practice: Find the same word three times on one page.

8.1 Save a Favorite

What you will learn: Save a webpage for later.

Before you begin: Open a safe webpage.

Exactly how to do it

  1. Press Ctrl+D.

  2. Review the proposed favorite name.

  3. Change the name if needed.

  4. Choose the folder/location.

  5. Activate Done/Save.

What should happen: The webpage is added to Favorites.

If that does not happen: If Ctrl+D opens another browser feature, verify Edge is the active app.

Practice: Favorite one practice site.

8.2 Open a Favorite

What you will learn: Navigate from the Favorites page/menu.

Before you begin: Have at least one favorite saved.

Exactly how to do it

  1. Press Ctrl+Shift+O.

  2. Use Tab/arrow keys through Favorites.

  3. Locate the desired site.

  4. Press Enter.

What should happen: The favorite opens.

If that does not happen: If a side pane appears rather than a full page, use F6/Tab to move into it.

Practice: Open a saved favorite and return.

Part 9 - History

9.1 Review Browser History

What you will learn: Find a page you visited earlier.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Ctrl+H.

  2. Move through the History pane/page using Tab and arrow keys.

  3. Search history if a search box is available.

  4. Press Enter on the desired history entry.

What should happen: The selected previously visited page opens.

If that does not happen: If private browsing was used, those pages should not appear in normal history.

Practice: Find and reopen one page from history.

Part 10 - Downloads

10.1 Open Downloads

What you will learn: Review downloaded files and their status.

Before you begin: Download a known-safe file or use an existing download.

Exactly how to do it

  1. Press Ctrl+J.

  2. Use Tab/arrow keys through downloads.

  3. Listen for filename and status.

  4. Use Open file, Show in folder, Delete/remove from list, or other actions only when appropriate.

What should happen: The Downloads interface opens and lists recent downloads.

If that does not happen: If the file is suspicious or unexpected, do not open it. Verify the source first.

Practice: Open Downloads and locate one known file.

Security: A downloaded file can be dangerous even if the webpage looked legitimate. Verify source, file type, and expected filename before opening.

Part 11 - Forms, Buttons, Checkboxes, and Combo Boxes

11.1 Fill a Web Form

What you will learn: Move through form controls and enter text.

Before you begin: Use a safe practice form.

Exactly how to do it

  1. Use your screen reader's form-field navigation or press Tab to the first field.

  2. Type in an edit field.

  3. Press Tab to the next control.

  4. For a checkbox, press Spacebar.

  5. For radio buttons, use Arrow keys.

  6. For a combo box/drop-down, press Alt+Down Arrow if needed, use arrows, then Enter.

  7. Review all entered information before activating Submit.

What should happen: The form fields contain the intended information.

If that does not happen: If letter keys navigate the page instead of typing, your screen reader may still be in browse/scan mode rather than focus/forms mode.

Practice: Complete a non-sensitive practice form.

Part 12 - Links and Opening New Tabs

Task Command
Open focused link in new background tab Ctrl+Enter in many Edge/link contexts
Open new tab Ctrl+T
Open context menu Shift+F10

12.1 Inspect a Link Before Opening

What you will learn: Reduce the risk of activating misleading links.

Before you begin: Focus a link.

Exactly how to do it

  1. Listen to the link text.

  2. Use your screen reader's link-information command if available.

  3. Press Shift+F10 if you need the link context menu.

  4. Choose Copy link only if you need to inspect or paste the address elsewhere.

  5. Open the link only if it matches the expected destination.

What should happen: You make a deliberate decision before navigating.

If that does not happen: If the link text is vague such as 'click here,' rely on screen-reader link details or the surrounding context.

Practice: Inspect three links on a known safe site.

Part 13 - PDFs in Edge

Microsoft Edge has a built-in PDF viewer. Screen-reader accessibility depends heavily on whether the PDF itself contains real text, tags, headings, and a logical reading order.

13.1 Open and Read a PDF

What you will learn: Use Edge's PDF viewer with a screen reader.

Before you begin: Open a known accessible PDF.

Exactly how to do it

  1. Open the PDF link or press Ctrl+O to open a local PDF file in Edge.

  2. Wait for the PDF viewer.

  3. Press Ctrl+F6 to move to content if needed.

  4. Use your screen reader's reading/navigation commands.

  5. Press Ctrl+F to search within the PDF.

  6. Press Ctrl+Plus/Minus to adjust zoom if needed.

What should happen: The PDF text is exposed to the screen reader.

If that does not happen: If the screen reader says very little or only 'image,' the PDF may be scanned or untagged and may require OCR or another accessible version.

Practice: Open one accessible PDF and search for a word.

PDF warning: Edge cannot make a badly structured PDF fully accessible just by opening it. If the document is image-only or has poor reading order, obtain an accessible version or use appropriate OCR/accessibility tools.

Part 14 - Read Aloud and Immersive Reader

Task Command
Start/stop Read Aloud Ctrl+Shift+U

14.1 Use Read Aloud

What you will learn: Have Edge speak webpage content independently of your screen reader.

Before you begin: Open a supported webpage.

Exactly how to do it

  1. Press Ctrl+Shift+U.

  2. Listen for Read Aloud to begin.

  3. Use the Read Aloud controls if you want to change voice/speed.

  4. Press Ctrl+Shift+U again to stop.

What should happen: Edge reads page content aloud.

If that does not happen: If nothing happens, the page may not support the feature or focus may be in a context where the shortcut is unavailable.

Practice: Start and stop Read Aloud.

14.2 Use Immersive Reader

What you will learn: Simplify supported webpage content.

Before you begin: Open a page that supports Immersive Reader.

Exactly how to do it

  1. Press F9.

  2. Wait for the simplified reading view.

  3. Navigate the content.

  4. Adjust text preferences if desired.

  5. Press F9 again to return.

What should happen: The page appears in a simplified reading layout.

If that does not happen: If F9 does nothing, that page may not support Immersive Reader.

Practice: Try F9 on two article-style webpages.

Part 15 - Caret Browsing

15.1 Turn Caret Browsing On and Off

What you will learn: Move a text cursor through webpage text using arrow keys.

Before you begin: Open a text-heavy webpage.

Exactly how to do it

  1. Press F7.

  2. If Edge asks whether to enable Caret Browsing, confirm.

  3. Use Arrow keys to move through text.

  4. Hold Shift while moving to select text.

  5. Press Shift+F10 on selected content when appropriate.

  6. Press F7 again to turn Caret Browsing off.

What should happen: A movable text caret appears/behaves within webpage content.

If that does not happen: If F7 triggers another laptop function, use Fn+F7.

Practice: Turn Caret Browsing on, select one word, then turn it off.

Part 16 - Accessibility Settings

Current Edge accessibility settings are under Settings and more > Settings > Accessibility.

16.1 Open Edge Accessibility Settings

What you will learn: Find browser accessibility options without searching through every settings page.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Alt+F or Alt+E to open Settings and more.

  2. Move to Settings and press Enter.

  3. Use the Settings navigation/search to open Accessibility.

  4. Review options such as page zoom, image descriptions for screen readers, high-visibility focus outline, captions, and related accessibility controls.

What should happen: The Accessibility settings page opens.

If that does not happen: If Accessibility is not immediately visible, use Settings search.

Practice: Open Accessibility and review every available setting.

16.2 Enable Image Descriptions for Screen Readers

What you will learn: Allow Edge to generate descriptions for unlabeled images using Microsoft's service.

Before you begin: Open Edge Settings > Accessibility.

Exactly how to do it

  1. Find Get image descriptions for screen readers.

  2. Turn it on.

  3. Confirm the consent prompt if shown.

  4. Open a webpage containing unlabeled images and use your screen reader to test.

What should happen: Edge may provide generated descriptions for otherwise unlabeled images.

If that does not happen: Generated descriptions can be imperfect and should not replace author-provided alt text. Do not rely on them for high-stakes interpretation.

Practice: Enable, test, and decide whether you want to keep the setting.

16.3 Enable High-Visibility Focus Outline

What you will learn: Make keyboard focus easier to locate visually for mixed visual/screen-reader use.

Before you begin: Open Accessibility settings.

Exactly how to do it

  1. Find Show a high visibility outline around the area of focus on the page.

  2. Turn it on.

  3. Open a webpage.

  4. Press Tab several times.

What should happen: Focused elements receive a temporary high-visibility outline.

If that does not happen: If you use no vision, this setting may not affect your screen-reader experience but can help sighted support people follow focus.

Practice: Turn it on and test.

Part 17 - Zoom, Full Screen, and Focus Visibility

Task Command
Zoom in Ctrl+Plus
Zoom out Ctrl+Minus
Reset zoom Ctrl+0
Full screen F11

17.1 Change Page Zoom

What you will learn: Increase or decrease visual page size without changing browser text itself.

Before you begin: Open any webpage.

Exactly how to do it

  1. Press Ctrl+Plus several times.

  2. Listen for Edge's zoom percentage if announced.

  3. Press Ctrl+Minus.

  4. Press Ctrl+0 to return to default.

What should happen: The page zoom changes and then resets.

If that does not happen: If browser controls also seem enlarged differently, verify you are changing page zoom rather than Windows display scaling.

Practice: Practice zooming and reset.

Accessibility: Screen-reader users may still benefit from zoom when using residual vision. Edge also allows a default page zoom under Accessibility settings.

Part 18 - Profiles, Sign-In, and Sync

Signing in to Edge can synchronize favorites, passwords, history, extensions, settings, open tabs, autofill information, and other selected data across devices.

18.1 Sign In to Edge

What you will learn: Connect Edge to a Microsoft account when desired.

Before you begin: Decide whether this is a personal or organization-managed device.

Exactly how to do it

  1. Move to the profile button using F6/Tab or browser toolbar navigation.

  2. Activate the profile button.

  3. Choose Sign in.

  4. Enter the Microsoft account credentials or select an available account.

  5. Complete verification if required.

  6. Review sync settings before enabling everything.

What should happen: Edge signs in and sync begins according to selected settings.

If that does not happen: If this is a shared/public device, do not enable persistent sync unless you fully understand the privacy implications.

Practice: Open profile settings and review sync categories.

Privacy: Sync can be convenient but can also copy sensitive browsing data, passwords, addresses, tabs, and settings between devices. Enable only the categories you intend to synchronize.

Part 19 - Privacy, Cookies, Passwords, and InPrivate

19.1 Open an InPrivate Window

What you will learn: Browse without saving normal local history/cookies after the session closes.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Ctrl+Shift+N.

  2. Listen for InPrivate mode.

  3. Browse as needed.

  4. Close the InPrivate window with Alt+F4 when finished.

What should happen: An InPrivate window opens.

If that does not happen: InPrivate does not make you anonymous to websites, your employer/school network, internet provider, or other monitoring systems.

Practice: Open and close one InPrivate window.

19.2 Review Saved Password Settings

What you will learn: Understand where Edge password settings live.

Before you begin: Open Edge Settings.

Exactly how to do it

  1. Use Settings search for Passwords.

  2. Open password/autofill settings.

  3. Review whether Edge offers to save passwords, autofill passwords, or use password-monitoring/security features.

  4. Do not expose or read stored passwords aloud in a public environment.

What should happen: You can locate password settings safely.

If that does not happen: If the browser asks to reveal a password, Windows/device authentication may be required.

Practice: Review settings without revealing a stored password.

Part 20 - Security and Phishing

  • Check the actual domain in the address bar before entering passwords or payment information.

  • Be suspicious of misspelled domains and unexpected subdomains.

  • Do not trust a site merely because it uses HTTPS; HTTPS protects the connection, not the site's honesty.

  • Use browser warnings seriously. Do not bypass SmartScreen/security warnings unless you independently know the site/file is safe.

  • Unexpected downloads should not be opened.

  • Never install an extension because a random webpage says it is required to view content.

  • Navigate to banking, email, government, and work sites using known addresses or trusted favorites rather than links in suspicious messages.

20.1 Verify a Site Before Signing In

What you will learn: Confirm the destination before entering credentials.

Before you begin: A page is asking for a username/password.

Exactly how to do it

  1. Press Ctrl+L.

  2. Read the full domain in the address bar.

  3. Confirm it is the expected organization's real domain.

  4. Press Escape to leave the address bar without changing it.

  5. Only then return to the form and sign in.

What should happen: You make the domain check before entering credentials.

If that does not happen: If the domain is unfamiliar, misspelled, shortened, or unexpected, do not sign in until independently verified.

Practice: Practice checking the domain of three known sites.

Part 21 - Narrator with Edge

Narrator's Scan Mode is designed for webpage reading and structural navigation.

Task Command

Next heading H in Scan Mode
Previous heading Shift+H
Next link Tab or Narrator/web navigation
Webpage summary Narrator+S

21.1 Navigate a Webpage with Narrator

What you will learn: Move by headings and interactive controls.

Before you begin: Narrator is on and Edge has a webpage open.

Exactly how to do it

  1. Press Ctrl+F6.

  2. Turn Scan Mode on with Narrator+Spacebar if needed.

  3. Press H to move to the next heading.

  4. Press Shift+H to move backward.

  5. Press Tab to move through focusable links/controls.

  6. Press Enter to activate a link.

  7. Press Narrator+S for a page summary when useful.

What should happen: Narrator moves through webpage structure.

If that does not happen: If letters type into a form instead of navigating, focus may be inside an edit field or Scan Mode may be off.

Practice: Navigate one page by headings, links, and summary.

21.2 Enter Text in a Form with Narrator

What you will learn: Switch from reading to typing.

Before you begin: Focus an edit field.

Exactly how to do it

  1. Press Enter or Tab into the field.

  2. If Scan Mode remains on and letters navigate, press Narrator+Spacebar to turn it off.

  3. Type the text.

  4. Press Tab to the next control.

  5. Turn Scan Mode back on when you return to normal page reading if needed.

What should happen: Typing goes into the form field rather than triggering navigation keys.

If that does not happen: If letters still navigate, verify the field has keyboard focus.

Practice: Complete a practice form.

22.1 Navigate a Webpage with NVDA

What you will learn: Use Browse Mode quick-navigation keys.

Before you begin: NVDA is running and Edge has web content.

Exactly how to do it

  1. Press Ctrl+F6.

  2. Make sure NVDA is in Browse Mode.

  3. Press H through headings.

  4. Press K through links.

  5. Press D through landmarks.

  6. Press E or F to find an edit/form field.

If that does not happen: If letters type instead of navigating, NVDA is probably in Focus Mode. Press NVDA+Space.

22.2 Type in Web Applications with NVDA

What you will learn: Use Focus Mode when a site needs direct keyboard interaction.

Before you begin: Move to an edit field or application control.

Exactly how to do it

  1. Press Enter or NVDA+Space to enter Focus Mode when necessary.

  2. Type/interact normally.

  3. Press NVDA+Space to return to Browse Mode when finished.

What should happen: The web app receives letter keys directly.

If that does not happen: If H/K still navigate the page while you intend to type, Focus Mode is not active or the control is not focused.

Practice: Practice entering and leaving Focus Mode.

If that does not happen: If quick-navigation letters continue to type after the form, exit Forms Mode.

Practice: Complete a non-sensitive practice form.

Part 24 - Braille Displays with Edge

Braille output is controlled by Narrator, NVDA, or JAWS. Edge provides the webpage accessibility tree that the screen reader converts to braille.

  • Braille should follow the focused link, form field, heading, browser control, or document text.

  • Routing keys can activate or position focus/caret depending on the screen reader and control.

  • Browse/Scan/Virtual mode affects what appears on braille just as it affects speech.

  • Long links and webpage text may require panning.

  • Poorly labeled web controls will also be poorly labeled in braille.

24.1 Test Braille with Edge

What you will learn: Verify browser controls, webpage content, and form entry.

Before you begin: Connect/configure the display through your screen reader.

Exactly how to do it

  1. Press Ctrl+L and confirm the address bar appears in braille.

  2. Open a webpage.

  3. Navigate to a heading and link and verify braille changes.

  4. Move to an edit field.

  5. Type using the braille keyboard if supported.

  6. Use a routing key if supported.

  7. Return to page navigation mode.

What should happen: Braille follows Edge and supports text entry according to the screen reader.

If that does not happen: If braille works in other apps but not Edge, verify the correct browser pane and screen-reader mode before changing braille settings.

Practice: Test address bar, heading, link, and edit field.

Part 25 - Troubleshooting

25.1 You Are Stuck in Browser Controls Instead of the Webpage

What you will learn: Move directly to web content.

Before you begin: Edge is open.

Exactly how to do it

  1. Press Escape to close menus/popups.

  2. Press Ctrl+F6.

  3. Listen for webpage content.

  4. Use your screen reader's heading command to confirm.

What should happen: Focus returns to the webpage.

If that does not happen: If Ctrl+F6 does not help, use F6/Shift+F6 through panes until web content is announced.

Practice: Move to toolbar and recover to content twice.

25.2 Letter Keys Type Instead of Navigating by Headings

What you will learn: Check screen-reader mode.

Before you begin: A webpage is open.

Exactly how to do it

  1. Narrator: turn Scan Mode on with Narrator+Spacebar.

  2. NVDA: switch to Browse Mode with NVDA+Space.

  3. JAWS: leave Forms Mode/return to Virtual Cursor.

  4. Make sure focus is not inside an edit field.

  5. Press H.

What should happen: H moves to a heading rather than typing.

If that does not happen: If the page has no headings, H may not move even though the mode is correct.

Practice: Practice mode recovery.

25.3 Letter Keys Navigate Instead of Typing in a Field

What you will learn: Enter direct-interaction mode.

Before you begin: Focus the edit field.

Exactly how to do it

  1. Narrator: turn Scan Mode off if needed.

  2. NVDA: enter Focus Mode.

  3. JAWS: enter Forms Mode.

  4. Type a short word.

  5. Press Tab when finished.

What should happen: Text appears in the field.

If that does not happen: If letters still navigate, the field may not actually have keyboard focus.

Practice: Practice switching modes in a safe form.

25.4 You Cannot Find a Download

What you will learn: Use Edge Downloads before searching the whole computer.

Before you begin: A file was downloaded recently.

Exactly how to do it

  1. Press Ctrl+J.

  2. Locate the filename.

  3. Listen for status.

  4. Choose Show in folder if needed.

  5. Confirm the file location.

What should happen: You find the downloaded file or its current status.

If that does not happen: If the download failed, Edge should show an error/status entry.

Practice: Locate two known downloads.

25.5 A PDF Is Not Readable

What you will learn: Determine whether the problem is the PDF rather than Edge.

Before you begin: Open the PDF.

Exactly how to do it

  1. Try Ctrl+F and search for a visible word.

  2. Use screen-reader reading commands.

  3. If no real text is exposed, inspect whether the PDF is image-only/scanned.

  4. Look for an accessible HTML or tagged-PDF version from the source.

  5. Use OCR tools only when appropriate and permitted.

What should happen: You identify whether the document itself lacks accessible text/structure.

If that does not happen: If another accessible PDF works correctly in Edge, the problem is likely the specific PDF.

Practice: Compare one accessible and one image-only PDF if available.

25.6 Edge Suddenly Feels Completely Different

What you will learn: Check pane, profile, zoom, and feature state before resetting anything.

Before you begin: Edge is open.

Exactly how to do it

  1. Press F6 and identify the current pane.

  2. Press Ctrl+0 to reset page zoom.

  3. Check whether you are in full screen with F11.

  4. Check whether Caret Browsing is on with F7.

  5. Check the active profile.

  6. Restart only after checking these states.

What should happen: The cause of the changed behavior becomes clearer.

If that does not happen: Do not reset all browser settings for a simple focus or mode problem.

Practice: Practice identifying zoom, full-screen, and Caret Browsing states.

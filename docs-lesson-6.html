Google Docs Lesson 6

Create and Navigate Accessible Tables

Google Docs manualAll Google Docs lessonsMy progress

Goal

Create a three-column contact schedule with fictional data.

Step-by-step instructions

  1. Use Insert, Table to create a small table with one header row.
  2. Enter concise column headings and consistent data.
  3. Do not merge cells or leave blank rows for spacing.
  4. Use Tab and Shift+Tab to move through cells.
  5. Add a short introduction before the table explaining its purpose.
  6. Read the table row by row with JAWS.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Create a three-column contact schedule with fictional data.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Docs-Lesson-6.

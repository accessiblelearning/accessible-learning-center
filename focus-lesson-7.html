Focus 40 Blue Lesson 7

Navigate Webpages, Forms, Lists, and Tables

Focus 40 Blue manualAll Focus lessonsMy progress

Goal

Document an accessible web-navigation practice session.

Step-by-step instructions

  1. Open Chrome and visit the Accessible Learning Center.
  2. Use JAWS quick navigation with the Focus to move by heading, link, list, form control, and table.
  3. Press a cursor router above a link and confirm it activates the intended item.
  4. Complete a practice form using fictional data and verify Forms Mode status.
  5. Navigate a simple table by row and column, listening to headers.
  6. Leave the page without submitting information to an external organization.

JAWS and braille tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Focus commands vary by device generation, JAWS settings, application, and connection method; use the official guide linked from the manual when a command differs.

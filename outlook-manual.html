Email, attachments, folders, search, contacts, and calendar tasks with a screen reader.

Move between Outlook areas

Keyboard command: In classic Outlook, Ctrl+1 usually opens Mail and Ctrl+2 usually opens Calendar.

What it does: Moves to a major Outlook area.

  1. Confirm Outlook is the active application.
  2. Press the command once.
  3. Ask your screen reader for the window title and focused control.
  4. Use Tab and Shift+Tab slowly to identify the folder list, item list, and reading area.

What you should hear: Outlook, the selected area, and a named folder, message, appointment, or control.

If that does not happen: You may be using new Outlook or Outlook on the web. Find the navigation control and use the labels announced in your version.

Create and review a message

Keyboard command: Ctrl+Shift+M commonly opens a new message.

  1. Press the command and confirm that a new message window opened.
  2. Move through To, Cc or Bcc when needed, Subject, and the message body.
  3. Write the message, then review every field before sending.
  4. Confirm recipients, subject, attachments, private information, and tone.

What you should hear: Separate accessible names for the recipient, subject, and message fields.

If that does not happen: Move backward and forward one control at a time. Do not enter an address until you hear the correct field name.

Reply or forward deliberately

Keyboard commands: Ctrl+R replies; Ctrl+Shift+R commonly replies to everyone; Ctrl+F forwards.

  1. Open the intended message and verify its sender and subject.
  2. Choose the command that matches your intended audience.
  3. Review all populated recipient fields.
  4. Remove quoted private information that should not be shared.

If that does not happen: Close the unsent draft, return to the original message, and confirm focus before trying again.

Search for a message

Keyboard command: Ctrl+E commonly moves to Search.

  1. Enter one useful clue such as a sender, subject word, or date.
  2. Move to the results and verify each message before opening it.
  3. Clear the search when finished so the complete folder is visible again.

If that does not happen: Find the current Search control with Tab or the ribbon. Search behavior differs between Outlook versions.

Handle attachments safely

Keyboard approach: From an open message, use Tab or Shift+Tab to locate the attachment list. Menus differ by Outlook version.

  1. Verify the sender and whether the file was expected.
  2. Listen to the complete filename and extension.
  3. Save a copy before editing when appropriate.
  4. Do not activate an unnamed or unexpected attachment.

If that does not happen: Use the message actions or attachment list rather than guessing from visual position.

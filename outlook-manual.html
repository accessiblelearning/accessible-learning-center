Basic how-tos

Open Mail and read a message

Keyboard commands: Ctrl+1 opens Mail in classic Outlook. Up Arrow and Down Arrow move through messages. Enter opens the selected message. Escape closes it.

  1. Press Ctrl+1.
  2. Use Tab or Shift+Tab until you hear a folder name or “message list.”
  3. Select Inbox, then press Tab if needed to reach its messages.
  4. Use the arrow keys to hear sender, subject, and date.
  5. Press Enter to open the intended message.
  6. Use your screen reader’s Say All command to read it. Press Escape to return.

You should hear: Inbox, the selected sender and subject, then the message window.

If that does not happen: Press Insert+T in JAWS or NVDA+T in NVDA to confirm the active window. New Outlook may use different navigation; locate the labeled Mail button with Tab.

Create and send a message

Keyboard command: Ctrl+Shift+M opens a new message. Alt+S sends it.

  1. Press Ctrl+Shift+M and confirm that a new-message window opens.
  2. Type the recipient in To and press Tab.
  3. Type a specific subject and press Tab until you reach the message body.
  4. Write the message.
  5. Press Shift+Tab to review the Subject and recipient fields, then return to the body.
  6. Press Alt+S only after the review is complete.

You should hear: To, Subject, and message fields announced separately.

If that does not happen: Do not type an address until the correct field is announced. Press Escape and choose to keep the draft if you need to start over.

Reply, reply to all, or forward

Keyboard commands: Ctrl+R replies. Ctrl+Shift+R replies to everyone. Ctrl+F forwards.

  1. Open and verify the original message.
  2. Choose the command for the audience you intend.
  3. Review every populated recipient field.
  4. Write your response and remove private quoted text when necessary.
  5. Press Alt+S to send.

If that does not happen: Close the unsent response, return to the original message, verify focus, and try once more.

Add an attachment

Keyboard command: Alt+N, A, F commonly opens Attach File in classic Outlook.

  1. Save and close the file you plan to attach.
  2. In the message, press Alt+N, then A, then F.
  3. Type or navigate to the file’s location.
  4. Select the file and press Enter.
  5. Use Shift+Tab and Tab to find the attachment and hear its full filename.
  6. Review recipients and subject before sending.

If that does not happen: Use the Insert or Attach File ribbon command. Do not send until the filename is announced.

Advanced how-tos

Search for a message

Keyboard command: Ctrl+E moves to Search.

  1. Press Ctrl+E.
  2. Type a sender, subject word, or phrase and press Enter.
  3. Move through results with the arrow keys.
  4. Open a result and verify its sender, subject, and date.
  5. Press Escape, then clear the search when finished.

If that does not happen: Find the Search field with Tab or the ribbon because search behavior varies by Outlook version.

Create and move to a folder

Keyboard commands: Ctrl+Shift+E opens Create New Folder in classic Outlook. Ctrl+Shift+V opens Move Item.

  1. Press Ctrl+Shift+E, type a clear folder name, choose its location, and confirm.
  2. Select a message you want to move.
  3. Press Ctrl+Shift+V.
  4. Choose the destination folder and press Enter.
  5. Open that folder and confirm the message arrived.

If that does not happen: Cancel before repeating. Verify which message and destination are selected.

Create a calendar appointment

Keyboard commands: Ctrl+2 opens Calendar in classic Outlook. Ctrl+Shift+A creates an appointment.

  1. Press Ctrl+2, then Ctrl+Shift+A.
  2. Enter a descriptive subject and location.
  3. Move through start date, start time, end date, and end time.
  4. Add useful notes and reminders.
  5. Review every field, then press Ctrl+S to save and close the appointment.

If that does not happen: Locate Calendar and New event by their announced labels in new Outlook or Outlook on the web.

Quick command list

  • Ctrl+1: Mail
  • Ctrl+2: Calendar
  • Ctrl+Shift+M: New message
  • Ctrl+R: Reply
  • Ctrl+Shift+R: Reply all
  • Ctrl+F: Forward
  • Ctrl+E: Search
  • Alt+S: Send
  • Ctrl+S: Save
  • F7: Check spelling

Version note: These commands are primarily for Outlook on Windows. Confirm the version and focused control before acting.

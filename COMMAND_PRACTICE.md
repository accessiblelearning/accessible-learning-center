# Command Practice courses

Updated September 30, 2026. Command Practice now supplies 1,258 exercises in 16 topic courses. Google Docs has 199. The complete course replaces the old five-command default, and teaches basic, intermediate and advanced commands in one session. Each new level has a visible label and one spoken/live-region transition. Existing category URLs remain valid; Word editing and VoiceOver subtopics resolve to their complete application courses.

`command-courses.js` contains the editable curriculum: command, task, teaching notes, input mode, and metadata containing level, official reference URL and ordered steps. Aliases share arrays rather than duplicate the curriculum. Every curriculum entry has a source link available during practice. Levels are pedagogical groupings, not vendor classifications. Coverage includes documented direct shortcuts, menu/ribbon access keys, selected multi-step sequences and contextual exercises. This is not a claim to include every version-specific, customizable, device-specific or mouse-dependent command.

Most application courses explicitly teach Windows desktop commands. Google Docs teaches Windows/Chrome commands and separate menu variants for other Windows browsers. VoiceOver teaches Mac commands. Narrator uses the standard layout; JAWS and NVDA use desktop layout with Insert as the screen-reader modifier. Learning Ally exercises standard control navigation instead of inventing unsupported universal Alt shortcuts. Braille display practice rehearses emulated keyboard commands, not universal display-button mappings. ZoomText speech commands are labeled separately from Fusion's JAWS speech.

The controller verifies every step of a sequence. Correct prefix steps do not award a completed command; errors leave the learner at the current step. Complete-command results retain errors for targeted retry. A builder lets the learner select modifier keys and a final key, including for sequences; this provides an alternative when assistive technology consumes physical keys. System and browser-reserved commands require the builder. The simulator does not open real application files, send messages, change system settings or assess whether an external application's outcome occurred. Results therefore say “Commands practiced.”

Speech and sound preferences remain in Settings. The superseded short/random command-course controls are hidden and excluded from keyboard navigation; their backing values remain compatible with earlier preferences. Every course uses ordered full-topic progression with short visible and spoken command explanations. Longer teaching notes are available in the collapsed “More explanation” section. Multi-step prompts retain the ordered key sequence and instructions to release keys or check each builder step.

Validation: 108 automated repository tests pass, including completing every expanded course, one transition per level, sequence scoring, wrong-step retry, real direct-key capture, protected input, all existing mission tests and learning assessments. Site validation checks 408 accessible pages. Chromium 153 completes all 199 Google Docs exercises in one session, records intermediate/advanced speech requests, checks direct Copy and the command builder, Mac course input, Escape navigation and 1100/390/320-pixel layouts. Browser screenshots were inspected, including builder contrast. Recorded speech requests are not a substitute for physical JAWS/NVDA/Narrator/VoiceOver audio and keyboard testing.

Official references are stored per exercise. Primary references include Google Docs keyboard shortcuts; Microsoft's Word, Excel, PowerPoint, Windows and Narrator command references; NV Access's current key commands; Mozilla's Firefox and Thunderbird shortcut guides; Freedom Scientific's JAWS and ZoomText hotkeys and Focus keyboard-command reference; Apple's VoiceOver command guide; and Bookshare's web-reader shortcuts. Content should be rechecked against these references when application versions or supported keyboard layouts change.

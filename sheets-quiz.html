Final quiz

Choose one best answer for each question based on the course material. There are two questions from each lesson and four choices per question. Question and answer order changes each time. There is no time limit. After grading, read the explanations and use the lesson links to review before retaking the quiz.

1. A spreadsheet is open, but the screen reader is not identifying cells as expected. What is the best initial check?
2. Two similarly named spreadsheets are open in different accounts. What should you confirm before entering work data?
3. You intend to format B2:B6, but only B2 is active. What must happen before applying the change?
4. A command changes the wrong worksheet. What context check would have prevented this?
5. A filled series was expected to increase, but every destination repeats the same value. What should you inspect?
6. You found a misspelled department name in several unrelated records. What should guide replacement?
7. B2:B4 contains 4, 6, and 8. Which result should =AVERAGE(B2:B4) return?
8. A total should include B2 through B6, but the formula uses B2:B5. What must be corrected?
9. A sheet has columns labelled Value, Value, and Value. What would most improve interpretation?
10. A cost of 12.5 should display as money with two decimals. Which change preserves its numeric usefulness?
11. You sort only the Names column of a table containing names and phone extensions. What can go wrong?
12. A filter shows three of ten records. Which conclusion is justified?
13. You want new Status entries chosen from New, Waiting, and Closed. Which approach fits?
14. A status formula should mark a target as met when completed work equals the requirement. Which boundary case must you test?
15. Monthly totals are 10, 15, and 20. Which chart summary best conveys the trend and values?
16. A chart's bars look reasonable, but its selected source range omits the last month. What should happen?
17. A recipient needs editable formulas and multiple worksheets. Which export is a better starting point than CSV or PDF?
18. A teammate only needs to inspect the tracker. Which permission is the least needed for that task?
19. Your exported tracker opens, but a status formula differs from the original. What should you do before delivery?
20. Which review best supports a usable shared-work tracker?

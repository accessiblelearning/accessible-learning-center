Purpose and setup

This manual supports independent practice with Cybersecurity for Screen Reader Users on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Ten-lesson learning path

  1. Lesson 1: Recognize Common Digital Threats — Classify five fictional workplace messages and explain the risk.
  2. Lesson 2: Strong Passwords and Password Managers — Create a password-policy checklist using examples that are not real passwords.
  3. Lesson 3: Multifactor Authentication and Recovery — Design a fictional MFA and recovery plan without secret codes.
  4. Lesson 4: Phishing Emails, Texts, and Calls — Analyze four fictional phishing examples with screen-reader steps.
  5. Lesson 5: Safe Links, Downloads, and Attachments — Create a safe-download checklist for a fictional employee.
  6. Lesson 6: Privacy, Permissions, and Data Handling — Classify fictional data and choose a safe handling method.
  7. Lesson 7: Updates, Backups, and Device Security — Create a weekly device-security routine.
  8. Lesson 8: Public Wi-Fi and Remote Work — Write a secure remote-work plan for a fictional trip.
  9. Lesson 9: Incident Reporting and Account Recovery — Create a concise incident report from a fictional scenario.
  10. Lesson 10: Final Accessible Security Scenario — Submit a full screen-reader-friendly cybersecurity response plan.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Use the course’s private assignment uploader only for the requested practice file.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

First-time keyboard guide

Use this short routine before following the Google Drive, Gmail, Forms, and Classroom Manual procedures. It explains exactly how the keyboard directions in this manual work.

Press a single key

  1. Find the named key without pressing it if possible.
  2. Press and release the key one time. Do not hold it unless the step specifically says to hold it.
  3. Stop and listen to the full screen-reader announcement before pressing another key.

Press a keyboard combination

  1. When a command contains a plus sign, such as Ctrl+S, hold down the first key.
  2. While continuing to hold the first key, press and release the final key once.
  3. Release the first key. The plus sign is not a key and should not be pressed.
  4. Listen for the expected result described in the procedure. If nothing changes, verify that the correct application or webpage has focus and try the command once more.

Press a sequence of keys

  1. When keys are separated by commas or the word “then,” press and release them in order instead of holding them together.
  2. After each key, listen for a menu, tab, control, or new screen before continuing.
  3. If the announcement does not match the step, press Escape once to close the current menu or dialog and restart that procedure.

Know which navigation key to try

  • Tab and Shift+Tab: move forward and backward among buttons, links, fields, and other controls.
  • Arrow keys: move inside menus, lists, groups of choices, text, and many screen-reader reading views.
  • Enter: opens the selected item or activates the focused command.
  • Space: activates many buttons and checks or clears checkboxes. In a text field, Space types a space.
  • Escape: cancels or closes the current menu, list, or dialog without intentionally accepting a change.

Verify before moving on

  1. Listen for the window, page, or application name so you know where focus is.
  2. Perform only one numbered step.
  3. Compare what the screen reader announces with the “What should happen” information in the procedure.
  4. If the result is wrong, stop. Use the procedure’s recovery directions, Escape to cancel, or Ctrl+Z to undo when that command is supported.
  5. Continue only after you can identify the result. Save completed work with Ctrl+S whenever the application supports saving.

Basic how-tos

Google Drive: open a file

What you will learn: Complete google drive: open a file independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Tab and Shift+Tab move among controls. Arrow keys move within a file list. Enter opens the selected item.

  1. Open drive.google.com and confirm the Google account.
  2. Use your screen reader’s heading command to find My Drive or Shared with me.
  3. Press Tab until the file list is announced.
  4. Use arrow keys to select a file and listen for its name, type, owner, and modified date.
  5. Press Enter to open it.

What should happen: A file-list item followed by the file’s name and details.

If that does not happen: Press Escape once to leave an open menu, then navigate by headings or landmarks back to the file area.

Practice: Repeat google drive: open a file with a second safe practice item, then explain the commands you used.

Google Drive: upload a file

What you will learn: Complete google drive: upload a file independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Use heading and button navigation to find New, then choose File upload.

  1. Open the Drive folder that should receive the file.
  2. Find and activate the New button.
  3. Choose File upload.
  4. In the file picker, type the complete path or navigate to the file.
  5. Select it and press Enter.
  6. Wait for the upload-complete announcement, then locate the file in Drive.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Do not upload again immediately. Search the folder for the filename and check for an upload-status alert.

Practice: Repeat google drive: upload a file with a second safe practice item, then explain the commands you used.

Gmail: read and reply

What you will learn: Complete gmail: read and reply independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Tab moves through controls. Enter opens a focused message. Ctrl+Enter may send only when that Gmail confirmation setting is enabled.

  1. Open Gmail and confirm the correct account and Inbox.
  2. Navigate to the message list and select the intended sender and subject.
  3. Press Enter and read the full message.
  4. Find and activate Reply.
  5. Write the response and review quoted content.
  6. Find the Send button and activate it.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Navigate by headings and buttons. Do not rely on single-letter shortcuts until Gmail keyboard shortcuts are enabled in Settings.

Practice: Repeat gmail: read and reply with a second safe practice item, then explain the commands you used.

Gmail: compose a new message

What you will learn: Complete gmail: compose a new message independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: C opens Compose only after Gmail keyboard shortcuts are enabled.

  1. Activate Compose by its labeled button, or press C if shortcuts are enabled.
  2. Enter the recipient, press Tab, and enter the subject.
  3. Move to the message body and write the message.
  4. Locate any attachment and verify its filename.
  5. Review recipients, subject, and body, then activate Send.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Use Tab and Shift+Tab to locate each labeled field. Escape may close the compose window while saving a draft.

Practice: Repeat gmail: compose a new message with a second safe practice item, then explain the commands you used.

Advanced how-tos

Google Drive: share with one person

What you will learn: Complete google drive: share with one person independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: Shift+F10 opens the selected file’s context menu in supported browsers and configurations.

  1. Select the exact file and hear its complete name.
  2. Press Shift+F10 and choose Share.
  3. Enter the person’s email address.
  4. Choose Viewer, Commenter, or Editor deliberately.
  5. Review the recipient and permission, then send the invitation.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Cancel the dialog and locate the labeled Share button. Never choose “Anyone with the link” by accident.

Practice: Repeat google drive: share with one person with a second safe practice item, then explain the commands you used.

Google Classroom: submit an assignment

What you will learn: Complete google classroom: submit an assignment independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Navigate by headings, links, and buttons; Enter or Space activates the focused control.

  1. Open the class and verify the assignment heading.
  2. Read all instructions, due information, and attached resources.
  3. Find Your work, then Add or create.
  4. Add the correct Drive file or upload a file.

  6. Read the confirmation dialog and confirm only when correct.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Return to the assignment heading and inspect controls in reading order. Verify whether the work says Assigned, Turned in, or Returned.

Your first complete Google keyboard session

This walkthrough teaches the browser and account checks that come before Drive, Gmail, Forms, or Classroom tasks.

  1. Open Chrome or Edge, press Ctrl+L, type google.com, and press Enter.
  2. Press the screen reader’s heading or landmark navigation command to locate the Google account area. Confirm the announced account before opening private work.
  3. If the wrong account is active, open the account menu, choose the correct account, and wait for the page to reload. Do not upload or send anything until the account is verified.
  4. Press Ctrl+L, type drive.google.com, and press Enter. Wait for Drive’s main region to load.
  5. Use Tab to locate New, press Enter, and use arrow keys to choose New folder. Type Google Practice and press Enter.
  6. Open the folder, create a Google Doc, type one sentence, and press Ctrl+S only as a verification habit—Google Docs saves automatically and should announce that the document is saved to Drive.
  7. Rename the document with a descriptive practice name. Return to Drive with Alt+Left Arrow and confirm that the file appears in the Google Practice folder.
  8. Press Ctrl+L, type mail.google.com, and press Enter. Locate Compose, but address the practice message only to yourself.
  9. Enter a subject that begins with Practice:, write one sentence, review the To, Subject, and message fields with Shift+Tab and Tab, and activate Send.
  10. Open the received message and verify the sender, subject, and body. Delete the message and the practice Drive folder when finished.

Success check: You confirmed the account, created and located a Drive item, and sent a reviewed message without relying on the mouse.

Quick command list

  • Tab / Shift+Tab: next or previous control
  • Enter: open or activate
  • Space: activate a button or change a checkbox
  • Escape: close a menu or dialog
  • Shift+F10: context menu
  • Ctrl+F: browser Find, not Drive search
  • C in Gmail: Compose, when Gmail shortcuts are enabled
  • R in Gmail: Reply, when Gmail shortcuts are enabled

Google communication and classroom skills

Google Drive, Gmail, Forms, and Classroom

Use common Google services with keyboard and screen-reader verification.

DriveGmailFormsClassroom

Google Drive: find and identify a file

Keyboard command: In most browsers, Ctrl+F uses browser Find; use Drive's labeled Search field when you need a Drive search.

  1. Confirm the active Google account.
  2. Identify whether you are in My Drive, Shared with me, or another location.
  3. Search using part of a filename or move through the file list.
  4. Verify the file name, owner, type, and location before opening or sharing.

What you should hear: A named search field or file-list item with its accessible details.

If that does not happen: Navigate by headings, landmarks, and form fields. Do not assume a shortcut and an owned file are the same thing.

Gmail: compose without sending accidentally

Keyboard command: Gmail's single-letter shortcuts require the Keyboard shortcuts setting. Use the Compose button until you have confirmed that setting.

  1. Activate Compose and confirm the new-message dialog.
  2. Move through recipients, subject, and message body.
  3. Add any attachment before the final review.
  4. Review every field and activate Send only when ready.

If that does not happen: Use Tab and Shift+Tab to locate the labeled fields. Escape may close a dialog, so listen for whether the draft was saved.

Google Forms: create an accessible question

Keyboard approach: Use Tab and Shift+Tab to move among labeled editor controls; use the announced Add question control instead of relying on screen position.

  1. Give the form a descriptive title and instructions.
  2. Add a question with a complete label.
  3. Choose a response type that matches the information requested.
  4. Set Required only when a response is genuinely necessary.
  5. Preview and complete the form with only the keyboard.

If that does not happen: Confirm whether focus is in the form editor, question text, toolbar, or preview.

Google Classroom: distinguish instructions and submission state

Keyboard approach: Navigate by headings, links, buttons, and form controls.

  1. Confirm the class and assignment title.
  2. Read the complete instructions and attached resources.
  3. Distinguish class comments from private comments.
  4. Before turning in work, verify the attached file and submission state.

If that does not happen: Return to the assignment heading and inspect each control in reading order. Never assume a visually nearby file belongs to the current assignment.

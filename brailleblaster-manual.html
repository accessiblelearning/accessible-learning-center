Purpose and setup

This manual supports independent practice with BrailleBlaster on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Basic and advanced how-tos

Open a source and save an editable project

Keyboard commands: Ctrl+O opens a file. Ctrl+S saves. Ctrl+Shift+S opens Save As.

  1. Open BrailleBlaster and press Ctrl+O.
  2. Select a practice DOCX, HTML, TXT, or supported source file.
  3. Confirm the print and braille views contain the expected text.
  4. Press Ctrl+Shift+S and save an editable BBZ project.
  5. Close and reopen the BBZ to confirm it works.

If that does not happen: Keep the source unchanged and record the import error, file type, and BrailleBlaster version.

Navigate and apply document structure

Keyboard commands: Ctrl+Home moves to the beginning, Ctrl+End to the end, and Ctrl+G opens Go To Page.

  1. Work in the Print View.
  2. Move to a real section heading in the source.
  3. Select only the heading text.
  4. Use the Styles menu to apply the correct heading style.
  5. Review the corresponding Braille View and repeat for lists and indented material.
  6. Save the BBZ project.

If that does not happen: Undo the style and confirm the selection does not include adjacent body text.

Insert and verify a page break

Keyboard command: Ctrl+Enter inserts a page break after the cursor when text follows it.

  1. Save the project.
  2. Place the cursor immediately before the text that should begin the new braille page.
  3. Press Ctrl+Enter.
  4. Check the Braille View and page numbers on both sides of the break.
  5. Undo if the break divides a heading from its following text.

If that does not happen: Confirm text exists after the cursor and use Edit, Page Break.

Enter six-key braille

Keyboard command: Alt+X toggles Six Key Mode. F, D, S represent dots 1, 2, 3; J, K, L represent dots 4, 5, 6.

  1. Save and place the cursor in Print View.
  2. Press Alt+X and confirm Six Key Mode.
  3. Chord FDS and JKL combinations to enter a short braille sample.
  4. Compare Print View and Braille View.
  5. Press Alt+X again to leave Six Key Mode.

If that does not happen: Some keyboards cannot register the required simultaneous keys; use a compatible keyboard or the menu.

Correct one translation and export BRF

Keyboard command: Ctrl+T opens Correct Braille Translation for selected print text.

  1. Proofread the source and braille views before making a correction.
  2. Select only the incorrectly translated word or character in Print View.
  3. Press Ctrl+T, enter the intended braille in the Braille field, and confirm.
  4. Recheck surrounding text and save the BBZ.
  5. Use the File menu to save or export a separate BRF.
  6. Open the BRF on a braille display and verify headings, page numbers, breaks, and final lines.

If that does not happen: Keep the BBZ and source copies; do not overwrite the editable project with the exported file.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Save the requested practice file locally with the exact filename given in the lesson. Assignment uploads are currently paused.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

Basic procedure

1. Interface, Open, and Save a BBZ Project

What you will learn: Create a project log describing the interface and saved BBZ file.

Before you begin: Open BrailleBlaster with an instructor-provided or original practice document. Save a separate working copy before changing structure or formatting.

Exactly how to do it

  1. Open BrailleBlaster and identify the text, braille, and style areas.
  2. Use File, Open to open an instructor-provided accessible source.
  3. Navigate by heading or line with JAWS.
  4. Use Save As and preserve the original source.
  5. Save the working project as BrailleBlaster-Lesson-1.bbz.
  6. Close and reopen the BBZ project.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a project log describing the interface and saved BBZ file.

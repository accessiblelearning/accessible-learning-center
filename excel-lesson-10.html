Excel Lesson 10

Final Employment Workbook Project

Excel manual All Excel lessons My progress

Goal

Independently build an accessible workbook that organizes, calculates, summarizes, and communicates workplace information.

Skills practiced

  • Plan an accessible table structure.
  • Use formulas and functions accurately.
  • Organize multiple worksheets.
  • Create an accessible summary for a supervisor.

Step-by-step instructions

  1. Create a workbook for a fictional department's monthly supply budget.
  2. Create a Purchases worksheet with the headers Date, Item, Category, Quantity, Unit Cost, and Line Total.
  3. Enter at least ten fictional purchases across at least three categories.
  4. Use a formula to calculate each Line Total.
  5. Format dates and currency appropriately without merging cells.
  6. Convert the purchase list to a table and give it a meaningful name.
  7. Create a Summary worksheet.
  8. Calculate the grand total, average line total, lowest line total, and highest line total.
  9. Use COUNTIF to count at least one category or status.
  10. Create one simple chart from summary data, add meaningful alt text, and keep its source data available.
  11. Add a plain-text summary that explains the most important result.
  12. Run the Accessibility Checker and review every worksheet using only the keyboard.
  13. Save the workbook as Excel-Lesson-10-Final.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Your assignment

Complete an accessible monthly supply-budget workbook with at least ten purchases, formulas, a table, summary calculations, a chart with alt text, and a written summary.

Save the finished assignment as Excel-Lesson-10-Final.xlsx.

Before submitting

  • The Purchases worksheet contains at least ten complete records.
  • All line totals and summary calculations use formulas.
  • The workbook includes a clearly named Summary worksheet.
  • The chart has alt text and its source data remains available.
  • There are no merged cells or color-only instructions.
  • The Accessibility Checker was reviewed.
  • The file is saved as Excel-Lesson-10-Final.xlsx.

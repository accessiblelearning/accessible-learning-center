Microsoft Word Lesson 2

Moving, Selecting, and Editing Text

Goal

Practice moving through text, selecting words, correcting mistakes, copying, cutting, pasting, undoing, and redoing.

Instructions

  1. Open Microsoft Word and create a blank document.
  2. Type: The quick brown fox jumps over the lazy dog.
  3. Press Enter twice.
  4. Type: Microsoft Word makes document editing easy.
  5. Use Ctrl+Left Arrow and Ctrl+Right Arrow to move by word.
  6. Use Left Arrow and Right Arrow to move by character.
  7. Select the word easy using Ctrl+Shift+Left Arrow or Ctrl+Shift+Right Arrow.
  8. Replace easy with efficient.
  9. Select the words Microsoft Word.
  10. Press Ctrl+C to copy them.
  11. Move to the end of the document.
  12. Press Enter twice and press Ctrl+V.
  13. Press Ctrl+Z to undo the paste.
  14. Press Ctrl+Y to redo it.
  15. Save the file as Word-Lesson-2.docx.

Your Assignment

Submit Word-Lesson-2.docx.

Before Submitting

  • The word easy should have been replaced with efficient.
  • Microsoft Word should appear again at the bottom of the document.
  • The file should be saved correctly.

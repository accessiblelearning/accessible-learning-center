PowerPoint Lesson 6

Accessible Tables and Charts

PowerPoint manual All PowerPoint lessons My progress

Goal

Present structured data with clear headers, accessible descriptions, and a text summary.

Skills practiced

  • Insert a simple table.
  • Use a header row.
  • Create a chart from clear source data.
  • Add alt text and a text equivalent.

Step-by-step instructions

  1. Create a presentation titled Monthly Training Report.
  2. Add a slide titled Training Completion Table.
  3. Use Alt+Q to find Insert Table. Create a table with three columns and five rows.
  4. Enter the headers Month, Enrolled, and Completed in the first row.
  5. Enter fictional data for January through April.
  6. Confirm that the first row is designated as a header row through Table Design options.
  7. Add a slide titled Completion Trend.
  8. Create a simple chart from the same data using Insert Chart and its data worksheet.
  9. Add alt text describing the chart's purpose and main trend.
  10. Keep the table slide so exact values remain available.
  11. Add a short text statement on the chart slide summarizing the trend without relying on color.
  12. Run Check Accessibility and review the table and chart.
  13. Save the presentation as PowerPoint-Lesson-6.pptx.

Keyboard help: Press Alt+Q to search PowerPoint commands when Ribbon KeyTips differ. For JAWS help, press Insert+Spacebar, then J, and search for the task.

Your assignment

Create a training report containing an accessible table, a chart with alt text, and a plain-text trend summary.

Save the finished assignment as PowerPoint-Lesson-6.pptx.

Before submitting

  • The chart has meaningful alt text.
  • Exact values remain available in the table.
  • The trend is explained in text.
  • The file is saved as PowerPoint-Lesson-6.pptx.

Microsoft Word Lesson 9

Spelling, Comments, and Track Changes

Goal

Practice reviewing a document using Word's spelling, comment, and revision tools.

Instructions

  1. Create a new document.
  2. Type: This sentance contains a spelling mistake.
  3. Press F7 to open Editor or spelling and grammar review.
  4. Correct sentance to sentence.
  5. Type another paragraph containing at least two sentences.
  6. Select one word or phrase.
  7. Press Ctrl+Alt+M to create a comment.
  8. Type: Review this section.
  9. Post the comment.
  10. Press Ctrl+Shift+E to turn on Track Changes.
  11. Add one word to the paragraph.
  12. Delete one word.
  13. Press Ctrl+Shift+E again to stop tracking new changes.
  14. Use the Review tab to inspect the tracked changes.
  15. Accept one change.
  16. Reject the other change.
  17. Save as Word-Lesson-9.docx.

Your Assignment

Submit Word-Lesson-9.docx.

Before Submitting

  • The spelling error should be corrected.
  • The document should contain a comment.
  • You should have practiced Track Changes.
  • One change should have been accepted and one rejected.

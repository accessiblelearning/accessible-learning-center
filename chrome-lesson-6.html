Chrome Lesson 6

Downloads, Uploads, and File Verification

Chrome manualAll Chrome lessonsMy progress

Goal

Download and upload files while confirming names, types, and locations.

Step-by-step instructions

  1. Use only a trusted practice page offering a harmless file.
  2. Before downloading, confirm the link text, source website, and expected file type.
  3. Activate the download and press Ctrl+J to open Downloads.
  4. Review the file name and status. Use Show in folder when available.
  5. In File Explorer, verify the extension and use Alt+Enter to review Properties.
  6. Do not open a file if the name or type differs from what was expected.
  7. Return to a lesson submission page in Chrome.
  8. Activate Choose File, select a non-sensitive practice document, and confirm the selected file name before submitting.
  9. Cancel the upload if the wrong file is selected; never upload client or confidential information.
  10. Create Chrome-Lesson-6.txt with the download-and-upload safety checklist.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

Your assignment

Create the report described above using fictional or public information only.

Save it as Chrome-Lesson-6.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • Source, file name, extension, and location checks are included.
  • The report explains how to cancel a wrong selection.
  • Confidential-information protection is addressed.
  • The file is Chrome-Lesson-6.txt.

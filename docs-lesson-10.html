Google Docs Lesson 10

Final Accessible Workplace Document

Google Docs manualAll Google Docs lessonsMy progress

Goal

Create a complete accessible employee onboarding procedure using fictional information.

Step-by-step instructions

  1. Plan a two-page workplace procedure with a clear audience and purpose.
  2. Use a descriptive title and logical heading hierarchy.
  3. Include one real list, one simple table, and two meaningful links.
  4. Add image alternative text if an image is included.
  5. Run a keyboard and screen-reader review from beginning to end.
  6. Download the final document as DOCX and verify its filename.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Create a complete accessible employee onboarding procedure using fictional information.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Docs-Lesson-10.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Google Docs Lesson 10.

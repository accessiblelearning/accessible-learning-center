Google Docs Lesson 7

Links, Images, and Alternative Text

Google Docs manualAll Google Docs lessonsMy progress

Goal

Create a resource sheet with two meaningful links and one described image.

Step-by-step instructions

  1. Select meaningful link text and press Ctrl+K.
  2. Enter a public web address and avoid text such as click here.
  3. Insert an image only when it supports the document purpose.
  4. Open image options and add concise alternative text where available.
  5. Mark purely decorative images as decorative when the option exists.
  6. Read the surrounding paragraph and link text without viewing the image.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Create a resource sheet with two meaningful links and one described image.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Docs-Lesson-7.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Google Docs Lesson 7.

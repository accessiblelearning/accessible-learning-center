First-time learner: how to follow a task

Read the task title and its starting location before pressing anything. A keyboard command acts on the active application and focused control. Merely having these instructions visible does not make the other application active.

  1. Keep these instructions available. Open the application separately. On Windows, hold Alt, tap Tab to choose its window, and release Alt. Check the window title before continuing.
  2. Focus is the place receiving your next keystroke. A screen reader announces its name and role; a visible border or highlight may mark it. Tab selects the next keyboard-accessible control. Shift+Tab reverses that movement. Neither command means “activate.”
  3. At a button or link, press Enter to activate. A checkbox is an on/off choice: Space changes it. Listen for checked or not checked. In an open menu, use arrows to select an item, then Enter. Escape usually closes that menu; it does not universally return to the previous page.
  4. At a text field, enter only the requested information. Ctrl+A selects all text in that field; typing then replaces it. Confirm focus before doing this. Use Left and Right to review a small correction, or Backspace to remove the character before the cursor.
  5. After opening a dialog, listen to its title, read its instructions, and Tab through its controls. Use Cancel if you are unsure. Do not repeatedly activate a button while a page or file is loading.
  6. At the result checkpoint, stop. Say what changed. If the result is different, use that task’s recovery paragraph before attempting the next task.

With a screen reader, arrow-key reading and text editing can use different modes. If letters become navigation commands instead of text, confirm you reached an editable field and consult your reader’s forms/focus-mode instructions in the Screen Readers manual. Do not turn the reader off to solve an unidentified focus problem.

When a task says to locate a named control, start with Tab or Shift+Tab and listen to each complete label and role. Tab skips ordinary paragraphs. If the page itself needs to be read, use your screen reader’s reading commands. If you pass the same controls twice without finding the requested one, stop and check the application, page, account, and open dialogs. A fixed number of Tab presses is unreliable because layouts change.

Recording progress: Write down the task, your starting location, the result, and one step to practice again. These activities are optional and repeatable; they are not a sequence of locked lessons.

Before you begin

You need Thunderbird installed, an existing email account, an internet connection for account setup and sending, and access to your provider's sign-in verification method. On a workplace computer, ask your technology team whether this email application is permitted before connecting a work account.

Begin with a personal practice account or a draft with no recipient. Use made-up practice content. Do not use client records in exercises.

Read the keyboard directions

A plus sign means hold the modifier while pressing the final key. For Ctrl+Shift+A, hold Control and Shift, tap A, then release all three. Do not type the plus sign. “Then” means separate actions. Pause after each action and listen before continuing. If your laptop uses function keys for volume or brightness, you may need its Fn key.

Tab moves among controls; Shift+Tab moves backward. Follow the announced control names instead of counting a fixed number of Tab presses. Read this manual in your browser, then switch to Thunderbird before practicing. A command sent to the browser can do something entirely different.

For screen-reader modes and recovery, review the Screen Readers manual and Recovery manual.

Email terms before you start

Email provider and Thunderbird
Your provider operates your mailbox. Thunderbird is an application for accessing it; installing Thunderbird does not create an email address.
Account, folder, and message
An account is a mailbox identity. Its folders organize messages. Select the account’s Inbox before choosing a message; two accounts can each have an Inbox.
Draft, Sent, and Outbox
A draft is unfinished mail. Sent normally stores a copy after sending. An Outbox can contain mail waiting to be sent. A saved draft is not evidence of delivery.
Attachment
A separate file included with a message. Its filename is different from the subject. Check both before sending.
Thread
A grouped conversation. A collapsed thread can conceal replies; expand it with the list’s available controls before concluding a reply is missing.

Install and open Thunderbird on Windows

Start here: A supported Windows computer, an internet connection, and permission to install applications. Have your existing email address available.

Step-by-step instructions

  1. Open your browser. Go to Thunderbird’s official website. Locate its download option and choose the Windows installer. Do not use a sponsored download site.
  2. After the download finishes, open the installer from your browser’s downloads list. Read the Windows permission prompt. Continue only if it identifies the application you intended to install; a managed device may require your technology team.
  3. Follow the installer’s labeled Next or Install controls. Leave options you do not understand at their defaults. Finish the installation and open Thunderbird.
  4. If Thunderbird is installed already, press the Windows key, type Thunderbird, review the matching application name, and press Enter. Continue with “Connect an existing email account” below.

Check your result

The Thunderbird application is open. You may see account setup instead of a mailbox on the first launch.

If something goes wrong

A browser tab showing Thunderbird’s website is not the installed application. Use the Windows application search to verify. If installation is blocked, retain the error and ask the device administrator.

Try it yourself

Point out which window is the browser and which is Thunderbird before entering account information.

Documentation: Mozilla installation instructions.

1. Connect an existing email account

What you will learn: Connect your account and reach your mailbox without guessing server settings.

Exactly how to do it

  1. Open Thunderbird. A new installation offers account setup. Otherwise, open its application menu and choose New Account, then Existing Email. Use Tab to reach the menu, Enter to open it, and arrow keys to explore.
  2. Enter the requested display name, complete email address, and password. Review each field before moving on.
  3. Activate Continue. Wait for the provider configuration results.
  4. Review the account and connection choices. IMAP is normally the proposed option. If automatic setup fails, obtain the exact settings from your provider or technology team.
  5. Activate Done when the settings are correct. If your provider opens a sign-in window, complete its authentication and review the requested access.
  6. Allow time for folders and messages to arrive.

What should happen: Your account and folders become available.

If that does not happen: Read the actual sign-in or configuration error before retrying. Never replace server names with guesses.

Source: Mozilla account configuration

2. Find your place and read a message

  1. Press F6 to move between major areas; Shift+F6 moves backward.
  2. Find the folder pane. Select Inbox with arrow keys.
  3. Move to the message list. Choose a message with Up or Down.
  4. Press Enter to open it. Read with your screen reader's reading commands.
  5. Close the opened message tab with Ctrl+W. Confirm the mailbox is active before continuing.

Practice: Explain aloud whether you are choosing a folder, choosing a message, or reading its contents. If you cannot name the area, pause rather than issuing a deletion or reply command.

Source: Mozilla keyboard shortcuts

3. Write, review, and save a draft

Start here: Thunderbird’s main mail window, with an account connected. This first exercise will not be sent.

Step-by-step instructions

  1. Press Ctrl+N to open a composition window. Confirm that a new message is active, rather than a folder or browser search field.
  2. Leave To empty for this exercise. Tab until Subject is announced. Type “Email practice — draft only.” Tab to the editable message body.
  3. Type a greeting, two practice sentences, and your name. Press Enter between paragraphs. Read back what you wrote using your normal text-reading method.
  4. Use Shift+Tab or Tab to review Subject and the recipient area. Confirm that no recipient has accidentally been added. Return to the body if you need to correct a sentence.
  5. Press Ctrl+S. Wait for saving to finish. Close only the composition window with Ctrl+W; if asked whether to save changes, choose Save.
  6. In the main window, use F6 to locate the folder pane. Use arrows to reach this account’s Drafts folder. Move to its message list with F6, select your subject, and open it with Enter.
  7. Verify that the subject and both sentences are still present. Save again after any changes.

Check your result

You can reopen your unfinished message. It remains a draft and has not been sent.

If something goes wrong

If Drafts appears empty, check the account and clear any active filter. If the composition window is still open, return there and save again. Do not use Send to make a draft appear in a folder.

Try it yourself

Change one sentence, save, close, and reopen the same draft. Explain how saving differs from sending.

Documentation: Writing and saving messages.

4. Add and verify a practice attachment

Start here: An open practice draft and a small, harmless file named email-practice.txt. Know the folder containing it.

Step-by-step instructions

  1. Press Ctrl+Shift+A in the composition window. Confirm that the file-selection dialog opens.
  2. If you know the file’s full path, Tab to File name, enter that path, and activate Open. Otherwise use the dialog’s folder navigation to reach its containing folder, select the filename, and activate Open. Selecting a folder only navigates; it does not attach a file.
  3. Back in the draft, locate the attachment area with Tab or Shift+Tab. Review the exact filename. If it is the wrong file, select that attachment and use its context menu to remove it. Confirm the attachment item has focus before deleting anything.
  4. Reattach the intended file and save the draft. Before sending an actual document, open the original file separately and verify its contents as well as its name.
  5. When receiving an attachment, identify its sender, message context, and filename before opening it. Use its available Save action if you want a local copy; note the destination folder and any rename you make.

Check your result

The draft lists exactly the file you intended. You can distinguish the attached copy from the original file on your computer.

If something goes wrong

If the file picker says the item cannot be found, check the path and extension. Cancel and locate the file in File Explorer instead of choosing another similarly named document. Large attachments may exceed your provider’s limit.

Try it yourself

Attach, remove, and reattach the practice file without deleting its original on disk.

Documentation: Attachment shortcut.

5. Find a message without losing the rest of your inbox

  1. Select the folder you want to search.
  2. Press Ctrl+Shift+K to reach Quick Filter.
  3. Enter a distinctive subject word or sender name.
  4. Review the available Sender, Recipients, Subject, and Body options. Select the fields relevant to your search.
  5. Check whether Unread, Starred, or Attachment filters are also limiting the results.
  6. Return to the results and inspect the matching messages.
  7. Press Escape as needed to clear the filter and hide the filter bar.

Expected result: Matching messages appear; clearing the filter restores the broader list. Filtering changes which messages you see, not which messages exist.

Practice: Search for “Email practice,” then deliberately use a word that is not in your message. Explain why an empty result does not prove your mail was deleted.

Source: Mozilla Quick Filter

6. Archive a message and locate it again

  1. Select one expendable practice message.
  2. Activate Archive, or press A while the message list has focus.
  3. Find the archive location for that account and locate the message again.

Archiving moves a message out of its current folder. The destination can be an account folder or a local folder, depending on the account's Copies & Folders settings. It remains searchable. Archiving is not a separate backup.

Practice: Before archiving anything important, demonstrate the complete round trip with your practice message: find it, archive it, and find it again.

Source: Mozilla archived messages

7. Troubleshooting practice

The command affected my browser.
Switch to Thunderbird, confirm the active window, and try again.
Typing goes into a search field.
Identify the focused control before repeating the command. Do not assume the message list is active.
My message list suddenly looks empty.
Check the selected folder and clear Quick Filter before assuming mail is missing.
The draft is not in Sent.
Saving and sending are different tasks. Look for the draft and review it before sending.
My screen reader uses the letter command itself.
Check focus and your reader's interaction mode. Use the corresponding Thunderbird menu action if needed. Do not turn off speech and continue blindly.
I cannot explain an error.
Record the exact error text, the action immediately before it, and whether it affects one account or all accounts. Share that information with your instructor or technology team.

8. Independent practice tasks

Choose any task. There is no required order or passing score. Use the instructions again whenever you need them.

  1. Orientation: Find Inbox and identify one message's sender and subject. Describe your current location.
  2. Draft: Write a three-sentence introduction without a recipient. Save it and explain why it has not been sent.
  3. Attachment: Add email-practice.txt and verify the filename.
  4. Search: Find your practice subject, then restore the unfiltered list.
  5. Recovery: Ask an instructor to select a different folder. Identify what changed before searching.
  6. Organization: Archive a practice message and retrieve it.

After each task, note what you completed independently, what prompt helped, and what you want to repeat. These are practice activities in Thunderbird; this manual does not yet add an automated Thunderbird Mission Control lesson.

Address a message: To, Cc, and Bcc

Start here: A new composition window. Use only your own address for the first practice.

Step-by-step instructions

  1. Tab to the To field. Type your complete email address and press Enter. The address becomes a recipient item. Review its spelling; an accepted-looking item is not proof that the address belongs to the intended person.
  2. To add another recipient, enter their address in the same row and confirm with Enter. To move onward after the last recipient, press Enter again or Tab and identify the next field.
  3. To correct an existing recipient, use the arrow keys in the recipient row to select that item. Press Enter to edit it, make the correction, and press Enter again. Delete removes a selected recipient item.
  4. If you need Cc or Bcc, reach the corresponding control above the address row with Tab or Shift+Tab and activate it. Cc recipients are visible to the other recipients. Bcc conceals the Bcc recipient list from them.
  5. Before sending, review every recipient row, not only To. In a practice draft, remove added recipients and save without sending.

Check your result

Each intended address is a distinct recipient item, and you know which address row it is in.

If something goes wrong

If a field is absent, activate its Cc or Bcc control first. If deleting removes message text instead of an address, stop: focus is in the body. Return to the recipient row before trying again.

Try it yourself

Explain who should see a copy of a hypothetical meeting invitation, then choose To or Cc. Do not test privacy by mailing real groups.

Documentation: Mozilla recipient addressing.

Send to yourself, reply, and forward

Start here: A saved practice draft and your own working email address.

Step-by-step instructions

  1. Open the draft, add your own address in To, and review Subject, body, and any attachments. Remove anything you did not intend to include.
  2. Press Ctrl+Enter to send. If a confirmation appears, read it and confirm only when the reviewed message is ready. Allow the operation to finish.
  3. Return to the main mail window and select the account’s Sent folder. Locate the practice subject. Then select Inbox and refresh that account with F5 if needed. Delivery can take time.
  4. Open the received practice message. Press Ctrl+R to reply to its sender. Check the recipient before writing a short answer; save the reply as a draft or send it to yourself.
  5. For a real group message, Ctrl+Shift+R opens Reply All. Review the expanded recipient list before writing. Cancel an unnecessary group reply rather than sending it by accident.
  6. To forward, open the original practice message and press Ctrl+L. Add your own address, inspect the quoted material and attached files, and add a sentence explaining why you are forwarding it. Save the practice forward as a draft.

Check your result

You can distinguish a newly composed message, a reply, and a forward by checking recipients and content, not just the subject prefix.

If something goes wrong

A Sent copy does not guarantee that someone read a message. If sending reports an error, record it and check the connection and account sign-in. Inspect Sent and Outbox before pressing Send repeatedly.

Try it yourself

Send yourself one clearly labeled test only. Identify its Sent copy and its received Inbox copy.

Documentation: Thunderbird command reference · Sending and receiving.

A repeatable mailbox routine

Start here: The main mail window. Choose a practice message that you can safely reorganize.

Step-by-step instructions

  1. Identify the account and select Inbox. Use F6 to reach the message list and arrows to select one message. Read its sender and subject before opening it.
  2. Open it with Enter, read it, and decide whether it needs a reply, a later action, or no action. Close the message tab with Ctrl+W when finished.
  3. If you want to distinguish read from unread, select the message in the list and press M once. Check the resulting status before pressing again; this command toggles the state.
  4. To retain the message outside Inbox, archive it using the archive task. To discard only an expendable practice message, select it in the message list and press Delete.
  5. After an accidental deletion, try Ctrl+Z immediately. Otherwise examine the account’s Trash folder and use the message’s context menu to move it back to Inbox. Do not empty Trash during this exercise.
  6. Finish by clearing any Quick Filter and checking the selected folder. This leaves a predictable starting point for your next session.

Check your result

You can explain where the practice message went and find it again.

If something goes wrong

Do not use Shift+Delete for practice: permanent deletion may not be recoverable. If multiple messages are selected unexpectedly, stop and select only the intended item before continuing.

Try it yourself

Record the starting folder, action, and destination for one archived message and one discarded test message.

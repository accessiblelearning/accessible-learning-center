Purpose: This manual is written directly to a person learning Windows 11 with a screen reader. It assumes little or no prior experience and explains exactly what to press, what you should hear, and how to recover when the result is different.

Three screen readers: Narrator is built into Windows 11. NVDA is a free third-party screen reader from NV Access. JAWS is a commercial screen reader from Freedom Scientific. Their commands are not interchangeable.

Command labels: Every procedure identifies whether a command belongs to WINDOWS, NARRATOR, NVDA, or JAWS.

How to Use This Manual

  • Begin with Parts 1-12 even if you eventually plan to use NVDA or JAWS. These sections teach Windows 11 keyboard navigation that all three screen readers rely on.

  • Do one action, stop, and listen to what changed before pressing another key.

  • Tab normally moves forward through controls. Shift+Tab moves backward.

  • Arrow keys normally move within lists, menus, radio-button groups, tree views, and text.

  • Enter activates many buttons, links, selected files, and menu commands.

  • Spacebar toggles checkboxes and many buttons.

  • Escape closes menus/dialogs or backs out of temporary interfaces.

  • Alt+Tab switches among open applications.

  • Windows key opens Start. Windows+S opens Search.

  • Learn Windows keyboard navigation first, then add the commands for your chosen screen reader.

Part 1 - What a Screen Reader Does

A screen reader converts information from the Windows interface into speech and, when connected, refreshable braille. It follows keyboard focus, a screen-reader cursor, browse/scan mode, or another navigation system.

  • Focus is the Windows control currently ready to receive input.

  • A button performs an action.

  • A checkbox can be checked or unchecked.

  • A combo box lets you choose from a list.

  • An edit field is where you type text.

  • A dialog box asks for information or a decision.

  • A screen reader usually announces both the control name and control type.

2.1 Navigate a Window with Tab

What you will learn: Move through controls without a mouse.

Before you begin: Open Settings or another simple Windows app.

Exactly how to do it

  1. Press Tab once.

  2. Listen to the focused control.

  3. Press Tab again.

  4. Continue through five controls.

  5. Press Shift+Tab twice to move backward.

  6. If focus enters a list, use Up/Down Arrow.

  7. Press Escape if a menu opens accidentally.

What should happen: Focus moves from control to control.

If that does not happen: If Tab seems stuck, press Escape once, then Tab again. If focus is in a list, use arrow keys.

Practice: Move forward ten controls and backward five.

Part 3 - Start, Search, Taskbar, and Switching Apps

3.1 Open an App from Start/Search

What you will learn: Launch programs without locating desktop icons.

Before you begin: Be anywhere in Windows.

Exactly how to do it

  1. Press the Windows key.

  2. Type the app name, for example Notepad.

  3. Wait for search results.

  4. Use Up/Down Arrow if multiple results appear.

  5. Press Enter on the correct result.

What should happen: The app opens.

If that does not happen: If the wrong result opens, press Alt+F4 and search using a more specific name.

Practice: Open Notepad, Settings, and Calculator.

3.2 Switch Between Open Apps

What you will learn: Move among running applications.

Before you begin: Open at least two apps.

Exactly how to do it

  1. Hold Alt.

  2. Press Tab repeatedly while holding Alt.

  3. Listen to each app name.

  4. Release Alt on the desired app.

What should happen: The selected app receives focus.

If that does not happen: If it is not listed, it may not be open.

Practice: Switch between Notepad and Settings three times.

3.3 Use the Taskbar

What you will learn: Reach pinned/running apps.

Before you begin: Be anywhere in Windows.

Exactly how to do it

  1. Press Windows+T.

  2. Use Left/Right Arrow through taskbar items.

  3. Press Enter to open or switch to the selected app.

  4. Press Escape when finished.

What should happen: Taskbar focus moves among apps.

If that does not happen: If Windows+T seems silent, press it again and listen for a taskbar item.

Practice: Open one pinned app.

Part 4 - Windows Settings

4.1 Open and Search Settings

What you will learn: Find a Windows option efficiently.

Before you begin: Be anywhere in Windows.

Exactly how to do it

  1. Press Windows+I.

  2. Wait for Settings.

  3. Tab to the search box if needed.

  4. Type Narrator, Bluetooth, Sound, or Accessibility.

  5. Use Down Arrow through results.

  6. Press Enter on the desired result.

  7. Use Tab/Shift+Tab through controls.

What should happen: The requested Settings page opens.

If that does not happen: If the exact phrase is not found, search with a broader word.

Practice: Find Accessibility > Narrator.

Part 5 - File Explorer

5.1 Open File Explorer

What you will learn: Browse folders and files.

Before you begin: Be anywhere in Windows.

Exactly how to do it

  1. Press Windows+E.

  2. Wait for File Explorer.

  3. Press Tab through major panes.

  4. When focus is in the file list, use arrow keys through files.

  5. Press Enter to open a folder/file.

  6. Press Alt+Left Arrow to go back.

  7. Press Alt+Up Arrow to move up one folder.

What should happen: You can enter and leave folders.

If that does not happen: If arrow keys do not move files, press Tab until the file list is focused.

Practice: Open Documents, enter a folder, then return.

5.2 Rename a File or Folder

What you will learn: Change an item's name.

Before you begin: Select a practice item.

Exactly how to do it

  1. Move to the item.

  2. Press F2.

  3. Type the new name.

  4. Press Enter.

  5. Listen to confirm the new name.

What should happen: The item is renamed.

If that does not happen: If F2 does nothing, confirm the file itself is selected.

Practice: Rename a practice file and rename it back.

Part 6 - Dialog Boxes, Menus, and Common Controls

  • Button: Enter or Spacebar.

  • Checkbox: Spacebar toggles.

  • Radio buttons: Arrow keys.

  • Combo box: Alt+Down Arrow opens, arrows choose, Enter confirms.

  • Tabs: Ctrl+Tab / Ctrl+Shift+Tab often changes tabs.

  • Context menu: Shift+F10.

  • Menus: Alt or F10 can expose menus in many desktop apps.

6.1 Use a Combo Box

What you will learn: Choose an option in a drop-down.

Before you begin: Focus is on a combo box.

Exactly how to do it

  1. Press Alt+Down Arrow.

  2. Listen to the current item.

  3. Press Up/Down Arrow through choices.

  4. Press Enter on the desired choice.

What should happen: The combo box closes with the selected value.

If that does not happen: If it does not open, try Spacebar or Enter.

Practice: Change a harmless option and restore it.

7.1 Type and Correct a Sentence

What you will learn: Use standard editing commands.

Before you begin: Open Notepad.

Exactly how to do it

  1. Type: The quick brown fox jumps over the lazy dog.

  2. Press Ctrl+Left Arrow to move backward by word.

  3. Press Left/Right Arrow by character.

  4. Use Backspace/Delete to remove text.

  5. Type the correction.

  6. Press Ctrl+Home.

  7. Use your screen reader's reading command to review.

What should happen: The correction occurs at the caret.

If that does not happen: If the caret is lost, use Ctrl+Home or Ctrl+End and navigate again.

Practice: Create and correct three errors.

Part 8 - Web Browsing Concepts

Narrator calls its webpage reading mode Scan Mode, NVDA calls it Browse Mode, and JAWS uses the Virtual Cursor. In these modes, single letters can jump to page structures instead of typing.

  • Tab moves among focusable links and form controls.

  • Enter activates.

  • H often moves by heading.

  • Shift+H often moves backward by heading.

  • Typing fields require a typing/focus/forms mode rather than page-navigation mode.

Key idea: If letters navigate instead of typing, check the screen reader's reading mode. If letters type when you expected heading navigation, check whether you are in a typing/focus/forms mode.

Part 10 - Copy, Cut, Paste, Rename, and Delete

10.1 Copy and Paste a File

What you will learn: Duplicate a file.

Before you begin: Select a practice file.

Exactly how to do it

  1. Press Ctrl+C.

  2. Navigate to the destination folder.

  3. Press Ctrl+V.

  4. Wait for the copy.

  5. Find the copied file.

What should happen: The copied file appears.

If that does not happen: If it does not, verify selection and destination permissions.

Practice: Copy a practice file.

10.2 Delete Safely

What you will learn: Delete a selected item deliberately.

Before you begin: Select a disposable practice file.

Exactly how to do it

  1. Read the filename carefully.

  2. Press Delete.

  3. If asked to confirm, read the dialog before choosing Yes.

  4. Avoid Shift+Delete for practice because it bypasses normal Recycle Bin behavior.

What should happen: The item is removed/moved to Recycle Bin.

If that does not happen: If the wrong item is selected, press Escape before confirming.

Practice: Delete and restore a practice item.

Part 11 - Keyboard Troubleshooting and Recovery

  • Press Escape once or twice if focus seems trapped.

  • Use Alt+Tab away and back if an app's focus becomes confusing.

  • Use Windows+S as a stable way to start another task.

  • If typing fails on a webpage, inspect the screen reader's browse/scan/forms mode.

  • If speech is silent, check system volume/output before changing many screen-reader settings.

Part 12 - Choosing Narrator, NVDA, or JAWS

Screen reader Overview
Narrator Built into Windows 11; immediate access; no installation.
NVDA Free/open-source; strong web and application support.
JAWS Commercial; extensive training, Office/web support, scripting, and enterprise use.

Backup strategy: Even if NVDA or JAWS is your main screen reader, Narrator can be valuable because it is built into Windows.

13.1 Start Narrator

What you will learn: Turn on Windows 11's built-in screen reader.

Before you begin: Be at the keyboard.

Exactly how to do it

  1. Hold Windows and Ctrl.

  2. Press Enter once.

  3. Release all keys.

  4. Listen for Narrator speech.

  5. If Narrator Home opens, use Tab through it or close/minimize it.

What should happen: Narrator announces the current item.

If that does not happen: If nothing happens, press Windows+Ctrl+N and turn Narrator on in Settings.

Practice: Start and stop Narrator twice.

14.1 Use Input Learning

What you will learn: Discover commands safely.

Before you begin: Narrator is on.

Exactly how to do it

  1. Press Narrator+1.

  2. Press a Narrator command.

  3. Listen to its description.

  4. Try several commands.

  5. Press Narrator+1 again to turn Input Learning off.

What should happen: Narrator describes commands without normally executing them.

If that does not happen: If commands act normally, Input Learning may be off.

Practice: Identify Next, Previous, Primary action, and Scan Mode.

14.2 Move by Narrator Item

What you will learn: Use Narrator's own item navigation.

Before you begin: Narrator is on.

Exactly how to do it

  1. Press Narrator+Right Arrow.

  2. Listen to the item.

  3. Press it again.

  4. Press Narrator+Left Arrow to return.

  5. Press Narrator+Enter on a harmless selected control.

What should happen: Narrator moves through items and activates the selected control.

If that does not happen: If nothing changes, press Tab to ensure the app has keyboard focus.

Practice: Move through five items.

15.1 Use Scan Mode on a Webpage

What you will learn: Read and navigate web content.

Before you begin: Open Edge, Chrome, or Firefox with Narrator.

Exactly how to do it

  1. Press Narrator+Spacebar if you need to confirm/toggle Scan Mode.

  2. Press Down Arrow through content.

  3. Press H to move to the next heading where supported.

  4. Press Shift+H for previous heading.

  5. Press Tab to a link or form control.

  6. Press Enter to activate.

  7. Type normally when focus enters an edit field; Scan Mode may turn off automatically.

  8. Use Up/Down Arrow to leave the edit field and resume reading.

What should happen: You can navigate page structure and enter text.

If that does not happen: If letters type instead of navigate, Scan Mode may be off.

Practice: Navigate by headings and links.

Part 18 - Narrator: Settings, Speech, Verbosity, and Punctuation

18.1 Open Narrator Settings

What you will learn: Adjust Narrator preferences.

Before you begin: Narrator may be on or off.

Exactly how to do it

  1. Press Windows+Ctrl+N.

  2. Use Tab through settings.

  3. Review voice, speed, pitch, volume, verbosity, typing feedback, Narrator key, and startup options.

  4. Change one setting at a time.

  5. Test and restore if needed.

What should happen: Narrator uses the changed setting.

If that does not happen: If you become lost, close Settings and reopen with Windows+Ctrl+N.

Practice: Change speech rate slightly and restore it.

Narrator key: Caps Lock and Insert both serve as the Narrator key by default.

Part 19 - Narrator: Braille

  • Connect a compatible braille display by USB/Bluetooth.

  • Open Narrator Settings > Braille.

  • Configure the display and braille input/output tables.

  • Device-specific routing/panning commands vary.

  • Narrator+Alt+B toggles the Braille Viewer.

19.1 Verify Braille

What you will learn: Confirm output, input, and routing.

Before you begin: Connect a supported display.

Exactly how to do it

  1. Move Narrator with Narrator+Right Arrow.

  2. Confirm braille changes.

  3. Open an edit field and type if display input is supported.

  4. Use a routing key and confirm focus/caret movement.

  5. Pan left/right with display controls.

What should happen: Output follows Narrator and supported input/routing work.

If that does not happen: If Windows sees the display but Narrator does not, check Narrator Braille settings and supported-display mappings.

Practice: Perform output, input, routing.

Part 20 - Narrator: Troubleshooting

20.1 Narrator Is Silent

What you will learn: Restore speech logically.

Before you begin: Narrator should be running.

Exactly how to do it

  1. Press Windows+Ctrl+Enter to confirm state.

  2. Check system volume/output.

  3. Press Tab or Narrator+Right Arrow to trigger speech.

  4. Open Narrator Settings with Windows+Ctrl+N.

  5. Restart Narrator.

What should happen: Speech returns.

If that does not happen: If Windows has no audio in any app, troubleshoot system sound.

Practice: Memorize the sequence.

Part 24 - NVDA: Settings, Add-ons, and Braille

Part 25 - NVDA: Troubleshooting

  • If NVDA is silent, press Ctrl, then navigate to trigger speech and check system audio.

  • If letters navigate instead of typing, switch to Focus Mode with NVDA+Space.

  • If letters type instead of navigating, return to Browse Mode with NVDA+Space.

  • After an NVDA update, test without optional add-ons if unusual behavior begins.

  • Use NVDA+1 when you forget a command.

Exactly how to do it

  1. Press Insert+V.

  2. Search or move through settings.

  3. Change only the intended option.

  4. Confirm/close.

  5. Test the application.

What should happen: The option changes for that context.

If that does not happen: Restore the previous value if behavior worsens.

Practice: Locate one setting without changing it.

Part 31 - JAWS: Troubleshooting

  • Press Insert+Esc to refresh screen information.

  • Use Insert+1, Insert+H, or Command Search when you forget a key.

  • If web quick keys type into a field, exit Forms Mode/return to Virtual Cursor.

  • Test another browser before changing many JAWS settings if one website behaves badly.

  • Review Quick Settings if an app-specific setting causes unexpected behavior.

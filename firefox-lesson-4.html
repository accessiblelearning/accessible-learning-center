Save and return to a useful page

Start here: The page you want to keep, open in Firefox.

Step-by-step instructions

  1. Press Ctrl+D. If a bookmark editor appears, Tab through its controls and locate the Name field. Give the bookmark a recognizable name such as “Learning Center — Firefox.”
  2. Review the folder/location choice. Choose a location you will recognize, then activate Save. If the page was already bookmarked, the editor may offer editing instead of a new save.
  3. Open the bookmark Library with Ctrl+Shift+O. Tab to its Search Bookmarks field, enter part of your saved name, and move to the matching results.
  4. Select the intended bookmark with arrow keys and press Enter to open it. Confirm the page heading or address matches what you saved.
  5. To rename or remove a practice bookmark, select it in the Library and use Shift+F10 to explore its context menu. Read the selected action before activating it. Removing a bookmark removes your saved link, not the website.

Check your result

You can close the original tab and still return through the saved bookmark.

If something goes wrong

If there is no match, clear the search and check its spelling and saved location. A website’s own search box is not the bookmark Library search.

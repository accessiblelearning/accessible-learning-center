Google Sheets with JAWS, NVDA, Narrator, VoiceOver, TalkBack, and Braille

Purpose: This manual teaches Google Sheets from the beginning, with special attention to keyboard and screen-reader use. It assumes no spreadsheet experience.

Reference environment: The main procedures use the current Google Sheets web application on a computer. Separate sections cover JAWS, NVDA, Narrator, VoiceOver, braille, and mobile use.

Core accessibility model: Google Sheets behaves like a web application rather than a normal webpage. Screen-reader browse/virtual modes often need to be disabled while editing the grid.

How to Use This Manual

  • Start with a blank practice spreadsheet rather than an important work file.

  • On Windows, press Ctrl+Alt+Z to turn on or verify screen-reader support.

  • With JAWS, turn Virtual PC Cursor off while editing. With NVDA, use Focus Mode. With VoiceOver on Mac, turn Quick Nav off.

  • Use Arrow keys to move cell by cell. Your screen reader should announce the cell address and contents.

  • Press Ctrl+/ to open Google Sheets' shortcut list.

  • Press Alt+/ on Windows/ChromeOS or Option+/ on Mac to search menus for a command.

  • Use formulas only after you understand cell references.

  • Check important formulas by testing them with known values.

  • Do not use color alone to communicate meaning in an accessible spreadsheet.

  • Give sheets, charts, ranges, and headers meaningful names.

Part 1 - What Google Sheets Is

Google Sheets is a web-based spreadsheet application. A spreadsheet contains one or more sheets. Each sheet is a grid made of rows and columns.

  • Column letters run across the top: A, B, C, and so on.

  • Row numbers run down the left side: 1, 2, 3, and so on.

  • A cell is the intersection of a column and row. For example, C4 means column C, row 4.

  • A range is a group of cells, such as A1:C5.

  • A formula begins with an equals sign (=).

  • A function is a built-in formula operation such as SUM or AVERAGE.

Part 2 - Create and Open a Spreadsheet

2.1 Create a Blank Spreadsheet

What you will learn: Open a new spreadsheet directly from the browser.

Before you begin: Use Chrome or another supported browser and sign in to the intended Google account.

Exactly how to do it

  1. Press Ctrl+L or Alt+D to focus the browser address bar.
  2. Type sheet.new.
  3. Press Enter.
  4. Wait for Google Sheets to open.
  5. Listen for 'Screen reader support enabled' if support was previously enabled.
  6. Use the Arrow keys to confirm that focus is in the grid.

What should happen: A blank spreadsheet opens with focus in a cell, usually A1.

If that does not happen: If a sign-in page appears, sign in to the correct Google account first. If arrows move browser elements instead of cells, review Part 3.

Practice: Create one blank practice spreadsheet.

2.2 Rename the Spreadsheet

What you will learn: Give the file a meaningful name.

Before you begin: A spreadsheet is open.

Exactly how to do it

  1. Press Alt+/.
  2. Type rename.
  3. Use Down Arrow to find the rename action.
  4. Press Enter.
  5. Type a descriptive name such as Monthly Budget Practice.
  6. Press Enter.

What should happen: The file name changes and Google Drive saves it automatically.

If that does not happen: If menu search does not open, use File menu or Tab to the document title control.

Practice: Rename your practice spreadsheet.

Part 3 - Turn On Screen Reader and Braille Support

3.1 Enable Screen Reader Support

What you will learn: Make Sheets expose its optimized accessibility interface.

Before you begin: A Google spreadsheet is open.

Exactly how to do it

  1. On Windows or ChromeOS, press Ctrl+Alt+Z. On Mac, press Command+Option+Z.
  2. Listen for confirmation that screen reader support is enabled.
  3. If you need to verify it through menus, open Tools: Windows/ChromeOS Alt+Shift+T; Mac Control+Option+T.
  4. Choose Accessibility settings.
  5. Verify Turn on screen reader support is checked.
  6. Close the dialog.

What should happen: Moving through cells causes the screen reader to announce cell address and contents.

If that does not happen: If your browser or screen reader intercepts the shortcut, use the Tools > Accessibility settings method.

Practice: Turn support off and back on in a disposable spreadsheet so you know the command.

3.2 Enable Braille Support

What you will learn: Improve braille display integration and routing.

Before you begin: A braille display is already configured in the screen reader.

Exactly how to do it

  1. Press Ctrl+Alt+H on Windows/ChromeOS or Command+Option+H on Mac.
  2. Listen for confirmation.
  3. Move through several cells.
  4. Use a routing key on the braille display.
  5. Type a few characters if braille input is configured.

What should happen: The display follows Sheets and routing/input become more responsive.

If that does not happen: If you do not use a braille display and Sheets becomes sluggish, turn braille support off using the same shortcut.

Practice: Test output, input, and routing.

4.1 Build a Simple Data Table

What you will learn: Create a predictable header-and-data structure.

Before you begin: Use a blank sheet.

Exactly how to do it

  1. Move to A1.
  2. Type Name and press Tab.
  3. Type Quantity and press Tab.
  4. Type Price and press Enter.
  5. Move to A2.
  6. Type Apples and press Tab.
  7. Type 3 and press Tab.
  8. Type 1.25 and press Enter.
  9. Move to A3 and enter another item the same way.

What should happen: Row 1 contains headers and later rows contain related records.

If that does not happen: If Enter moves in an unexpected direction, use Arrow keys to return to the intended cell.

Practice: Create a three-column, four-row practice table.

5.1 Move Efficiently Through Data

What you will learn: Use structure rather than pressing Arrow hundreds of times.

Before you begin: A table has several rows and columns.

Exactly how to do it

  1. Move to A1.
  2. Press Ctrl+Right Arrow to move toward the edge of the current data region.
  3. Press Ctrl+Down Arrow to move toward the bottom of the data region.
  4. Press Ctrl+Home to return to A1.
  5. Use ordinary Arrow keys to inspect nearby cells.

What should happen: You can travel quickly and still confirm the current cell address.

If that does not happen: Blank cells can change where Ctrl+Arrow stops. Use the screen reader's announced cell address to stay oriented.

Practice: Navigate from A1 to the lower-right data cell and back.

5.2 Hear Row and Column Context

What you will learn: Use Sheets' verbalize commands to understand a cell in a wide table.

Before you begin: Screen reader support is on.

Exactly how to do it

  1. Move to a data cell.
  2. Press Ctrl+Alt+Shift+R on Windows/ChromeOS to verbalize the row from the first column to the current column.
  3. Press Ctrl+Alt+Shift+C to verbalize the column from the first row to the current row.
  4. Repeat in another cell.

What should happen: Sheets announces contextual values that help identify the row/column meaning.

If that does not happen: If the shortcut is intercepted, open Accessibility > Verbalize to screen reader and choose the equivalent action.

Practice: Use both verbalize commands in a table with headers.

6.1 Edit an Existing Cell

What you will learn: Correct text without replacing the wrong cell.

Before you begin: Focus the cell containing the text.

Exactly how to do it

  1. Press Enter or use the edit command available in your browser/Sheets environment.
  2. Use Left/Right Arrow and Ctrl+Left/Right Arrow inside the cell text.
  3. Use Backspace/Delete to correct characters.
  4. Press Enter to accept the change.
  5. Move away and return to verify the final value.

What should happen: Only the intended cell changes.

If that does not happen: If Arrow keys move to another cell instead of within the text, you are not in cell-edit mode; activate the cell again.

Practice: Correct three intentional spelling errors.

6.2 Copy a Formula or Value

What you will learn: Reuse content without retyping.

Before you begin: Focus a filled cell.

Exactly how to do it

  1. Press Ctrl+C.
  2. Move to the destination cell.
  3. Press Ctrl+V.
  4. Move away and return to verify the result.

What should happen: The value/formula is pasted. Formula references may adjust when copied.

If that does not happen: If you only wanted the displayed value rather than the formula, use Paste special through Edit/menu search.

Practice: Copy one value and one formula.

Part 7 - Select Cells, Rows, Columns, and Ranges

7.1 Select a Rectangular Range

What you will learn: Prepare cells for formatting, formulas, or sorting.

Before you begin: Use a small data table.

Exactly how to do it

  1. Move to the top-left cell of the intended range.
  2. Hold Shift.
  3. Press Right Arrow to extend across columns.
  4. Press Down Arrow to extend across rows.
  5. Release Shift.
  6. Use a screen-reader verbalize/selection command if needed to confirm the range.

What should happen: The intended adjacent cells are selected.

If that does not happen: If the selection includes too many cells, press Escape and start again from the top-left cell.

Practice: Select A1:C4.

Part 8 - Add, Delete, Resize, and Move Rows and Columns

8.1 Insert a Row

What you will learn: Add space without overwriting existing data.

Before you begin: Focus a cell near where the row belongs.

Exactly how to do it

  1. Open the Insert menu with Alt+Shift+I on Windows/ChromeOS, or search menus with Alt+/.
  2. Choose Rows.
  3. Choose Insert 1 row above or Insert 1 row below.
  4. Move through the new row to verify its location.

What should happen: A blank row appears and existing data shifts.

If that does not happen: If a column was inserted instead, undo with Ctrl+Z and repeat while listening carefully to the submenu.

Practice: Insert and then undo one practice row.

8.2 Resize a Column

What you will learn: Make visual width fit data while preserving content.

Before you begin: Focus a cell in the target column.

Exactly how to do it

  1. Select the column with Ctrl+Space twice if needed.
  2. Use Alt+/ and search for Resize column.
  3. Open the command.
  4. Enter a pixel width or choose fit-to-data when offered.
  5. Confirm.

What should happen: The visual width changes; cell contents are unchanged.

If that does not happen: Screen-reader users may not notice the visual change. Verify with a sighted check when visual layout matters to recipients.

Practice: Resize one practice column.

Part 9 - Multiple Sheets and Sheet Tabs

9.1 Add and Rename a Sheet

What you will learn: Organize one workbook into meaningful sections.

Before you begin: A spreadsheet is open.

Exactly how to do it

  1. Use Alt+/ and search for Insert new sheet, or use the plus-sheet command in the interface.
  2. Open the sheet list with Alt+Shift+K.
  3. Move to the new sheet.
  4. Open its context menu with Shift+F10.
  5. Choose Rename.
  6. Type a meaningful name such as January.
  7. Press Enter.

What should happen: A new sheet tab has a descriptive name.

If that does not happen: If a browser context menu appears instead of the Sheets menu, use the sheet list and menu search commands.

Practice: Create sheets named January and February.

9.2 Switch Sheets

What you will learn: Move without hunting visually for tabs.

Before you begin: The file has multiple sheets.

Exactly how to do it

  1. Press Alt+Down Arrow to move to the next sheet.
  2. Press Alt+Up Arrow to move to the previous sheet.
  3. Press Alt+Shift+K to open the complete list.
  4. Use Up/Down Arrow and press Enter on the desired sheet.

What should happen: The active sheet changes and focus returns to its grid.

If that does not happen: If Alt+Arrow is intercepted by your system/browser, use Alt+Shift+K.

Practice: Switch among three sheets.

10.1 Apply Number Formatting

What you will learn: Change how a value is displayed without changing its underlying meaning.

Before you begin: Enter 0.25 in a practice cell.

Exactly how to do it

  1. Focus the cell.
  2. Press Ctrl+Shift+5.
  3. Move away and return.
  4. Listen for the displayed percentage.
  5. Use Format menu or menu search for additional number formats.

Part 11 - Formulas and Cell References

11.1 Create a Formula

What you will learn: Calculate from cells instead of typing the answer manually.

Before you begin: Enter 5 in A1 and 7 in B1.

Exactly how to do it

  1. Move to C1.
  2. Type =A1+B1.
  3. Press Enter.
  4. Return to C1.
  5. Listen for the result.
  6. Edit A1 to 10 and return to C1.

What should happen: C1 recalculates automatically from 12 to 17.

If that does not happen: If the formula appears as text, verify the cell is not formatted as Plain text and that the formula begins with =.

Practice: Create addition, subtraction, multiplication, and division formulas.

Operators: Common operators are + addition, - subtraction, * multiplication, / division, and ^ exponent.

Part 12 - Common Functions

Function Example Purpose
SUM =SUM(B2:B10) Adds values.
AVERAGE =AVERAGE(B2:B10) Calculates arithmetic mean.
MIN =MIN(B2:B10) Returns smallest value.
MAX =MAX(B2:B10) Returns largest value.
COUNT =COUNT(B2:B10) Counts numeric cells.
COUNTA =COUNTA(A2:A10) Counts nonempty cells.
IF =IF(B2>=70,"Pass","Review") Returns one result when a condition is true and another when false.
COUNTIF =COUNTIF(C2:C20,"Yes") Counts cells that meet a condition.
SUMIF =SUMIF(A2:A20,"Food",B2:B20) Adds values meeting a condition.

12.1 Build a SUM Function

What you will learn: Add a column reliably.

Before you begin: Enter several numbers in B2:B5.

Exactly how to do it

  1. Move to B6.
  2. Type =SUM(B2:B5).
  3. Press Enter.
  4. Verify the answer manually with small numbers.
  5. Change one input and confirm the total recalculates.

What should happen: B6 contains the current total.

If that does not happen: If the result is an error, spell the function and verify colon/range references.

Practice: Create SUM, AVERAGE, MIN, and MAX for the same values.

Part 13 - Relative and Absolute References

A relative reference changes when a formula is copied. An absolute reference keeps a row and/or column fixed using dollar signs.

Task Command / Method
A1 Relative column and row
$A$1 Absolute column and row
$A1 Absolute column, relative row
A$1 Relative column, absolute row

13.1 Use an Absolute Reference

What you will learn: Apply one tax/rate cell to many rows.

Before you begin: Put a rate such as 0.05 in E1 and amounts in B2:B5.

Exactly how to do it

  1. Move to C2.
  2. Type =B2*$E$1.
  3. Press Enter.
  4. Copy C2 downward into C3:C5.
  5. Inspect each formula/result.
  6. Confirm every formula still points to E1.

What should happen: The B-row reference changes while $E$1 stays fixed.

If that does not happen: If E1 changes to E2/E3, the reference was not absolute.

Practice: Create a tax or commission calculation.

Part 14 - Fill and Autofill

14.1 Continue a Series

What you will learn: Fill sequential numbers or dates.

Before you begin: Enter 1 in A1 and 2 in A2.

Exactly how to do it

  1. Select A1:A2.
  2. Extend the selection downward into several empty cells.
  3. Press Ctrl+Alt+Enter on Windows/ChromeOS, or Command+Option+Enter on Mac.
  4. Move through the filled cells.

What should happen: Sheets continues the numeric series.

If that does not happen: If values simply repeat or remain unchanged, the starting pattern/selection may not define a series.

Practice: Autofill 1 through 10 and a short date sequence.

Part 15 - Sort Data

15.1 Sort a Table Safely

What you will learn: Reorder complete records without separating columns.

Before you begin: Use a table with headers and several rows.

Exactly how to do it

  1. Select the entire data range, including all related columns.
  2. Open Data using the menu bar or Alt+/ menu search.
  3. Choose Sort range.
  4. Indicate that the range has a header row if offered.
  5. Choose the column and A-to-Z or Z-to-A order.
  6. Apply the sort.
  7. Read several rows to verify records stayed together.

What should happen: Rows are reordered based on the selected column while record fields stay aligned.

If that does not happen: Never sort only one data column in a multi-column record table unless that is truly intended. Undo immediately if records become mismatched.

Practice: Sort a practice table by Name and then by Amount.

Part 16 - Filters and Filter Views

16.1 Create and Use a Filter

What you will learn: Temporarily hide rows that do not meet criteria.

Before you begin: Use a table with a header row.

Exactly how to do it

  1. Select the data range.
  2. Open Data.
  3. Choose Create a filter.
  4. Move into the filtered range; the screen reader should announce when entering it.
  5. Open the filter control for the desired header using the context/menu controls available.
  6. Review values or conditions.
  7. Toggle values to include/exclude.
  8. Tab to OK and press Enter.

What should happen: Rows not meeting the criteria are hidden; Google reports the available row count when the filter is applied.

If that does not happen: If colleagues are using the same file, consider a filter view when you do not want your filter to alter their view.

Practice: Filter a Category column to one value, then remove the filter.

Accessibility: A filtered sheet contains hidden rows. Do not assume missing rows were deleted.

Part 17 - Data Validation, Dropdowns, and Checkboxes

17.1 Create a Dropdown

What you will learn: Restrict a cell to known choices.

Before you begin: Select one or more practice cells.

Exactly how to do it

  1. Use Alt+/ and type dropdown, or open Data > Data validation.
  2. Choose Add rule.
  3. Choose Dropdown or Dropdown from a range.
  4. Enter options such as Not started, In progress, Done.
  5. Choose whether invalid data should be rejected or only warned about.
  6. Activate Done.
  7. Focus one dropdown cell and open/select a value.

What should happen: The cell offers controlled choices and data validation.

If that does not happen: Multiple-selection dropdowns are only available in supported chip configurations; mobile behavior can differ.

Practice: Create a three-value status dropdown.

17.2 Create and Toggle Checkboxes

What you will learn: Track yes/no status with a keyboard-accessible control.

Before you begin: Select practice cells.

Exactly how to do it

  1. Open Insert.
  2. Choose Checkbox.
  3. Move to a checkbox cell.
  4. Press Spacebar to toggle it.
  5. Press Spacebar again to restore the other state.

What should happen: The checkbox changes checked state.

If that does not happen: If Space types a character, verify the focused cell contains a checkbox and you are not editing text.

Practice: Create and toggle five checkboxes.

Part 18 - Tables, Named Ranges, and Named Functions

Google Sheets includes higher-level structures that can make formulas easier to understand.

  • Named range: gives a range a human-readable name instead of using only A1 references.

  • Named function: lets you build a reusable custom function from built-in Sheets formulas.

  • Tables and structured features may vary by account/rollout; use menus and current help to confirm availability.

18.1 Create a Named Range

What you will learn: Make an important range easier to refer to.

Before you begin: Select a simple numeric range.

Exactly how to do it

  1. Open Data.
  2. Choose Named ranges.
  3. Enter a descriptive name without spaces, such as Sales_Total_Input.
  4. Confirm the range.
  5. Save/Done.
  6. Use the named range in a simple formula if supported.

What should happen: The range can be referred to by name in formulas and navigation.

If that does not happen: If the name is rejected, use letters, numbers, and underscores and follow Sheets naming rules.

Practice: Create one named range.

Named functions: Google currently supports Named functions under Data > Named functions and allows them to be imported into other Sheets files.

19.2 Add Accessible Chart Text

What you will learn: Give a chart a meaningful accessible name/description.

Exactly how to do it

Part 20 - Pivot Tables

Before you begin: Use a clean table with one header row and no blank header names.

Exactly how to do it

  1. Select the complete source data.
  2. Open Insert or Data and choose Pivot table.
  3. Choose whether to create it in a new sheet or existing sheet.
  4. Use the Pivot table editor side panel.
  5. Add a field under Rows.
  6. Add a numeric field under Values.
  7. Review the resulting summary table cell by cell.

What should happen: Sheets creates a summary such as total sales by category.

If that does not happen: Pivot editor controls can be complex with a screen reader. Use Alt+/ menu search and Tab/Shift+Tab through the side panel; simplify the first practice pivot.

Part 22 - Notes, Comments, and Collaboration

  3. Press Escape.
  4. Move away and return to the cell.

Part 23 - Sharing and Permissions

23.1 Share a Spreadsheet

What you will learn: Give the correct person the minimum necessary permission.

Before you begin: Open the correct spreadsheet.

Exactly how to do it

  1. Use the Share button through Tab/landmarks or Alt+/ search for Share.
  2. Enter the recipient's email address.
  3. Choose Viewer, Commenter, or Editor as appropriate.
  4. Review the file name and recipient.
  5. Add a message if needed.
  6. Send.

Part 24 - Version History and Recovery

24.1 Review Version History

What you will learn: Recover earlier work or identify changes.

Before you begin: Use a file with several edits.

Exactly how to do it

  1. Open File.
  2. Open Version history.
  3. Choose See version history.
  4. Move through saved versions and collaborator/date information.

Part 25 - Download, Print, and Export

  • File > Download can export formats such as Microsoft Excel (.xlsx), PDF, CSV, and others depending on the current file/sheet.

  • CSV exports one sheet at a time and does not preserve formulas/formatting in the same way as a spreadsheet file.

  • PDF is useful for fixed-layout distribution but may be less usable for data analysis than the original accessible sheet.

  • Excel export should be checked after download because formulas, charts, or advanced Sheets features may behave differently.

  • Printing is visual output; use Print settings to define current sheet, selected cells, headers, scaling, and page breaks.

Accessibility: When distributing data to screen-reader users, offer the original accessible spreadsheet or another structured data format rather than only an image or scanned PDF.

Part 26 - Accessible Spreadsheet Design

  • Use a single clear header row at the top of each data table.

  • Give every column a unique, meaningful header.

  • Give each sheet a descriptive name; avoid Sheet1, Sheet2 when the file is shared.

  • Keep one record per row and one field per column.

  • Avoid merged cells in data tables.

  • Avoid blank rows/columns inside the core data region unless they have a real structural purpose.

  • Do not use color alone to indicate status, errors, ownership, or priority.

  • Use text labels such as High, Medium, Low in addition to color.

  • Keep formulas consistent down a calculated column.

  • Provide alt text/title for charts/images and keep source data available.

  • Use notes/comments deliberately and avoid hiding essential instructions only in a comment.

  • Freeze headers visually when useful, but do not rely on freezing as a substitute for meaningful header text.

  • Protect formula/input ranges when appropriate, while ensuring intended users have necessary access.

26.1 Audit a Spreadsheet for Accessibility

What you will learn: Check structure before sharing.

Before you begin: Use a completed practice sheet.

Exactly how to do it

  1. Read every sheet name.
  2. Read the first row of each table and confirm unique headers.
  3. Navigate down each column and check that data types are consistent.
  4. Identify merged cells and unnecessary blanks.
  5. Check whether any meaning exists only through color.
  6. Check charts/images for accessible titles/alt text.
  7. Test the spreadsheet with a screen reader from A1 through representative data.

What should happen: The file is easier to understand without visual interpretation.

If that does not happen: If the sheet only makes sense visually, redesign the structure instead of adding more verbal instructions.

Practice: Audit one existing spreadsheet.

  • Use Sheets Arrow-key navigation in the grid.

  • Use Ctrl+/ for Sheets shortcut help rather than relying only on JAWS web-navigation keys.

27.1 JAWS Orientation Test

What you will learn: Confirm the correct interaction mode before doing real work.

Before you begin: JAWS and Google Sheets are open.

Exactly how to do it

  1. Press JAWS+Z until Virtual PC Cursor is off.
  2. Press Ctrl+Alt+Z if screen-reader support is not already on.
  3. Move Right Arrow three cells.
  4. Move Down Arrow three cells.
  5. Listen for each cell address and value.
  6. Press Alt+/ and search for Rename, then press Escape.

If that does not happen: If H/L/F web navigation commands begin moving around the browser instead of cells, Virtual PC Cursor may have been turned back on.

  • Test braille input inside a cell.

Part 33 - Troubleshooting

33.1 Arrow Keys Move the Webpage Instead of Cells

What you will learn: Restore application interaction mode.

Before you begin: Sheets is open with a screen reader.

Exactly how to do it

  1. Press Escape to close menus/dialogs.
  2. Verify screen-reader support with Ctrl+Alt+Z.
  3. JAWS: turn Virtual PC Cursor off with JAWS+Z.
  4. NVDA: switch to Focus Mode with NVDA+Space.
  5. VoiceOver: turn Quick Nav off.
  6. Return to the grid and try Arrow keys.

What should happen: Arrow keys move from cell to cell and addresses are announced.

If that does not happen: If focus is not in the grid, use Sheets landmarks/Tab navigation or reopen the spreadsheet.

Practice: Practice deliberately switching out of and back into editing mode.

33.2 A Formula Shows an Error

What you will learn: Diagnose syntax and references instead of replacing it blindly.

Before you begin: A formula cell shows an error.

Exactly how to do it

  1. Edit the formula.
  2. Check that it begins with =.
  3. Check function spelling.
  4. Check parentheses and commas/argument separators.
  5. Check referenced cells/ranges.
  6. Check for division by zero or missing values.
  7. Use the function help box/reference when needed.
  8. Test the formula on small known values.

What should happen: The error becomes understandable or the formula calculates correctly.

If that does not happen: Different error types point to different causes; do not hide an error with IFERROR until you understand why it occurs.

Practice: Fix one intentionally broken SUM or IF formula.

33.3 Data Changed After Sorting

What you will learn: Check whether the full record range was selected.

Before you begin: Rows no longer seem related.

Exactly how to do it

  1. Immediately press Ctrl+Z if the sort was just performed.
  2. Identify all columns that belong to each record.
  3. Select the entire table.
  4. Repeat Sort range with the header-row option.

What should happen: Complete records move together.

If that does not happen: If the file was already saved/edited by others, use Version history to recover the correct state.

Practice: Practice sorting a copy.

33.4 Screen Reader Stops Announcing Useful Context

What you will learn: Re-establish Sheets accessibility state.

Before you begin: Cell navigation still works but announcements are poor.

Exactly how to do it

  1. Press Ctrl+Alt+Z to verify screen-reader support.
  2. Use Accessibility > Verbalize to screen reader.
  3. Use Ctrl+Alt+Shift+R or C for row/column context.
  4. Check whether braille support should be on/off for your setup.
  5. Refresh the browser only after saving/sync status is stable.

What should happen: Contextual announcements return.

If that does not happen: If only one file behaves badly, test a new blank sheet to separate file complexity from screen-reader configuration.

Practice: Compare the problem file with sheet.new.

33.5 A Shared User Cannot Edit

What you will learn: Check permissions rather than spreadsheet formulas.

Before you begin: The person can open but not modify the file.

Exactly how to do it

  1. Open Share.
  2. Find the person's account.
  3. Read their permission level.
  4. Change Viewer/Commenter to Editor only if appropriate.
  5. Check whether a protected range/sheet is blocking only specific cells.
  6. Confirm they are signed into the intended Google account.

What should happen: The correct person has the intended access.

If that does not happen: Do not make the entire file public just to fix one user's permission problem.

Practice: Review sharing on a harmless practice file.

33.6 The Spreadsheet Is Too Visually Complex

What you will learn: Simplify structure for accessibility.

Before you begin: The sheet uses merged cells, color-only meaning, or many scattered tables.

Exactly how to do it

  1. Make a backup/copy.
  2. Give each table a single header row.
  3. Remove unnecessary merged cells.
  4. Replace color-only status with text labels.
  5. Separate unrelated tables onto descriptively named sheets.
  6. Add accessible titles/descriptions to charts.
  7. Test keyboard/screen-reader reading order.

What should happen: The data can be understood without reconstructing a visual layout mentally.

If that does not happen: If the original visual layout must remain, create a second accessible data sheet for structured access.

Practice: Simplify one complex practice sheet.

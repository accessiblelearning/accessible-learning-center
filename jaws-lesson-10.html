Choose your screen reader

Complete this lesson with JAWS, Windows Narrator, or NVDA. Use one primary screen reader at a time. Follow the column for your selection whenever commands differ.

Goal

Complete a realistic Windows, web, form, document, and troubleshooting workflow with the chosen screen reader.

Shared practice steps

  1. Start the chosen screen reader and state which one you selected.
  2. Use Windows search and File Explorer to locate an instructor-provided file.
  3. Open a public webpage and navigate by headings, links, lists, and a table.
  4. Complete a practice form with fictional data without submitting it externally.
  5. Edit and save a short workplace document with a verified filename.
  6. Troubleshoot one simulated focus, speech, or reading-mode problem using official help.

Your assignment

Submit a final report naming the selected screen reader, the commands used, completed tasks, and one troubleshooting solution.

Use fictional, public, instructor-provided, or redacted information only. Never submit passwords, license information, account codes, or private workplace data.

Save your work with a filename beginning Screen-Readers-Lesson-10.

Before submitting

  • The selected screen reader is named.
  • The commands match JAWS, Narrator, or NVDA.
  • Shared Windows commands are distinguished from screen-reader commands.
  • The file contains no credentials or sensitive information.

JAWS Lesson 10

Final Workplace Navigation and Problem-Solving Project

JAWS manual All JAWS lessons My progress

Goal

Combine core JAWS skills to complete a realistic workplace information task independently.

Skills practiced

  • Navigate Windows and multiple applications.
  • Read a structured webpage and complete a form safely.
  • Extract information from headings, links, lists, and tables.
  • Use JAWS help or AI responsibly when a command is forgotten.

Step-by-step instructions

  1. Open a web browser and a text editor. Use Alt+Tab to confirm both applications are available.
  2. Visit an accessible employment, training, or public-service webpage that does not require signing in.
  3. Use the Virtual Cursor and heading commands to identify the page title and main sections.
  4. Use the Links List to locate one useful resource link. Do not submit applications or share personal information.
  5. Locate a list or table and record three useful facts in the text editor.
  6. Locate a form field and identify its label and type. Use fictional information if interaction is necessary, and do not submit the form.
  7. Use Insert+T, Insert+Tab, and at least one element list to confirm context during the task.
  8. If a command is forgotten, use Keyboard Help, JAWS Commands Search, FSCompanion, or official documentation. Record which help source was used and verify the answer.
  9. Write a concise workplace report with the page title, resource link text, three facts, form-field description, commands used, and one accessibility observation.
  10. Review the report with Say All and word spelling. Save it as JAWS-Lesson-10.txt.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Your assignment

Submit the final workplace navigation report demonstrating independent, safe, and accurate JAWS use.

Save the finished assignment as JAWS-Lesson-10.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • The report includes all required workplace findings.
  • At least eight JAWS or Windows commands are documented.
  • No private information was entered or submitted.
  • Any AI-assisted answer was verified.
  • The file is named JAWS-Lesson-10.txt.

Purpose and setup

This manual supports independent practice with Google Calendar on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Basic and advanced how-tos

Create an event

Keyboard commands: C creates an event when Google Calendar shortcuts are available. Tab and Shift+Tab move through fields.

  1. Open Google Calendar and confirm the account and displayed date.
  2. Press C or activate Create.
  3. Enter a specific title.
  4. Review the start date, start time, end date, end time, time zone, and location.
  5. Add a useful description, then activate Save.

You should hear: The event title and a saved confirmation.

If that does not happen: Check for an error or unsaved-event dialog before repeating the command.

Invite guests and check permissions

  1. Open the event and find Add guests.
  2. Enter one address at a time and confirm each guest.
  3. Review whether guests may modify the event, invite others, or see the guest list.
  4. Save and choose whether to send invitation updates.

If that does not happen: Cancel and reopen the guest list. Do not send until every address and permission is correct.

Move by date and search

Keyboard commands: T returns to today, G opens Go to date, and / moves to Search when shortcuts are enabled.

  1. Press G, enter the requested date, and confirm.
  2. Navigate through events and verify dates and times.
  3. Press /, enter an event title or guest, and submit.
  4. Open and verify the result before editing.

If that does not happen: Use the labeled Today, Search, and date controls.

Change or cancel a repeating event safely

  1. Open the event and confirm its title, date, organizer, and calendar.
  2. Choose Edit or Delete deliberately.
  3. Choose this event, this and following events, or all events carefully.
  4. Review whether guests will receive an update.
  5. Confirm the result in the calendar.

If that does not happen: Cancel the dialog. Never guess which events will be affected.

Ten-lesson learning path

  1. Lesson 1: Calendar Layout and Keyboard Navigation — Create a command reference describing six Calendar controls.
  2. Lesson 2: Create a Complete Event — Document a fictional 30-minute team check-in.
  3. Lesson 3: Edit, Delete, and Restore Events — Write an edit-and-recovery checklist using a fictional event.
  4. Lesson 4: Create Recurring Events — Plan a four-week fictional training series.
  5. Lesson 5: Invite Guests and Respond to Invitations — Create a guest-permission and invitation-response guide.
  6. Lesson 6: Notifications and Reminders — Design a notification plan for three kinds of work events.
  7. Lesson 7: Multiple Calendars and Color Labels — Describe an accessible organization plan for work and training calendars.
  8. Lesson 8: Search, Agenda, and Schedule Review — Create a weekly schedule review checklist.
  9. Lesson 9: Sharing, Privacy, and Time Zones — Create a privacy and time-zone plan for a remote team.
  10. Lesson 10: Final Workplace Scheduling Project — Submit a complete accessible weekly scheduling plan.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Save the requested practice file locally with the exact filename given in the lesson. Assignment uploads are currently paused.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

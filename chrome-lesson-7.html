Chrome Lesson 7

Forms, Forms Mode, and Site Permissions

Chrome manualAll Chrome lessonsMy progress

Goal

Complete browser forms and make careful decisions about site permission requests.

Step-by-step instructions

  1. Open a safe practice form and keep the JAWS Virtual Cursor on.
  2. Press F or Insert+F5 to locate form fields.
  3. Press Enter on an edit field to enter Forms Mode.
  4. Use Tab, Shift+Tab, Spacebar, Arrow keys, and Alt+Down Arrow as appropriate for controls.
  5. Use fictional practice information only.
  6. Exit Forms Mode with Num Pad Plus in the JAWS desktop layout.
  7. When Chrome requests notification, camera, microphone, or location permission, read the site name and requested permission before deciding.
  8. Deny unexpected permission requests and ask authorized support before changing managed workplace permissions.
  9. Review all form entries without submitting personal information.
  10. Save a forms-and-permissions report as Chrome-Lesson-7.txt.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

Your assignment

Create the report described above using fictional or public information only.

Save it as Chrome-Lesson-7.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • Forms Mode and Virtual Cursor navigation are distinguished.
  • At least four control types are described.
  • Permission requests are evaluated by site and purpose.
  • The file is Chrome-Lesson-7.txt.

Accessible PDFs Lesson 6

Tags, Reading Order, and Document Properties

Accessible PDFs manualAll Accessible PDFs lessonsMy progress

Goal

Write an accessibility inventory for a public or instructor-provided PDF.

Step-by-step instructions

  1. Open Document Properties and inspect the title and language.
  2. Identify whether the PDF is tagged.
  3. Explain why tags support headings, lists, tables, and reading order.
  4. Use the Tags or Reading Order tools only if Acrobat includes them.
  5. Do not reorder a production document without a backup.
  6. Save remediation work as a new copy.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Write an accessibility inventory for a public or instructor-provided PDF.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Pdf-Lesson-6.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Accessible PDFs Lesson 6.

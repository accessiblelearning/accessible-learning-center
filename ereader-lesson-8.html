NLS Braille eReader Lesson 8

Settings, Language, and Status

NLS Braille eReader manualAll NLS Braille eReader lessonsMy progress

Goal

Create a settings inventory without serial numbers.

Step-by-step instructions

  1. Open Settings and review available categories.
  2. Locate braille code, language, display, and status options.
  3. Change only one reversible instructor-approved setting.
  4. Read the effect and restore the original value.
  5. Record battery, storage, and software information.
  6. Avoid reset or update commands during ordinary practice.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Create a settings inventory without serial numbers.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Purpose: This manual teaches the BrailleNote Touch Plus from the beginning. It assumes no prior experience and provides physical orientation, exact braille-keyboard commands, expected speech/braille feedback, troubleshooting, practice, and independence checks.

Current reference: HumanWare's current support page lists BrailleNote Touch Plus User Guide version 6. The command model in this guide follows HumanWare's current KeySoft documentation and current support materials.

Important product note: The BrailleNote Touch Plus is an Android-based braille notetaker with HumanWare's KeySoft accessibility layer. It can also work as a braille display for a computer or mobile device through Braille Terminal.

How to Use This Manual

  • First learn the physical controls and KeySoft navigation pattern before using email, web, or third-party apps.

  • Main Menu: Home button or Space with dots 1-2-3-4-5-6.

  • Next item: Next thumb key or Space. Previous item: Previous thumb key or Backspace.

  • Activate selected item: Enter (dot 8) or a cursor-routing key.

  • Back/exit current screen: Back button or Space with E.

  • Contextual Help: Space with H. Context menu: Space with M or press and hold Recent apps.

  • Braille panning: Left and Right thumb keys.

  • Use first-letter navigation in lists and menus whenever KeySoft supports it.

  • Do not change Android accessibility settings casually; KeySoft is the accessibility layer that makes the Touch Plus usable.

  • Before connecting the Touch Plus as an external braille display, first pair/connect it, then configure the host screen reader, then test braille output, input, and routing.

Part 1 - What the BrailleNote Touch Plus Is

The BrailleNote Touch Plus combines a touchscreen Android tablet, KeySoft applications, speech, a 32-cell refreshable braille display, and a removable physical braille-keyboard cover.

  • KeySoft Main Menu: the primary accessible home screen.

  • KeyWord: word processing.

  • KeyMail: email.

  • KeyList: contacts.

  • KeyPlan: calendar/planner.

  • KeyFiles: file manager.

  • EasyReader Plus: accessible book-reading app.

  • Google Chrome: web browser.

  • Braille Terminal: turns the Touch Plus into an external braille display for another device.

  • All Applications: access to installed Android and Google Play apps.

Part 2 - Physical Orientation

2.1 Top Face

  • Place the device flat with the touchscreen and braille display facing up and the seven front-edge buttons closest to you.

  • The touchscreen occupies the upper portion of the top face.

  • Directly below the touchscreen is the 32-cell refreshable braille display.

  • Above each braille cell is a cursor-routing key. Pressing a routing key moves the cursor or activates an item depending on context.

  • Internal stereo speakers are positioned to the left and right of the braille cells.

  • An internal microphone is located to the right of the braille display, below the right speaker.

  • The removable braille keyboard cover sits over the touchscreen when attached and provides Perkins-style braille input.

Part 3 - Power, Charging, Locking, and Unlocking

3.1 Charge the Touch Plus

What you will learn: Connect power safely.

Before you begin: Use the supplied USB-C charging cable and suitable adapter.

Exactly how to do it

  1. Locate the USB-C port at the upper-left edge.

  2. Insert the reversible USB-C plug.

  3. Connect the other end to the power adapter.

  4. Plug the adapter into AC power.

  5. Allow the battery to charge.

What should happen: The LED and/or spoken/braille status indicate charging.

If that does not happen: If it does not charge, try the supplied cable/adapter and another outlet. Charging from a computer can be slower.

Practice: Locate the port and connect/disconnect the cable.

3.2 Power On

What you will learn: Start KeySoft.

Before you begin: The battery has charge.

Exactly how to do it

  1. Press and hold the oval Power button on the left edge.

  2. Feel for the startup vibration.

  3. Wait for 'Starting KeySoft' or equivalent braille/speech feedback.

  4. Allow the Main Menu to finish loading.

What should happen: The Touch Plus starts and KeySoft becomes available.

If that does not happen: If startup stalls, connect AC power and retry before attempting a reset.

Practice: Power on from fully off and wait for Main Menu.

3.3 Return to Main Menu and Unlock

What you will learn: Recover from an unfamiliar screen.

Before you begin: The Touch Plus is on.

Exactly how to do it

  1. Press the round Home button to return to Main Menu.

  2. If the lock screen is active, press Space with U.

  3. Alternatively navigate to the Unlock control with thumb keys and activate it.

What should happen: The KeySoft Main Menu is available.

If that does not happen: If the device asks for a PIN/password, enter the configured lock credential.

Practice: Practice Home and unlock commands.

4.1 Navigate a Menu

What you will learn: Use the universal KeySoft pattern.

Before you begin: Open Main Menu.

Exactly how to do it

  1. Press Space or Next thumb.

  2. Listen/read the next item.

  3. Press Backspace or Previous thumb.

  4. Move to the item you want.

  5. Press Enter or a cursor-routing key.

What should happen: The selected item opens.

If that does not happen: If typing letters appears instead of moving, you may be in an edit field rather than a menu.

Practice: Navigate to three apps and open one.

Before you begin: Return to Main Menu.

Exactly how to do it

  3. Listen/read the selected application name.

  4. Press Enter or a routing key.

What should happen: The chosen application opens.

If that does not happen: If several items begin with the same letter, repeat the letter or use thumb keys.

Practice: Open KeyWord, return Home, then open KeyFiles.

Part 6 - Contextual Help and Context Menu

6.1 Use Contextual Help

What you will learn: Learn commands for the current location.

Before you begin: Be anywhere in a KeySoft app/menu.

Exactly how to do it

  1. Press Space with H.

  2. Listen/read 'Contextual help'.

  3. Use Previous/Next to move through help topics.

  4. Read the commands relevant to your current location.

  5. Press Back or Space with E to leave help.

What should happen: You receive context-specific instructions without leaving the task permanently.

If that does not happen: If Help does not open, the current third-party Android app may not support KeySoft contextual help.

Practice: Use Help in Main Menu, KeyWord, and Chrome.

6.2 Use the Context Menu

What you will learn: Find current actions like a right-click menu.

Before you begin: Focus an item.

Exactly how to do it

  1. Press Space with M, or press and hold the square Recent apps button.

  2. Use Previous/Next through available actions.

  3. Press Enter on the intended action.

  4. Press Back to cancel.

What should happen: Actions relevant to the selected item appear.

If that does not happen: Not every screen/app has a KeySoft context menu.

Practice: Open the context menu on a Main Menu app and cancel.

7.1 Adjust Speech Without Opening Settings

What you will learn: Change volume or rate quickly.

Before you begin: Speech is on.

Exactly how to do it

  1. Press Enter with dot 4 several times to raise accessibility volume.

  2. Press Enter with dot 1 to lower it.

  3. Press Enter with dot 6 to increase speech rate.

  4. Press Enter with dot 3 to decrease speech rate.

  5. Set comfortable levels.

What should happen: Speech changes immediately.

If that does not happen: If media volume changes instead, verify you used the correct dot command.

Practice: Practice all four commands.

Part 8 - Notification Shade and Android Settings

8.1 Open Notifications

What you will learn: Check battery, Wi-Fi, downloads, and system notices.

Before you begin: The Touch Plus is running.

Exactly how to do it

  1. Press Enter with N.

  2. Use Previous/Next through notification items.

  3. Open a notification only if you recognize it.

  4. Press Back to return.

What should happen: The Android notification shade becomes accessible through KeySoft.

If that does not happen: If you hear no notifications, the shade may be empty.

Practice: Check battery/Wi-Fi status.

8.2 Open Android Settings

What you will learn: Change system-level settings carefully.

Before you begin: Know which setting you need.

Exactly how to do it

  1. Press Enter with Q.

  2. Navigate with Previous/Next and first-letter navigation.

  3. Open the desired category.

  4. Change one setting at a time.

  5. Press Back to return.

What should happen: Android settings open while KeySoft continues providing accessibility.

If that does not happen: Do not turn off accessibility/KeySoft unless intentionally handing the device to a sighted user.

Practice: Locate Wi-Fi, Bluetooth, and Storage without changing them.

Part 9 - KeyWord Word Processor

9.1 Create and Save a Document

What you will learn: Write a basic document.

Before you begin: Open KeyWord from Main Menu.

Exactly how to do it

  1. Choose Create/New document.

  2. Type a short title and paragraph using braille input.

  3. Press Space with S to save.

  4. Enter a filename/location if prompted.

  5. Confirm the save.

  6. Press Space with E to leave the file when finished.

What should happen: The document is stored and can be reopened.

If that does not happen: If Save opens 'Save As,' provide a unique filename and confirm the folder.

Practice: Create, save, close, and reopen a practice document.

Part 10 - KeyFiles File Manager

10.1 Browse Files and Folders

What you will learn: Find stored documents without using the touchscreen.

Before you begin: Open KeyFiles.

Exactly how to do it

  1. Use Previous/Next to move through drives, folders, and files.

  2. Use first-letter navigation for a known filename/folder.

  3. Press Enter/routing key to open a folder or file.

  4. Use Back to go to the parent/previous view.

  5. Use Space with M for file actions when available.

What should happen: You can identify storage location and file before opening it.

If that does not happen: If an external file will not open directly, copy it to internal storage first; third-party apps can have external-storage permission limits.

Practice: Navigate internal storage and one folder.

10.2 Safely Eject SD or USB Storage

What you will learn: Prevent corruption before physical removal.

Before you begin: An SD card or USB drive is connected.

Exactly how to do it

  1. Press Enter with E.

  2. Select the storage device to eject.

  3. Press Enter.

  4. Wait for the safe-removal confirmation.

  5. Physically remove the card/drive only after confirmation.

What should happen: The media is unmounted safely.

If that does not happen: If no storage is listed, verify it is actually connected.

Practice: Practice reaching the eject menu without removing media.

Part 11 - KeyMail and Email

KeyMail provides an accessible email workflow. Account-provider security requirements can change, so follow current HumanWare/account-provider sign-in instructions rather than old 'less secure app' procedures.

11.1 Compose a Basic Email

What you will learn: Send a message only after verifying recipient and content.

Before you begin: An email account is configured.

Exactly how to do it

  1. Open KeyMail.

  2. Choose Compose/New message.

  3. Enter the recipient address and verify it.

  4. Move to Subject and type a concise subject.

  5. Move to the message body and type the message.

  6. Use the context menu/help to locate Attach when needed.

  7. Review recipient, subject, attachment, and body.

  8. Activate Send.

What should happen: The message is sent through the configured account.

If that does not happen: If sign-in fails, check current OAuth/account-provider requirements and HumanWare support rather than repeatedly changing password/security settings.

Practice: Compose a draft to yourself before sending.

13.1 Read and Navigate a Book

What you will learn: Use EasyReader without relying on touchscreen exploration.

Before you begin: Open a downloaded safe book.

Exactly how to do it

  1. Press Space with G to play/pause.

  2. Press Space with T to review navigation settings.

  3. Use Space+dots 1-3 and Space+dots 4-6 to move previous/next at the selected navigation level.

  4. Press Enter with M to add a bookmark.

What should happen: Reading and structural navigation work from the braille keyboard.

If that does not happen: If the book lacks headings/pages, only the navigation levels present in that title will be available.

Part 14 - KeyList, KeyPlan, and KeyCalc

  • KeyList stores and searches contacts. Use first-letter navigation and contextual help for fields/actions.

  • KeyPlan provides calendar/planner functions. Verify date, time, recurrence, and reminder before saving appointments.

  • KeyCalc provides calculator functions. Use contextual help for mode-specific commands.

  • These apps use the same KeySoft pattern: Previous/Next, Enter, Back, first-letter navigation, Space+H help, Space+M context menu.

Part 15 - SD Cards, USB Drives, and External Storage

  • SDHC slot: rear edge, immediately to the right of the full-size USB port.

  • USB storage port: rear edge near the left corner.

  • USB-C computer/charging port: upper-left side, not the rear USB host port.

  • HumanWare recommends copying files to internal storage when a third-party app cannot open content directly from USB/SD storage.

  • Always eject with Enter+E before physical removal.

Part 16 - Wi-Fi and Bluetooth

16.1 Connect to Wi-Fi

What you will learn: Join a trusted wireless network.

Before you begin: Know the network name and password.

Exactly how to do it

  1. Press Enter with Q.

  2. Open Wi-Fi settings.

  3. Turn Wi-Fi on if needed.

  4. Select the trusted network.

  5. Enter the password carefully.

  6. Activate Connect.

  7. Use Enter with dots 3-4 to hear connectivity information when supported.

What should happen: The device connects and online apps can use the network.

If that does not happen: If it fails, verify password case and network restrictions.

Practice: Connect to a known network.

16.2 Pair a Bluetooth Device

What you will learn: Connect headphones/keyboard/host device.

Before you begin: Bluetooth device is in pairing mode.

Exactly how to do it

  1. Press Enter with Q.

  2. Open Bluetooth settings.

  3. Turn Bluetooth on.

  4. Find the intended device by name.

  5. Activate Pair and confirm pairing prompts.

What should happen: The device appears as connected/paired.

If that does not happen: Verify names carefully in public areas to avoid pairing with the wrong device.

Practice: Pair and unpair a harmless device.

Part 17 - Braille Terminal

Braille Terminal makes the Touch Plus act as a braille display/controller for another computer or mobile device.

17.1 Start Braille Terminal

What you will learn: Choose Bluetooth or USB connection mode.

Before you begin: The host device is ready.

Exactly how to do it

  1. Return to Main Menu.

  2. Type B until Braille Terminal is selected.

  3. Press Enter.

  4. Choose Bluetooth or USB.

  5. Press Enter.

  6. Complete pairing/connection on the host device.

  7. Turn on/configure the host screen reader's braille support.

What should happen: The Touch Plus begins displaying the host screen reader's braille output.

If that does not happen: While Braille Terminal is active, normal KeySoft keyboard shortcuts are forwarded to the host. Use the physical Home button to leave Braille Terminal without necessarily breaking the connection.

Practice: Start Braille Terminal and return Home.

Connection rule: Pair/connect first, configure the host screen reader second, then test OUTPUT, INPUT, and ROUTING.

Part 18 - Connect to iPhone/iPad

18.1 Pair with VoiceOver

What you will learn: Use the Touch Plus as an Apple braille display.

Before you begin: Bluetooth is on and Braille Terminal is set to Bluetooth.

Exactly how to do it

  1. On the Touch Plus, open Braille Terminal and choose Bluetooth.

  2. On iPhone/iPad, open Settings > Accessibility > VoiceOver > Braille.

  3. Move to the list of detected braille displays.

  4. Choose the Brailliant/BrailleNote Touch Plus entry.

  5. Confirm Pair on both devices if prompted.

  6. Return to an iPhone/iPad app.

  7. Test that VoiceOver text appears on the Touch Plus.

  8. Type with the braille keyboard and test a routing key.

What should happen: VoiceOver uses the Touch Plus for braille input/output.

If that does not happen: Apple's settings paths can shift by iOS version; stay within VoiceOver > Braille and select the detected display.

Practice: Test output, input, and routing.

Part 19 - Connect to Windows with JAWS/NVDA/Narrator

19.1 Windows Connection Workflow

What you will learn: Use Bluetooth or USB without mixing KeySoft and host commands.

Before you begin: Braille Terminal is open.

Exactly how to do it

  1. Choose Bluetooth or USB in Braille Terminal.

  2. Complete Windows pairing or connect the USB-C cable as appropriate.

  3. Start the screen reader.

  4. Open that screen reader's braille/display settings.

  5. Choose a HumanWare/Brailliant/BrailleNote-compatible display driver if required.

  6. Verify COM/USB/Bluetooth connection when the screen reader asks.

  7. Test host text on the braille display.

  8. Type from the Touch Plus.

  9. Use a routing key.

What should happen: The host screen reader controls braille output and interprets input commands.

If that does not happen: Exact screen-reader driver menus change. Use HumanWare's current connection guides and the screen reader's current braille settings.

Practice: Perform the three-part output/input/routing test.

Part 20 - Connect to Mac and Android

  • Mac: put Braille Terminal in Bluetooth, pair in macOS/VoiceOver braille settings, then test output/input/routing.

  • Android: put Braille Terminal in Bluetooth and pair the display in TalkBack braille-display settings/current Android accessibility workflow.

  • Do not assume commands are identical across VoiceOver, TalkBack, JAWS, NVDA, and Narrator; once in Braille Terminal, the host screen reader's command set controls behavior.

Part 21 - Running Apps and Multitasking

21.1 Switch Running Apps

What you will learn: Return to a recent app without reopening it from Main Menu.

Before you begin: At least two apps have been opened.

Exactly how to do it

  1. Press the square Recent apps button, or Space with dots 2-3-5.

  2. Use thumb keys through running apps.

  3. Press Enter/routing key to return to one.

  4. Double-press Recent apps to switch quickly between the last two apps when supported.

What should happen: The running app returns with its state preserved.

If that does not happen: Exiting with Back does not always close an app. Use Recent apps and Dismiss/Clear all when you truly need to close it.

Practice: Open KeyWord and KeyFiles and switch between them.

21.2 Close a Running App

What you will learn: Dismiss an app intentionally.

Before you begin: Recent apps is open.

Exactly how to do it

  1. Move to the app.

  2. Move to its Dismiss item/action.

  3. Activate Dismiss.

  4. Use Clear All only when you intend to close all running apps.

What should happen: The selected application is fully closed.

If that does not happen: Closing Braille Terminal ends its host connection; leaving it with Home can preserve the connection.

Practice: Close a disposable app and reopen it.

Part 22 - Google Play and Third-Party Apps

  • All Applications contains KeySoft apps plus Android apps installed from Google Play.

  • Third-party apps may be less accessible than KeySoft apps and may not support Contextual Help.

  • Before installing an app, review developer, permissions, account requirements, and whether its current Android version supports the Touch Plus.

  • Do not grant camera, microphone, contacts, storage, or accessibility permissions unless needed.

  • KeySoft remains the system accessibility service; a poorly designed app can still have unlabeled or unreachable controls.

Part 23 - Updates and System Information

23.1 Check Device/App Information

What you will learn: Identify versions before troubleshooting.

Before you begin: Return to Main Menu.

Exactly how to do it

  1. Press Space with I for system information.

  2. Listen/read device and software information.

  3. To inspect one app, focus it on Main Menu/All Applications.

  4. Open the context menu with Space+M or long-press Recent apps.

  5. Choose Information/App info.

What should happen: You can identify software/app versions without guessing.

If that does not happen: If version information differs from an old tutorial, rely on current HumanWare support materials.

Practice: Record the KeySoft/user-guide version used for your unit.

KeyUpdater: HumanWare provides KeyUpdater for KeySoft/app updates. After an update, the device may need to restart to finish installation.

Part 24 - Security, Privacy, and Backups

  • Use a lock-screen credential if the Touch Plus contains email, contacts, school/work documents, or cloud accounts.

  • Do not disable KeySoft accessibility accidentally by holding both volume buttons unless a sighted-access workflow intentionally requires it.

  • Use current OAuth/sign-in methods for email and Google accounts; do not follow obsolete instructions to weaken account security.

  • Safely eject SD/USB storage before removal.

  • Back up important documents to an approved external/cloud location.

  • Third-party apps can request broad permissions; grant only what is necessary.

  • Braille Terminal can expose host-device screen content on the Touch Plus, so treat both devices as part of the same privacy boundary.

Part 25 - Troubleshooting

25.1 You Are Lost in a Menu/App

What you will learn: Return to a known KeySoft location.

Before you begin: The Touch Plus is responsive.

Exactly how to do it

  1. Press Space with H and listen to contextual help.

  2. Press Back or Space with E once or more.

  3. Press the physical Home button.

  4. At Main Menu, use first-letter navigation to reopen the needed app.

What should happen: You return to a predictable location.

If that does not happen: If the Home button does not respond, try Recent apps or a power restart only after simpler recovery.

Practice: Practice recovery from three apps.

25.2 No Speech but Braille Works

What you will learn: Restore speech without changing accessibility service.

Before you begin: The device is responsive in braille.

Exactly how to do it

  1. Press Space with Previous thumb to toggle speech.

  2. Press Enter+dot 4 to raise accessibility volume.

  3. Press Space+R to repeat.

What should happen: Speech returns.

If that does not happen: If speech remains silent, check Android sound output/headphones/Bluetooth.

Practice: Toggle speech off/on deliberately.

25.3 Braille Does Not Update

What you will learn: Check application/focus before hardware assumptions.

Before you begin: Speech is working.

Exactly how to do it

  1. Pan Left/Right.

  2. Move to Main Menu with Home.

  3. Move Next/Previous and see whether cells update.

  4. If using Braille Terminal, verify the host screen reader is connected and braille is enabled.

  5. Restart Braille Terminal or the host screen reader before restarting the whole Touch Plus.

What should happen: Braille resumes or the failure is isolated to host connection/app.

If that does not happen: If cells never change even in Main Menu, use HumanWare hardware support.

Practice: Test internal KeySoft braille before host braille.

25.4 External Storage Will Not Open

What you will learn: Use internal-copy workflow and permissions awareness.

Before you begin: USB/SD is detected.

Exactly how to do it

  1. Open KeyFiles.

  2. Find the file.

  3. Use Context menu to copy it to internal storage.

  4. Open the internal copy.

  5. Safely eject media afterward.

What should happen: KeySoft/third-party app can access the copied file more reliably.

If that does not happen: Some third-party apps lack external-storage permission; this is not necessarily file corruption.

Practice: Copy/open one harmless file.

25.5 Braille Terminal Will Not Connect

What you will learn: Use the connection rule instead of random pairing retries.

Before you begin: Host and Touch Plus are nearby.

Exactly how to do it

  1. Close any stale host braille connection.

  2. Open Braille Terminal and choose the intended connection type.

  3. Pair/connect the devices.

  4. Then open/configure the host screen reader's braille settings.

  5. Test OUTPUT first, then INPUT, then ROUTING.

  6. Only remove/re-pair the Bluetooth device if simpler reconnection fails.

What should happen: The connection is restored or the failure stage is identified.

If that does not happen: Do not troubleshoot Touch Plus KeySoft shortcuts while Braille Terminal is forwarding keys to the host.

Practice: Practice identifying whether failure is pairing, screen-reader config, or routing.

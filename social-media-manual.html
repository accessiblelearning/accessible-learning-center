All manuals Table of contents Start of manual

Purpose: This manual teaches how to use major social-media platforms with a screen reader and how to create posts that are accessible to other people. It assumes no prior social-media experience.

Platforms: Facebook, LinkedIn, YouTube, and X. Interfaces change frequently, so the manual teaches stable navigation patterns first and then platform-specific controls.

Screen readers: Desktop guidance applies to Narrator, NVDA, JAWS, and VoiceOver where appropriate. Mobile guidance applies to VoiceOver on iPhone/iPad and TalkBack on Android.

How to Use This Manual

  • Use headings, landmarks, buttons, links, edit fields, and lists rather than tabbing through every item on long feeds.

  • When a platform introduces a new layout, identify the main navigation region, search field, feed/timeline, post composer, notifications, profile, and settings before learning platform-specific shortcuts.

  • Use screen-reader application/focus mode only when the web app requires direct keyboard commands; return to browse/virtual mode for ordinary webpage navigation.

  • Before posting media, add meaningful alt text to images and accurate captions to video when the platform supports them.

  • Write hashtags in CamelCase, avoid long strings of emoji, and avoid decorative Unicode characters that screen readers may announce one symbol at a time.

  • Before changing privacy or audience settings, have the screen reader repeat the selected audience or account name.

  • Do not trust direct messages that ask for passwords, codes, gift cards, crypto, remote access, or urgent money transfers.

Part 1 - Social Media with a Screen Reader

Most social platforms are dynamic web applications. New posts load without a full page refresh, menus open in dialogs, buttons change labels after activation, and feeds can contain repeated controls. The key skill is maintaining context.

  • Main navigation: Home/Feed, Search, Notifications, Messages, Profile, Settings.

  • Feed/timeline: a long list of posts. Each post can contain author, time, text, media, reaction controls, comment/reply controls, and menus.

  • Composer: edit field/dialog for creating a post.

  • Post details: a focused page/dialog for one post and its replies/comments.

  • Notifications: activity related to your account.

  • Direct messages: private conversations; not automatically trustworthy merely because they appear inside a social platform.

Part 2 - Screen Reader Navigation Patterns

Next list L
Screen-reader elements list NVDA+F7 / JAWS+F3 or Insert+F7 / VO rotor

Command warning: Screen-reader single-letter commands work only in browse/virtual mode. If typing H, B, or E enters characters into a post field, exit the edit field or return to browse mode.

2.1 Rebuild Context on Any Platform

What you will learn: Recover when focus gets lost in a dynamic feed.

Before you begin: A social-media webpage is open.

Exactly how to do it

  1. Press Escape once or twice to close an open menu/dialog if appropriate.
  2. Use your screen reader to move to the page title or first heading.
  3. Move by landmarks/regions to find navigation or main content.
  4. Use headings or buttons to find the feed, search, notifications, or composer.
  5. Have the screen reader repeat the focused item before activating it.

What should happen: You regain a known location without refreshing or signing out.

If that does not happen: If the page remains confused, use the browser address bar and reload the known platform homepage, then navigate again.

Practice: Practice getting lost intentionally and recovering.

Part 3 - Writing Accessible Social Posts

  • Use sentence case rather than all capitals.

  • Keep important information in text, not only inside an image.

  • Break long posts into short paragraphs.

  • Put emoji at natural points and avoid repeating the same emoji many times.

  • Use descriptive link wording when the platform allows it.

  • Use CamelCase hashtags: #ScreenReaderUsers rather than #screenreaderusers.

  • Do not use decorative mathematical/script Unicode characters as fake fonts; screen readers may announce them poorly or character by character.

  • If a post depends on a chart, screenshot, flyer, or meme, add the essential information in alt text or the post body.

Part 4 - Image Descriptions and Alt Text

Alt text should communicate the image information needed to understand the post. Describe purpose and key content, not every pixel.

  • Good: “Three coworkers seated around a conference table reviewing a tactile diagram.”

  • Better for text-heavy image: include the important visible words in the post itself, then describe the visual context.

  • Avoid starting every description with “Image of” unless the platform does not already identify it as an image.

  • Do not use auto-generated alt text as a substitute for reviewing important images.

4.1 Add Alt Text Before Posting

What you will learn: Make an uploaded image understandable to screen-reader users.

Before you begin: A social platform supports author-supplied alt text.

Exactly how to do it

  1. Upload/select the image in the post composer.
  2. Move through the image editing controls until you find Alt text, ALT, Edit, Accessibility, or Image description.
  3. Open that control.
  4. Type a concise description of the image’s important content and purpose.
  5. Save/Done the description.
  6. Return to the post composer and review the audience and post text before publishing.

What should happen: The platform stores your description with the image.

If that does not happen: If the platform does not expose an alt-text control in the current app, put the essential image description in the post text and try the desktop/web composer if practical.

Practice: Add alt text to a harmless test image.

Part 5 - Video Captions and Audio Description

  • Captions provide text access to speech and meaningful audio.

  • Auto-captions are useful but should be reviewed for names, jargon, numbers, and punctuation when you control the video.

  • Burned-in/on-screen captions are not always exposed as text to screen readers, but they still help many viewers; platform caption tracks are preferable when available.

  • Audio description narrates important visual information that is not obvious from dialogue/sound.

  • If audio description is not supported as a separate track, include essential visual context in narration or the description/post text.

Part 7 - Facebook: Orientation and Feed

Interface note: Facebook changes its desktop and mobile layouts frequently. Use headings, buttons, landmarks, and the platform’s labeled navigation rather than memorizing a long tab order.

7.1 Find the Facebook Feed

What you will learn: Reach posts from the homepage.

Before you begin: You are signed in.

Exactly how to do it

  1. Open facebook.com or the Facebook app.
  2. Find the main navigation/Home control and activate it if needed.
  3. Move to the main content/feed region.
  4. Use headings, article-like groups, or screen-reader reading commands to move through posts.
  5. Within a post, read the author and post text before moving to reaction/comment/share controls.

What should happen: You can read one post at a time while maintaining author/context.

If that does not happen: If focus lands in Stories/Reels or another carousel, move by landmark/heading to the main feed.

Practice: Read five posts and identify each author.

Part 8 - Facebook: Posting, Comments, Groups, and Messages

8.1 Create a Facebook Post

What you will learn: Publish text with the intended audience.

Before you begin: You are on Facebook Home.

Exactly how to do it

  1. Find the “What’s on your mind” or Create post control.
  2. Activate it and move to the post text field.
  3. Type the post.
  4. If adding a photo, upload it and open the image-editing controls.
  5. Use Facebook’s Add alternative text control when available and enter a description.
  6. Move to the audience/privacy selector and have the screen reader read the selected audience.
  7. Activate Post only after reviewing text, media, alt text, and audience.

What should happen: The post appears with the intended audience.

If that does not happen: If the composer becomes difficult, press Escape, reopen it, and add one element at a time.

Practice: Create a Friends-only test post and remove it afterward if desired.

  • Comments: open the Comments control for the post, move to the comment edit field, type, then submit with the labeled button/Enter as supported.

  • Groups: verify the group name before posting because group privacy/audience differs from your personal feed.

  • Messenger/DMs: read the conversation name before sending; treat unexpected links/payment requests as suspicious.

  • Facebook currently provides an Add alternative text option when editing photos before sharing.

Part 9 - LinkedIn: Orientation and Feed

LinkedIn publishes dedicated screen-reader support articles and states that it tests with JAWS, NVDA, Narrator, VoiceOver, and TalkBack. Its desktop navigation is generally well-labeled but dynamic dialogs and feed cards can still be dense.

9.1 Navigate LinkedIn by Regions

What you will learn: Move among the major LinkedIn areas.

Before you begin: You are signed in on linkedin.com.

Exactly how to do it

  1. Use the main navigation to identify Home, My Network, Jobs, Messaging, Notifications, and Me/Profile.
  2. Activate Home.
  3. Move to main content and locate the feed.
  4. Read posts by heading/author text and then use buttons for reaction/comment/repost controls.
  5. Use the Me/Profile menu to return to your profile when needed.

What should happen: You can move between the major LinkedIn work areas without tabbing through every control.

If that does not happen: If a mobile-optimized view appears unexpectedly in the browser, maximize the browser window or use the current desktop layout controls.

Practice: Open Home, Jobs, Messaging, and Profile.

Part 10 - LinkedIn: Profile, Posts, Networking, and Jobs

10.1 Add Alt Text to a LinkedIn Image Post

What you will learn: Create an accessible image post.

Before you begin: Start a LinkedIn post and upload an image.

Exactly how to do it

  1. After the image uploads, find Alt.text or ALT.
  2. Activate it.
  3. Type the description.
  4. Choose Save/Done.
  5. Review post visibility and comment controls.
  6. Publish the post.

What should happen: LinkedIn stores author-provided alt text with the image.

If that does not happen: If LinkedIn supplies automatic alt text, replace/review it when the image matters to understanding the post.

Practice: Add alt text to one test photo.

  • Profile: LinkedIn provides screen-reader-specific help for profile intro, contact info, experience, skills, education, recommendations, and Open to Work options.

  • Networking: read the person’s name/headline before Connect/Follow; avoid sending connection requests from ambiguous search-result controls.

  • Jobs: use the Jobs navigation item, search filters, job-details heading, and application controls. External applications may open another employer/ATS site.

  • Messaging: confirm recipient/thread before typing; LinkedIn job scams can still occur inside legitimate messaging.

Part 11 - YouTube: Search and Watching Videos

11.1 Search YouTube with a Screen Reader

What you will learn: Find a video efficiently.

Before you begin: YouTube is open in a desktop browser.

Exactly how to do it

  1. Press / to move to YouTube Search, or navigate to the Search edit field.
  2. Type the search term.
  3. Press Enter.
  4. Move through result titles/headings/links.
  5. Read the channel name and result description before opening a video.
  6. Activate the video title.

What should happen: The watch page opens and the player is available.

If that does not happen: If / types into another edit field, leave that field first or navigate directly to Search.

Practice: Search for a known channel and play one video.

12.1 Turn Captions On and Review Settings

What you will learn: Use text captions during playback.

Before you begin: A video offers captions.

Exactly how to do it

  1. Give focus to the video player.
  2. Press C.
  3. If you need caption language/style, move to the Settings button.
  4. Open Subtitles/CC and choose the available track/language.
  5. Use the caption Options area for visual styling if needed.
  6. Press C again to turn captions off.

What should happen: Captions are displayed while speech continues.

If that does not happen: Not every video has accurate human-reviewed captions; auto-captions can contain errors.

Practice: Toggle captions on two videos.

Part 13 - YouTube: Comments, Subscriptions, Playlists, and Uploading

  • Subscribe: locate the Subscribe/Unsubscribe button near the channel/video information and confirm the new button state.

  • Comments: navigate to the comments heading/region, activate the Add a comment edit field, type, and submit with the labeled Comment button.

  • Playlists: use Save to add a video to a playlist; confirm the exact playlist before closing the dialog.

  • Uploading: YouTube Studio > Create > Upload videos. Add a clear title, description, audience settings, visibility, and captions.

  • Creators should review/edit automatic captions when possible. YouTube also provides caption-management tools and caption-generation workflows.

Part 14 - X: Orientation and Timeline

X publishes accessibility features including screen-reader/braille support, keyboard shortcuts, image descriptions, captions, reduce-motion settings, font/display customization, and autoplay controls.

14.1 Read the X Home Timeline

What you will learn: Use X’s timeline without tabbing through every control.

Before you begin: You are signed in at x.com.

Exactly how to do it

  1. Press g then h to move to Home when X keyboard shortcuts are active.
  2. Press j for the next post.
  3. Press k for the previous post.
  4. Press Enter to open the current post’s detail view when needed.
  5. Use Escape/browser navigation to return to the timeline.

What should happen: Focus moves post by post through the timeline.

If that does not happen: If j/k type into a text field, leave the field before using X shortcuts. Press ? to review the active shortcut list.

Practice: Move through ten posts and open one detail view.

Part 16 - X: Posting, Replies, Direct Messages, and Alt Text

16.1 Create an Accessible X Post

What you will learn: Publish text and image description with keyboard access.

Before you begin: You are on x.com.

Exactly how to do it

  1. Press n to open a new post.
  2. Type the post text.
  3. If adding an image, upload it.
  4. Find the +ALT / Add description control for the image.
  5. Type a meaningful image description and save it.
  6. Review the post text and media.
  7. Press Ctrl+Enter on Windows or Command+Enter on Mac to send, or activate the Post button.

What should happen: The post is published with alt text when added.

If that does not happen: If the ALT control is not exposed in the current client, try the latest X web/mobile app or include critical image information in the post text.

Practice: Post a harmless image with alt text, then read it back.

  • X recommends sentence case, CamelCase hashtags, line breaks for long text, limited emoji repetition, and avoiding special/decorative characters.

  • Replies use r; always verify which post is currently focused before replying.

  • Direct Messages can contain phishing. Do not assume a verified/known-looking account is trustworthy when it asks for credentials or payment.

Part 17 - Mobile Social Media with VoiceOver

  • Swipe right/left through controls; double-tap to activate.

  • Use the VoiceOver rotor to move by headings, links, form controls, or containers where supported.

  • Use the two-finger scrub to go back/cancel in many contexts.

  • When composing, move deliberately among audience, text, media, alt-text/caption, and Post/Share controls before publishing.

  • X documents an iOS Magic Tap option that can be configured for composing a post.

  • For media, find the ALT/Accessibility/Edit controls after selecting the image rather than assuming the description field appears automatically.

Part 18 - Mobile Social Media with TalkBack

  • Swipe right/left through controls; double-tap to activate.

  • Use TalkBack reading controls for headings/links/controls when the app exposes them.

  • Use TalkBack’s global Back gesture/system Back to close dialogs or return.

  • After uploading media, explore the image editing controls for Alt text/Description before posting.

  • X documents TalkBack/Android support along with reduce motion, autoplay, media preview, sound, and font-size settings.

  • If a mobile app becomes difficult, try the platform’s mobile website or desktop browser with a screen reader before assuming the task is impossible.

Part 19 - Privacy, Security, and Scam Safety

  • Check the audience before every sensitive post: Public/Anyone, Friends/Connections, group, followers, or custom audience.

  • Assume public posts can be copied, screenshot, quoted, reposted, or archived.

  • Never send passwords, one-time codes, recovery codes, bank details, or remote-access codes through social DMs.

  • If a friend’s account suddenly asks for money or gift cards, verify through a separate known contact method.

  • Use MFA/passkeys on social accounts where available.

  • Review active sessions/devices and connected apps periodically.

  • Do not install browser extensions or apps sent through a DM just to view a post/video.

Part 20 - Troubleshooting

20.1 Feed Navigation Suddenly Stops Working

What you will learn: Recover from focus/mode problems.

Before you begin: A single-letter command no longer moves through posts.

Exactly how to do it

  1. Press Escape to leave any open menu/edit field.
  2. Have the screen reader report the focused control.
  3. Return to browse/virtual mode if you are in focus/forms mode.
  4. Move to the main/feed region.
  5. Retry the platform or screen-reader navigation command.

What should happen: Feed navigation works again.

If that does not happen: If the platform changed layout, use headings/buttons/landmarks rather than relying on the old shortcut.

Practice: Practice entering/exiting an edit field and restoring navigation.

20.2 Post Button Seems Disabled

What you will learn: Find a missing required step.

Before you begin: You finished writing a post.

Exactly how to do it

  1. Review the composer from the beginning.
  2. Check whether media is still uploading.
  3. Check whether an audience/visibility selection is required.
  4. Check for an error message or character/media limit.
  5. Remove one optional media item and test again if needed.

What should happen: The missing requirement/error becomes clear.

If that does not happen: Copy your post text to a temporary safe note before reloading a broken composer so you do not lose it.

Practice: Practice recovering a draft.

20.3 Alt Text Control Is Hard to Find

What you will learn: Use the media-editing layer rather than the main composer.

Before you begin: An image is already attached.

Exactly how to do it

  1. Move to the attached image/media controls.
  2. Open Edit, ALT, Accessibility, or image options.
  3. Look for Add/Edit alternative text or description.
  4. If absent, try the platform’s current desktop web composer or current mobile app.
  5. If still unavailable, include the essential description in the post body.

What should happen: The image receives an accessible description or equivalent text is provided.

If that does not happen: Platform features can vary by account/client; do not delay critical information solely because an alt-text control is unavailable.

Practice: Find the alt-text control on two platforms.

20.4 Screen Reader Repeats Too Many Controls

What you will learn: Use structure rather than Tab navigation.

Before you begin: A post has many Like/Reply/Share/Menu controls.

Exactly how to do it

  1. Use heading/article navigation to move to the next post.
  2. Use the platform’s next-post shortcut when available, such as j on X.
  3. Use screen-reader elements lists/rotor to jump to a specific control only when needed.
  4. Avoid tabbing through every reaction control on every post.

What should happen: Reading becomes faster and less repetitive.

If that does not happen: If posts are not marked structurally, use Find/Search for author text or switch platform client/browser.

Practice: Read ten posts without tabbing through every button.

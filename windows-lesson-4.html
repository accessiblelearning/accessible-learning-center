Windows 11 Lesson 4

Creating, Renaming, Copying, Moving, and Deleting Files

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Organize practice files and folders using safe keyboard commands.

Skills practiced

  • Create a folder and text file.
  • Rename an item.
  • Copy and move items.
  • Use Delete and the Recycle Bin safely.

Step-by-step instructions

  1. Open Documents in File Explorer and create a folder with Ctrl+Shift+N.
  2. Name the folder Windows Practice and press Enter.
  3. Open the folder and create Windows-Lesson-4.txt in Notepad. Type Practice document and save it.
  4. Return to File Explorer and press F2 on the file. Rename it Workplace-Practice.txt.
  5. Press Ctrl+C to copy the file.
  6. Create a second folder named Archive, open it, and press Ctrl+V to paste the copy.
  7. Return to the original file, press Ctrl+X, open Archive, and press Ctrl+V to move it. Confirm whether Windows asks about a duplicate name and cancel rather than overwrite unexpectedly.
  8. Select one unnecessary practice copy and press Delete. Open the Recycle Bin and confirm the item is present without permanently deleting it.
  9. Restore the item if available, then write Windows-Lesson-4.txt describing each operation and the difference between copy and move.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

Before submitting

  • Copy and move are distinguished accurately.
  • The report explains how unexpected overwrite prompts were handled.
  • The Recycle Bin is included.
  • The file is named Windows-Lesson-4.txt.

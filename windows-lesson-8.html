Windows 11 Lesson 8

Security, Privacy, Updates, and Safe Downloads

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Recognize routine Windows security tasks and avoid unsafe or unauthorized changes.

Skills practiced

  • Identify Windows Update status.
  • Recognize User Account Control prompts.
  • Review file extensions and download locations.
  • Apply safe privacy and phishing habits.

Step-by-step instructions

  1. Press Windows+I and search for Windows Update.
  2. Review the update status and any restart message. Do not pause updates or install optional items on a workplace computer without permission.
  3. Open Update history and review recent entries without uninstalling anything.
  4. Discuss User Account Control: when a prompt requests administrator approval, stop and confirm the action with authorized support staff.
  5. Open File Explorer and confirm that a practice file’s name and extension match the expected type.
  6. Open the Downloads folder and review names only. Do not run unknown files.
  7. Use Alt+Enter on a known practice file to review its type and location.
  8. Write three warning signs of a suspicious download or message, such as unexpected urgency, mismatched file type, or a request for credentials.
  9. Record the approved help contact or general process for reporting a suspicious prompt without including private phone numbers in the assignment.
  10. Create Windows-Lesson-8.txt with the update, download, and security checklist.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

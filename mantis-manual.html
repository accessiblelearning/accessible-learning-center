Purpose and setup

This manual supports independent practice with Mantis Q40 on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Basic and advanced how-tos

Orient the controls and open the main menu

Device controls: Use the QWERTY keyboard for typing, the panning controls to move through braille, cursor routers to position the cursor, and the Home button to return to the device menu.

  1. Place the Mantis with the braille cells closest to you.
  2. Locate the QWERTY keyboard, 40 cursor routers, panning controls, and Home button.
  3. Power on and wait for the startup message.
  4. Press Home and move through menu items one at a time.
  5. Press Enter only after the intended item is displayed.

If that does not happen: Confirm the device has completed startup and that no dialog or update message is open.

Connect to Windows in Terminal mode

Keyboard commands: In Terminal mode, the Mantis QWERTY keyboard sends standard Windows and application commands such as Alt+Tab, Ctrl+S, and Insert+T for JAWS.

  1. Start JAWS on the computer.
  2. Connect the Mantis by USB or pair the intended Bluetooth connection.
  3. From the Mantis menu, open Terminal.
  4. Select the verified USB or Bluetooth channel.
  5. Press Insert+T and confirm the Windows title appears in braille.
  6. Open a practice document, type a short line, and press Ctrl+S.

If that does not happen: Confirm the connection channel, JAWS braille display selection, and Windows focus before pairing again.

Read and edit from the braille line

Device commands: Panning controls move backward or forward; a cursor router above a cell moves the editing cursor to that text position.

  1. Open a practice document and verify its title.
  2. Pan forward one display and then back.
  3. Route to a known word.
  4. Use Shift with arrow keys on the QWERTY keyboard to select a small range.
  5. Type a correction, review it in braille, and press Ctrl+S.

If that does not happen: Undo with Ctrl+Z and verify whether focus, the braille cursor, and the editing caret are aligned.

Transfer a local file safely

  1. Save and close the local Mantis file.
  2. Connect the device or removable storage as described for the current firmware.
  3. On the computer, open File Explorer with Windows+E.
  4. Open the Mantis storage location and verify the source and destination.
  5. Copy with Ctrl+C and paste with Ctrl+V.
  6. Confirm the filename and size, then eject safely before disconnecting.

If that does not happen: Preserve both copies and never unplug while a transfer or update is in progress.

Ten-lesson learning path

  1. Lesson 1: Orientation, Power, and Status — Create an orientation guide naming major controls and their purposes.
  2. Lesson 2: Connect by USB and Bluetooth — Write a safe connection checklist without including pairing codes.
  3. Lesson 3: Use Terminal Mode with JAWS — Submit a terminal-mode practice log.
  4. Lesson 4: Read and Navigate with Braille Commands — Create a command chart for reading and navigation.
  5. Lesson 5: Editor and Local Files — Create Mantis-Lesson-5.txt in the local editor.
  6. Lesson 6: Cursor Routing, Selection, and Editing — Submit a revision log and the edited text file.
  7. Lesson 7: Menus, Profiles, and Settings — Create a settings safety checklist.
  8. Lesson 8: USB Storage and File Transfer — Write a file-transfer verification report.
  9. Lesson 9: Troubleshooting and Updates — Create a no-data-loss troubleshooting flow.
  10. Lesson 10: Final Workplace Braille Project — Complete an end-to-end braille-display workplace task.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Save the requested practice file locally with the exact filename given in the lesson. Assignment uploads are currently paused.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

How to Read This Manual

You do not need to memorize the entire manual. Work through it in order the first time. Later, use the headings and quick-reference sections to look up a task.

  • Whenever you see MANTIS, the command is performed on the Mantis Q40.

  • Whenever you see MAC, it is a standard macOS keyboard command.

  • Whenever you see VOICEOVER, it is an Apple VoiceOver command.

  • VO means the VoiceOver modifier. By default, VO is Control+Option held together. Caps Lock can also be configured as VO.

  • When you see 'press', press and release the key unless the instruction says to hold it.

  • When you see a combination such as Ctrl+M, hold Ctrl, press M once, then release both keys.

  • Read the 'What should happen' paragraph after every procedure. It tells you how to confirm you succeeded.

  • If your result is different, follow the 'If that does not happen' instructions before trying unrelated settings.

Part 1 — Meet the Mantis Q40

The Mantis Q40 is unusual because it combines two devices in one: a full QWERTY keyboard and a 40-cell refreshable braille display. You can use it by itself for several tasks, or connect it to another device and use it as a braille display and keyboard.

  • 40 refreshable braille cells display text tactually.

  • A row of cursor-routing buttons lets you move directly to a braille position.

  • The QWERTY keyboard lets you type the same way you would on a conventional computer keyboard.

  • Navigation/thumb controls let you move through menus and pan the braille display.

  • Bluetooth and USB can connect the Mantis to computers and mobile devices.

  • Standalone applications include tools such as Editor, Library, Online Library, Terminal, Calculator, and Date/Time depending on firmware and configuration.

Supported files: HumanWare lists DOC, DOCX, TXT, BRF, and BRL for the Editor, and BRF, PEF, TXT, HTML, DOCX, NISO, and RTF for the Library.

1.1 Orient the Mantis by Touch

What you will learn: Find the keyboard, braille cells, routing buttons, and navigation controls without relying on sight.

Before you begin: Put the Mantis on a table with the braille display edge closest to your body.

Exactly how to do it

  1. Rest both hands lightly on the QWERTY keyboard. Find the familiar typing area and the home-row keys.
  2. Move both hands toward your body until your fingertips reach the long horizontal row of 40 braille cells.
  3. Move one index finger slowly from the far-left braille cell to the far-right braille cell. Do not press hard. Refreshable braille pins are designed to be read with light fingertip pressure.
  4. Move your fingertip slightly above the braille cells. Feel for the small cursor-routing buttons positioned above the cells.
  5. Return your hands to the front edge and locate the thumb/navigation controls. These controls are used frequently for moving and panning.
  6. Move your hands back to the QWERTY keyboard.
  7. Repeat the route keyboard → braille display → routing buttons → navigation controls → keyboard until you can find each area without searching.

What should happen: You can name and locate the keyboard, 40 braille cells, routing buttons, and navigation controls.

If that does not happen: If you become disoriented, stop pressing keys. Return both hands to the QWERTY home row and begin the tactile route again.

Practice: With the Mantis turned off, locate all four areas three times in a row.

Part 2 — Power, Charging, Startup, and Shutdown

2.1 Charge the Mantis

What you will learn: Connect the Mantis to power safely.

Before you begin: Use the charging equipment supplied with or approved for the Mantis.

Exactly how to do it

  1. Locate the charging/USB connection on the Mantis.
  2. Insert the appropriate charging cable gently. Do not force the connector. If it does not enter easily, verify orientation.
  3. Connect the other end to the appropriate power source.
  4. Leave the Mantis connected long enough to obtain a useful charge before long sessions.
  5. Before disconnecting, hold the plug rather than pulling on the cable.

What should happen: The device charges and can be powered on normally.

If that does not happen: If the device will not charge, try a known-good cable/power source that is appropriate for the device. Inspect the port for debris without inserting metal objects. If charging still fails, contact HumanWare support.

Practice: Practice locating the charging port with the device powered off.

2.2 Turn the Mantis On

What you will learn: Power on the device and recognize when startup is complete.

Before you begin: Make sure the battery is charged or the device is connected to power.

Exactly how to do it

  1. Locate the power control.
  2. Press and hold the power control for normal startup, then release it.
  3. Place your reading fingers lightly on the braille display.
  4. Wait while the braille cells initialize. Do not repeatedly press keyboard keys while the device is starting.
  5. When text or a menu item appears on the braille display, read it.
  6. Pause before doing anything else. The displayed item is the current focus.

What should happen: The braille display initializes and a menu/status item becomes readable.

If that does not happen: If nothing happens, connect power and try again. If the display briefly changes but then becomes blank, allow additional startup time before assuming failure.

Practice: Power the device on from a completely off state two times.

2.3 Turning the Mantis Off

Use the normal power/shutdown procedure rather than disconnecting power or forcing a restart. Save open files first. If an application asks whether to save changes, choose the option that preserves your work before shutting down.

Important: A forced power-off should be reserved for an unresponsive device after normal exit/shutdown methods fail.

Part 3 — Learn the Basic Navigation Controls

Most standalone Mantis tasks follow the same pattern: move to an item, read it in braille, then activate it. Do not activate an item simply because you think you know where you are.

MANTIS Move to previous menu item Press the Previous thumb/navigation key.

Expected result: The braille display changes to the preceding item.

MANTIS Move to next menu item Press the Next thumb/navigation key.

Expected result: The braille display changes to the next item.

MANTIS Activate/open current item Press Enter.

Expected result: The selected menu item or application opens.

MANTIS Pan braille left Press the Left thumb/navigation key.

Expected result: Earlier text appears on the braille display.

MANTIS Pan braille right Press the Right thumb/navigation key.

Expected result: Later text appears on the braille display.

MANTIS Open Context menu Press Ctrl+M.

Expected result: A context-sensitive menu opens.

3.1 Move Through a Menu One Item at a Time

What you will learn: Navigate without losing your place.

Before you begin: Turn on the Mantis and wait until a menu item is displayed.

Exactly how to do it

  1. Press the Next thumb/navigation key once.
  2. Stop. Read the entire braille item.
  3. Press Next once more.
  4. Stop again and read the item.
  5. Press Previous once.
  6. Confirm that you returned to the item you just passed.
  7. Continue one press at a time until the item you want is displayed.
  8. Read the item one final time.
  9. Press Enter to open it.

What should happen: The item you deliberately selected opens.

If that does not happen: If an unexpected application opens, you probably activated before confirming the item. Exit back to the previous menu and repeat more slowly.

Practice: Find Editor, open it, exit, then find Library and open it.

Part 4 — Understand the Main Menu and Context Menus

The Main menu is your starting point for standalone Mantis applications. A Context menu is different: it contains commands that make sense for the item or application you are currently using.

4.1 Use a Context Menu

What you will learn: Open a list of commands that applies to your current location.

Before you begin: Be inside an application such as Editor or Library.

Exactly how to do it

  1. Hold Ctrl.
  2. While holding Ctrl, press M once.
  3. Release both keys.
  4. Read the first context-menu item.
  5. Press Next one time to move to the next command.
  6. Read it before moving again.
  7. Continue until the command you want is displayed.
  8. Press Enter to perform that command.
  9. If you opened the menu by mistake, use Escape/Back as appropriate to close it without choosing an action.

What should happen: A command runs, or the menu closes if you cancel it.

If that does not happen: If Ctrl+M seems to do nothing, verify that you are in an application/context where a context menu is available.

Practice: Open the context menu in two different applications and notice that the choices can differ.

Part 5 — Read Braille on a 40-Cell Display

A 40-cell display can show only 40 braille cells at one time. Long lines and paragraphs therefore appear in sections. Moving the visible section is called panning.

5.1 Pan Through a Long Line

What you will learn: Read text longer than 40 cells.

Before you begin: Open a document or book with a sentence longer than one display length.

Exactly how to do it

  1. Read the current 40-cell display from left to right.
  2. When you reach the end of the visible braille and the text continues, press the Right thumb/navigation key once.
  3. Read the next displayed portion.
  4. Continue pressing Right once per display length until you reach the end of the passage.
  5. To review earlier text, press the Left thumb/navigation key once.
  6. Read the previous portion.
  7. Continue left as needed.

What should happen: The displayed text moves forward or backward while you remain in the same document.

If that does not happen: If pressing a navigation key changes menu items instead of text, you may not actually be inside the document. Open/interact with the document first.

Practice: Read a paragraph that requires at least three right pans, then return to its beginning.

Part 6 — Use Cursor-Routing Buttons

Each cursor-routing button corresponds to the braille cell directly below it. Routing can move an editing cursor or screen-reader focus directly to a location.

6.1 Route to a Character

What you will learn: Move directly to a character shown on the braille display.

Before you begin: Open editable text or connect to a screen reader that supports routing.

Exactly how to do it

  1. Read the braille line and choose the exact character or word you want.
  2. Keep one fingertip on the target braille cell.
  3. Move that fingertip straight upward to the cursor-routing button above the cell.
  4. Press the routing button once.
  5. Move the cursor one character with Left Arrow or Right Arrow, or type a test character if you are in an editor.
  6. Confirm that the action occurred at the intended location.
  7. Undo or correct the test change if necessary.

What should happen: The editing caret or screen-reader position moves to the selected braille location.

If that does not happen: If the cursor lands one cell away, slow down and move your finger straight upward from the target cell rather than diagonally.

Practice: Route to five different characters in one paragraph.

Part 7 — Use the Built-In Editor

The Editor lets you create and edit documents without connecting the Mantis to another device. HumanWare lists DOC, DOCX, TXT, BRF, and BRL among supported Editor formats.

7.1 Open Editor

What you will learn: Start the built-in text editor.

Before you begin: Be at the Main menu.

Exactly how to do it

  1. Press Next or Previous one item at a time.
  2. Read each item.
  3. When Editor is displayed, stop.
  4. Press Enter.
  5. Wait for Editor to open and read the first available item or document area.

What should happen: Editor opens.

If that does not happen: If another application opens, return to the Main menu and select Editor more slowly.

Practice: Open and exit Editor three times.

7.2 Create, Type, Correct, Save, and Reopen a Document

What you will learn: Complete a full writing workflow from beginning to end.

Before you begin: Open Editor.

Exactly how to do it

  1. Choose New Document or the equivalent new-file command. If you do not see it, press Ctrl+M and inspect the context menu one item at a time.
  2. Once the editing area is active, type: The Mantis Q40 is ready for practice.
  3. Read what you typed on the braille display. Pan right if necessary.
  4. Choose one word and press the routing button above a letter in that word.
  5. Use Left Arrow or Right Arrow to verify the insertion point.
  6. Use Backspace/Delete to remove one character.
  7. Type the correct character.
  8. Read the corrected text.
  9. Open the Save command using the available menu/context command.
  10. When asked for a filename, type a descriptive name such as MantisPractice1.
  11. If a file-format choice is presented, choose a format appropriate for your purpose, such as DOCX or TXT.
  12. Confirm Save.
  13. Close the document.
  14. Use Editor's Open command.
  15. Navigate to MantisPractice1.
  16. Press Enter.
  17. Read the first sentence and confirm your correction is still present.

What should happen: The saved file reopens with the text you entered.

If that does not happen: If the file cannot be found, check the folder/location and filename. If your changes are missing, make sure you actually confirmed Save rather than leaving the save screen.

Practice: Repeat the entire procedure using a second file called MantisPractice2.

7.3 Editing Concepts You Should Know

  • Backspace normally deletes the character before the insertion point.

  • Delete normally removes the character at or after the insertion point depending on context.

  • Arrow keys move the editing caret without necessarily moving the VoiceOver or screen-reader cursor.

  • Cursor-routing is often faster than moving character by character through a long line.

  • Save frequently during important work.

Part 8 — Open and Read Books and Files in Library

Library is the Mantis reading application. HumanWare lists BRF, PEF, TXT, HTML, DOCX, NISO, and RTF as supported Library formats.

8.1 Open a File in Library

What you will learn: Find a file by name and begin reading it.

Before you begin: Have a supported file available on the device or attached storage.

Exactly how to do it

  1. Return to the Main menu.
  2. Move one item at a time until Library is displayed.
  3. Press Enter.
  4. Navigate through folders/files one item at a time.
  5. Read the entire filename before opening it.
  6. When the correct filename is displayed, press Enter.
  7. Read the first 40 cells.
  8. If the text continues, press the Right thumb/navigation key to pan.
  9. Continue reading and panning.
  10. Use the Library's navigation/context commands when you need to move by larger units such as sections, pages, or bookmarks.
  11. When finished, exit back to the Library file list.

What should happen: The selected file opens and you can read it across multiple braille displays.

If that does not happen: If you open the wrong file, exit to the file list and confirm the full filename before pressing Enter again.

Practice: Place two similarly named practice files in the same folder and practice choosing the correct one.

Part 9 — Understand Common File Types

  • BRF — Braille Ready Format. Common for prepared braille books and documents.

  • BRL — another braille-oriented file format.

  • DOC/DOCX — Microsoft Word document formats.

  • TXT — plain text with minimal formatting.

  • PEF — Portable Embosser Format used for braille content.

  • HTML — webpage/document markup that Library can read when supported.

  • RTF — Rich Text Format.

  • NISO/DAISY-related content — accessible publication structures may be supported through Library depending on file package and firmware.

Important: How braille appears depends on the file, translation table, language, and whether the content is already braille-ready.

Part 10 — Work with Storage and File Organization

Organize files so you can find them again. A simple structure is easier to remember than many deeply nested folders.

  • Books

  • Practice

  • Documents

  • Work or School

  • Completed

10.1 Create a Practice Folder and Use It

What you will learn: Keep practice files separate from important originals.

Before you begin: Open the file-management or Library area where folder commands are available.

Exactly how to do it

  1. Press Ctrl+M if folder commands are accessed through the Context menu.
  2. Move one command at a time until New Folder/Create Folder is displayed.
  3. Press Enter.
  4. Type Practice.
  5. Confirm the folder creation.
  6. Navigate until Practice is displayed and press Enter.
  7. Copy or move a non-important sample file into this folder using the available context command.
  8. Exit the folder and reopen it.
  9. Confirm the sample file is present.

What should happen: The Practice folder exists and contains the sample file.

If that does not happen: If the folder was created in the wrong location, navigate to its actual location and move/recreate it rather than creating many duplicate folders.

Practice: Create a second folder named Books and place a sample BRF in it.

Part 11 — Connect to Wi-Fi

11.1 Join a Wireless Network

What you will learn: Connect the Mantis to a Wi-Fi network for online services and updates.

Before you begin: Know the exact Wi-Fi network name and password.

Exactly how to do it

  1. Open the Main menu.
  2. Navigate to Settings or the network option used by your firmware.
  3. Press Enter.
  4. Navigate to Wi-Fi.
  5. Press Enter.
  6. If Wi-Fi is off, turn it on.
  7. Wait for available networks to appear.
  8. Move through the network names one at a time.
  9. Stop at the exact network you want. Read the full name.
  10. Press Enter.
  11. Type the Wi-Fi password exactly. Passwords are case-sensitive.
  12. Activate Connect/OK.
  13. Wait for a connected status or confirmation.
  14. Return to the Wi-Fi screen and verify the network name if you are unsure.

What should happen: The Mantis reports that it is connected to the intended network.

If that does not happen: If connection fails, check the network name, password, Caps Lock state, and signal. Re-enter the password carefully before changing other settings.

Practice: Disconnect from and reconnect to a network you are authorized to use.

Part 12 — Check and Update Firmware

HumanWare currently lists firmware 2.6.0 build 5120. HumanWare also states that a device still running version 1.x must first install version 2.0 manually before it can be updated to later firmware through Wi-Fi or manual installation.

12.1 Check Your Firmware Version

What you will learn: Find out which software version your Mantis is running.

Before you begin: Do not start an update yet.

Exactly how to do it

  1. Open Settings.
  2. Navigate to the device information/about/software area.
  3. Open it.
  4. Read the firmware/software version shown.
  5. Write the version down or save it in a note.
  6. Compare it with the current version shown on HumanWare's Mantis Q40 support page.

What should happen: You know the installed firmware version before making any changes.

If that does not happen: If you cannot find version information, use the HumanWare User Guide for the exact menu location for your firmware.

Practice: Check the version and return to the Main menu without changing anything.

Update safety: Connect to reliable power, use a reliable network, and do not power the device off during an update. If you are on version 1.x, follow HumanWare's required 2.0 intermediate-update procedure.

Part 13 — Understand Bluetooth and Terminal Mode

When the Mantis is connected to another device, there are two separate layers to understand. First, the computer/phone must connect to the Mantis by Bluetooth or USB. Second, the screen reader must recognize and use the Mantis as its braille display.

Remember: PAIR/CONNECT first. CONFIGURE THE SCREEN READER second. TEST output, input, and routing third.

13.1 Perform the Three Connection Tests

What you will learn: Verify that a connection actually works, not merely that Bluetooth says 'connected.'

Before you begin: Pair/connect the Mantis and choose it in the host screen reader's braille settings.

Exactly how to do it

  1. Output test: move the screen-reader focus to another item on the computer or phone.
  2. Read the Mantis display. It should change to match the new focus.
  3. Input test: open a text field.
  4. Type a short phrase on the Mantis QWERTY keyboard.
  5. Confirm the phrase appears on the host device.
  6. Routing test: press a cursor-routing button over a character or control represented in braille.
  7. Confirm the caret/focus moves to that location.

What should happen: All three tests work: braille output, keyboard input, and cursor routing.

If that does not happen: If one test fails, troubleshoot that specific layer instead of assuming the entire connection is broken.

Practice: Use the three-test sequence every time you set up the Mantis with a new device.

Part 14 — Connect the Mantis to a Mac

On a Mac, Apple's VoiceOver screen reader supplies the accessibility information. The Mantis displays that information in braille and can also function as a QWERTY keyboard.

14.1 Turn on VoiceOver

What you will learn: Start the Mac screen reader.

Before you begin: Be at the Mac keyboard or use the Mantis keyboard if it is already acting as the Mac keyboard.

Exactly how to do it

  1. Hold Command.
  2. Press F5 once.
  3. Release the keys.
  4. If your Mac uses standard function-key behavior differently, you may need to include Fn.
  5. Listen for VoiceOver speech.
  6. Hold Control+Option and press Right Arrow once.
  7. Release all keys.
  8. Listen to the next Mac item.

What should happen: VoiceOver speaks and moves when you use VO+Right Arrow.

If that does not happen: If nothing happens, try Command+Fn+F5 if your Mac requires Fn. You can also enable VoiceOver from System Settings > Accessibility > VoiceOver.

Practice: Turn VoiceOver off and on again, then move one item forward and one backward.

14.2 Open Bluetooth Settings on the Mac

What you will learn: Reach the Mac's Bluetooth controls using only the keyboard and VoiceOver.

Before you begin: VoiceOver should be on.

Exactly how to do it

  1. Press Command+Space to open Spotlight.
  2. Type Bluetooth Settings.
  3. Press Return.
  4. Wait for System Settings to open.
  5. Press VO+Right Arrow once. Listen to the item.
  6. Continue pressing VO+Right Arrow one item at a time.
  7. If VoiceOver says 'group,' 'table,' 'toolbar,' or another container that contains the controls you need, press VO+Shift+Down Arrow to interact with it.
  8. Inside the group, use VO+Right Arrow to move item by item.
  9. To leave that group, press VO+Shift+Up Arrow.

What should happen: You can reach and inspect Bluetooth controls without using the mouse.

If that does not happen: If VoiceOver seems to skip everything inside a group, you probably need to interact with the group using VO+Shift+Down Arrow.

Practice: Navigate into one group, inspect three items, and exit the group.

14.3 Pair and Verify Mantis on a Mac

What you will learn: Complete the Mac connection and prove that it works.

Before you begin: Turn on Mantis and place it in the appropriate Bluetooth/terminal connection mode.

Exactly how to do it

  1. On the Mac, open Bluetooth Settings using Command+Space, type Bluetooth Settings, press Return.
  2. Use VO+Right Arrow and interaction commands until the list of Bluetooth devices is available.
  3. Move one item at a time until Mantis Q40 is announced.
  4. Move to its Connect/Pair button.
  5. Press VO+Space to activate the button.
  6. Complete any pairing confirmation that appears.
  7. Open VoiceOver Utility. You can use Spotlight: Command+Space, type VoiceOver Utility, press Return.
  8. Navigate to the Braille category using VO+Right Arrow and VO+Shift+Down/Up Arrow as necessary.
  9. Confirm that Mantis Q40 appears as the connected braille display.
  10. Output test: press VO+Right Arrow and confirm the braille cells change.
  11. Input test: open TextEdit with Command+Space, type TextEdit, press Return. Navigate to the editing area and type Mantis Mac test.
  12. Routing test: press a routing button over one of the letters and verify the caret/focus changes.

What should happen: The Mantis follows VoiceOver focus, types into the Mac, and routes to braille positions.

If that does not happen: If Bluetooth shows connected but braille does not change, check VoiceOver's Braille settings. Pairing and screen-reader configuration are separate.

Practice: Disconnect and reconnect once, then repeat the three tests.

Part 15 — Learn VoiceOver Navigation from the Beginning

You do not need to see the Mac screen to use VoiceOver. Think of VoiceOver as moving a reading cursor from one accessible item to the next.

VOICEOVER Next item VO+Right Arrow

Expected result: VoiceOver announces/displays the next item.

VOICEOVER Previous item VO+Left Arrow

Expected result: VoiceOver returns to the preceding item.

VOICEOVER Activate current item VO+Space

Expected result: The selected button, checkbox, link, or control is activated.

VOICEOVER Interact with group VO+Shift+Down Arrow

Expected result: You enter the container so its contents can be navigated.

VOICEOVER Stop interacting VO+Shift+Up Arrow

Expected result: You return to the outer level.

VOICEOVER Open Rotor VO+U

Expected result: The VoiceOver Rotor opens.

VOICEOVER Read from current position VO+A

Expected result: VoiceOver begins reading from the current position.

15.1 Navigate a Mac Window

What you will learn: Move, enter groups, activate controls, and recover when you get lost.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Press VO+Right Arrow once.
  2. Stop and listen/read the item name and control type.
  3. Press VO+Right Arrow again.
  4. Press VO+Left Arrow once and confirm you returned.
  5. When VoiceOver announces a group or toolbar you want to explore, press VO+Shift+Down Arrow.
  6. Inside the group, press VO+Right Arrow one item at a time.
  7. To leave, press VO+Shift+Up Arrow.
  8. Continue until the control you want is announced.
  9. Press VO+Space to activate it.
  10. After activation, stop. Listen and read the braille display before pressing another command.

What should happen: You can move forward/backward, enter/leave a group, and activate the intended control.

If that does not happen: If you cannot find a control, listen for a container you may need to interact with. If you are deep inside nested groups, use VO+Shift+Up Arrow repeatedly to move outward.

Practice: Open System Settings and navigate through at least ten items without using a mouse.

15.2 Use the VoiceOver Rotor

What you will learn: Jump efficiently among categories such as headings, links, buttons, or form controls.

Before you begin: Use the Rotor in a webpage or other context where categories are available.

Exactly how to do it

  1. Press VO+U.
  2. Listen/read the current rotor category.
  3. Use the appropriate arrow navigation to move among rotor categories.
  4. Choose a category such as Headings, Links, Buttons, or Form Controls.
  5. Move through the items in that category.
  6. When the desired item is reached, leave the rotor and continue normal navigation or activate the item.

What should happen: You can use a category to move among similar webpage/interface elements.

If that does not happen: If the category you want is not available, it may not apply to the current context or may not be enabled in VoiceOver settings.

Practice: Open a webpage and move among headings, then links.

Part 16 — Type and Edit on a Mac with Mantis

16.1 Create and Edit Text in TextEdit

What you will learn: Use the Mantis as both a keyboard and braille display for Mac text editing.

Before you begin: Mantis is connected to VoiceOver and passes the three connection tests.

Exactly how to do it

  1. Press Command+Space.
  2. Type TextEdit.
  3. Press Return.
  4. Use VO+Right Arrow until VoiceOver announces the document/editing area.
  5. If it is a group or text area requiring interaction, press VO+Shift+Down Arrow.
  6. Type: The quick brown fox jumps over the lazy dog.
  7. Read the sentence in braille.
  8. Find the word brown on the braille display.
  9. Press a cursor-routing button above one of its letters.
  10. Press Left Arrow or Right Arrow once to verify caret movement.
  11. Use Backspace/Delete to remove a character.
  12. Type the replacement character.
  13. Read the corrected word in braille.
  14. Press Command+S.
  15. Type a filename if prompted.
  16. Navigate to Save and activate it, or press Return when the Save button is the default.

What should happen: The text is corrected and saved.

If that does not happen: If typing triggers VoiceOver commands rather than text entry, make sure keyboard focus is actually in the editing area and that Quick Nav or another navigation mode is not intercepting typing.

Practice: Create a paragraph with three deliberate errors, route to each error, correct it, and save.

Part 17 — Connect to iPhone or iPad

17.1 Pair with iOS VoiceOver

What you will learn: Use Mantis as a braille display and keyboard with iPhone/iPad.

Before you begin: Turn on the Mantis and VoiceOver on the iPhone/iPad.

Exactly how to do it

  3. Open VoiceOver.
  4. Open Braille.
  5. On Mantis, enter the appropriate Bluetooth/terminal connection mode.
  6. On iPhone/iPad, move to the Braille Devices area.
  7. Wait for Mantis Q40 to appear.
  8. Select Mantis Q40.

Part 21 — Braille Settings and Translation

Braille settings determine how text is translated and presented. The correct choice depends on your language, braille code, and task.

  • Use the braille table appropriate for your language and code.

  • Contracted and uncontracted braille serve different reading and learning needs.

  • Computer braille and literary braille are not interchangeable in every task.

  • When Mantis is connected to a screen reader, the screen reader may control the active braille translation table.

  • If braille looks consistently wrong, check translation/table settings before assuming the hardware is faulty.

21.1 Diagnose Unexpected Braille

What you will learn: Determine whether odd braille is a translation setting rather than a connection failure.

Before you begin: Make sure the display is otherwise changing normally.

Exactly how to do it

  1. Read several words and identify whether the cells are consistently displaying unexpected contractions/symbols.
  2. Check the Mantis braille/language settings when working standalone.
  3. If connected to a screen reader, open that screen reader's Braille settings.
  4. Verify the language and input/output braille tables.
  5. Change only one setting at a time.
  6. Return to the same sample text and compare the result.

What should happen: The sample text displays according to the selected braille code.

If that does not happen: If only one file looks wrong while other text looks correct, inspect the file format/translation rather than changing global settings immediately.

Practice: Use one sample sentence to compare two appropriate braille table settings, then restore your preferred table.

Part 22 — Battery, Care, and Safe Transport

  • Use appropriate charging equipment.

  • Keep liquids, crumbs, and loose debris away from the braille cells and keyboard.

  • Read braille with light pressure; do not press the pins down forcefully.

  • Do not place heavy objects on top of the braille display.

  • Use the protective shell/case during transport.

  • Avoid extreme heat, cold, and moisture.

  • Disconnect cables by holding the plug rather than pulling the cable.

  • Back up important files.

Cleaning: Use only cleaning methods recommended by HumanWare. Do not introduce liquids or sharp objects into the braille cells.

Part 23 — Troubleshooting

23.1 Mantis Will Not Turn On

What you will learn: Check power problems in a logical order.

Before you begin: Do not repeatedly hold the power button for long periods.

Exactly how to do it

  1. Connect the Mantis to an appropriate charger/power source.
  2. Wait a short period to allow a deeply discharged battery to begin charging.
  3. Try normal startup again.
  4. If there is still no response, inspect the cable and connector for obvious damage.
  5. Try a known-good appropriate charging cable/power source if available.
  6. If the device remains unresponsive, stop experimenting and contact HumanWare support.

What should happen: The Mantis starts or you have isolated the issue enough to seek support.

If that does not happen: If the device becomes unusually hot, smells unusual, or the battery/case appears damaged, disconnect it safely and do not continue charging or using it until evaluated.

Practice: Review this sequence so you can perform it without guessing.

23.2 Bluetooth Says Connected but No Braille Appears

What you will learn: Find the missing connection layer.

Before you begin: The host device shows Mantis as paired/connected.

Exactly how to do it

  1. Confirm the Mantis is powered on.
  2. Confirm it is in the intended terminal/display mode rather than inside a standalone app.
  3. Confirm the screen reader is running.
  4. Open the screen reader's Braille settings.
  5. Verify Mantis Q40 is selected as the active braille display.
  6. Move the screen-reader focus one item.
  7. Check whether the braille changes.
  8. If not, disconnect and reconnect Mantis once.
  9. Restart the screen reader.
  10. Restart Mantis if necessary.
  11. Only then move to advanced driver/firmware troubleshooting.

What should happen: The missing layer is corrected and the display follows screen-reader focus.

If that does not happen: If pairing continues to work but the screen reader cannot see Mantis, use the current HumanWare platform-specific guide for driver/connection details.

Practice: Memorize the four layers: POWER → CONNECTION → MANTIS MODE → SCREEN READER.

23.3 You Cannot Find a Control on the Mac

What you will learn: Recover from confusing VoiceOver navigation.

Before you begin: VoiceOver is running.

Exactly how to do it

  1. Press VO+Left Arrow once to prove VoiceOver is moving.
  2. Press VO+Right Arrow slowly and listen to each item.
  3. If VoiceOver announces a group, toolbar, table, or similar container, press VO+Shift+Down Arrow to interact.
  4. Use VO+Right Arrow inside that container.
  5. If the target is not there, press VO+Shift+Up Arrow to leave it.
  6. Continue through the parent area.
  7. For a webpage, press VO+U and use the Rotor to move by headings, links, buttons, or form controls.
  8. Activate the target only after VoiceOver announces the correct item.

What should happen: You can get unstuck without using the mouse.

If that does not happen: If you are deeply nested, press VO+Shift+Up Arrow more than once to move outward before continuing.

Practice: Open a System Settings page and deliberately enter and leave multiple groups.

23.4 A File Will Not Open

What you will learn: Check file compatibility before assuming the file is damaged.

Before you begin: Know the filename and extension.

Exactly how to do it

  1. Read the file extension.
  2. Confirm that the application you are using supports that format.
  3. For Editor, remember HumanWare lists DOC, DOCX, TXT, BRF, and BRL.
  4. For Library, remember HumanWare lists BRF, PEF, TXT, HTML, DOCX, NISO, and RTF.
  5. If the format is supported, copy the file to a known-good location and try again.
  6. Try another known-good file of the same format.
  7. If only one file fails, the file itself may be damaged or structured unexpectedly.

What should happen: You can distinguish format/app mismatch from a broader application problem.

If that does not happen: If many supported files fail, restart the application/device and check firmware before modifying the files.

Practice: Sort sample files by which Mantis application should open them.

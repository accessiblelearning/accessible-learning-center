Page Numbers, Running Heads, and Breaks

BrailleBlaster manualAll BrailleBlaster lessonsMy progress

Goal

Prepare a two-page practice document with verified numbering.

Step-by-step instructions

  1. Locate print page indicators and braille page settings.
  2. Review page-number placement in the braille view.
  3. Insert a page break only at a logical boundary.
  4. Set or review a running head according to the assignment.
  5. Check that blank pages are intentional.
  6. Save a versioned BBZ copy.

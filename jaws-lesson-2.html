JAWS Lesson 2

Reading Text by Character, Word, Line, and Paragraph

JAWS manual All JAWS lessons My progress

Goal

Read and review text precisely with JAWS using different reading units.

Skills practiced

  • Read characters, words, lines, sentences, and paragraphs.
  • Spell the current word or line.
  • Use Say All and move to the beginning or end of text.
  • Select text and have JAWS read the selection.

Step-by-step instructions

  1. Open Notepad and type three short paragraphs about a fictional workplace training schedule.
  2. Press Ctrl+Home to move to the beginning of the document.
  3. Use Left Arrow and Right Arrow to read by character.
  4. Use Insert+Left Arrow and Insert+Right Arrow to read by word.
  5. Use Up Arrow and Down Arrow to read by line.
  6. Press Insert+Num Pad 5 twice quickly to spell the current word. Laptop-layout commands may differ; use Keyboard Help if needed.
  7. Press Ctrl+Down Arrow and Ctrl+Up Arrow to move by paragraph.
  8. Press Insert+Down Arrow to read the document continuously, then press Ctrl to stop speech.
  9. Select one sentence with Shift plus an Arrow command and press Insert+Shift+Down Arrow to read the selected text.
  10. Add a final paragraph explaining which reading unit was most useful. Save as JAWS-Lesson-2.txt.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

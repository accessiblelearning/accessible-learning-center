Your goal

Archive one test message and find it again. Delete a separate disposable message and recover it through Undo or Trash without emptying Trash.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Archive a message and locate it again

  1. Select one expendable practice message.
  2. Activate Archive, or press A while the message list has focus.
  3. Find the archive location for that account and locate the message again.

Archiving moves a message out of its current folder. The destination can be an account folder or a local folder, depending on the account's Copies & Folders settings. It remains searchable. Archiving is not a separate backup.

Practice: Before archiving anything important, demonstrate the complete round trip with your practice message: find it, archive it, and find it again.

Source: Mozilla archived messages

A repeatable mailbox routine

Start here: The main mail window. Choose a practice message that you can safely reorganize.

Step-by-step instructions

  1. Identify the account and select Inbox. Use F6 to reach the message list and arrows to select one message. Read its sender and subject before opening it.
  2. Open it with Enter, read it, and decide whether it needs a reply, a later action, or no action. Close the message tab with Ctrl+W when finished.
  3. If you want to distinguish read from unread, select the message in the list and press M once. Check the resulting status before pressing again; this command toggles the state.
  4. To retain the message outside Inbox, archive it using the archive task. To discard only an expendable practice message, select it in the message list and press Delete.
  5. After an accidental deletion, try Ctrl+Z immediately. Otherwise examine the account’s Trash folder and use the message’s context menu to move it back to Inbox. Do not empty Trash during this exercise.
  6. Finish by clearing any Quick Filter and checking the selected folder. This leaves a predictable starting point for your next session.

Check your result

You can explain where the practice message went and find it again.

If something goes wrong

Do not use Shift+Delete for practice: permanent deletion may not be recoverable. If multiple messages are selected unexpectedly, stop and select only the intended item before continuing.

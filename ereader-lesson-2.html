Bookshelf and File Organization

NLS Braille eReader manualAll NLS Braille eReader lessonsMy progress

Goal

Submit a bookshelf navigation log.

Step-by-step instructions

  1. Open the Bookshelf from the main menu.
  2. Move through folders and book titles.
  3. Open an instructor-provided BRF or supported braille book.
  4. Return to the Bookshelf without deleting the book.
  5. Identify internal storage and removable media if present.
  6. Record the exact title and location.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Submit a bookshelf navigation log.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Ereader-Lesson-2.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies NLS Braille eReader Lesson 2.

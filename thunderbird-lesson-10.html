Your goal

Prepare a self-addressed practice message with a checked attachment. Review recipients, subject, body, and file; send once, locate the received copy, reply, and explain how you would recover a missing draft.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Write, review, and save a draft

Start here: Thunderbird’s main mail window, with an account connected. This first exercise will not be sent.

Step-by-step instructions

  1. Press Ctrl+N to open a composition window. Confirm that a new message is active, rather than a folder or browser search field.
  2. Leave To empty for this exercise. Tab until Subject is announced. Type “Email practice — draft only.” Tab to the editable message body.
  3. Type a greeting, two practice sentences, and your name. Press Enter between paragraphs. Read back what you wrote using your normal text-reading method.
  4. Use Shift+Tab or Tab to review Subject and the recipient area. Confirm that no recipient has accidentally been added. Return to the body if you need to correct a sentence.
  5. Press Ctrl+S. Wait for saving to finish. Close only the composition window with Ctrl+W; if asked whether to save changes, choose Save.
  6. In the main window, use F6 to locate the folder pane. Use arrows to reach this account’s Drafts folder. Move to its message list with F6, select your subject, and open it with Enter.
  7. Verify that the subject and both sentences are still present. Save again after any changes.

Check your result

You can reopen your unfinished message. It remains a draft and has not been sent.

If something goes wrong

If Drafts appears empty, check the account and clear any active filter. If the composition window is still open, return there and save again. Do not use Send to make a draft appear in a folder.

Try it yourself

Change one sentence, save, close, and reopen the same draft. Explain how saving differs from sending.

Add and verify a practice attachment

Start here: An open practice draft and a small, harmless file named email-practice.txt. Know the folder containing it.

Step-by-step instructions

  1. Press Ctrl+Shift+A in the composition window. Confirm that the file-selection dialog opens.
  2. If you know the file’s full path, Tab to File name, enter that path, and activate Open. Otherwise use the dialog’s folder navigation to reach its containing folder, select the filename, and activate Open. Selecting a folder only navigates; it does not attach a file.
  3. Back in the draft, locate the attachment area with Tab or Shift+Tab. Review the exact filename. If it is the wrong file, select that attachment and use its context menu to remove it. Confirm the attachment item has focus before deleting anything.
  4. Reattach the intended file and save the draft. Before sending an actual document, open the original file separately and verify its contents as well as its name.
  5. When receiving an attachment, identify its sender, message context, and filename before opening it. Use its available Save action if you want a local copy; note the destination folder and any rename you make.

Check your result

The draft lists exactly the file you intended. You can distinguish the attached copy from the original file on your computer.

If something goes wrong

If the file picker says the item cannot be found, check the path and extension. Cancel and locate the file in File Explorer instead of choosing another similarly named document. Large attachments may exceed your provider’s limit.

Try it yourself

Attach, remove, and reattach the practice file without deleting its original on disk.

Send to yourself, reply, and forward

Start here: A saved practice draft and your own working email address.

Step-by-step instructions

  1. Open the draft, add your own address in To, and review Subject, body, and any attachments. Remove anything you did not intend to include.
  2. Press Ctrl+Enter to send. If a confirmation appears, read it and confirm only when the reviewed message is ready. Allow the operation to finish.
  3. Return to the main mail window and select the account’s Sent folder. Locate the practice subject. Then select Inbox and refresh that account with F5 if needed. Delivery can take time.
  4. Open the received practice message. Press Ctrl+R to reply to its sender. Check the recipient before writing a short answer; save the reply as a draft or send it to yourself.
  5. For a real group message, Ctrl+Shift+R opens Reply All. Review the expanded recipient list before writing. Cancel an unnecessary group reply rather than sending it by accident.
  6. To forward, open the original practice message and press Ctrl+L. Add your own address, inspect the quoted material and attached files, and add a sentence explaining why you are forwarding it. Save the practice forward as a draft.

Check your result

You can distinguish a newly composed message, a reply, and a forward by checking recipients and content, not just the subject prefix.

If something goes wrong

A Sent copy does not guarantee that someone read a message. If sending reports an error, record it and check the connection and account sign-in. Inspect Sent and Outbox before pressing Send repeatedly.

Try it yourself

Send yourself one clearly labeled test only. Identify its Sent copy and its received Inbox copy.

Troubleshooting practice

The command affected my browser.
Switch to Thunderbird, confirm the active window, and try again.
Typing goes into a search field.
Identify the focused control before repeating the command. Do not assume the message list is active.
My message list suddenly looks empty.
Check the selected folder and clear Quick Filter before assuming mail is missing.
The draft is not in Sent.
Saving and sending are different tasks. Look for the draft and review it before sending.
My screen reader uses the letter command itself.
Check focus and your reader's interaction mode. Use the corresponding Thunderbird menu action if needed. Do not turn off speech and continue blindly.
I cannot explain an error.
Record the exact error text, the action immediately before it, and whether it affects one account or all accounts. Share that information with your instructor or technology team.

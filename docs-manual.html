Purpose and setup

This manual supports independent practice with Google Docs on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Ten-lesson learning path

  1. Lesson 1: Create, Name, and Organize a Document — Create a one-page staff update with a title, date, and two short paragraphs.
  2. Lesson 2: Navigate, Select, Edit, and Find Text — Revise a fictional office announcement and describe the commands used.
  3. Lesson 3: Format Text and Paragraphs Accessibly — Format a readable two-section workplace notice with true headings.
  4. Lesson 4: Headings, Outline, and Document Structure — Build a structured procedure with four logical sections.
  5. Lesson 5: Bulleted and Numbered Lists — Create a supply list and a five-step opening checklist.
  6. Lesson 6: Create and Navigate Accessible Tables — Create a three-column contact schedule with fictional data.
  7. Lesson 7: Links, Images, and Alternative Text — Create a resource sheet with two meaningful links and one described image.
  8. Lesson 8: Comments, Suggestions, and Collaboration — Submit a revision log describing one comment and one suggestion.
  9. Lesson 9: Sharing, Permissions, and Privacy — Create a permission plan for a fictional team document; do not share the actual file.
  10. Lesson 10: Final Accessible Workplace Document — Create a complete accessible employee onboarding procedure using fictional information.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Use the course’s private assignment uploader only for the requested practice file.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

Microsoft Word Lesson 1

Opening Word, Creating, and Saving a Document

Goal

Learn how to open Microsoft Word, create a blank document, enter text, and save the document.

Instructions

  1. Press the Windows key.
  2. Type Word.
  3. Press Enter on Microsoft Word.
  4. Press Ctrl+N to create a blank document.
  5. Type the heading: My First Word Document
  6. Press Enter twice.
  7. Type: I am learning to use Microsoft Word independently with a screen reader.
  8. Press Enter twice.
  9. Type: I can create, type, save, and reopen Word documents.
  10. Press Ctrl+S.
  11. Choose a location you can find again.
  12. Name the file Word-Lesson-1.
  13. Save it as a DOCX file.

Your Assignment

Complete the assignment and save it as:

Word-Lesson-1.docx

Before Submitting

  • Make sure all required text is present.
  • Make sure the file is saved as DOCX.
  • Make sure the filename is Word-Lesson-1.

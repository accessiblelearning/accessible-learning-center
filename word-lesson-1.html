Microsoft Word Lesson 1

Opening Word and Creating a Document

What You Will Learn

In this lesson, you will learn how to open Microsoft Word, create a blank document, type text, and save your work.

Step-by-Step Instructions

Step 1: Open Microsoft Word

  1. Press the Windows key.
  2. Type Word.
  3. Use the Up or Down Arrow keys if more than one result appears.
  4. Press Enter on Microsoft Word.
  5. Wait for Word to open.

Step 2: Create a Blank Document

  1. Press Ctrl+N.
  2. Wait for a blank document to open.

Step 3: Type Your Practice Document

Type the following text:

My First Microsoft Word Document

I am learning how to create and edit documents using Microsoft Word with a screen reader.

This lesson helped me practice opening Word, creating a document, typing text, and saving my work.

Step 4: Save the Document

  1. Press Ctrl+S.
  2. Choose the Documents folder or another location you can easily find.
  3. Name the file: Word-Lesson-1
  4. Press Enter or activate Save.

Your Assignment

Create the document using the instructions above and save it as:

Word-Lesson-1.docx

Keep the file because you will submit it through the assignment system.

Before You Finish

  • Make sure Microsoft Word opened successfully.
  • Make sure you created a blank document.
  • Make sure all three lines or paragraphs of practice text are included.
  • Make sure the document is saved as a Word DOCX file.
  • Make sure the filename is Word-Lesson-1.

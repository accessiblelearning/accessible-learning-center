Windows 11 Lesson 5

Selecting, Sorting, Viewing, and Finding Files

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Find and organize files efficiently without changing or deleting unrelated content.

Skills practiced

  • Select one or multiple files.
  • Sort and change views.
  • Use File Explorer search.
  • Inspect file properties.

Step-by-step instructions

  1. Open the Windows Practice folder created earlier.
  2. Use Arrow keys to select one item and Ctrl+Spacebar to change its selection state when supported.
  3. Use Shift+Arrow to select a continuous range only among practice files.
  4. Press Ctrl+A to select all practice items, then press Escape or click nowhere with the keyboard focus to avoid accidental action; do not delete them.
  5. Use the File Explorer command controls or context menu to review Sort options. Sort by Name, then by Date modified.
  6. Change the view only within the practice folder and note how JAWS announcements change.
  7. Press Ctrl+F to move to File Explorer search. Search for Lesson.
  8. Press Escape or Alt+Left Arrow to return from search results.
  9. Select a practice file and press Alt+Enter to review Properties. Press Escape without changing attributes.
  10. Create Windows-Lesson-5.txt comparing selection methods, sort order, views, search, and Properties.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

Before submitting

  • Search and sort are compared.
  • The student warns against deleting while a large selection is active.
  • The file is named Windows-Lesson-5.txt.

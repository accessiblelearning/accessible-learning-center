Chrome Lesson 8

Zoom, Full Screen, and Accessible Browser Settings

Chrome manualAll Chrome lessonsMy progress

Goal

Use Chrome display and accessibility controls without disrupting screen-reader access.

Step-by-step instructions

  1. Press Ctrl+Plus to increase page zoom and Ctrl+Minus to decrease it.
  2. Press Ctrl+0 to reset page zoom.
  3. Press F11 to enter or leave full screen and note how browser controls change.
  4. Open Chrome Settings with Alt+F, then Settings, or enter chrome://settings in the address bar.
  5. Search Settings for Appearance and review font size and page zoom without changing shared settings.
  6. Search for Accessibility and review available options.
  7. Test whether the page remains usable at 200 percent zoom.
  8. With JAWS, verify headings, links, and form controls still work after zoom changes.
  9. Return zoom to the learner’s preferred level.
  10. Create Chrome-Lesson-8.txt describing useful adjustments and the difference between Chrome settings and assistive-technology settings.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

Your assignment

Create the report described above using fictional or public information only.

Save it as Chrome-Lesson-8.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • Zoom in, out, and reset commands are included.
  • The page is evaluated at 200 percent.
  • Browser settings and screen-reader settings are distinguished.
  • The file is Chrome-Lesson-8.txt.

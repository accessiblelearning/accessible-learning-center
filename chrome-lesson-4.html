Chrome Lesson 4

Web Search, Research, and Source Evaluation

Chrome manualAll Chrome lessonsMy progress

Goal

Search efficiently and record trustworthy workplace information.

Step-by-step instructions

  1. Press Ctrl+L and type a specific research question.
  2. Review search results by heading with H and by link with Tab or Insert+F7.
  3. Open one promising result in a new tab with Ctrl+Enter from the address bar suggestion or the available link context command.
  4. Check the page title, organization, publication or update date, and web address.
  5. Prefer official government, educational, manufacturer, or primary-source pages for factual instructions.
  6. Compare the same fact with a second reliable source.
  7. Do not enter personal information into an unfamiliar search form.
  8. Record the question, two sources, dates, and the fact verified.
  9. Return to the original tab and close unused tabs.
  10. Save the research report as Chrome-Lesson-4.txt.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

Your assignment

Create the report described above using fictional or public information only.

Save it as Chrome-Lesson-4.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • The research question is specific.
  • Two sources and their organizations are recorded.
  • The report explains why the sources are trustworthy.
  • The file is Chrome-Lesson-4.txt.

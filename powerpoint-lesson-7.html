PowerPoint Lesson 7

Meaningful Links and Contact Information

PowerPoint manual All PowerPoint lessons My progress

Goal

Add links that clearly identify their destination and work with keyboard navigation.

Skills practiced

  • Insert a hyperlink with Ctrl+K.
  • Write meaningful link text.
  • Add an email link.
  • Test links without relying on their visual appearance.

Step-by-step instructions

  1. Create a presentation titled New Employee Resources.
  2. Add a slide titled Technology Resources.
  3. Type Microsoft Accessibility Help, select the text, and press Ctrl+K.
  4. Enter https://support.microsoft.com/accessibility as the address and confirm the dialog.
  5. Add the meaningful link text Freedom Scientific JAWS Training and link it to https://www.freedomscientific.com/training/jaws/.
  6. Add a slide titled Department Contacts.
  7. Enter a fictional contact name and email address. Use Ctrl+K to create a mailto link if appropriate.
  8. Avoid link text such as click here or read more because it does not identify the destination.
  9. Press Tab through the slide objects and listen to each link with JAWS.
  10. Use Shift+F10 and Edit Link if a destination needs correction.
  11. Run Check Accessibility and review link-related suggestions.
  12. Save the presentation as PowerPoint-Lesson-7.pptx.

Keyboard help: Press Alt+Q to search PowerPoint commands when Ribbon KeyTips differ. For JAWS help, press Insert+Spacebar, then J, and search for the task.

Your assignment

Create a three-slide employee-resources presentation with two meaningful web links and one fictional department contact.

Save the finished assignment as PowerPoint-Lesson-7.pptx.

Before submitting

  • Link text explains each destination.
  • No link uses vague text such as click here.
  • The contact information is fictional and contains no private data.
  • All links were reviewed with keyboard navigation.
  • The file is saved as PowerPoint-Lesson-7.pptx.

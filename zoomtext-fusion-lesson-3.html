Your goal

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Operate the ZoomText toolbar with the keyboard

Start here: The ZoomText toolbar is the active window. These toolbar directions are for ZoomText; use Fusion’s own controls when running Fusion.

Step-by-step instructions

  1. Identify the toolbar tab or control that has focus. Use the arrow keys to move among toolbar items. Listen to the control name before activating it.
  2. At a split button, distinguish its two actions: Enter operates its main function, while Down opens its associated choices. Read the choices before selecting one.
  3. At the Zoom Level control, use Up or Down to change the level. Use Left or Right to leave that control for adjacent toolbar items.
  4. Switch to the practice document with Alt+Tab and inspect one heading and one line of text. Return to the toolbar to make another small adjustment only if needed.
  5. When a settings menu opens unexpectedly, use Escape to close that menu and identify the focused toolbar item again.

Check your result

You can use controls by their labels and roles instead of searching for a small visual target.

If something goes wrong

If arrow keys change the level instead of moving to another item, you may be inside the Zoom Level control. Use Left or Right to leave it. If the document scrolls instead, the document has focus rather than the toolbar.

Try it yourself

Reach Zoom Level, change it one step, and return it to the value you recorded.

Choose useful magnification

What you will learn: Balance readable text with enough surrounding context.

Exactly how to do it

  1. In ZoomText or Fusion Desktop layout, use Caps Lock+Up to increase zoom and Caps Lock+Down to decrease it. Fusion Laptop layout adds Alt to these combinations.
  2. Use the matching 1x toggle in the table below to compare the enlarged view with the whole screen.
  3. Return to your preferred size and read a short paragraph.

What should happen: You can locate both the text and the surrounding controls.

If that does not happen: If a command reads text instead, stop and check the Fusion keyboard layout. Do not keep repeating it.

Practice: Find a heading, move to a paragraph, then find a nearby button. Note which zoom level made all three easiest.

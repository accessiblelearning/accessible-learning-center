Independent Self-Study Guide

Chat, Search, Files, Images, Voice, Projects, Work, Memory, Privacy, Accessibility, and Responsible Use

Purpose: This manual teaches ChatGPT from the beginning. It assumes no previous AI experience and explains how to ask questions, work with files and images, verify answers, manage privacy and memory, use advanced features when available, and use ChatGPT effectively with screen readers and braille.

Current reference: This guide reflects the current ChatGPT product as of September 2026. Features can vary by plan, region, device, workspace policy, model, and rollout.

Core principle: ChatGPT can be useful without being automatically correct. Verify important facts, protect sensitive information, and keep human control over important decisions and actions.

How to Use This Manual

  • Begin with ordinary Chat before exploring advanced features.

  • Use a new chat for a new topic when old context may cause confusion.

  • Give clear goals, relevant context, constraints, and desired output format.

  • For current facts, ask ChatGPT to search the web and check the cited sources.

  • Do not paste passwords, security codes, private keys, or sensitive records into a general chat.

  • Use Temporary Chat when you want a conversation that does not appear in normal history and does not create memory.

  • Use Projects to keep related chats, files, and instructions together.

  • Use Work for longer multi-step deliverables or delegated tasks when your plan provides it.

  • Use screen-reader heading, landmark, button, and edit-field navigation to move efficiently through ChatGPT.

  • Always review important output before sending, publishing, submitting, or acting on it.

Part 1 - What ChatGPT Is

ChatGPT is an AI assistant from OpenAI. It can work with natural-language instructions and, depending on the experience and plan, can search the web, analyze files and images, generate images, run data analysis, use voice, organize work in Projects, use connected apps, perform deep research, schedule tasks, and complete longer multi-step work.

  • ChatGPT generates responses from the conversation and available tools/context.

  • It can make mistakes, including confident factual errors.

  • It does not automatically know that information has changed unless current information is retrieved.

  • Different plans and workspaces may expose different models, tools, limits, and permissions.

  • An organization's administrator may restrict plugins, apps, Work, file use, browsing, or data settings.

Part 2 - Chat, Work, and Codex

Experience Best use
Chat Fast conversational help, questions, brainstorming, search, files, images, voice, and everyday assistance.
Work Longer multi-step work and finished deliverables; can use files, apps, browsers, tasks, and approvals when available.
Codex Software-development experience for writing/debugging code, repositories, tests, terminals, and developer workflows.

Availability: Chat is the default experience. Work is available to eligible paid plans and may be controlled by workspace administrators. Codex availability depends on the product surface and plan.

Important UI change: Older ChatGPT instructions may refer to Canvas. Current writing and coding workflows are delivered through writing blocks, code blocks, Work, and other current tools instead.

Part 3 - Open ChatGPT and Start a Chat

3.1 Start a New Chat on the Web

What you will learn: Open a clean conversation.

Before you begin: Use an up-to-date supported browser.

Exactly how to do it

  1. Press Ctrl+L or Alt+D to focus the browser address bar.
  2. Type chatgpt.com.
  3. Press Enter.
  4. Sign in if required.
  5. Find and activate New chat using Tab/Shift+Tab, screen-reader button navigation, or the sidebar.
  6. Move to the message/prompt edit field.
  7. Type a simple question such as: Explain what a spreadsheet is in three sentences.
  8. Activate Send or press Enter when the edit field uses Enter to submit.

What should happen: A new assistant response appears in the conversation.

If that does not happen: If Enter inserts a new line instead of sending, locate and activate the Send button. If focus is lost, use edit-field navigation to return to the prompt.

Practice: Start three low-risk chats on different topics.

3.2 Continue a Conversation

What you will learn: Ask a follow-up without repeating all context.

Before you begin: A response is already present.

Exactly how to do it

  1. Return to the prompt edit field.
  2. Ask a follow-up that clearly refers to the prior answer, such as: Give me an example.
  3. Send the message.
  4. Read the new response.
  5. Ask one more follow-up that changes the format, such as: Turn that into a checklist.

What should happen: ChatGPT uses the existing conversation context.

If that does not happen: If it misunderstands what 'that' refers to, restate the subject explicitly.

Practice: Use three follow-ups in one chat.

Part 4 - Understand the Chat Interface

  • Sidebar/Recents: previous chats and Projects; exact names and ordering can change.

  • New chat: begins a fresh conversation.

  • Conversation area: contains your messages, assistant responses, citations, widgets, files, and other results.

  • Prompt/message field: where you type or dictate the next request.

  • Attachment/plus controls: can expose file, image, search, study, or other tools depending on plan/device.

  • Model/mode or experience controls: can change the model, Chat/Work experience, Temporary Chat, or other behavior depending on current UI.

  • Profile/Settings: account, personalization, data controls, notifications, apps/plugins, and other preferences.

Screen reader strategy: Navigate by headings, buttons, edit fields, and landmarks instead of pressing Tab through every element in a long conversation.

Part 5 - Prompting Fundamentals

Task How / What to know
Goal What do you want ChatGPT to do?
Context What background is needed?
Constraints Length, audience, tone, exclusions, date, platform, or other requirements.
Input Text, file, data, problem, or question to work with.
Output Paragraph, numbered steps, table, email, checklist, code, etc.
Verification Ask for current sources or uncertainty when correctness matters.

5.1 Write a Strong Basic Prompt

What you will learn: Get a useful answer without unnecessary back-and-forth.

Before you begin: Choose a harmless task.

Exactly how to do it

  1. State the goal first.
  2. Add the audience or purpose.
  3. Add only relevant context.
  4. Specify output format.
  5. Add any important limits.
  6. For factual/current work, ask for sources or web verification.

What should happen: The answer is more targeted and structured.

If that does not happen: If the result is still vague, identify which requirement was missing and add it.

Practice: Ask ChatGPT to explain one familiar topic to a complete beginner in five steps.

Part 6 - Better Prompts and Follow-Up Questions

  • Ask for assumptions: 'List the assumptions you made.'

  • Ask for alternatives: 'Give me three options and the tradeoffs.'

  • Ask for simplification: 'Explain this without jargon.'

  • Ask for exact procedure: 'Give the exact keys/buttons and expected result.'

  • Ask for verification: 'Which statements here need current verification?'

  • Ask for restructuring: 'Turn this into headings and numbered steps.'

  • Ask for a revision: 'Keep the content, but make it shorter and more formal.'

Good correction pattern: Tell ChatGPT exactly what is wrong: 'The shortcut in step 4 is outdated. Verify the current official command and rewrite that section.'

Part 7 - Conversation Context and New Chats

ChatGPT uses prior messages in the current conversation. Long or mixed-topic chats can create confusion.

7.1 Start Fresh When Context Is Working Against You

What you will learn: Remove irrelevant conversation baggage.

Before you begin: A long chat has started producing confused answers.

Exactly how to do it

  1. Write down the current task and essential requirements.
  2. Start a new chat.
  3. Paste a concise task brief rather than the entire old conversation.
  4. Provide only the files/context needed for the new task.
  5. Continue from the clean conversation.

What should happen: The model receives a simpler instruction set.

If that does not happen: If important context was lost, add it explicitly in the new brief.

Practice: Turn a long request into a five-line clean brief.

Part 8 - Models and Modes

ChatGPT can expose different models or modes depending on plan, workspace, task, and rollout. Model names and availability change over time.

  • Use the default/Instant experience for normal everyday work when it meets the task.

  • Use a reasoning-oriented option for complex analysis when available and useful.

  • Use Search when the answer depends on current external information.

  • Use Deep Research for a larger multi-source research task when available.

  • Use Work for longer multi-step deliverables when available.

  • Do not choose a model only because its name sounds more advanced; test whether the result fits the task.

Current-model caution: This manual intentionally does not hard-code a single model list because OpenAI changes model availability over time.

Part 9 - Search the Web

9.1 Ask ChatGPT for Current Information

What you will learn: Use web search instead of relying only on model knowledge.

Before you begin: The question depends on recent information.

Exactly how to do it

  1. State that you want current information.
  2. Ask ChatGPT to search the web.
  3. Include the date/time window when relevant, such as today, this week, or the latest official release.
  4. Read the answer.
  5. Move through the citations/source links.
  6. Open at least one important source and confirm the claim.

What should happen: The answer includes current retrieved information and citations when Search is used.

If that does not happen: If the answer has no current sources, ask explicitly: Search the web and cite the sources you used.

Practice: Research one current software version.

Search example: Search the web for the current Windows 11 accessibility shortcuts and use Microsoft sources.

Part 10 - Verify Answers and Sources

10.1 Verify a ChatGPT Claim

What you will learn: Separate a plausible statement from an evidenced statement.

Before you begin: Choose an important factual claim.

Exactly how to do it

  1. Ask ChatGPT for the source.
  2. Open the source.
  3. Confirm the source title, date, and publisher.
  4. Find the statement that supports the claim.
  5. Check whether the source includes a limitation ChatGPT omitted.
  6. Use a second trustworthy source when the stakes justify it.

What should happen: You know whether the claim is genuinely supported.

If that does not happen: If the cited source does not support the claim, treat the statement as incorrect or unverified.

Practice: Verify three claims from one research response.

Citation warning: A citation is useful only when the linked source actually supports the sentence.

Part 11 - Upload and Work with Files

11.1 Upload a File

What you will learn: Give ChatGPT a document to summarize or analyze.

Before you begin: Use a non-sensitive practice file.

Exactly how to do it

  1. Find the attachment or plus button near the prompt.
  2. Activate it.
  3. Choose the file-upload option.
  4. Select the file from your device or available Library/source.
  5. Wait for the file to appear as attached.
  6. Ask a specific question such as: Summarize the three main sections and cite page numbers if available.
  7. Send the prompt.

What should happen: ChatGPT analyzes the uploaded file and answers from it when supported.

If that does not happen: If the file fails to upload, check file type, size, plan limits, browser/app version, and network connection.

Practice: Upload a harmless PDF or DOCX and ask five questions.

  • Files can include PDFs, presentations, text documents, spreadsheets, and other supported formats.

  • File support and limits vary by plan and product surface.

  • Do not assume a visually complex or scanned document was parsed perfectly.

  • Ask ChatGPT to identify uncertainty when content is missing or unreadable.

Part 12 - Data Analysis and Spreadsheets

12.1 Analyze a Spreadsheet

What you will learn: Use ChatGPT to summarize structured data.

Before you begin: Upload a non-sensitive CSV/XLSX practice file.

Exactly how to do it

  1. Attach the spreadsheet.
  2. Describe the question in plain language.
  3. Ask ChatGPT to explain which columns/rows it used.
  4. Ask for a table or chart when helpful.
  5. Check totals/percentages against a small manual calculation.
  6. Ask for the output file when you need a transformed spreadsheet and the feature supports file creation.

What should happen: ChatGPT can calculate, summarize, clean, or visualize structured data.

If that does not happen: If the numbers matter, independently verify key calculations. A polished chart does not prove the calculation was correct.

Practice: Analyze a ten-row practice dataset.

Part 13 - Images: Analyze, Generate, and Edit

13.1 Analyze an Image

  1. Attach a PNG, JPEG/JPG, or supported image.
  2. Ask a concrete question: Describe the layout, read visible labels, or identify the main chart trend.
  3. For important details, ask ChatGPT to state uncertainty.
  4. Verify high-stakes details such as medication labels, identities, hazards, or legal documents independently.

Expected result: ChatGPT provides a text interpretation of the image.

Limitation: Image analysis can be incomplete or wrong; do not use it as the sole basis for safety-critical decisions.

13.2 Generate or Edit an Image

  1. Describe the image you want in the prompt.
  2. Include subject, setting, composition, text requirements, and accessibility needs.
  3. Ask ChatGPT to generate the image.
  4. For an existing uploaded image, describe the exact edit such as removing an object or changing the background.
  5. Review the result and ask for another revision if necessary.

Accessibility: Ask for a concise text description/alt-text draft for generated images you intend to share.

Part 14 - Voice

14.1 Start a Voice Conversation

What you will learn: Talk with ChatGPT instead of typing.

Before you begin: Use a supported web/mobile/desktop surface and grant microphone permission when appropriate.

Exactly how to do it

  1. Find the Voice control near the prompt/composer.
  2. Activate it.
  3. Choose/confirm a voice if prompted.
  4. Speak naturally.
  5. Pause or interrupt when the voice experience supports interruption.
  6. End Voice using the on-screen control.

What should happen: ChatGPT responds with speech and, in current supported experiences, text also appears in the chat.

If that does not happen: If Voice cannot hear you, check microphone permissions and selected input device.

Practice: Ask a simple question, interrupt with a follow-up, then end Voice.

Current product note: The current GPT-Live voice experience can use web search and memory in supported consumer experiences. Availability can differ for managed workspaces.

Privacy: Voice conversations can contain sensitive spoken information. Use headphones and an appropriate environment.

Part 15 - Writing Blocks and Code Blocks

Current ChatGPT places reusable drafts and code into interactive blocks inside the conversation.

  • Writing blocks: editable draft areas for emails, messages, social posts, and documents.

  • Code blocks: separate code from prose and can support copy, edit, preview, or run actions depending on the language and environment.

  • Actions vary by plan, device, workspace settings, model, and rollout.

  • Edits generally remain associated with the conversation.

15.1 Revise a Writing Block

What you will learn: Edit a draft without rebuilding it from scratch.

Before you begin: Ask ChatGPT for a complete draft.

Exactly how to do it

  1. Open/focus the writing block.
  2. Edit the text directly if the current interface supports editing.
  3. Or tell ChatGPT exactly what to change.
  4. Review the revised block.
  5. Copy, save, send, or continue editing using the available actions.

What should happen: The draft remains a reusable artifact inside the conversation.

If that does not happen: If you do not receive a writing block, ask for a complete reusable draft rather than a brainstorming list.

Practice: Create and revise a short email draft.

Older instructions: Canvas was used in older ChatGPT versions. Current manuals should teach writing blocks, code blocks, Projects, and Work instead.

Part 16 - Projects

16.1 Create a Project

What you will learn: Keep related chats, files, and instructions together.

Before you begin: You are signed in.

Exactly how to do it

  1. Find Projects in the sidebar/navigation.
  2. Activate New project or the equivalent create control.
  3. Give the project a descriptive name.
  4. Add project instructions when useful.
  5. Upload relevant reference files.
  6. Start a chat inside the project.

What should happen: New project chats can use the project's shared context, files, and instructions according to current settings.

If that does not happen: If Projects is not visible, check the account/surface and current rollout. Projects are intended to be available broadly to signed-in users.

Practice: Create a harmless practice project with one file.

  • Projects are useful for long-running writing, research, planning, reporting, and repeated work.

  • Shared-project availability and permissions depend on plan/workspace.

  • Do not place confidential information in a shared project unless every participant is authorized.

Part 17 - Work

ChatGPT Work is the current agent/workspace for longer multi-step tasks and finished deliverables on eligible paid plans.

17.1 Start a Work Task

What you will learn: Delegate a multi-step outcome while retaining control.

Before you begin: Your account includes Work.

Exactly how to do it

  1. Select Work instead of ordinary Chat.
  2. Start a new Work chat or open a Project.
  3. Attach relevant files and context.
  4. Describe the finished outcome you need.
  5. Review progress updates and answer questions when needed.
  6. Review any request to approve an important external action.
  7. Inspect the finished deliverable before using it.

What should happen: Work carries out a longer task and produces a result/deliverable.

If that does not happen: If Work is absent, the plan, region, rollout, or workspace policy may not provide it. Use ordinary Chat for the same task in smaller steps.

Practice: Use Work for a harmless research or document task if available.

Cloud browser: Work can use a separate cloud browser for supported web tasks on eligible plans. The cloud browser has its own cookies/sessions and may continue remotely until it needs your input or confirmation.

Consequential actions: Review website, account, recipient, amount, destination, and final action before approving transactions, messages, bookings, or other hard-to-reverse steps.

Part 18 - Plugins and Connected Apps

ChatGPT can connect to external services through apps, now discovered primarily through the Plugin directory in the current product.

  • Apps can search or reference external data such as files, messages, calendars, or other connected services.

  • Some apps can take supported write actions.

  • Some plugins combine apps with reusable skills or workflows.

  • Availability depends on plan, region, workspace, role, model, and permissions.

  • Workspace administrators may restrict plugins/apps.

18.1 Connect an App Safely

What you will learn: Grant only the permissions needed.

Before you begin: Choose a low-risk supported service.

Exactly how to do it

  1. Open Settings/Plugins or the current plugin directory.
  2. Choose the plugin/app.
  3. Read the requested permissions.
  4. Authenticate through the provider's official sign-in flow.
  5. Return to ChatGPT.
  6. Ask ChatGPT for a harmless read-only task first.
  7. Review Settings > Apps/Plugins to disconnect when no longer needed.

What should happen: ChatGPT can access only the permissions that were granted and supported.

If that does not happen: Never paste a password or security code into the chat to connect an app; use the secure sign-in flow.

Practice: Connect and disconnect a low-risk service if available.

Part 19 - Deep Research

Deep Research is designed for multi-step research across multiple online sources and can produce structured cited outputs. Availability depends on plan and workspace.

19.1 Run a Deep Research Task

What you will learn: Use a slower, broader research workflow when ordinary Search is not enough.

Before you begin: Choose a research question that benefits from several sources.

Exactly how to do it

  1. Select Deep Research when available.
  2. State the research question and scope.
  3. Specify date range, countries, industries, source types, or exclusions.
  4. Attach relevant files if supported.
  5. Start the research.
  6. Read the final structured report and citations.
  7. Open important sources and verify key claims.

What should happen: You receive a longer multi-source research result.

If that does not happen: Deep Research reduces manual source gathering but does not eliminate the need to check sources and conclusions.

Practice: Research a low-stakes comparison of two public technologies.

Part 20 - Study Mode

20.1 Use Study Mode as a Tutor

What you will learn: Practice learning rather than simply requesting an answer.

Before you begin: Choose a topic you are studying.

Exactly how to do it

  1. Open Study Mode from the available tools or supported direct entry point.
  2. Tell ChatGPT what subject and level you are studying.
  3. Ask it to teach using questions and hints.
  4. Answer in your own words.
  5. Ask for a quiz or flashcard-style review.
  6. Upload course notes/images when allowed and ask Study Mode to use them.

What should happen: Study Mode guides you through learning with questions, explanations, and practice.

If that does not happen: If it gives the answer too quickly, say: Ask one question at a time and give hints before the answer.

Practice: Complete a five-question practice session.

Availability: Study Mode is currently available across ChatGPT plans on web, iOS, and Android, though individual learning shortcuts can vary.

Part 21 - Scheduled Tasks and Monitoring

21.1 Create a Reminder or Recurring Task

What you will learn: Have ChatGPT deliver something later or repeatedly when supported.

Before you begin: Your account has Scheduled Tasks.

Exactly how to do it

  1. Tell ChatGPT the action and schedule, such as: Remind me every weekday morning to review my task list.
  2. Review the task confirmation.
  3. Open Scheduled or Settings > Notifications > Manage tasks to review it.
  4. Edit, pause, resume, or delete the task as needed.
  5. Review notification settings for push/email delivery.

What should happen: ChatGPT runs the task on the supported schedule.

If that does not happen: Task frequency, exact timing, monitoring, connected-app support, and limits depend on plan and account.

Practice: Create one harmless one-time reminder and delete it after testing.

Sensitive information: Do not put passwords, account numbers, health/financial secrets, or other sensitive personal information into a task title or instructions that may be shared or surfaced in notifications.

Project limitation: Current scheduled-task documentation notes that a task created in a Project cannot access files uploaded to that Project.

Part 22 - Memory and Personalization

Memory can personalize future replies. Depending on account and settings, ChatGPT may use saved memories and/or relevant past conversation history.

22.1 Review Memory Settings

What you will learn: Decide what ChatGPT may remember.

Before you begin: Open Settings.

Exactly how to do it

  1. Open Personalization or Memory settings.
  2. Review Reference saved memories and Reference chat history when offered.
  3. Turn features on/off according to your preference.
  4. Open Manage memories.
  5. Review individual saved items.
  6. Delete an item you no longer want remembered.

What should happen: Memory behavior reflects your selected settings.

If that does not happen: If memory controls are absent or restricted, the account/workspace may use different settings.

Practice: Review what ChatGPT remembers and remove one disposable test memory.

Ask directly: You can also ask ChatGPT what it remembers about you and request that a specific memory be forgotten.

Part 23 - Temporary Chat

23.1 Start a Temporary Chat

What you will learn: Have a conversation that starts without normal saved-history/memory behavior.

Before you begin: Open a new chat.

Exactly how to do it

  1. Find the Temporary control near the top of the new-chat interface.
  2. Activate Temporary.
  3. Choose personalization behavior if the current interface offers that choice.
  4. Confirm that the conversation is marked Temporary.
  5. Use the chat normally.

What should happen: An unsaved Temporary Chat does not appear in ordinary history, does not create new memories, and is not used to improve models while it remains temporary.

If that does not happen: Temporary chats may still be retained for up to 30 days for safety/security purposes. Saving a temporary chat converts it into a regular chat.

Practice: Use a Temporary Chat for a harmless test question.

Current detail: Current Temporary Chat can be non-personalized by default, with some interfaces allowing a personalized temporary conversation that can reference existing memories without creating new ones.

Part 24 - Chat History, Archive, Delete, and Library

  • Regular chats remain in account history until deleted, subject to account/workspace retention rules.

  • Archive hides a chat from the normal sidebar but keeps it in the account.

  • Delete removes it from the account view and schedules deletion from OpenAI systems, subject to documented exceptions/retention.

  • Deletion is not the same as archiving.

  • Files saved in Library are managed separately from chats when Library is available; deleting a chat does not automatically delete a file saved in Library.

24.1 Archive or Delete Deliberately

What you will learn: Avoid confusing 'hide' with 'remove'.

Before you begin: Choose a disposable test chat.

Exactly how to do it

  1. Open the chat's more-options menu.
  2. Choose Archive if you only want to remove it from normal Recents.
  3. Open Settings and find archived chats to confirm it still exists.
  4. For a truly disposable chat, use Delete.
  5. Read the confirmation and complete deletion only when sure.

What should happen: You understand the difference between archive and delete.

If that does not happen: Deleted chats cannot normally be recovered. Use Archive when you may need the chat later.

Practice: Archive one test chat and delete another.

Part 25 - Data Controls and Privacy

25.1 Turn Off Model Improvement for Future Chats

What you will learn: Change whether new personal-account conversations may be used to improve models.

Before you begin: Open Settings.

Exactly how to do it

  1. Open Data Controls.
  2. Find Improve the model for everyone.
  3. Turn it off if that is your preference.
  4. Close Settings.

What should happen: New conversations remain in history but are not used to improve models under this setting.

If that does not happen: Managed Business/Enterprise/Edu workspaces have different organizational data policies and may not expose the same consumer control.

Practice: Locate the setting and decide deliberately.

  • Temporary Chats are not used to improve models while temporary.

  • Personal-account memory controls are separate from model-improvement controls.

  • Connected apps and external services have their own privacy policies and permissions.

  • Consumer, Business, Enterprise, Edu, Healthcare, and other workspaces can have different retention and data-handling rules.

  • Never assume a chat is appropriate for confidential data simply because model training is turned off.

Part 26 - Sharing Conversations and Projects

26.1 Share a Conversation Carefully

What you will learn: Create a shareable link only after reviewing the content.

Before you begin: Use a non-sensitive chat.

Exactly how to do it

  1. Open the chat's Share control.
  2. Review what part of the conversation will be shared.
  3. Remove or avoid private information.
  4. Create/copy the share link.
  5. Open the link in a separate/private browser session if practical to see what the recipient will see.
  6. Delete the shared link later if it should no longer be accessible.

What should happen: Recipients can view the shared snapshot/content according to the current sharing system.

If that does not happen: Do not rely on obscurity of a link as access control for confidential information.

Practice: Share a harmless practice chat and revoke the link.

Projects: Shared Projects can expose chats, uploaded files, and project context to collaborators. Verify membership and file sensitivity before sharing.

Part 27 - Screen Reader Use on Windows

ChatGPT is a dynamic web application. JAWS, NVDA, and Narrator can be used effectively by combining browser navigation with form controls, headings, landmarks, and ordinary editing.

27.1 JAWS

  • Use H/Shift+H for headings when Virtual PC Cursor is on.

  • Use E/Shift+E for edit fields and B/Shift+B for buttons when supported by JAWS web navigation.

  • Press Enter on the prompt edit field and type normally.

  • Use JAWS+Z to switch Virtual PC Cursor off/on if a complex interactive control works better in Forms/application mode.

  • Use JAWS heading/link lists when a long response is difficult to scan.

27.2 NVDA

  • Use H/Shift+H for headings in Browse Mode.

  • Use E/Shift+E for edit fields and B/Shift+B for buttons.

  • Press NVDA+Space to switch Browse/Focus Mode when an interactive control requires it.

  • Use NVDA+F7 Elements List for headings/links/form fields when useful.

27.3 Narrator

  • Use Narrator+Space to turn Scan Mode on/off as needed.

  • Use heading/form-control navigation in Scan Mode to locate the prompt and response headings.

  • Turn Scan Mode off when typing or interacting with a control that needs direct keystrokes.

  • Use Narrator+Tab to repeat the focused control when orientation is unclear.

Keyboard shortcut list: ChatGPT has a keyboard-shortcut list available from the interface; Ctrl+/ is a commonly documented shortcut for opening it. Because shortcuts can evolve, use the current shortcut list before memorizing less common commands.

Part 28 - VoiceOver on Mac and iPhone/iPad

28.1 Mac

  • Use VO+Command+H/Shift+VO+Command+H to move through headings in webpages where supported.

  • Use VO+U Rotor to find headings, links, form controls, and landmarks.

  • Use the Rotor to jump among headings, links, form controls, or other elements.

Exactly how to do it

  3. Move to the prompt edit field.

  5. Send it.
  6. Read the response.

Part 31 - Accessibility Prompting Techniques

Task How / What to know
Visual instruction is vague Ask: Give exact keyboard/screen-reader steps, expected feedback, and recovery.
Dense table is hard to navigate Ask: Convert this table into a structured list grouped by topic.
Image has important information Ask: Describe layout and text, then state uncertain details explicitly.
Response is full of emojis Ask: Rewrite without decorative emoji or repeated symbols.
Long response is hard to scan Ask: Add descriptive headings and a short summary at the top.
Need accessible link text Ask: Replace raw URLs with meaningful descriptive link labels when possible.

Procedure standard: For assistive-technology instructions, ask for: exact command -> where focus starts -> what should be announced -> what to do if it fails -> practice.

Part 32 - Responsible and Safe Use

  • Verify important factual claims.

  • Do not use ChatGPT as the sole authority for medical, legal, financial, safety, or other high-stakes decisions.

  • Protect confidential and personal information.

  • Do not use generated accusations or profiles as evidence about real people.

  • Review generated code before running it.

  • Review generated messages before sending them.

  • Review external actions before approving them.

  • Follow school, employer, professional, and organizational AI-use policies.

  • Disclose AI assistance when required.

Part 33 - Common Limitations and Hallucinations

ChatGPT can produce a confident answer that is wrong. It can also misunderstand a file, image, ambiguous prompt, current event, or niche technical command.

  • Invented or outdated citations.

  • Wrong keyboard shortcuts or menu names.

  • Incorrect calculations.

  • Misread text from complex images/documents.

  • Overconfident statements about people or current events.

  • Assuming a feature is available to every plan.

  • Continuing an earlier mistaken assumption through several follow-ups.

Recovery: Stop, identify the disputed claim, ask for current official verification, and check the source yourself.

Part 34 - Troubleshooting

34.1 ChatGPT Misunderstands the Task

What you will learn: Reset the instruction instead of adding vague corrections.

Before you begin: The answer is going in the wrong direction.

Exactly how to do it

  1. State what is wrong in one sentence.
  2. Restate the desired outcome.
  3. Restate nonnegotiable constraints.
  4. Provide a short example if useful.
  5. Ask ChatGPT to rewrite from the corrected instruction.

What should happen: The next response follows a cleaner instruction.

If that does not happen: If the conversation contains too many conflicting instructions, start a new chat.

Practice: Correct one deliberately vague prompt.

34.2 The Answer Looks Outdated

What you will learn: Force current verification.

Before you begin: The question involves software, law, news, prices, schedules, public figures, or another changing topic.

Exactly how to do it

  1. Say: Search the web for the current information.
  2. Specify today's date or required time window.
  3. Ask for official/primary sources.
  4. Open the sources.
  5. Compare the published/update dates.

What should happen: The response uses fresher external information.

If that does not happen: If the product cannot search in the current mode, open a new standard Chat/Search conversation or verify independently.

Practice: Verify one current product feature.

34.3 File Analysis Misses Important Content

What you will learn: Improve the source or narrow the question.

Before you begin: An uploaded file seems partially understood.

Exactly how to do it

  1. Ask ChatGPT which pages/sections it could read.
  2. Specify the exact page/heading/table you need.
  3. Upload a cleaner copy if available.
  4. For scanned pages, provide a higher-quality version or extracted text.
  5. Verify the answer against the original.

What should happen: The analysis becomes more focused.

If that does not happen: Do not trust an answer based on unreadable source material.

Practice: Test with a simple known PDF.

34.4 Screen Reader Focus Is Lost

What you will learn: Return to a known structural point.

Before you begin: The prompt or controls are hard to find.

Exactly how to do it

  1. Press Escape to close an open menu/dialog.
  2. Use heading navigation to find the conversation heading.
  3. Use edit-field navigation to locate the prompt.
  4. Use button navigation to find Send/Voice/attachment controls.
  5. Switch screen-reader browse/focus mode if the control needs direct interaction.

What should happen: You return to the prompt or a known response location.

If that does not happen: If the web app became unresponsive, refresh only after ensuring unsent text is copied or no longer needed.

Practice: Practice recovery from an open menu.

34.5 Voice Does Not Hear You

What you will learn: Check permissions and input hardware.

Before you begin: Voice is open but not responding.

Exactly how to do it

  1. End Voice.
  2. Check browser/app microphone permission.
  3. Check the selected operating-system input device.
  4. Test the microphone in another app.
  5. Return to ChatGPT Voice.
  6. Speak a short test phrase.

What should happen: Voice begins receiving speech.

If that does not happen: If microphone access is blocked by workspace policy or hardware, use text chat.

Practice: Test before an important voice session.

34.6 Memory Produced an Unwanted Assumption

What you will learn: Correct personalization rather than repeatedly correcting every answer.

Before you begin: ChatGPT keeps using an old preference or fact.

Exactly how to do it

  1. Tell ChatGPT the information is wrong/outdated.
  2. Ask it to forget that specific memory.
  3. Open Settings > Personalization/Memory.
  4. Review Manage memories.
  5. Delete the outdated item.
  6. Start a new chat and test.

What should happen: The unwanted personalization stops influencing new chats when the relevant memory is removed.

If that does not happen: If the detail comes from chat-history reference rather than a saved memory, review the chat-history personalization control or use Temporary Chat.

Practice: Create and remove a harmless test preference.

34.7 A Tool or Feature Is Missing

What you will learn: Check availability rather than assuming an error.

Before you begin: A manual step references a feature you cannot find.

Exactly how to do it

  1. Check whether you are signed in to the intended account/workspace.
  2. Check your plan.
  3. Check web versus mobile versus desktop availability.
  4. Check workspace/admin restrictions.
  5. Check the current OpenAI Help Center for rollout/region requirements.
  6. Use the closest standard Chat alternative when possible.

What should happen: You identify availability instead of repeatedly searching the UI.

If that does not happen: Features may roll out gradually or change names; use current official documentation.

Practice: Compare feature availability on two devices if you use both.

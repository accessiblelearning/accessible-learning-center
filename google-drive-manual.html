How to Use This Manual

  • Use a harmless practice folder first.

  • On Windows, use the screen reader in application/focus mode while navigating Drive shortcuts.

  • Press Ctrl+/ to open the current Drive shortcut list.

  • Use Ctrl+F6 to move among major Drive regions on Windows/ChromeOS; Command+F6 on Mac.

  • Always confirm the selected file or folder before moving, deleting, or sharing it.

Part 1 - What Google Drive Is

  • Cloud storage for files and folders.

  • My Drive contains items you create or add.

  • Shared with me shows items others share with you.

  • Shared drives may appear in work/school accounts.

  • Drive can open Google Docs, Sheets, Slides, Forms, PDFs, media, and many other file types.

Part 2 - Open Drive and Understand the Interface

2.1 Open Drive

What you will learn: Reach Google Drive without a mouse.

Keyboard command: Windows/ChromeOS: Ctrl+L or Alt+D, type drive.google.com, Enter. Move among major Drive regions with Ctrl+F6; move backward with Ctrl+Shift+F6.

Before you begin: Use a supported browser and the correct Google account.

Exactly how to do it

  1. Press Ctrl+L or Alt+D.
  2. Type drive.google.com.
  3. Press Enter.
  4. Wait for the file/folder area.
  5. Press Ctrl+F6 repeatedly to hear major regions; press Shift+Ctrl+F6 to move backward.

What should happen: You can identify the file list, navigation tree, search/banner area, and side panels.

If that does not happen: If Ctrl+F6 changes browser tabs or another application, return to Drive and try again.

Practice: Identify all major regions once.

Part 3 - Screen Reader Setup

Task Command / Method
JAWS Use Virtual PC Cursor off for direct Drive application shortcuts; turn it on temporarily to inspect the Ctrl+/ shortcut table.
NVDA Use Focus Mode for Drive application interaction; Browse Mode can help read static shortcut/help content.
VoiceOver Use standard web-app interaction; Command+F6 moves among major regions.
Narrator Turn Scan Mode off when it intercepts Drive application shortcuts.

Web-app rule: Letters such as / and sequence shortcuts must reach Drive, not be captured as screen-reader webpage-navigation commands.

4.1 Move Through Files

What you will learn: Browse by keyboard.

Keyboard command: Press Alt+G, then I to move focus to the items view. Use Arrow keys to move, Space to select/deselect, Enter to open, and Shift+F10 for the item action menu.

Before you begin: Focus the items area.

Exactly how to do it

  1. Press Alt+G, then I to move focus to the items view; then use Arrow keys to move through files and folders.
  2. Press Space to select an item without opening it.
  3. Press Enter to open the selected item.
  4. Press Shift+F10 for the item action menu.

What should happen: The selected file/folder is announced and can be opened or acted on.

If that does not happen: If letters trigger screen-reader commands, switch to application/focus mode.

Practice: Open and close three harmless files.

Part 5 - Create Folders and Files

5.1 Create a Folder

What you will learn: Create an organizational folder.

Keyboard command: Press Alt+C, then F to create a new folder in the current Drive location. Type the folder name and press Enter.

Before you begin: Open the destination folder first.

Exactly how to do it

  1. Press Alt+C, then F. Release the first shortcut before pressing F.
  2. Type the new folder name in the dialog.
  3. Press Enter to create the folder.

What should happen: The folder appears in the current location.

If that does not happen: If another menu opens, use Alt+C then F as the current shortcut alternative.

Practice: Create Practice Files.

Task Command / Method
New folder Alt+C then F
New Google Doc Alt+C then T
New Google Sheet Alt+C then S
New Google Slides presentation Alt+C then P
New Google Form Alt+C then O

Part 6 - Upload Files and Folders

6.1 Upload a File

What you will learn: Copy a local file into Drive.

Keyboard command: Press Alt+C, then U to open File upload. In the operating-system file picker, use keyboard navigation to select the file and press Enter/Open.

Before you begin: Use a harmless local file.

Exactly how to do it

  1. Press Alt+C, then U. Release the first shortcut before pressing U.
  2. The operating-system file picker opens; use its keyboard controls to locate the file.
  3. Select the file and press Enter/Open.
  4. Wait for the upload status/notification before assuming the file is available.

What should happen: The file appears in Drive.

If that does not happen: Check upload status and available storage if the item does not appear.

Practice: Upload one TXT or PDF file.

Shortcut: Current Drive documentation lists Alt+C then U for file upload on Windows/ChromeOS.

Part 7 - Select and Open Items

  • Space toggles item selection.

  • Enter opens the focused item.

  • Ctrl+A selects all items in the current Drive item region where supported.

  • Escape clears selection or backs out of some actions.

  • Shift+F10 opens the selected item context/action menu.

Part 8 - Rename, Move, Copy, and Shortcuts

8.1 Rename

What you will learn: Rename without opening the file.

Keyboard command: Focus the item and press F2. Type the new name and press Enter.

Before you begin: Focus one practice item.

Exactly how to do it

  1. Press F2.
  2. Type the new name.
  3. Press Enter.

What should happen: The item keeps its content but has the new name.

If that does not happen: If F2 does not work in your current view, use Shift+F10 and choose Rename.

Practice: Rename and restore one file.

8.2 Move an Item

What you will learn: Place a file in another folder.

Keyboard command: Focus/select the item, press Shift+F10, use Arrow keys to Organize/Move, press Enter, navigate the destination with Arrow/Tab keys, then activate Move.

Before you begin: Select a practice item.

Exactly how to do it

  1. Open Shift+F10.
  2. Choose Organize or Move.
  3. Navigate the destination tree.
  4. Choose Move here/Move.
  5. Confirm the new location.

What should happen: The item moves to the destination.

If that does not happen: Use Search if you lose track of the moved file.

Practice: Move a file into Practice Files and back.

Drive shortcut: Google documents a copy-then Ctrl+Shift+V workflow in a destination for creating a Drive shortcut in supported contexts.

Part 9 - Search Drive

9.1 Search

What you will learn: Find a file without remembering its folder.

Keyboard command: Press / to focus Drive Search, type the search term, and press Enter.

Before you begin: Know one word from the filename or content.

Exactly how to do it

  1. Press /.
  2. Type the search term.
  3. Press Enter.
  4. Move through results.
  5. Open the intended item.

What should happen: Drive displays matching items.

If that does not happen: Use advanced search filters for owner, type, date, or location when results are broad.

Practice: Find one file by partial name.

Part 10 - Special Views

  • Recent: recently accessed items.

  • Starred: items you marked for quick access.

  • Shared with me: items other people shared with you.

  • Spam: suspicious shared content.

  • Trash: deleted items that may be restorable until permanently removed.

  • Storage: usage and larger files.

Part 11 - Sharing and Permissions

11.1 Share a File

What you will learn: Give another person appropriate access.

Keyboard command: Select the item and press S when the current Drive shortcut is available; otherwise press Shift+F10, use Arrow keys to Share, and press Enter. In the Share dialog use Tab/Shift+Tab and Enter/Space.

Before you begin: Use a non-sensitive practice file.

Exactly how to do it

  1. Focus the file and press Space to select it.
  2. Press Shift+F10.
  3. Choose Share.
  4. Enter the person or group.
  5. Choose Viewer, Commenter, or Editor.
  6. Read the file name, recipient, and permission again.
  7. Send.

What should happen: The recipient receives the intended permission.

If that does not happen: Do not use broad link sharing to solve a one-person permission problem.

Practice: Inspect sharing without sending, then cancel.

Least privilege: Viewer is safer than Editor when editing is not required.

Part 12 - File Details and Activity

  • Use Alt+G then D to move to Details when available.

  • Review file owner, location, modified date, sharing, and activity.

  • Use details before deleting or moving a similarly named file.

Part 13 - Downloads and Offline Access

  • Download creates a local copy; it does not remove the Drive original.

  • Offline access can make selected Google files available without internet.

  • Downloaded Office/PDF files can diverge from the cloud original after local editing.

Part 14 - Drive for Desktop

  • Drive for desktop exposes synced files through File Explorer/Finder.

  • Use ordinary screen-reader file-navigation commands there.

  • Understand streaming versus mirroring/offline availability before assuming a local copy exists.

  • Deleting a synced file can synchronize deletion; confirm before removing.

Part 15 - Screen Reader Workflows

  • JAWS: Virtual PC Cursor off for Drive shortcuts; on temporarily for reading static help tables.

  • NVDA: Focus Mode for Drive; Browse Mode for static help.

  • Narrator: Scan Mode off when direct application keystrokes are needed.

  • VoiceOver: use Command+F6 among regions and ordinary form/control navigation.

Part 16 - Braille and Mobile

  • Braille follows the active screen reader; test output, input, and routing.

  • Android: TalkBack can open items with swipe/tap and use long-press selection for actions.

  • iPhone/iPad: VoiceOver can navigate Drive controls and files; external keyboard/braille helps with larger management tasks.

Part 17 - Security and Privacy

  • Verify account before uploading sensitive files.

  • Review link-sharing permissions.

  • Do not treat Shared with me as proof a file is trustworthy.

  • Use Spam/Report controls for suspicious Drive shares.

  • Check organization policy before using personal Drive for work/school data.

Part 18 - Troubleshooting

Drive shortcuts type letters

  1. Switch JAWS/NVDA/Narrator into application/focus mode.
  2. Press Ctrl+/ to verify current shortcuts.

Cannot find a moved file

  1. Press /.
  2. Search by name.
  3. Review location in Details.

Cannot edit a shared file

  1. Check permission level.
  2. Confirm correct Google account.
  3. Ask owner for Editor access only if needed.

Upload appears stuck

  1. Check network.
  2. Check storage quota.
  3. Review upload status.
  4. Retry with a smaller harmless file.

Google Android Accessibility Help - TalkBack

Purpose: This manual teaches Android with TalkBack from the beginning. It explains physical orientation, touch exploration, navigation, typing, system gestures, web browsing, TalkBack settings, braille input/output, external keyboards, security, troubleshooting, and independent practice.

Device differences: Android phones and tablets vary by manufacturer. Pixel, Samsung Galaxy, Motorola, OnePlus, and other devices may place buttons differently or rename settings. The TalkBack concepts and core gestures are consistent, but exact menus can differ.

Current reference: The guide is aligned with current Android Accessibility Help, including Android 16-era TalkBack features and TalkBack 16.2 keyboard/braille changes.

How to Use This Manual

  • Work through the first gesture sections slowly. TalkBack changes how ordinary touch works.

  • Touching an item normally speaks it; activating it usually requires a double-tap.

  • One-finger swipes generally move TalkBack focus. Two-finger gestures generally scroll or perform system navigation when gesture navigation is in use.

  • Use the built-in TalkBack Tutorial and Practice area whenever a gesture feels unreliable.

  • On devices that support multi-finger gestures, a three-finger tap opens the TalkBack menu.

  • Reading controls change what an up/down swipe navigates: characters, words, headings, controls, and more.

  • Braille support is built into TalkBack. BrailleBack is not required for current supported braille displays.

  • When typing with the TalkBack braille keyboard, normal TalkBack gestures are temporarily replaced by braille-keyboard gestures.

  • Never change several TalkBack settings at once while learning. Change one setting, test it, and keep or reverse it.

Part 1 - What TalkBack Is

TalkBack is Android's built-in screen reader. It speaks or displays in braille what is focused, describes controls and alerts, and changes the touch interface so a blind or low-vision user can navigate independently.

  • Focus: the item TalkBack is currently describing.

  • Explore by touch: drag one finger around the screen and TalkBack speaks what is under the finger.

  • Swipe navigation: move focus in a predictable sequence without needing to know where items are visually.

  • Activation: after focusing an item, double-tap anywhere with one finger to activate it.

  • Reading controls: change the navigation unit used by up/down swipes.

  • TalkBack menu: quick access to settings, voice commands, screen search, hide/show screen, and context actions.

  • Braille: TalkBack supports both an onscreen braille keyboard and connected refreshable braille displays.

Part 2 - Physical Orientation and Android Device Types

Important: There is no single physical Android layout. Always identify your exact device model before memorizing button locations.

  • Most modern phones have a flat touchscreen on the front, one or more cameras near the top, and physical side buttons.

  • Common side buttons include Power/Side key and Volume Up/Down. Their side and vertical order vary by manufacturer.

  • USB-C is the standard charging/data connector on most current Android phones and tablets and is usually on the bottom edge.

  • Some tablets place USB-C on a side edge depending on orientation.

  • Some devices use on-screen gesture navigation; others use a three-button navigation bar with Back, Home, and Overview/Recents.

  • Foldable phones may have multiple displays and hinge-dependent layouts.

2.1 Identify Your Device Before Learning Gestures

What you will learn: Create a reliable physical map of your own phone/tablet.

Before you begin: Have the device powered on and safely held.

Exactly how to do it

  1. Find the screen: the large smooth glass surface on the front.

  2. Find the Power/Side key and press it briefly once to hear whether the screen locks/wakes.

  3. Find Volume Up and Volume Down by pressing each once and listening for the volume change.

  4. Locate the charging port by touch without inserting a cable blindly at an angle.

  5. Ask Settings > About phone/tablet for the exact manufacturer and model name if you do not know it.

  6. Write down the exact model and button layout in your own notes.

What should happen: You have a model-specific physical map instead of relying on generic assumptions.

If that does not happen: If you cannot identify a control safely, use the manufacturer's official hardware guide for that exact model.

Practice: Locate each physical control three times with the screen off.

Part 3 - Turn TalkBack On and Off

3.1 Turn TalkBack On in Settings

What you will learn: Enable TalkBack using the standard Android Settings path.

Before you begin: The device is already set up and you can access Settings.

Exactly how to do it

  1. Open Settings.

  2. Open Accessibility.

  3. Open TalkBack.

  4. Turn Use TalkBack on.

  5. Confirm the permission/confirmation prompt.

  6. Listen to TalkBack begin speaking.

What should happen: TalkBack starts and touch behavior changes.

If that does not happen: Menu names vary by manufacturer. Use Settings search for TalkBack if necessary.

Practice: Turn TalkBack on and enter the Tutorial.

3.2 Configure the TalkBack Shortcut

What you will learn: Make it possible to toggle TalkBack without navigating Settings.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Open Settings > Accessibility > TalkBack.

  2. Open TalkBack shortcut.

  3. Turn the shortcut on.

  4. Follow the device-specific instructions for the offered shortcut method.

  5. Test the shortcut once to turn TalkBack off, then use it again to turn TalkBack on.

What should happen: You can toggle TalkBack using the configured accessibility shortcut.

If that does not happen: The shortcut varies by device and Android version. Do not assume one universal button combination.

Practice: Toggle TalkBack off and back on without opening Settings.

3.3 Use Google Assistant to Toggle TalkBack

What you will learn: Use voice control when Assistant is already configured.

Before you begin: Google Assistant/Gemini voice activation is available on the device.

Exactly how to do it

  1. Say Hey Google.

  2. Say Turn on TalkBack or Turn off TalkBack.

  3. Wait for the change to complete.

What should happen: TalkBack changes state by voice command.

If that does not happen: If Assistant is not configured, use Settings or the accessibility shortcut instead.

Practice: Use voice to turn TalkBack on once.

Android 16 keyboard option: Google documents an Android 16 external-keyboard shortcut for TalkBack using the Action key + Alt + T. The Action key depends on the keyboard, such as Windows key on a Windows keyboard or Command on a Mac keyboard.

Part 4 - TalkBack Tutorial and Practice

4.1 Open Tutorial and Help

What you will learn: Practice gestures without fear of activating normal app controls.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Open the TalkBack menu with a three-finger tap on supported multi-finger devices, or swipe down then right in one motion.

  2. Choose TalkBack settings.

  3. Choose Tutorial and help.

  4. Open the gesture practice/tutorial section.

  5. Perform each gesture until TalkBack identifies it consistently.

What should happen: You can practice gestures in a controlled environment.

If that does not happen: If a three-finger tap does not open the menu, the device may not support multi-finger TalkBack gestures; use swipe down then right.

Practice: Practice swipe right, swipe left, double-tap, two-finger scroll, and reading-control gestures.

Part 5 - Explore by Touch

5.1 Explore the Screen

What you will learn: Learn spatial layout without activating anything.

Before you begin: TalkBack is on and the Home screen is visible.

Exactly how to do it

  1. Place one finger lightly near the upper-left area of the screen.

  2. Without lifting the finger, slowly drag across the screen.

  3. Listen as TalkBack speaks each item your finger crosses.

  4. Move toward the bottom edge and sides to learn where persistent controls are.

  5. Lift your finger when finished. Do not double-tap.

What should happen: TalkBack describes items under the finger without opening them.

If that does not happen: If an item opens, you likely double-tapped or used single-tap activation. Review TalkBack settings.

Practice: Explore the Home screen without opening an app.

Part 6 - Core One-Finger Navigation

Task Gesture / Command
Next item Swipe right with one finger
Previous item Swipe left with one finger
Change reading control / navigate by selected unit Swipe up or down with one finger, depending current reading control
Explore by touch Drag one finger
Focus item by touch Tap/touch item

6.1 Move Sequentially

What you will learn: Navigate without knowing the screen layout.

Before you begin: TalkBack focus is on any item.

Exactly how to do it

  1. Swipe right once.

  2. Listen to the next item.

  3. Swipe right several more times.

  4. Swipe left to move backward.

  5. Continue until you can predict that right means next and left means previous.

What should happen: Focus moves in TalkBack's accessibility order.

If that does not happen: If swipes scroll instead, use one finger, not two.

Practice: Move forward ten items and backward five.

Part 7 - Activate, Long-Press, and Scroll

Task Gesture / Command
Activate focused item Double-tap with one finger anywhere
Long press focused item Double-tap and hold
Scroll vertically Two-finger swipe up/down or two-finger drag
Scroll horizontally Two-finger swipe left/right when content supports it

7.1 Open an App with TalkBack

What you will learn: Focus first, then activate.

Before you begin: Be on the Home screen.

Exactly how to do it

  1. Swipe right/left until the desired app is announced.

  2. Double-tap anywhere with one finger.

  3. Wait for the app to open.

  4. Use swipe right to identify the first controls.

What should happen: The focused app opens.

If that does not happen: If the wrong app opens, you activated a different focused item. Swipe to refocus and try again.

Practice: Open Settings and return Home.

Part 8 - Home, Back, Overview, Notifications, and Quick Settings

Gesture navigation: When Android gesture navigation is enabled, TalkBack commonly uses two-finger system gestures so they do not conflict with one-finger TalkBack navigation.

  • Home: on gesture-navigation devices, use the TalkBack/system Home gesture appropriate to the device, often a two-finger swipe up from the bottom edge.

  • Back: commonly swipe down then left in one motion, or use the device's two-finger Back system gesture depending configuration.

  • Overview/Recent apps: use the device-specific TalkBack system gesture or focus the Overview button on three-button navigation devices.

  • Notifications: system gesture varies, but TalkBack can also navigate the status/notification shade after it is opened.

  • Quick Settings: usually reached by expanding the shade farther than notifications.

Why wording is cautious: Manufacturers and navigation modes differ. Use TalkBack Tutorial > System actions on your own device as the authoritative gesture set.

Part 9 - TalkBack Menu and Reading Controls

9.1 Open the TalkBack Menu

What you will learn: Reach common TalkBack commands quickly.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Three-finger tap the screen if multi-finger gestures are supported.

  2. If that does not work, swipe down then right in one continuous motion.

  3. Explore menu items such as TalkBack settings, Screen search, Voice commands, Hide/show screen, and context actions.

  4. Press Back to close the menu.

What should happen: The TalkBack menu opens.

If that does not happen: If no menu opens with three-finger tap, use the one-finger angled gesture.

Practice: Open and close the menu three times.

9.2 Change Reading Controls

What you will learn: Choose whether up/down swipes navigate characters, words, headings, controls, and other units.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Perform a three-finger swipe up or down on supported devices, or the one-finger up-then-down/down-then-up gesture on older/single-finger setups.

  2. Listen to the selected reading control.

  3. Repeat until you hear the unit you want, such as Characters or Headings.

  4. Use one-finger swipe up/down to move by that unit.

What should happen: Navigation changes to the selected reading unit.

If that does not happen: If the gesture scrolls content, verify the number of fingers and that TalkBack supports multi-finger gestures.

Practice: Select Characters, navigate, then select Headings on a webpage.

Part 10 - Home Screen and App Drawer

10.1 Navigate the Home Screen

What you will learn: Find apps, folders, widgets, and system areas.

Before you begin: You are on Home.

Exactly how to do it

  1. Swipe right through Home-screen items.

  2. Listen for app names, folders, widgets, and page indicators.

  3. Use a two-finger horizontal swipe if the launcher uses multiple Home pages.

  4. Double-tap the desired app.

What should happen: You can locate and open Home-screen items.

If that does not happen: Launcher behavior varies by manufacturer. If page gestures differ, use explore-by-touch or the app drawer.

Practice: Find three apps without opening them, then open one.

10.2 Use the App Drawer

What you will learn: Find an installed app even if it is not on the Home screen.

Before you begin: Your launcher provides an app drawer.

Exactly how to do it

  1. Use the launcher's app-drawer gesture or activate the Apps button if present.

  2. Use swipe navigation through apps or focus the search field.

  3. Type part of the app name when search is available.

  4. Double-tap the result.

What should happen: The desired app opens.

If that does not happen: Some launchers do not use a traditional app drawer. Use Home-screen search instead.

Practice: Open Chrome through app search.

Part 11 - Notifications

11.1 Read and Dismiss Notifications

What you will learn: Review alerts without opening every app.

Before you begin: At least one notification is present.

Exactly how to do it

  1. Open the notification shade using the device-specific TalkBack/system gesture.

  2. Swipe right through notifications.

  3. Listen to app name, sender/title, and available actions.

  4. Double-tap a notification to open it, or use its Dismiss/Clear action when appropriate.

  5. Close the shade with Back/Home.

What should happen: You can review notifications independently.

If that does not happen: If the shade does not open, practice the system-action gesture in TalkBack Tutorial.

Practice: Read three notifications and dismiss one harmless notification.

Privacy: Notification text can reveal sensitive messages. Review lock-screen notification settings if other people can see your device.

Part 12 - Quick Settings

12.1 Change a Quick Setting

What you will learn: Toggle Wi-Fi, Bluetooth, Do Not Disturb, or another system control.

Before you begin: Open the Quick Settings panel.

Exactly how to do it

  1. Navigate with swipe right/left.

  2. Listen to each tile name and state, such as Wi-Fi on or Bluetooth off.

  3. Double-tap only the tile you intend to change.

  4. Listen for the new state.

  5. Close Quick Settings.

What should happen: The selected setting changes.

If that does not happen: If the tile opens a detailed settings page instead of toggling, use Back after reviewing it.

Practice: Toggle Bluetooth only if safe, then restore its original state.

Part 13 - Text Entry with Gboard

13.1 Type with Explore-by-Touch Gboard

What you will learn: Enter text using the standard onscreen keyboard.

Before you begin: Focus an editable text field and open the keyboard.

Exactly how to do it

  1. Move one finger across the keyboard until TalkBack announces the desired letter.

  2. Lift your finger to enter that letter on standard TalkBack/Gboard touch typing.

  3. Repeat for the word.

  4. Use Backspace/Delete by locating its key and activating it.

  5. Use the Back system gesture to dismiss the keyboard when finished.

What should happen: Text appears in the field as keys are selected.

If that does not happen: Typing behavior can be customized. If lifting your finger does not type the key, check TalkBack typing preferences.

Practice: Type your first name and a short sentence.

13.2 Use Password Fields Safely

What you will learn: Control how secure text is spoken.

Before you begin: Open a safe password field or TalkBack speech settings.

Exactly how to do it

  1. Review TalkBack settings for speaking passwords/secure fields.

  2. Choose the privacy level appropriate to your environment.

  3. When in public, use headphones or reduced password feedback.

  4. Never practice with a real password in a public setting.

What should happen: Password feedback matches your privacy needs.

If that does not happen: If TalkBack speaks more than expected, change secure-field verbosity before entering sensitive credentials.

Practice: Review the setting without entering a real password.

Part 14 - Text Editing and Selection

14.1 Review Text by Character or Word

What you will learn: Move precisely inside an edit field.

Before you begin: An edit field contains text.

Exactly how to do it

  1. Focus the edit field.

  2. Use reading controls to choose Characters or Words.

  3. Swipe up/down to move the cursor/review position by the selected unit.

  4. Use the TalkBack menu > Edit options when you need selection, copy, cut, or paste.

  5. Confirm the selected range before deleting/replacing text.

What should happen: You can edit without erasing the whole field.

If that does not happen: If up/down changes volume or another function, verify the reading control and current focus.

Practice: Correct three spelling errors in a practice note.

Part 15 - Voice Typing and Google Assistant

15.1 Dictate Text

What you will learn: Use speech input instead of the onscreen keyboard.

Before you begin: Gboard voice typing is enabled and the environment is private enough for dictation.

Exactly how to do it

  1. Focus the edit field.

  2. Find the microphone/voice typing key on Gboard.

  3. Double-tap it.

  4. Speak a short sentence clearly.

  5. Wait for text to appear.

  6. Review the text before sending or saving.

What should happen: Spoken words are converted to text.

If that does not happen: If voice typing is unavailable, check microphone permission, keyboard settings, and network/on-device language support.

Practice: Dictate one short harmless sentence and correct any error manually.

Part 16 - Chrome and Web Navigation

16.1 Read a Webpage with TalkBack

What you will learn: Navigate headings, links, controls, and text in Chrome.

Before you begin: Open a webpage in Chrome.

Exactly how to do it

  1. Use one-finger swipe right/left for sequential navigation.

  2. Use Reading controls to select Headings.

  3. Swipe up/down to move by heading.

  4. Select Links or Controls when useful and navigate by that unit.

  5. Double-tap the focused link/control to activate it.

  6. Use the TalkBack menu Screen search when you know a word on the current screen.

What should happen: You can move through webpage structure efficiently.

If that does not happen: Poorly structured websites may have few or no useful headings. Use sequential navigation or Chrome Find as a fallback.

Practice: Navigate one article by headings, then follow a link and go Back.

Physical keyboard: TalkBack 16.2 introduced an Enhanced keymap with Browse mode for physical keyboards. Smart Browse mode can automatically leave Browse mode when entering edit fields and restore it afterward.

Part 17 - Messages and Email

17.1 Send a Text Message

What you will learn: Compose and verify a simple message.

Before you begin: Open your messaging app.

Exactly how to do it

  1. Find New conversation/Start chat.

  2. Enter or select the recipient.

  3. Review the recipient name/number carefully.

  4. Focus the message field.

  5. Type or dictate the message.

  6. Review the message.

  7. Double-tap Send.

What should happen: The message is sent to the intended recipient.

If that does not happen: If several contacts have similar names, verify the number or other identifying detail before sending.

Practice: Draft a harmless message and cancel before sending if preferred.

17.2 Read and Reply to Email

What you will learn: Open a message and reply without losing context.

Before you begin: Open Gmail or another accessible mail app.

Exactly how to do it

  1. Navigate the message list with swipes.

  2. Double-tap the desired message.

  3. Read sender, subject, and message body.

  4. Find Reply.

  5. Enter the response.

  6. Review it, then send only when ready.

What should happen: The reply is associated with the correct conversation.

If that does not happen: If navigation becomes noisy, use TalkBack reading controls to move by headings/controls when the app exposes them.

Practice: Open one non-sensitive email and locate Reply.

Part 18 - Phone and Video Calls

18.1 Answer and End a Call

What you will learn: Handle a standard incoming phone call.

Before you begin: A safe practice call is incoming.

Exactly how to do it

  1. Navigate to the Answer control using TalkBack or the device-specific call gesture.

  2. Activate Answer.

  3. Use Volume buttons to adjust call volume if needed.

  4. Locate Mute, Speaker, Keypad, and End call controls by swipe navigation.

  5. Activate End call when finished.

What should happen: The call connects and ends intentionally.

If that does not happen: Call-screen layouts vary by manufacturer and dialer app. Practice before relying on it in an urgent situation.

Practice: Practice with a trusted caller.

Part 19 - TalkBack Settings and Speech

19.1 Open TalkBack Settings

What you will learn: Adjust speech, verbosity, gestures, braille, and keyboard features.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Open the TalkBack menu.

  2. Choose TalkBack settings.

  3. Review Speech, Verbosity, Gestures, Braille keyboard, Braille display, Advanced settings, and Tutorial/help.

  4. Change only one setting at a time.

  5. Test the change before making another.

What should happen: You can customize TalkBack without losing track of what changed.

If that does not happen: If TalkBack becomes hard to use after a change, return to the same setting and restore the previous option.

Practice: Change speech rate slightly, test, then restore it.

Version check: Google documents the TalkBack version inside TalkBack settings > Advanced settings > Others/Open TalkBack at the Play Store path. Menu labels can change slightly over releases.

Part 20 - Hide Screen and Privacy Features

20.1 Hide or Show the Screen

What you will learn: Prevent nearby people from visually reading the display while TalkBack continues.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Open the TalkBack menu.

  2. Choose Hide or show screen.

  3. Confirm the screen is hidden while TalkBack continues speaking.

  4. Use the TalkBack menu again to show the screen when needed.

What should happen: The visual display is hidden without turning TalkBack off.

If that does not happen: If you need sighted assistance, show the screen before handing the device to another person.

Practice: Hide the screen, navigate two items, then show it again.

Part 21 - TalkBack Braille Keyboard

Important: The TalkBack braille keyboard uses six fingers to enter 6-dot braille. Google says TalkBack must be on and Magnification must be off.

21.1 Set Up the TalkBack Braille Keyboard

What you will learn: Enable the onscreen braille keyboard.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Open the TalkBack menu.

  2. Choose TalkBack settings.

  3. Open Braille keyboard.

  4. Choose Set up braille keyboard and follow the prompts.

  5. Open an editable field.

  6. Choose the input-method switcher.

  7. Select TalkBack braille keyboard.

  8. Complete the tutorial the first time.

What should happen: The screen becomes a six-dot braille input surface.

If that does not happen: If the keyboard option is missing, confirm TalkBack is current and that Magnification is off.

Practice: Complete the braille-keyboard tutorial.

Part 22 - Refreshable Braille Displays

Current model: Google states that BrailleBack is not required to connect a supported braille display to TalkBack.

22.1 Connect a Braille Display

What you will learn: Pair a refreshable braille display with TalkBack.

Before you begin: The display is supported and ready to pair.

Exactly how to do it

  1. Open TalkBack settings.

  2. Open Braille display.

  3. Choose the connection/pairing option offered by the device.

  4. Put the braille display into its Bluetooth/USB pairing mode.

  5. Select the display when it appears.

  6. Confirm pairing if a code is requested.

  7. Open Braille display commands to review device-specific keystrokes.

What should happen: Braille output follows TalkBack focus.

If that does not happen: If the device does not appear, verify Bluetooth/USB mode and supported-display guidance for that model.

Practice: Pair the display and read three Home-screen items.

22.2 Test Output, Input, and Routing

What you will learn: Verify the three essential braille functions.

Before you begin: The display is connected.

Exactly how to do it

  1. Move TalkBack focus through several items and confirm braille output changes.

  2. Open an edit field.

  3. Use a routing key on the field or press Enter/Dot 8 as appropriate to activate editing.

  4. Type a short word from the braille display.

  5. Use routing/arrow keys to move within the text.

  6. Correct one character.

What should happen: Braille output, input, and routing all function.

If that does not happen: If one function fails, inspect TalkBack settings > Braille display > Braille display commands for that specific display.

Practice: Perform output, input, routing.

Part 23 - External Keyboard and Enhanced Keymap

TalkBack 16.2: Google documents two keymaps: Default and Enhanced. On first activation of TalkBack 16.2 or later, Enhanced keymap is turned on by default.

23.1 Review Physical-Keyboard TalkBack Commands

What you will learn: Use a keyboard for efficient navigation and web browsing.

Before you begin: A Bluetooth/USB keyboard is connected.

Exactly how to do it

  1. Open TalkBack settings > Advanced settings > Keyboard shortcuts.

  2. Review Choose a keymap.

  3. Select Enhanced keymap if you want Browse-mode commands and it is not already selected.

  4. Identify the TalkBack modifier key configured for your keyboard.

  5. Test TalkBack key + Right Arrow for next item and TalkBack key + Left Arrow for previous item.

  6. Double-press the TalkBack key to enter Browse mode when using the Enhanced keymap.

  7. Test headings/links lists in a browser if available.

What should happen: The physical keyboard can control TalkBack efficiently.

If that does not happen: If the modifier conflicts with another system shortcut, change the TalkBack key in Keyboard shortcuts settings.

Practice: Navigate ten items and one webpage using the keyboard.

Part 24 - Files, Sharing, and Downloads

24.1 Open a Download Safely

What you will learn: Find a downloaded file and verify it before opening.

Before you begin: A known-safe file has been downloaded.

Exactly how to do it

  1. Open the Files app or Downloads area.

  2. Navigate to Downloads.

  3. Listen to the full filename and file type.

  4. Open only if the source and file type are expected.

  5. Use Share only after checking which app/person will receive the file.

What should happen: The correct file opens or is shared intentionally.

If that does not happen: If the file is unexpected, do not open it; delete or verify the source first.

Practice: Locate one known download without opening it immediately.

Part 25 - Device Security and Privacy

  • Use a secure screen lock such as PIN/password plus biometrics when appropriate.

  • Configure lock-screen notifications so private message content is not exposed unnecessarily.

  • Review app permissions for microphone, camera, location, contacts, and files.

  • Do not grant Accessibility service permissions to unknown apps; accessibility services can have extensive control over a device.

  • Use Play Protect and install apps from trusted sources.

  • When using Hide screen, remember the device is still active and can perform actions.

  • Use headphones when TalkBack might speak private content in public.

  • Before sharing the screen in a video meeting, close sensitive apps and notifications.

Part 26 - Manufacturer Differences

  • Pixel devices generally follow Google's Android Accessibility Help most closely.

  • Samsung Galaxy devices may add Samsung-specific settings, One UI navigation, and different default apps.

  • Motorola, OnePlus, Xiaomi, and others can rename settings and change launcher/call-screen layouts.

  • The position of Power and Volume buttons varies by model.

  • Some devices use manufacturer screen readers or accessibility features in addition to TalkBack.

  • When a step in this manual does not match your device, search Settings for the feature name rather than guessing a different gesture.

Part 27 - Troubleshooting

27.1 One-Finger Swipes Scroll Instead of Moving Focus

What you will learn: Check whether TalkBack is on and whether too many fingers are being used.

Before you begin: The device is unlocked.

Exactly how to do it

  1. Confirm TalkBack is speaking.

  2. Try a slow one-finger swipe right.

  3. If the screen scrolls, lift all fingers and retry with exactly one finger.

  4. Open Tutorial and practice if needed.

What should happen: Swipe right moves to the next focused item.

If that does not happen: If TalkBack is off, re-enable it using the configured shortcut.

Practice: Practice five clean one-finger swipes.

27.2 Double-Tap Activates the Wrong Item

What you will learn: Separate focusing from activation.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Swipe until the exact item is announced.

  2. Pause.

  3. Double-tap anywhere on the screen without touching a different item first.

  4. Listen for the result.

What should happen: The focused item activates.

If that does not happen: If another item activates, you changed focus immediately before the double-tap. Slow the sequence down.

Practice: Open and close Settings using swipe-then-double-tap.

27.3 Three-Finger Gestures Do Not Work

What you will learn: Determine whether the device supports multi-finger TalkBack gestures.

Before you begin: TalkBack is on.

Exactly how to do it

  1. Three-finger tap the screen.

  2. If the TalkBack menu opens, multi-finger gestures are supported.

  3. If nothing happens, use swipe down then right to open the TalkBack menu.

  4. Use the one-finger angled reading-control gestures when needed.

What should happen: You know which gesture family your device supports.

If that does not happen: Older/unsupported devices may provide only one-finger TalkBack gestures.

Practice: Test TalkBack menu access both ways.

27.4 You Cannot Type in a Field

What you will learn: Make sure the field is activated and the intended keyboard is active.

Before you begin: Focus an edit field.

Exactly how to do it

  1. Double-tap the field.

  2. Listen for editing/keyboard feedback.

  3. Explore the keyboard by touch.

  4. If the TalkBack braille keyboard is active unintentionally, hide it with a two-finger swipe down or switch keyboards with a three-finger swipe down.

  5. Type one test character.

What should happen: Text appears in the field.

If that does not happen: If no keyboard appears, the control may not be editable or another input method may be selected.

Practice: Enter and exit a text field three times.

27.5 Braille Display Connects but Does Not Type

What you will learn: Check edit activation and braille commands.

Before you begin: The display already shows TalkBack output.

Exactly how to do it

  1. Focus an edit field.

  2. Press a routing key on the field, or press Enter/Dot 8 if the display lacks routing keys.

  3. Try typing.

  4. Open TalkBack settings > Braille display > Braille display commands.

  5. Confirm the input command mapping for the display.

What should happen: Braille input works in the edit field.

If that does not happen: Output working by itself does not prove input/routing are configured. Test all three separately.

Practice: Test output, input, and routing after every new display pairing.

27.6 Speech Is Too Fast or Too Detailed

What you will learn: Adjust one setting at a time.

Before you begin: TalkBack is usable but uncomfortable.

Exactly how to do it

  1. Open TalkBack settings.

  2. Adjust speech rate slightly.

  3. Test for a minute.

  4. If verbosity is the problem, open Verbosity and change only the relevant category.

  5. Restore the previous value if the change is worse.

What should happen: Speech becomes more comfortable without creating new problems.

If that does not happen: Avoid large multi-setting changes that make it hard to identify what caused a problem.

Practice: Adjust one speech setting and restore it.

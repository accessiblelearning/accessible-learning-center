Excel Lesson 1

Excel Basics: Workbooks, Worksheets, and Cells

Excel manual All Excel lessons My progress

Goal

Open Excel, understand the worksheet grid, enter a simple workplace contact list, and save a workbook.

Skills practiced

  • Identify a workbook, worksheet, row, column, cell, and cell address.
  • Move one cell at a time with the Arrow keys.
  • Enter and correct text in cells.
  • Save an Excel workbook as an XLSX file.

Step-by-step instructions

  1. Open Microsoft Excel and create a Blank workbook.
  2. JAWS announces the active cell address and its contents. The first cell is A1.
  3. Type Name in A1, press Tab, type Department in B1, press Tab, and type Extension in C1.
  4. Press Home to return to column A in the current row.
  5. In row 2, enter Jordan Lee, Training, and 4101. Use Tab after each entry.
  6. In row 3, enter Morgan Reed, Technology, and 4102.
  7. In row 4, enter Casey Hall, Employment, and 4103.
  8. Use the Arrow keys to review each cell. Press Insert+Up Arrow to hear the current line or cell information when useful.
  9. Press Ctrl+S. Choose a folder you can locate later.
  10. Save the workbook as Excel-Lesson-1.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Your assignment

Create a three-column employee contact list with the headers Name, Department, and Extension. Include at least five fictional employees.

Save the finished assignment as Excel-Lesson-1.xlsx.

Before submitting

  • Row 1 contains clear column headers.
  • At least five fictional employee records are included.
  • There are no completely blank rows inside the list.
  • The file is saved as Excel-Lesson-1.xlsx.

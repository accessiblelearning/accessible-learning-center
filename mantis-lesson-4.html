Mantis Q40 Lesson 4

Read and Navigate with Braille Commands

Mantis Q40 manualAll Mantis Q40 lessonsMy progress

Goal

Create a command chart for reading and navigation.

Step-by-step instructions

  1. Open a short practice document in the connected computer.
  2. Pan left and right with the documented thumb keys.
  3. Use cursor routing to move to a word.
  4. Navigate by line, paragraph, and heading using the active screen reader.
  5. Verify focus after switching applications.
  6. Record commands that depend on JAWS versus the Mantis.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

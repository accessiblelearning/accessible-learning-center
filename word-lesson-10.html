Microsoft Word Lesson 10

Final Independent Word Assignment

First-time setup and success checks

Lesson goal in plain language: Complete Final Independent Word Assignment.

Prepare before step 1

  1. Open the correct application, website, or device screen and wait for its name to be announced.
  2. Open Microsoft Word manual and review the matching procedure if any command or term is unfamiliar.
  3. Use only fictional, public, disposable, or instructor-provided practice information. Make a copy before changing an important file.
  4. Read all numbered instructions once before performing them so you know the intended final result.

Commands used or referenced

Use the exact keyboard or device commands stated in the numbered instructions.

For a plus-sign command, hold the modifier key, press and release the final key, then release the modifier. For a sequence, press and release each key in order. Stop after every command and listen for the result.

Work and verify

  1. Perform one numbered instruction and stop. Identify the active window, focused control, selected item, cell, slide, message, field, or device area before continuing.
  2. Compare the result with the lesson goal. A sound alone is not enough; verify the name, state, value, location, permission, or content.
  3. If the result is wrong, press Escape once to leave an unexpected menu, identify focus again, and use Undo only when the change is safely reversible.
  4. Save or synchronize at natural stopping points. Confirm the filename and location before closing.
  5. Complete the “Before submitting” checklist from top to bottom. Correct missing items before marking the lesson complete.
  6. Close and reopen the practice item, or return to it from the product’s main screen, to prove you can locate and verify the result independently.

Success standard: Explain what each major command did, show the finished result, and recover from one harmless focus or navigation error without another person naming the next key.

Goal

Demonstrate the Microsoft Word skills you have practiced throughout Lessons 1 through 9.

Your Assignment

Create a one-page document titled My Accessible Technology Skills.

Requirements

  1. Create the document independently.
  2. Use the title My Accessible Technology Skills.
  3. Apply Heading 1 to the title.
  4. Create at least two Heading 2 sections.
  5. Write at least two paragraphs of body text.
  6. Include one bulleted or numbered list containing at least three items.
  7. Include one simple table containing at least three columns and three rows.
  8. Make the first table row a header row.
  9. Include one descriptive hyperlink.
  10. Use at least one example of bold or italic formatting.
  11. Run spelling and grammar review.
  12. Run Accessibility Checker or Accessibility Assistant.
  13. Correct important accessibility issues that Word identifies.
  14. Save the document as Word-Lesson-10-Final.docx.
  15. Create a PDF copy if you are able to do so.

What the Assignment Checker Will Review

  • Document structure
  • Correct use of headings
  • Paragraph content
  • Lists
  • Table structure
  • Meaningful hyperlink text
  • Basic formatting
  • Accessibility
  • Filename
  • Overall organization

Remember

The goal is not perfection. The goal is to demonstrate that you can create and organize a Word document independently. Feedback will identify what you did well and a small number of things to improve next time.

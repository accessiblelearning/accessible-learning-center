Goal

Submit the final BBZ or BRF plus a proofreading checklist.

Step-by-step instructions

  1. Use the braille view to proofread structure and spacing.
  2. Check headings, lists, page numbers, and transcriber notes.
  3. Run any available validation tools.
  4. Save the final BBZ project.
  5. Export a BRF copy using File or the documented export command.
  6. Open the BRF in an approved viewer and spot-check it.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

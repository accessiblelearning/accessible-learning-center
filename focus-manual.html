Identify your Focus model first

This course emphasizes the Focus 40 Blue fifth generation. A fifth-generation Focus has a Menu button centered between braille keys 1 and 4. Older Focus 40 Blue models have different controls, ports, features, and firmware. Never install firmware until the exact model and generation are confirmed.

  • Use the official guide for the assigned device generation.
  • Start JAWS before connecting the Focus to Windows.
  • Save open work before changing connections or settings.
  • Use instructor-provided or fictional files during practice.
  • Never submit passwords, pairing codes, serial numbers, protected books, or private workplace information.

Major controls and features

  • 40 refreshable braille cells: display one line of computer text in braille.
  • Cursor router buttons: move the cursor, activate links, and support text selection.
  • Perkins-style keyboard and BrailleIn: enter text and Windows or JAWS commands.
  • Panning buttons, rocker bars, and NAV rockers: move through text and structured information.
  • USB and Bluetooth: connect to computers and supported mobile devices.
  • Fifth-generation Scratchpad and BRF Book Reader: create notes and read supported files without a computer.

Basic and advanced how-tos

Connect the Focus to JAWS by USB

Keyboard commands: Insert+J opens the JAWS window. Alt+O opens Options, then B opens Braille in common JAWS versions.

  1. Start JAWS and save open work.
  2. Connect the Focus directly with its USB cable and power it on.
  3. Wait for the braille cells to refresh.
  4. Open JAWS Braille settings and confirm Focus is the active display.
  5. Press a Windows key and verify that its result appears in both speech and braille.

You should feel: Text matching the focused Windows control.

If that does not happen: Confirm the cable, power, JAWS driver, and exact Focus generation before changing settings.

Read, pan, and route the cursor

Device commands: The left and right panning buttons move one display width. A cursor router button moves the cursor to its corresponding braille cell.

  1. Open a harmless practice document.
  2. Read the current 40-cell line from left to right.
  3. Press the right panning button once and confirm the next portion appears.
  4. Press the left panning button to return.
  5. Press the cursor router above a known word.
  6. Type one practice character, verify its location, then undo with Ctrl+Z.

If that does not happen: Confirm the active window and editing caret before routing again.

Use Focus keyboard help

Device command: Press Space with T-H chord, dots 1-4-5-6, for Focus keyboard help.

  1. Save work and turn keyboard help on.
  2. Press one unfamiliar Focus control.
  3. Read its description without performing the command.
  4. Exit help before returning to the document.

If that does not happen: With Focus connected to JAWS, press Insert+Space followed by J and search JAWS Command Search for the function.

Switch among saved connections

Device commands: On fifth-generation Focus Blue, Menu+Dot 1 through Menu+Dot 5 selects a Bluetooth connection; Menu+Dot 8 selects USB.

  1. Save work on the currently connected device.
  2. Identify which connection number belongs to the target device.
  3. Press Menu with the assigned dot once.
  4. Wait for the display to refresh and verify the target device’s focused item.
  5. Use Menu+Dot 8 to return to USB when needed.

If that does not happen: Do not repeat rapidly. Confirm pairing and the saved connection number in the Focus Connections menu.

Ten-lesson learning path

  1. Lesson 1: Orientation, Power, and Device Identification — Create a tactile orientation guide naming the major controls and explaining how to identify the device generation.
  2. Lesson 2: Connect by USB and Configure JAWS — Write a USB connection and JAWS verification checklist.
  3. Lesson 3: Pair and Manage Bluetooth Connections — Create a credential-free Bluetooth pairing and connection-switching guide.
  4. Lesson 4: Read, Pan, Route the Cursor, and Select Text — Submit a command chart for panning, navigation, cursor routing, and text selection.
  5. Lesson 5: Type with BrailleIn and Edit Text — Create Focus-Lesson-5.txt or DOCX containing a short corrected workplace note.
  6. Lesson 6: Navigate Windows, File Explorer, and Documents — Create a keyboard-and-braille workflow for finding and reading a workplace file.
  7. Lesson 7: Navigate Webpages, Forms, Lists, and Tables — Document an accessible web-navigation practice session.
  8. Lesson 8: Use Scratchpad, BRF Book Reader, and microSD Safely — Create a local note and a storage-safety checklist; submit only your original note.
  9. Lesson 9: Braille Settings, Study Mode, Cleaning, and Updates — Create a safe settings, cleaning, and firmware checklist.
  10. Lesson 10: Final Focus 40 Blue Workplace Project — Complete an end-to-end Focus 40 Blue workplace task and submit only the original summary.

Safe working routine

  1. Identify the Focus model and generation.
  2. Confirm power, battery, cable, and connection mode.
  3. Confirm the active JAWS braille display and Windows focus.
  4. Practice on a copy and verify the destination before saving or transferring.
  5. Restore reversible settings after practice.
  6. Disconnect, clean, and update only according to the official instructions.

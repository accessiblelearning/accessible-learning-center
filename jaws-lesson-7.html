Screen Readers Lesson 7

Navigate Tables, Lists, and Structured Information

Screen Readers manualAll Screen Readers lessonsMy progress

Choose your screen reader

Complete this lesson with JAWS, Windows Narrator, or NVDA. Use one primary screen reader at a time. Follow the column for your selection whenever commands differ.

Goal

Read relationships in tables and lists without losing row or column context.

Shared practice steps

  1. Open a page containing a simple accessible table.
  2. Move to the table using T in the active web-reading mode.
  3. Read the caption and column headers before the data.
  4. Use the selected screen reader’s table commands to move one cell at a time.
  5. Move out of the table and locate a list.
  6. Read list boundaries, item count when announced, and each item.

Your assignment

Create a table-and-list reading report with the table caption, headers, one data relationship, and list structure.

Use fictional, public, instructor-provided, or redacted information only. Never submit passwords, license information, account codes, or private workplace data.

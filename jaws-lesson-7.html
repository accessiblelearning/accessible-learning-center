JAWS Lesson 7

Tables, Lists, and Structured Information

JAWS manual All JAWS lessons My progress

Goal

Navigate tables and other structured content accurately with JAWS.

Skills practiced

  • Locate tables and lists.
  • Read table cells with row and column context.
  • Move among cells without losing position.
  • Recognize useful headers and identify accessibility problems.

Step-by-step instructions

  1. Open a web page or document containing an accessible data table.
  2. Press T to move to the next table and Shift+T to move to the previous table.
  3. Press Insert+Ctrl+T to open the Tables List when supported.
  4. Inside the table, use Ctrl+Alt+Arrow keys to move among cells.
  5. Press Ctrl+Alt+Num Pad 5 to read the current cell, or use Keyboard Help to find the equivalent laptop-layout command.
  6. Listen for row and column header announcements while moving through the data.
  7. Press L to move to a list and I to move among list items.
  8. Record a small schedule from the table, including two row labels and two column labels.
  9. Identify whether the table had meaningful headers. If headers were not announced, note that as an accessibility problem.
  10. Create JAWS-Lesson-7.txt with the recorded information and a short table-accessibility review.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Your assignment

Submit a structured-content report showing accurate table navigation and an accessibility review.

Save the finished assignment as JAWS-Lesson-7.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • Two row labels and two column labels are recorded.
  • The report explains how cell movement worked.
  • Header announcements are evaluated.
  • The file is named JAWS-Lesson-7.txt.

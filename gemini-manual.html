Google Gemini Manual

Independent self-study guide for Gemini on the web, mobile devices, connected Google apps, and assistive technology.

All manuals Table of contents Website practice procedures Gemini lessons

Web, Mobile, Gemini Live, Files, Gems, Deep Research, Connected Apps, Accessibility, Privacy, and Responsible Use

Purpose: This manual teaches Google Gemini from the beginning. It assumes no prior AI experience and explains exact workflows, expected results, common problems, privacy choices, accessibility techniques, and responsible-use habits.

Reference: This guide reflects current Google Gemini Apps Help as of September 2026. Gemini changes frequently; features can depend on account type, age, country, device, language, subscription, administrator settings, and staged rollout.

Important account distinction: Personal Google Accounts, work/school Google Workspace accounts, and supervised accounts can have different eligibility, retention, privacy, Connected Apps, and administrator controls. This manual marks those differences where they matter.

Accuracy warning: Google states that Gemini Apps can make mistakes and recommends double-checking responses and not relying on Gemini responses for professional advice.

How to Use This Manual

  • Learn ordinary chat first, then files, sources, Gems, Deep Research, Connected Apps, and mobile features.

  • Use a new chat when an old conversation has accumulated irrelevant context.

  • For current or consequential facts, ask Gemini for sources and verify the sources yourself.

  • Do not paste passwords, recovery codes, private keys, or unnecessary confidential information into Gemini.

  • When Gemini uses Gmail, Drive, Calendar, Tasks, or Keep, confirm the exact account and review the source or resulting action.

  • For screen readers, use normal web navigation first: headings, landmarks/regions, buttons, edit fields, and links. Switch browse/focus modes only when needed.

  • Feature availability changes. If a control named in this manual is absent, use Gemini Help for your exact account/device before assuming something is wrong.

Part 1 - What Google Gemini Is

Gemini Apps are Google AI experiences that let you ask questions, create and transform content, work with files and images, conduct research, and—when you choose to connect supported services—work with information from other Google products.

  • Gemini web app: gemini.google.com in a supported browser.

  • Gemini mobile apps: Android and iPhone/iPad experiences.

  • Gemini Live: conversational voice interaction with optional camera/screen sharing in supported mobile contexts.

  • Gems: reusable customized versions of Gemini with instructions and, in some cases, reference files.

  • Deep Research: a research workflow that creates a plan, researches selected sources, and produces a report.

  • Connected Apps: optional links to supported Google and other services.

  • Gemini in Chrome: an integrated browser experience available only to eligible users/devices and subject to rollout.

Mental model: Gemini is an AI assistant, not an authority. It can generate plausible but incorrect information, so important answers still need verification.

Part 2 - Accounts, Sign-In, and Availability

  • Some Gemini web features can be used without signing in in supported locations, but sign-in is required for additional features and saved activity.

  • A personal Google Account can be used subject to age and regional requirements.

  • Work accounts require a qualifying Google Workspace setup and may be controlled by an administrator.

  • School accounts require the institution to enable Gemini Apps; age requirements can apply.

  • The web app currently supports Chrome, Safari, Firefox, Opera, and Microsoft Edge (Google Help may display Edge under its Chromium naming).

  • Feature availability varies by language, country, device, account type, subscription, and rollout.

2.1 Sign In on the Web

What you will learn: Open Gemini with the intended Google Account.

Before you begin: Use a trusted browser.

Exactly how to do it

  1. Open the browser address bar with Ctrl+L (Windows) or Command+L (Mac).
  2. Type gemini.google.com and press Enter.
  3. Find the Sign in button if you are signed out.
  4. Activate Sign in.
  5. Choose or enter the intended Google Account.
  6. Complete any two-step verification.
  7. After Gemini loads, open the account/profile menu and verify the account if the task involves personal or work data.

What should happen: Gemini opens under the intended account.

If that does not happen: If access is denied, check age, administrator, region, browser, and account eligibility rather than repeatedly changing account security settings.

Practice: Sign in, verify the account, then sign out only if safe to do so.

Part 3 - Open and Navigate Gemini on the Web

3.1 Start a Simple Chat

What you will learn: Enter a prompt and read the response.

Before you begin: Gemini is open.

Exactly how to do it

  1. Move to the prompt/edit box near the main chat area.
  2. Type a harmless question such as: Explain cloud storage in three bullet points.
  3. Activate Submit or press Enter when the edit box supports submission.
  4. Wait for generation to finish.
  5. Move into the response using screen-reader reading commands or ordinary browser navigation.
  6. Read any sources, action buttons, or follow-up controls after the response.

What should happen: Gemini produces a response in the conversation.

If that does not happen: If Enter inserts a new line instead of submitting, use the Submit button. If focus is lost, use headings/landmarks or Shift+Tab/Tab to return to the prompt area.

Practice: Ask three low-risk questions.

Web orientation: The Gemini web interface can contain a navigation/sidebar, New chat, recent chats, feature areas such as Gems, and the current conversation. Exact labels and order change over time; use landmarks/headings/buttons rather than memorizing visual coordinates.

Part 4 - Start, Continue, and Manage Chats

4.1 Start a New Chat

What you will learn: Separate unrelated tasks so old context does not affect new work.

Before you begin: A conversation is open.

Exactly how to do it

  1. Find and activate New chat. If the sidebar is collapsed, first open Menu.
  2. Wait for a blank prompt area.
  3. Enter the new task.
  4. Check that previous messages are no longer part of the visible conversation.

What should happen: A fresh conversation starts.

If that does not happen: If New chat is unavailable while signed out, sign in if needed for the feature or reload the app.

Practice: Start one chat for travel ideas and another for a writing task.

4.2 Edit a Prompt

What you will learn: Correct a prompt and regenerate the response.

Before you begin: You are signed in and the prompt is editable.

Exactly how to do it

  1. Move to your most recent prompt.
  2. Find Edit text or the edit action associated with the prompt.
  3. Activate it.
  4. Change the wording.
  5. Activate Update.
  6. Read the regenerated response.

What should happen: Gemini responds to the revised prompt.

If that does not happen: If edit is unavailable, send a follow-up correction or start a new chat.

Practice: Change one prompt from a general request to a specific one.

Other drafts: For some responses, Gemini may offer other drafts. Google notes this is not available for every response, including some responses generated using apps.

Part 5 - Prompting Fundamentals

Task How / Where
Goal State exactly what you want Gemini to produce.
Context Give only the background needed for the task.
Constraints Specify audience, length, tone, exclusions, date range, or format.
Input Provide the text, file, image, or data Gemini should work from.
Verification Ask Gemini to identify uncertainty and provide sources when facts matter.

5.1 Build a Better Prompt

What you will learn: Turn a vague request into a useful one.

Before you begin: Choose a low-risk task.

Exactly how to do it

  1. State the goal.
  2. Add the audience or purpose.
  3. Add important constraints.
  4. Ask for a specific output format.
  5. Ask Gemini to mark uncertainty or cite current sources if factual accuracy matters.

What should happen: The response is more relevant and structured.

If that does not happen: If Gemini still misses the task, ask what assumption it made, then revise the prompt.

Practice: Improve the prompt “Tell me about budgeting” into a specific beginner task.

Part 6 - Models, Reasoning, and Limits

Gemini may let signed-in users choose among available models or reasoning modes. Google changes model names, access levels, and limits over time.

  • A chat uses one selected model; Google notes that switching models in an existing chat can start a new chat.

  • Subscription plans can provide higher limits or access to stronger models/features.

  • More reasoning does not eliminate hallucinations.

  • Use the model selector only when you understand why you need a different model; otherwise the default is usually appropriate.

  • If a task depends on current information, source access matters as much as model capability.

Do not memorize model names: Because model names and plan entitlements change frequently, this manual teaches the model selector concept rather than a fixed 2026 product list.

Part 7 - Verify Responses and Related Sources

7.1 Check a Factual Answer

What you will learn: Confirm that important claims are supported.

Before you begin: Use a claim that can be verified publicly.

Exactly how to do it

  1. Ask Gemini the factual question.
  2. Look for Related sources, source links, or citations associated with the answer.
  3. Open a source in a new tab when practical.
  4. Confirm the source is reputable and current.
  5. Find the passage that supports the claim.
  6. Compare the source with Gemini’s wording.
  7. If the claim is consequential, check a second independent source or primary source.

What should happen: You know whether the claim is supported rather than merely plausible.

If that does not happen: If no source is supplied, search independently. If a source does not support the claim, do not repeat the claim as verified.

Practice: Verify three claims from one response.

Google warning: Google itself tells users to double-check Gemini responses and not rely on them for professional advice.

Part 8 - Upload and Analyze Files

8.1 Upload a File

What you will learn: Ask Gemini about a document or supported file.

Before you begin: Use a non-confidential practice file.

Exactly how to do it

  1. Open a new chat.
  2. Find Add files.
  3. Choose Upload files or Add from Drive when available.
  4. Select the intended file.
  5. Wait until the file is visibly/verbally attached to the prompt.
  6. Ask a specific question such as: Summarize this document in five bullets and list anything you are uncertain about.
  7. Submit the prompt.
  8. Compare the answer with the source file.

What should happen: Gemini uses the uploaded file as context.

If that does not happen: If the file is rejected, check current supported formats/size limits. If the document is sensitive, stop and use an approved environment instead.

Practice: Upload a harmless PDF or DOCX and ask for a summary.

Generated files: Current Gemini Help states that Gemini can also generate supported files from chats, including Google Docs/Sheets and formats such as PDF, DOCX, XLSX, CSV, LaTeX, TXT, RTF, and Markdown, subject to feature availability.

Part 9 - Work with Images and Generated Media

  • You can attach images and ask Gemini to describe, analyze, transform, or reason about them, subject to policy and capability.

  • Image descriptions can be useful for accessibility but should not be treated as guaranteed identification of people, medication, hazards, colors, signs, or other safety-critical details.

  • Gemini Apps can generate and edit images where the feature is available.

  • Google provides a separate verification feature for certain AI-generated images, video, and audio; current limits and supported media vary.

9.1 Ask About an Image Accessibly

What you will learn: Use Gemini as an image-description aid while keeping human verification for important details.

Before you begin: Use a non-sensitive image.

Exactly how to do it

  1. Choose Add files.
  2. Upload one image.
  3. Ask for a neutral description before asking interpretive questions.
  4. Ask Gemini to separate visible facts from inferences.
  5. Ask follow-up questions about layout, text, or objects.
  6. Verify any safety-critical or identity-related conclusion through another method.

What should happen: You receive a structured text description.

If that does not happen: If the description conflicts with known facts, do not keep prompting until you get the desired answer; treat the image interpretation as uncertain.

Practice: Describe one simple image and identify which statements are observations versus inferences.

Part 10 - Gemini Live

Gemini Live provides a spoken conversational mode on supported mobile devices. Depending on device and feature availability, you can converse by voice and may choose to share your camera or screen.

10.1 Start a Gemini Live Conversation

What you will learn: Use hands-free conversational interaction.

Before you begin: Gemini mobile app is installed and microphone permission is appropriate.

Exactly how to do it

  1. Open the Gemini app.
  2. Find and activate Live.
  3. Allow microphone access if you intentionally want to use voice.
  4. Speak a simple question.
  5. Listen to Gemini’s spoken answer.
  6. Ask a follow-up naturally.
  7. End Live when finished.

What should happen: The conversation continues by voice without retyping each message.

If that does not happen: If Gemini cannot hear you, check microphone permission, audio routing, and whether Live is listening.

Practice: Use Live for a low-risk brainstorming task.

Privacy: If Keep Activity is on, Google states that Gemini Live transcripts and data you choose to share can appear in Gemini Apps Activity. Separate controls govern whether audio and Live recordings are used to improve Google services; Google states that improvement setting is off by default.

Part 11 - Gems

Gems are customized versions of Gemini that reuse instructions for recurring tasks. Google provides premade Gems and lets eligible users create/customize Gems.

11.1 Use a Premade Gem

What you will learn: Try specialized instructions without recreating them each time.

Before you begin: You are signed in and Gems are available.

Exactly how to do it

  1. Open the Gemini sidebar/menu.
  2. Choose Gems. If Gems is not shown directly, check Settings and help > Gems.
  3. Under premade Gems, choose one appropriate for a harmless task.
  4. Enter a prompt.
  5. Review how the Gem’s standing instructions affect the response.

What should happen: The Gem responds according to its specialized instructions.

If that does not happen: If Gems is missing, the feature may be unavailable for the account/device/age/region.

Practice: Compare the same prompt in ordinary Gemini and a premade Gem.

11.2 Create a Custom Gem

What you will learn: Save repeatable instructions.

Before you begin: Gem creation is available for your account.

Exactly how to do it

  1. Open Gems and choose the create/customize option.
  2. Give the Gem a descriptive name.
  3. Write instructions describing its role, audience, style, boundaries, and required checks.
  4. Optionally add non-sensitive knowledge files if supported.
  5. Save the Gem.
  6. Start a chat with it and test a typical prompt.
  7. Edit the Gem if it behaves incorrectly.

What should happen: The same instructions are applied to future chats with that Gem.

If that does not happen: Do not put passwords, secrets, or unnecessary private data into Gem instructions/knowledge.

Practice: Create a “Plain Language Editor” Gem for non-sensitive text.

Part 12 - Deep Research

Deep Research creates a research plan, searches selected sources, and produces a longer report. Google currently requires users to be signed in and at least 18. Usage limits vary by plan.

12.1 Run a Deep Research Report

What you will learn: Research a topic with a visible plan and sources.

Before you begin: You meet account/age requirements.

Exactly how to do it

  1. Open gemini.google.com.
  2. Open Add files and choose Deep Research.
  3. Optionally add files.
  4. Open Sources and choose the sources to include. Google Search is included by default unless you deselect it.
  5. Enter the research question.
  6. Submit the prompt.
  7. Review the proposed research plan.
  8. Edit the plan if needed.
  9. Activate Start research.
  10. When the report is ready, open it and review the citations/sources.

What should happen: Gemini produces a structured research report grounded in the selected sources.

If that does not happen: If Gmail/Drive sources are unavailable, check whether Google Workspace is connected and whether the account permits it. If a source is weak, verify independently.

Practice: Research a low-risk topic and verify three citations.

Source controls: Current Google Help says Deep Research can use Google Search by default and, when connected/eligible, can add sources such as Gmail, Drive, uploaded files, and NotebookLM notebooks.

Part 13 - Canvas, Notebooks, and Generated Files

  • Canvas in Gemini Apps can be used to create and refine documents, code, apps, and other structured work where available.

  • Gemini Apps Help currently also lists notebooks as a project-organization feature. Availability can depend on account and rollout.

  • Generated files can be downloaded or exported to Drive in supported formats.

  • Before exporting, read the complete generated content and verify factual claims, formulas, citations, and accessibility.

13.1 Export a Useful Response

What you will learn: Move reviewed Gemini output into a normal file.

Before you begin: Use non-sensitive generated content.

Exactly how to do it

  1. Ask Gemini to produce the desired content and format.
  2. Review and edit the content in chat/Canvas if available.
  3. Choose the available export/download option.
  4. Open the resulting file in its native application.
  5. Check headings, tables, formulas, links, and accessibility.
  6. Save the reviewed final version.

What should happen: You have a normal document/file rather than relying only on chat history.

If that does not happen: If formatting breaks during export, copy the content into the destination app and format it there.

Practice: Export one short document and inspect it in Google Docs or Word.

Part 14 - Connected Apps

Connected Apps let Gemini work with supported Google and third-party services. Availability depends on account, region, settings, and administrator policies.

14.1 Review Connected Apps

What you will learn: Know what Gemini is allowed to access.

Before you begin: You are signed in.

Exactly how to do it

  1. Open Settings and help.
  2. Open Connected Apps.
  3. Review which services are connected.
  4. Read the permission/availability information for any service you do not recognize.
  5. Disconnect a service only if you intentionally want Gemini to stop using it.

What should happen: You understand which services Gemini may use in supported prompts.

If that does not happen: If a connection is controlled by work/school policy, contact the administrator rather than trying to bypass it.

Practice: Review the list without changing it.

Least access: Connect only services you intend to use. A connected service can increase convenience, but it also broadens the information Gemini can draw on for your requests.

Part 15 - Gmail, Drive, Docs, Calendar, Tasks, and Keep

Google’s current Workspace connection can help Gemini find/summarize information in Gmail, Docs, and Drive; create or retrieve Calendar events, Tasks, Keep notes/lists, and related productivity information, subject to account settings and feature availability.

15.1 Ask Gemini About Google Workspace Data

What you will learn: Retrieve information while checking the source.

Before you begin: Use the same Google Account that has the Workspace information and make sure the Workspace app is connected.

Exactly how to do it

  1. Start a new chat.
  2. Ask for the service explicitly, such as: Find the latest email from [known sender] about [topic].
  3. You can type @ and select a supported service when the interface offers it.
  4. Read Gemini’s response.
  5. Open/review the listed source after the response.
  6. Confirm the date and content against the actual Gmail/Drive/Calendar item before acting.

What should happen: Gemini returns information based on connected Workspace data and lists sources where supported.

If that does not happen: Google warns that Gemini can hallucinate or use older information; if the answer matters, always open the source item.

Practice: Ask for a harmless recent email or calendar fact and verify it in the source app.

Current requirement: Google says Keep Activity must be on for personal-account Google Workspace connection in Gemini Apps. Work/school availability also depends on administrator controls and Workspace settings.

Current limitations: Google documents limits including inability, in this connection workflow, to access some comments/images in Docs or Gmail, access standalone pictures/videos in Drive, manage Drive folders, or count Drive/Gmail items/storage in the ways users may expect.

Part 16 - Gemini in Chrome

Gemini in Chrome is a browser-integrated Gemini experience being rolled out to eligible users. It can use content from the current tab and, on computers, can optionally use multiple shared tabs.

Task How / Where
Open/close Gemini in Chrome - Windows Alt+G
Switch between tab and Gemini - Windows Alt+Shift+G
Selection mode - Windows Ctrl+Alt+G
Open/close - Mac Control+G
Switch tab/Gemini - Mac Control+Command+G

Shortcut caveat: Google lets users customize these shortcuts. Treat the table as the current defaults, not immutable commands.

Privacy: Gemini in Chrome can use current tab content when you invoke it. Review connected-app and Chrome Gemini settings if you do not want specific content included.

Part 17 - Android Gemini App

  • Gemini can function as the Gemini mobile app and, on eligible Android configurations, as a digital-assistant experience.

  • You can type, speak, attach images/files, use Live, and invoke Gemini over supported screens/apps.

  • Screen actions can send information from the current screen/file/page to Gemini; Google notes that some actions auto-submit content unless you disable auto-submit.

  • Connected Apps can enable calls, messages, smart-home controls, calendar/task actions, and other supported functions, depending on region/device/account.

17.1 Ask About the Current Screen

What you will learn: Use screen context deliberately rather than sharing it accidentally.

Before you begin: Use a non-sensitive screen.

Exactly how to do it

  1. Open Gemini over the current app/page using the supported Android invocation method.
  2. Review the suggestion chips or Ask about option.
  3. Before activating a screen action, decide whether the displayed content is safe to upload/share with Gemini.
  4. Use Ask about for a deliberate question.
  5. If you do not want actions to auto-submit screen content, press and hold a suggestion and turn off auto-submit when the control is available.

What should happen: Gemini responds using the selected screen context.

If that does not happen: If the screen contains passwords, messages, health, financial, or work data you should not share, cancel the action and ask without screen context.

Practice: Practice on a public webpage.

Part 18 - iPhone and iPad Gemini App

  • The Gemini iOS app supports text, voice, images, and camera-based interaction on eligible devices and accounts.

  • Some features can be available without sign-in, while saved activity and additional features require a Google Account.

  • Use VoiceOver standard navigation: swipe right/left through controls, double-tap to activate, and use the rotor for text/navigation when useful.

  • Feature parity with Android is not guaranteed; Android-only assistant/system integrations may not exist on iPhone/iPad.

18.1 Start a VoiceOver-Friendly Chat

What you will learn: Use Gemini without relying on visual location.

Before you begin: VoiceOver is on and Gemini is installed.

Exactly how to do it

  1. Open Gemini.
  2. Swipe right until the prompt/edit field is announced.
  3. Double-tap to edit.
  4. Type or dictate the prompt.
  5. Move to Submit and double-tap.
  6. Use VoiceOver heading/link/control navigation to review the response and any sources.
  7. Return to the edit field for a follow-up.

What should happen: You can conduct the conversation entirely with VoiceOver.

If that does not happen: If focus becomes trapped in a generated object or media area, use the rotor, headings, or return to the top/navigation controls and re-enter the conversation.

Practice: Complete a three-turn chat using only VoiceOver gestures.

Part 19 - Screen Readers and Braille

Gemini’s web interface is a dynamic web application. The most reliable strategy is to combine browser/screen-reader structural navigation with ordinary Tab/Shift+Tab control navigation.

19.1 JAWS

  • Use Chrome or another supported browser. Browse/Virtual Cursor is useful for reading responses and headings; Forms Mode/direct focus is useful in the prompt box.

  • Use H/Shift+H for headings, B for buttons, E for edit fields, and Tab for interactive controls where appropriate.

  • If a Gemini shortcut conflicts with JAWS, use the visible control or JAWS command-help rather than guessing.

19.2 NVDA

  • Browse Mode is useful for reading responses; Focus Mode is useful in the prompt editor and app-like controls.

  • Use H for headings, B for buttons, E for edit fields, K for links, and NVDA+Space to switch Browse/Focus Mode as needed.

19.3 Narrator

  • Use Scan Mode for reading web content and Narrator+Space to toggle Scan Mode when direct app interaction is needed.

  • Use Narrator navigation commands or Tab/Shift+Tab to move among controls.

19.4 VoiceOver on Mac

  • Use VO+Right/Left Arrow through controls, VO+Command+H through headings, and VoiceOver interaction commands where grouped web content requires it.

  • Quick Nav can help with reading but may need to be adjusted when editing or using app-like controls.

19.5 Braille Displays

  • Braille works through the active screen reader rather than through a separate Gemini braille mode.

  • Test the prompt edit field, response text, links/sources, and routing keys.

  • Long generated responses can be easier to navigate with headings requested in the prompt.

  • Ask Gemini to avoid decorative emoji/symbols if they create excessive braille/speech clutter.

  • For tables that are hard to navigate, ask Gemini to convert the information to a list.

Part 20 - Gemini Apps Activity, Keep Activity, and Privacy

For personal accounts, Google provides Gemini Apps Activity controls. When Keep Activity is on, Gemini Apps activity is stored in the Google Account and can be reviewed/deleted. Google states that even when Keep Activity is off, conversations can still be saved for up to 72 hours to provide the service and process feedback, but they do not appear in Gemini Apps Activity.

20.1 Review Gemini Apps Activity

What you will learn: See what your account has stored.

Before you begin: Use a personal Google Account.

Exactly how to do it

  1. Open gemini.google.com.
  2. Open Settings and help.
  3. Choose Activity.
  4. Review recent Gemini activity.
  5. Open an item’s details if you need to understand associated audio, screen-sharing, video, files, or other data.
  6. Delete selected activity or change Keep Activity only if you understand the effect.

What should happen: You can see and manage stored Gemini Apps activity.

If that does not happen: Work/school accounts can have administrator-controlled retention and may not expose the same controls.

Practice: Review activity without deleting it.

Live data: Google states that when Keep Activity is on, Live transcripts and media you choose to share can be saved in Gemini Apps Activity. A separate setting controls whether audio/Live recordings may be used to improve Google services, and Google states this improvement setting is off by default.

Privacy habit: Do not use privacy settings as a substitute for data minimization. Avoid sending information Gemini does not need.

Part 21 - Work and School Accounts

  • Work/school access depends on Google Workspace edition, licensing, age, and administrator configuration.

  • Administrators can control access to Gemini Apps, Connected Apps, and retention-related settings.

  • Use the organization-approved account for organizational data; do not move private work/school data into a personal Gemini account to bypass restrictions.

  • Before using Gemini for confidential work, review the organization’s AI/data policy and the Workspace protections that apply to that account.

  • Features available to personal Google Accounts can be unavailable or configured differently for work/school accounts.

Rule: If an administrator has disabled a feature, do not try to bypass the control. Use the approved workflow or ask the organization for an accessible alternative.

Part 22 - Responsible and Safe Use

  • Verify important facts, citations, calculations, legal/policy statements, medical/financial information, and current product instructions.

  • Do not treat an AI-generated source list as verified until you open the sources.

  • Protect confidential and personal information.

  • Use human review for consequential decisions affecting another person.

  • Do not use Gemini to impersonate someone, mislead people about synthetic media, or bypass security controls.

  • When Gemini can take actions through Connected Apps, confirm the recipient, date/time, content, and target before allowing the action.

  • For accessibility descriptions, distinguish observation from inference and verify safety-critical details.

22.1 Use a Responsible-Use Check Before Acting

What you will learn: Decide whether a Gemini answer is safe to use.

Before you begin: The output could affect money, school, work, health, safety, privacy, or another person.

Exactly how to do it

  1. Identify the consequence if the answer is wrong.
  2. Identify any sensitive data used in the prompt.
  3. List the factual claims that matter.
  4. Verify those claims with current trustworthy sources.
  5. Check the applicable workplace/school/platform policy.
  6. Keep a human responsible for the final action.
  7. Only then use or share the result.

What should happen: Gemini is treated as assistance rather than authority.

If that does not happen: If verification is impossible and the stakes are high, do not act from the Gemini output alone.

Practice: Apply the check to one low-risk and one hypothetical high-risk task.

Part 23 - Troubleshooting

23.1 Gemini Gives an Incorrect or Invented Answer

What you will learn: Shift from generation to evidence.

Before you begin: You suspect a factual error.

Exactly how to do it

  1. Ask Gemini to identify the specific claims and sources.
  2. Open the sources.
  3. Check current primary/official sources independently.
  4. Correct the prompt or provide authoritative source material.
  5. Remove unsupported claims from anything you plan to use.

What should happen: You determine what is supported.

If that does not happen: Do not keep regenerating until Gemini happens to agree with you. Verification is external evidence, not repetition.

Practice: Correct one deliberately testable error.

23.2 Gemini Cannot Find Gmail or Drive Information

What you will learn: Check connection, account, settings, and source wording.

Before you begin: You expected Workspace access.

Exactly how to do it

  1. Verify you are signed into the same Google Account that owns the information.
  2. Open Connected Apps and confirm Google Workspace is connected.
  3. For personal accounts, verify Keep Activity is on if the connection requires it.
  4. Check Gmail smart-features/personalization requirements when applicable.
  5. Ask explicitly for Gmail, Drive, Docs, Calendar, Tasks, or Keep and include distinctive keywords.
  6. Open the resulting source to verify it.

What should happen: Gemini either finds the item or the missing prerequisite becomes clear.

If that does not happen: Do not paste a confidential document URL/content into a personal account simply to bypass an organizational control.

Practice: Locate one harmless source item.

23.3 A Feature Is Missing

What you will learn: Determine whether the issue is eligibility or navigation.

Before you begin: A tutorial names a feature you cannot find.

Exactly how to do it

  1. Open Gemini Help for the feature.
  2. Check age, country, language, device, plan, account type, and administrator requirements.
  3. Check whether the feature is web-only or mobile-only.
  4. Check whether Google describes it as a gradual rollout.
  5. Return to Gemini and search Settings/sidebar only after confirming eligibility.

What should happen: You distinguish “not available” from “I cannot find it.”

If that does not happen: Do not change account security or payment settings blindly to chase a feature.

Practice: Check availability requirements for Deep Research or Gemini in Chrome.

23.4 Screen Reader Focus Is Lost

What you will learn: Rebuild web-app location without refreshing unnecessarily.

Before you begin: Gemini is still open.

Exactly how to do it

  1. Press Escape to close a menu/dialog if one is open.
  2. Use the screen reader’s heading/landmark navigation to locate the main conversation or New chat.
  3. Use E/edit-field navigation or Tab/Shift+Tab to return to the prompt box.
  4. If a generated table/object is difficult, ask Gemini to restate it as headings and lists.
  5. Refresh the page only if ordinary focus recovery fails.

What should happen: You return to a predictable control.

If that does not happen: If the issue is repeatable, try another Google-supported browser and report accessibility feedback to Google.

Practice: Recover focus after opening the sidebar and a source link.

23.5 Gemini Uses an Old Email or Source

What you will learn: Force date/source verification.

Before you begin: The answer may be based on stale connected data.

Exactly how to do it

  1. Ask Gemini for the exact source item and date.
  2. Open that source.
  3. Check for newer messages/files/events.
  4. Rephrase the prompt to request the most recent item after a specific date.
  5. Verify the final answer in the source app.

What should happen: The latest source is distinguished from older material.

If that does not happen: Google explicitly warns that connected Workspace responses can be outdated or hallucinated; never assume “latest” without checking.

Practice: Compare two dated source items.

Basic procedure

1. Open Gemini and Navigate the Chat Interface

What you will learn: Identify the prompt field, send control, new-chat control, response area, and account controls.

Before you begin: Use a free or approved AI service and only fictional or public information. Do not enter private workplace, client, medical, financial, or account information.

Exactly how to do it

  1. Open the Google Gemini manual and review the prompting, verification, privacy, and screen-reader sections.
  2. Open an available AI tool in a regular browser tab. If an account or feature is unavailable, study the sample prompt and write the expected process instead.
  3. Navigate by headings and form controls. Find the prompt edit field and confirm its label before typing.
  4. Use this practice prompt or adapt it without adding private information:
    Act as an accessible workplace skills coach. Help me identify the prompt field, send control, new-chat control, response area, and account controls. Use fictional or public information only. Organize the response with descriptive headings and numbered steps. Identify anything I must verify.
  5. Read the complete response by heading, paragraph, list item, and link. Do not assume the first answer is correct.
  6. Send at least one follow-up prompt that improves clarity, accuracy, accessibility, or completeness.
  7. Verify important claims using the original source or another authoritative source. Record unsupported statements and corrections.
  8. Edit the final result in your own words. Remove generic, inaccurate, biased, or unnecessary content.
  9. Create a short process note naming the tool, prompts used, facts checked, changes made, and remaining uncertainty.
  10. Save the assignment as gemini-Lesson-1.txt.

Screen-reader help: JAWS and NVDA users can press H for headings, B for buttons, and E for edit fields in browse mode. Narrator users can navigate with Scan Mode. Press Tab and Shift+Tab for interactive controls. Because AI interfaces change frequently, listen to each control’s current accessible name.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Confirm focus is in the intended edit field or control. Review the page by headings and buttons, shorten the request, and never solve an interface problem by entering private information or starting a paid trial.

Practice: Identify the prompt field, send control, new-chat control, response area, and account controls.

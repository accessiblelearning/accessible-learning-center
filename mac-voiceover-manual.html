First-time keyboard guide

Use this short routine before following the VoiceOver Manual for Mac procedures. It explains exactly how the keyboard directions in this manual work.

Press a single key

  1. Find the named key without pressing it if possible.
  2. Press and release the key one time. Do not hold it unless the step specifically says to hold it.
  3. Stop and listen to the full screen-reader announcement before pressing another key.

Press a keyboard combination

  1. When a command contains a plus sign, such as Command+S, hold down the first key.
  2. While continuing to hold the first key, press and release the final key once.
  3. Release the first key. The plus sign is not a key and should not be pressed.
  4. Listen for the expected result described in the procedure. If nothing changes, verify that the correct application or webpage has focus and try the command once more.

Press a sequence of keys

  1. When keys are separated by commas or the word “then,” press and release them in order instead of holding them together.
  2. After each key, listen for a menu, tab, control, or new screen before continuing.
  3. If the announcement does not match the step, press Escape once to close the current menu or dialog and restart that procedure.

Know which navigation key to try

  • Tab and Shift+Tab: move forward and backward among buttons, links, fields, and other controls.
  • Arrow keys: move inside menus, lists, groups of choices, text, and many screen-reader reading views.
  • Return (also called Enter): confirms many dialogs. In a Finder file list, Return starts renaming; use Command+O to open a selected file. VO+Space activates the control under the VoiceOver cursor.
  • Space: activates many buttons and checks or clears checkboxes. In a text field, Space types a space.
  • Escape: cancels or closes the current menu, list, or dialog without intentionally accepting a change.

Verify before moving on

  1. Listen for the window, page, or application name so you know where focus is.
  2. Perform only one numbered step.
  3. Compare what the screen reader announces with the “What should happen” information in the procedure.
  4. If the result is wrong, stop. Use the procedure’s recovery directions, Escape to cancel, or Command+Z to undo when that command is supported.
  5. Continue only after you can identify the result. Save completed work with Command+S whenever the application supports saving.

Your first Mac session

  1. Follow Turn VoiceOver on. If VoiceOver is already talking, leave it on.
  2. Practice holding Control and Option while pressing an arrow key. Release all keys after each command.
  3. Open Keyboard Help with VO+K. Identify three commands and press Escape to leave help.
  4. Use Spotlight to open TextEdit, then complete Create, save, and reopen a practice note.
  5. Try the Mac VoiceOver command exercises. Afterwards, return to your note and perform each action on the real Mac.

Success check: You can find your note, explain how to enter and leave a group, and recover from a wrong menu with Escape.

Apple VoiceOver User Guide

Purpose: This manual is written directly to the person learning VoiceOver. It explains exactly what to press, what should happen, and how to recover when the result is different.

VO: VO means the VoiceOver modifier. By default, use Control+Option together. Current default settings also allow Caps Lock. A customized Mac may enable only one choice; this manual spells out Control+Option so you can follow it consistently.

Function keys: Apple notes that VoiceOver commands using F1–F12 require Fn with the default function-key behavior. If your keyboard is set to use standard function keys, omit Fn where appropriate. Option may be labeled Alt; Command is a separate key and is not the Windows Control key.

Build a command while keeping VoiceOver running

Before you begin: Open one topic. The builder also works on a Windows keyboard or touch device. It checks your answer without controlling a real Mac.

  1. Choose Start Command Practice. Read or listen to the task and its command.
  2. Move to the VoiceOver modifier list. Choose Control+Option (VO), Caps Lock (VO alternative), or No VoiceOver modifier. Choose Caps Lock only as a VO modifier, not as a capital-letter setting.
  3. Use the additional-key checkboxes for Shift, Command, or Fn only when the command calls for them. For example, VO+Shift+Down Arrow needs VO and Shift.
  4. Choose the final key. In that example, choose Down Arrow.
  5. Activate Check command. A correct answer advances automatically. An incorrect answer gives feedback and lets you adjust the same controls.
  6. Use Repeat instructions whenever needed. At the end, review your attempts or practice missed commands. Use the visible Back link to return to topics.

What should happen: The page announces feedback and moves to the next exercise. Results describe the commands practiced here; they do not certify that a real Mac action occurred.

Optional practice with the actual key combination

  1. Open “Practice by pressing the keys,” then activate “Focus keyboard practice area.”
  2. For VO commands in this area, hold Control and Option and add the other named keys. A Mac may send a command to VoiceOver before the browser can receive it.
  3. If needed, press VO+Tab first, release the keys, then enter the next VoiceOver combination. This tells VoiceOver to ignore that next combination; it does not perform the real VoiceOver action.
  4. If the page still does not receive the command, Tab to the builder and complete the exercise there. Keep your screen reader running. No response is not counted as a wrong attempt.

VoiceOver on/off and VoiceOver Utility exercises use the builder only, so answering does not turn speech off or move to another application. For a real-world check, follow the relevant procedure in this manual on your Mac outside the simulator.

Part 1 - What VoiceOver Is

VoiceOver is the screen reader built into macOS. It speaks and can display in braille the item currently selected by the VoiceOver cursor. You can control the Mac with keyboard commands, trackpad gestures, or a connected braille display.

  • VoiceOver cursor: the item VoiceOver is currently describing.

  • Keyboard focus: the control receiving keyboard input.

  • Interaction: entering a group, toolbar, table, web area, or other container so you can move through its contents.

  • Activation: performing the action of the selected control.

  • Rotor: a navigation tool that lets you choose categories such as headings, links, or form controls.

  • Item Chooser: a searchable list of items available in the current context.

Part 2 - Turn VoiceOver On and Off

2.1 Turn VoiceOver On

What you will learn: Start VoiceOver.

Before you begin: Be at the Mac keyboard.

Exactly how to do it

  1. Hold Command.

  2. Press F5 once.

  3. Release both keys.

  4. If your Mac requires Fn for function keys, try Command+Fn+F5.

  5. Listen for VoiceOver speech.

What should happen: VoiceOver announces that it is on and begins speaking the focused item.

If that does not happen: If nothing happens, open System Settings > Accessibility > VoiceOver and turn VoiceOver on there.

Practice: Start VoiceOver if it is off and identify the spoken control. Before practicing the off/on toggle, locate Command and F5 so you can restore speech with the same shortcut.

Task Command
Turn VoiceOver on/off Command+F5
Alternative on Touch ID Mac Hold Command and quickly press Touch ID three times

Part 3 - VoiceOver Modifier and Keyboard Help

3.1 Learn the VO Modifier

What you will learn: Use VoiceOver commands correctly.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Place one finger on Control and one on Option.

  2. Hold both keys together.

  3. While holding them, press Right Arrow once.

  4. Release all keys.

  5. Repeat using Left Arrow.

What should happen: VoiceOver moves to the next or previous item.

If that does not happen: If nothing changes, make sure both Control and Option were held while the arrow key was pressed.

Practice: Move forward five items and backward five items.

3.2 Use Keyboard Help

What you will learn: Safely learn what keys and commands do.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Press VO+K.

  2. Press a key or VoiceOver command you want to identify.

  3. Listen to VoiceOver describe it.

  4. Try several commands.

  5. Press Escape to leave Keyboard Help.

What should happen: VoiceOver identifies commands without carrying them out normally.

If that does not happen: If the command performs an action instead, Keyboard Help may not have opened; press VO+K again.

Practice: Identify VO+Space, VO+Right Arrow, VO+Left Arrow, and VO+Shift+Down Arrow.

Part 4 - Move Through the Mac Interface

Task Command
Next item VO+Right Arrow
Previous item VO+Left Arrow
Read from current position VO+A
Read a webpage from its beginning to the current position VO+B
Pause/resume speech Control

4.1 Move One Item at a Time

What you will learn: Navigate without using a mouse.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Press VO+Right Arrow once.

  2. Stop and listen to the item name and type.

  3. Press VO+Right Arrow again.

  4. Press VO+Left Arrow once and confirm you returned.

  5. Continue one item at a time.

What should happen: VoiceOver describes a different item after each move.

If that does not happen: If movement seems stuck, you may be inside a group or control. Press VO+Shift+Up Arrow to move outward, then try again.

Practice: Explore ten items on the current screen without activating them.

Part 5 - Interact with Groups

Task Command
Interact with group VO+Shift+Down Arrow
Stop interacting VO+Shift+Up Arrow

5.1 Enter and Leave a Group

What you will learn: Reach controls that are inside toolbars, tables, web areas, and other containers.

Before you begin: VoiceOver is focused on a group or container.

Exactly how to do it

  1. Listen for VoiceOver to announce a group, toolbar, table, or similar container.

  2. Press VO+Shift+Down Arrow.

  3. Press VO+Right Arrow to move through items inside it.

  4. When finished, press VO+Shift+Up Arrow.

  5. Continue VO+Right Arrow at the outer level.

What should happen: You can move inside the group and then return to its parent level.

If that does not happen: If VoiceOver skips controls you expect to be inside a group, interact with it. If you feel trapped, press VO+Shift+Up Arrow more than once.

Practice: Enter a toolbar, inspect three items, then leave it.

Part 6 - Activate Controls

Task Command
Activate selected control VO+Space

6.1 Activate a Button or Link

What you will learn: Perform the action of the selected item.

Before you begin: VoiceOver is focused on the desired control.

Exactly how to do it

  1. Use VO+Right/Left Arrow until VoiceOver announces the exact button, link, checkbox, or other control.

  2. Stop and confirm the name.

  3. Press VO+Space.

  4. Listen for what changed before pressing another key.

What should happen: The button activates, link opens, checkbox toggles, or control performs its action.

If that does not happen: If the wrong action occurs, you activated the wrong item. Return and confirm the control name before pressing VO+Space.

Practice: Find a harmless button and activate it deliberately.

Part 7 - Desktop, Dock, and Menu Bar

Task Command
Move to Dock VO+D
Move to menu bar VO+M

7.1 Open an App from the Dock

What you will learn: Use the Dock without a mouse.

Before you begin: VoiceOver is on.

Exactly how to do it

  1. Press VO+D.

  2. Use VO+Right/Left Arrow through Dock items.

  3. Stop when the desired app is announced.

  4. Press VO+Space.

What should happen: The application opens or comes to the front.

If that does not happen: If the Dock does not appear, make sure VoiceOver is active and try VO+D again.

Practice: Open Finder or another safe app from the Dock.

7.2 Use the Menu Bar

What you will learn: Open menus and choose commands.

Before you begin: An app is active.

Exactly how to do it

  1. Press VO+M to move to the menu bar.

  2. Press VO+Left Arrow or VO+Right Arrow until you hear the desired menu. To find the Apple menu, move left to it. In the menu bar, typing a menu’s first letter, such as H for Help, can also select it.

  3. Open the desired menu with VO+Space.

  4. Use VO+Down Arrow or VO+Up Arrow through menu items. VO+Right Arrow opens a submenu; VO+Left Arrow returns from it.

  5. Press Enter/VO+Space on the command.

  6. Press Escape to close without choosing.

What should happen: The selected menu command runs.

If that does not happen: If focus remains inside the application, press VO+M again and listen for a menu name. VO+Shift+M opens the current item’s shortcut menu, not the Apple menu.

Practice: Open the Apple menu and close it with Escape.

Part 8 - Finder and Spotlight

8.1 Open Spotlight

What you will learn: Find an app, file, or setting quickly.

Before you begin: Be anywhere in macOS.

Exactly how to do it

  1. Press Command+Space.

  2. Type a search term such as TextEdit.

  3. Use Up/Down Arrow or VoiceOver navigation through results.

  4. Press Return on the desired result.

What should happen: The selected app/file/result opens.

If that does not happen: If Spotlight does not open, check whether another app has reassigned Command+Space.

Practice: Open TextEdit with Spotlight.

8.2 Navigate Finder

What you will learn: Browse files and folders.

Before you begin: Finder is open.

Exactly how to do it

  1. Use VO+Right/Left Arrow through Finder controls.

  2. Interact with the file list/table when announced using VO+Shift+Down Arrow.

  3. Use arrow keys or VoiceOver navigation through items.

  4. Press Command+O to open the selected file or folder. Command+Down Arrow is another Finder open command. Return starts renaming a selected file; if that happens accidentally, press Escape.

  5. Use VO+Shift+Up Arrow to leave the file list.

What should happen: You can select and open files/folders.

If that does not happen: If arrow keys do not move through files, make sure focus is inside the file list.

Practice: Open a folder and return to its parent.

8.3 Create, save, and reopen a practice note

What you will learn: Open an app, create a document, name it, choose a folder, and find it again.

Before you begin: VoiceOver is on. Use a new practice note, and keep any existing documents open without changing them.

  1. Press Command+Space, type TextEdit, choose the TextEdit application result with Down Arrow if necessary, and press Return.
  2. Press Command+N for a new document. If a file chooser appears first, find New Document with VO navigation and activate it with VO+Space.
  3. Find the document’s text area with VO+Right Arrow. Interact with it using VO+Shift+Down Arrow if needed. Confirm Quick Nav is not intercepting typing.
  4. Type: “This is my VoiceOver practice note.” Press Return and type a second sentence. Use VO+L to hear the current line.
  5. Press Command+S. Find the Save As name field using VO navigation or VO+I Item Chooser. Select the existing filename with Command+A and type “VoiceOver Practice”. Let TextEdit keep the extension appropriate to the document format.
  6. While in the save dialog, press Command+Shift+G, type ~/Documents, and press Return to choose your Documents folder. If that folder is unavailable, cancel the folder field and choose an available folder from the save dialog.
  7. Navigate to the Save button and activate it with VO+Space. Wait until the save dialog closes. If asked to replace an existing file, cancel and choose a different practice filename.
  8. Press VO+D, move to Finder, and activate it. In Finder, press Command+Shift+G, type ~/Documents, and press Return. Use Command+2 for list view if desired.
  9. Navigate to the file list and interact with it. Move down the rows with VO+Down Arrow until “VoiceOver Practice” is selected. Press Command+O to open it, then read your two sentences.

What should happen: The reopened document contains the same text in the chosen folder.

If that does not happen: Check the folder and filename. Return in Finder renames an item; press Escape to cancel that and use Command+O to open. If TextEdit is still showing a save dialog, complete or cancel that dialog before switching apps.

Practice: Add one sentence, save with Command+S, and locate the saved document again.

What you will learn: Move between open apps.

Before you begin: At least two apps are open.

Exactly how to do it

Part 10 - VoiceOver Rotor and Item Chooser

Task Command
Open Rotor VO+U
Open Item Chooser VO+I

10.1 Use the Rotor

What you will learn: Navigate by category rather than item-by-item.

Before you begin: Be on a webpage or context where rotor categories are available.

Exactly how to do it

  1. Press VO+U.

  2. Move among rotor categories with Left/Right Arrow.

  3. Choose a category such as Headings, Links, Buttons, or Form Controls.

  4. Move through matching items with Up/Down Arrow.

  5. Press Return or Space to move to the selected item and close the rotor. Escape closes the rotor without selecting an item.

What should happen: You jump among items in the selected category.

If that does not happen: If a category is missing, it may not apply to the current context or may be disabled in VoiceOver settings.

Practice: Open a webpage and move by headings.

10.2 Use Item Chooser

What you will learn: Find an item from a searchable list.

Before you begin: Be in an app or webpage with many controls.

Exactly how to do it

  1. Press VO+I.

  2. Type a few letters from the item’s name to narrow the list. Delete removes letters so you can try again.

  3. Press Up Arrow or Down Arrow to move through matching items.

  4. Press Enter on the desired item.

What should happen: VoiceOver moves to the chosen item.

If that does not happen: If nothing matches, try a shorter search term.

Practice: Use Item Chooser to find a known button or link.

Part 11 - Quick Nav

Quick Nav provides shorter navigation commands. It has separate arrow-key and single-key modes.

  1. Press VO+Shift+Q to toggle arrow-key Quick Nav. Listen for its state. With it on, Left and Right Arrow move the VoiceOver cursor, and Up plus Down Arrow together activates the current item.
  2. Press VO+Q to toggle single-key Quick Nav. With it on, letters can navigate instead of typing: for example, B moves to the next button on a suitable page, and Shift+B moves to the previous button.
  3. Before typing into a field, make sure keyboard focus is in that field. If letters still navigate, use VO+Q and listen for single-key Quick Nav off.
  4. If ordinary arrows do not move the insertion point as expected, use VO+Shift+Q and listen for arrow-key Quick Nav off.

Pressing Left and Right Arrow together can also toggle Quick Nav, but that behavior is configurable. The explicit commands above avoid assuming how the arrow pair is configured.

Practice: Navigate to a button with Quick Nav, then turn the relevant modes off and type a word in the practice field in Part 12.

Part 12 - Web Navigation

VoiceOver can navigate webpages by DOM order, groups, headings, links, buttons, form controls, landmarks, tables, images, frames, and live regions.

12.1 Scan a Webpage by Headings

What you will learn: Understand a page before reading every line.

Before you begin: Safari or another accessible browser is open on a webpage.

Exactly how to do it

  1. Press VO+U.

  2. Choose Headings in the rotor.

  3. Move through heading items with Up/Down Arrow.

  4. Stop on a heading that sounds relevant.

  5. Press Return to jump to that heading and close the rotor. Escape instead cancels the selection.

  6. Use VO+A or normal navigation to read from there.

What should happen: You can jump directly to major sections.

If that does not happen: If the page has no headings, use Landmarks, Links, or Buttons instead.

Practice: Find the main heading and two subheadings on a webpage.

12.2 Navigate Form Controls

What you will learn: Complete fields and buttons on a webpage.

Before you begin: Be on a webpage containing a form.

Exactly how to do it

  1. Use the rotor and choose Form Controls.

  2. Move to the desired text field, checkbox, popup, or button.

  3. If required, interact with the control using VO+Shift+Down Arrow.

  4. Type or choose the value.

  5. Stop interacting when finished.

  6. Move to the next form control.

What should happen: You can complete the form without manually reading every page element.

If that does not happen: If typing triggers navigation, check Quick Nav and focus/interaction state.

Practice: Fill a safe practice form.

12.3 Open a webpage and complete a practice field

Before you begin: Practice in Safari on your Mac. The sample controls below have no submit action.

  1. Use Command+Space to find Safari and press Return on the application result.
  2. Press Command+L, type https://accessiblelearningcenter.org/mac-voiceover-manual.html, and press Return. Wait for the page to load.
  3. Press VO+U. Use Left or Right Arrow to choose Headings, then Up or Down Arrow to find “12.3 Open a webpage and complete a practice field”. Press Return to move there.
  4. Navigate forward with VO+Right Arrow to the “Practice word” text field. If needed, interact using VO+Shift+Down Arrow. Type the word “hello”.
  5. If letters trigger navigation, confirm the field has focus and turn single-key Quick Nav off with VO+Q. Listen for the off announcement before trying again.
  6. Press Tab, or navigate with VO+Right Arrow, to “Practice checkbox”. Press VO+Space once. Listen for its checked state; activate it again to clear it.
  7. Open VO+I, type “Practice word”, select the matching field with Down Arrow, and press Return to move back to it. Read the text you entered.
Local practice controls

What should happen: You can enter text, change a checkbox, and find the field again. The controls do not submit or save your practice text.

If that does not happen: Confirm you are in the webpage content rather than the address bar. Press Escape to close an unwanted rotor or menu. Use VO+Shift+Up Arrow to leave an unrelated group and return to the practice heading.

Part 13 - Read and Edit Text

13.1 Read Text

What you will learn: Read continuously from your current location.

Before you begin: Focus is in readable text.

Exactly how to do it

  1. Move VoiceOver to the desired starting point.

  2. Press VO+A.

  3. Listen while VoiceOver reads.

  4. Press Control to pause speech.

  5. Press Control again to resume where supported, or restart reading from the desired position.

What should happen: VoiceOver reads from the current location.

If that does not happen: If it reads the wrong area, move the VoiceOver cursor to the text first.

Practice: Read one paragraph and pause halfway.

13.2 Edit Text

What you will learn: Type, move the insertion point, and correct text.

Before you begin: Be in an editable text field or document.

Exactly how to do it

  1. Move to the text field.

  2. Interact if required.

  3. Type a sentence.

  4. Use Left/Right Arrow to move the insertion point by character.

  5. Use Option+Left/Right Arrow to move by word in standard Mac text editing.

  6. Use Backspace/Delete to remove text.

  7. Type the correction.

  8. Use VO+A or text-navigation commands to review.

What should happen: The text changes at the insertion point.

If that does not happen: If typed letters trigger VoiceOver navigation, verify that keyboard focus is in the text field and Quick Nav is not intercepting typing.

Practice: Type a sentence with one deliberate error and correct it.

Part 14 - Tables and Structured Content

When VoiceOver reaches a table, interact with it to navigate its cells. VoiceOver can announce row/column information depending on verbosity and the app.

14.1 Navigate a Table

What you will learn: Move through structured rows and columns.

Before you begin: VoiceOver is focused on a table.

Exactly how to do it

  1. Press VO+Shift+Down Arrow to interact.

  2. Use VoiceOver/arrow navigation through cells.

  3. Listen for row and column information.

  4. Move systematically rather than jumping randomly.

  5. Press VO+Shift+Up Arrow when finished.

What should happen: You can inspect table cells and leave the table.

If that does not happen: If VoiceOver only says 'table' and skips cells, interact with it first.

Practice: Read at least three cells from a simple table.

Part 16 - Braille Displays and Braille Access

VoiceOver supports compatible refreshable braille displays over Bluetooth or USB. macOS Tahoe also includes Braille Access and Braille Keyboard Input features.

  • Connect a supported display through Bluetooth or USB.

  • Open VoiceOver Utility > Braille to review display, translation, layout, status, and Braille Access settings.

  • Cursor-routing keys can move VoiceOver focus or the insertion point to the cell represented by the routing button.

  • Braille Keyboard Input can use supported display keys for braille entry and assigned commands.

  • Braille Access can provide a more notetaker-like environment on supported configurations.

16.1 Verify a Braille Display Connection

What you will learn: Confirm the display actually works with VoiceOver.

Before you begin: Pair/connect the braille display.

Exactly how to do it

  1. Open VoiceOver Utility.

  2. Open Braille settings.

  3. Confirm the display appears.

  4. Move VoiceOver with VO+Right Arrow.

  5. Check that braille changes.

  6. Type in a text field if the display provides input.

  7. Press a routing key and confirm focus/caret movement.

What should happen: Braille output follows VoiceOver and supported input/routing works.

If that does not happen: If Bluetooth says connected but braille does not update, check VoiceOver Utility > Braille and the display's connection mode.

Practice: Perform the three tests: output, input, routing.

Part 18 - VoiceOver Utility

Task Command
Open VoiceOver Utility VO+Fn+F8 or VO+Fn+8

VoiceOver Utility is the main configuration application for VoiceOver.

  • General: overall VoiceOver behavior and startup options.

  • Verbosity: speech, braille, text, announcements, and hints.

  • Speech: voices and pronunciation.

  • Navigation: cursor tracking, interaction, wrapping, and movement behavior.

  • Web: webpage navigation and Web Rotor settings.

  • Sound: VoiceOver sound effects.

  • Visuals: VoiceOver cursor and visual panels.

  • Commands: customize keyboard commands and gestures.

  • Braille: translation, layout, status, displays, and Braille Access.

  • Activities: save different VoiceOver settings for particular tasks or apps.

  • VoiceOver Recognition: recognition features for otherwise inaccessible content.

  • Screen Sharing: settings for VoiceOver during screen sharing.

Part 19 - Speech, Pronunciation, Verbosity, and Punctuation

19.1 Change Speech Voice or Rate

What you will learn: Make VoiceOver easier to understand.

Before you begin: VoiceOver Utility is open.

Exactly how to do it

  1. In VoiceOver Utility, use VO+Right Arrow to find the categories list. Interact with it if needed, then use Up or Down Arrow to select Speech.

  2. Stop interacting with the categories list using VO+Shift+Up Arrow, move to the Voices tab, and activate it with VO+Space.

  3. Move to the current voice and choose another voice if desired.

  4. Move to the speaking-rate control. If it is a slider, interact with it and use an arrow key to change it one step; if it is an editable value, enter a small change. Listen to the new value before continuing.

  5. Test the result by navigating several items.

  6. Keep the setting that remains clear during longer listening.

What should happen: VoiceOver speaks with the selected voice/rate.

If that does not happen: If speech becomes too fast to understand, return to the previous rate or reduce it.

Practice: Try two rates and choose the more comfortable one.

19.2 Change Verbosity

What you will learn: Control how much information VoiceOver announces.

Before you begin: VoiceOver Utility is open.

Exactly how to do it

  1. Open Verbosity.

  2. Review Speech, Text, Announcements, and Hints settings.

  3. Change one setting at a time.

  4. Navigate a few controls to hear the effect.

  5. Restore or refine the setting as needed.

What should happen: VoiceOver gives more or less detail according to your choices.

If that does not happen: If you become unsure what changed, reset only the changed category rather than changing several more options.

Practice: Reduce one repetitive announcement, then restore it.

Part 20 - Customize Commands and Activities

VoiceOver Utility lets you customize additional key commands and trackpad gestures. Activities let you save different VoiceOver settings for particular apps or tasks.

Best practice: Learn the default commands first. Customize only after you understand what the default command does, and document your changes so you can recover after troubleshooting or updates.

Part 21 - Troubleshooting

21.1 VoiceOver Is Not Speaking

What you will learn: Restore speech in a logical order.

Before you begin: VoiceOver should be on.

Exactly how to do it

  1. Press Command+F5 and listen for the VoiceOver state.

  2. Check Mac volume and audio output.

  3. Press VO+A to request reading.

  4. Press Control in case speech was paused.

  5. Open VoiceOver Utility and verify the selected voice/speech settings.

  6. Turn VoiceOver off and on again if necessary.

What should happen: VoiceOver speech returns.

If that does not happen: If the Mac has no sound in any app, troubleshoot system audio rather than VoiceOver alone.

Practice: Memorize the order: VoiceOver state > volume/output > speech command > Utility settings > restart VoiceOver.

21.2 VoiceOver Skips Controls

What you will learn: Recover when controls seem unreachable.

Before you begin: VoiceOver is moving but not reaching the desired control.

Exactly how to do it

  1. Move with VO+Right Arrow slowly.

  2. Listen for group, toolbar, table, or web area.

  3. Press VO+Shift+Down Arrow to interact.

  4. Explore inside with VO+Right Arrow.

  5. Press VO+Shift+Up Arrow to leave.

  6. Use VO+I Item Chooser or VO+U Rotor if appropriate.

What should happen: You reach controls that were previously skipped.

If that does not happen: If the app is genuinely inaccessible, try an alternate control path or report the accessibility problem to the app developer.

Practice: Find a control inside a group and activate it.

21.3 Typing Produces Commands Instead of Text

What you will learn: Restore normal text entry.

Before you begin: Focus should be in a text field.

Exactly how to do it

  1. Confirm VoiceOver is focused on the text field.

  2. Interact with the field if needed.

  3. Check whether Quick Nav is on.

  4. Press VO+Q and listen for single-key Quick Nav off if letter keys navigate instead of typing. Use VO+Shift+Q to turn arrow-key Quick Nav off if arrows do not move the insertion point.

  5. Type a short word.

  6. Use arrow keys to verify the insertion point.

What should happen: Letters appear in the text field.

If that does not happen: If letters still do not appear, check keyboard focus and whether the app uses a special editing mode.

Practice: Open TextEdit and type a short sentence.

    When you are stuck

    1. Stop and listen to the current window title, control name, or error message.
    2. Save your work before troubleshooting.
    3. Search this page using a few important words from the task or message.
    4. Open the matching manual before trying a lesson again.
    5. Use the program's official help or ask an instructor when a step could change or delete information.

    Assignment uploads are currently paused. Complete each assignment and save it in a location you can find again. Existing submissions and progress records have not been deleted.

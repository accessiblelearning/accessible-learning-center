First-time setup and success checks

Lesson goal in plain language: Independently create, check, and practice a professional accessible presentation.

Prepare before step 1

  1. Open the correct application, website, or device screen and wait for its name to be announced.
  2. Open PowerPoint manual and review the matching procedure if any command or term is unfamiliar.
  3. Use only fictional, public, disposable, or instructor-provided practice information. Make a copy before changing an important file.
  4. Read all numbered instructions once before performing them so you know the intended final result.

Commands used or referenced

Alt+Q, Insert+Spacebar,

For a plus-sign command, hold the modifier key, press and release the final key, then release the modifier. For a sequence, press and release each key in order. Stop after every command and listen for the result.

Work and verify

  1. Perform one numbered instruction and stop. Identify the active window, focused control, selected item, cell, slide, message, field, or device area before continuing.
  2. Compare the result with the lesson goal. A sound alone is not enough; verify the name, state, value, location, permission, or content.
  3. If the result is wrong, press Escape once to leave an unexpected menu, identify focus again, and use Undo only when the change is safely reversible.
  4. Save or synchronize at natural stopping points. Use the required filename PowerPoint-Lesson-10-Final.pptx.
  5. Complete the “Before submitting” checklist from top to bottom. Correct missing items before marking the lesson complete.
  6. Close and reopen the practice item, or return to it from the product’s main screen, to prove you can locate and verify the result independently.

Success standard: Explain what each major command did, show the finished result, and recover from one harmless focus or navigation error without another person naming the next key.

Goal

Independently create, check, and practice a professional accessible presentation.

Skills practiced

  • Plan a logical presentation structure.
  • Use layouts, titles, lists, links, and visuals accessibly.
  • Verify reading order and alternative text.
  • Present with keyboard commands and speaker notes.

Step-by-step instructions

  1. Create a presentation for a fictional new-employee orientation.
  2. Include a title slide and at least six additional slides.
  3. Cover Welcome, Daily Schedule, Workplace Expectations, Technology Resources, Safety or Emergency Information, and Contact Information.
  4. Use built-in layouts and give every slide a unique title.
  5. Include at least one meaningful image with alt text.
  6. Include either an accessible table or a chart with alt text, source values, and a text summary.
  7. Include at least one meaningful hyperlink.
  8. Check the reading order on every slide.
  9. Use strong contrast and do not communicate by color alone.
  10. Add concise speaker notes to every content slide.
  11. Run Check Accessibility and resolve applicable errors and warnings.
  12. Present the entire deck using only the keyboard.
  13. Save the presentation as PowerPoint-Lesson-10-Final.pptx.

Keyboard help: Press Alt+Q to search PowerPoint commands when Ribbon KeyTips differ. For JAWS help, press Insert+Spacebar, then J, and search for the task.

Your assignment

Create a professional, accessible new-employee orientation presentation with at least seven slides and all required accessibility features.

Save the finished assignment as PowerPoint-Lesson-10-Final.pptx.

Before submitting

  • The deck contains at least seven logically ordered slides.
  • Every slide has a unique title and uses a built-in layout.
  • All meaningful visuals have alt text.
  • Tables or charts include accessible structure and text equivalents.
  • Links use meaningful text.
  • Reading order and contrast were reviewed.
  • Speaker notes are included.
  • Accessibility Checker was completed.
  • The file is saved as PowerPoint-Lesson-10-Final.pptx.

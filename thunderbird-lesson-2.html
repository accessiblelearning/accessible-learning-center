Install and open Thunderbird on Windows

Start here: A supported Windows computer, an internet connection, and permission to install applications. Have your existing email address available.

Step-by-step instructions

  1. Open your browser. Go to Thunderbird’s official website. Locate its download option and choose the Windows installer. Do not use a sponsored download site.
  2. After the download finishes, open the installer from your browser’s downloads list. Read the Windows permission prompt. Continue only if it identifies the application you intended to install; a managed device may require your technology team.
  3. Follow the installer’s labeled Next or Install controls. Leave options you do not understand at their defaults. Finish the installation and open Thunderbird.
  4. If Thunderbird is installed already, press the Windows key, type Thunderbird, review the matching application name, and press Enter. Continue with “Connect an existing email account” below.

Check your result

The Thunderbird application is open. You may see account setup instead of a mailbox on the first launch.

If something goes wrong

A browser tab showing Thunderbird’s website is not the installed application. Use the Windows application search to verify. If installation is blocked, retain the error and ask the device administrator.

Try it yourself

Point out which window is the browser and which is Thunderbird before entering account information.

Connect an existing email account

What you will learn: Connect your account and reach your mailbox without guessing server settings.

Exactly how to do it

  1. Open Thunderbird. A new installation offers account setup. Otherwise, open its application menu and choose New Account, then Existing Email. Use Tab to reach the menu, Enter to open it, and arrow keys to explore.
  2. Enter the requested display name, complete email address, and password. Review each field before moving on.
  3. Activate Continue. Wait for the provider configuration results.
  4. Review the account and connection choices. IMAP is normally the proposed option. If automatic setup fails, obtain the exact settings from your provider or technology team.
  5. Activate Done when the settings are correct. If your provider opens a sign-in window, complete its authentication and review the requested access.
  6. Allow time for folders and messages to arrive.

What should happen: Your account and folders become available.

If that does not happen: Read the actual sign-in or configuration error before retrying. Never replace server names with guesses.

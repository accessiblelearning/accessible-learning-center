JAWS Lesson 8

Built-in Help, Settings, and Troubleshooting

JAWS manual All JAWS lessons My progress

Goal

Use JAWS help and safe troubleshooting tools without making risky system changes.

Skills practiced

  • Open screen-sensitive help, Hot Key Help, and Windows Key Help.
  • Search for JAWS commands.
  • Refresh the screen and restore normal voice settings.
  • Describe a repeatable troubleshooting sequence.

Step-by-step instructions

  1. In a familiar application, press Insert+F1 for screen-sensitive help. Close the help after reviewing it.
  2. Press Insert+H to open JAWS Hot Key Help for the current application.
  3. Press Insert+W to open Windows Key Help and review common Windows commands.
  4. Open JAWS Commands Search using Insert+Spacebar, then J. Search for a command such as read title or list links.
  5. Press Insert+V to open Quick Settings. Review options, then press Escape without changing unfamiliar settings.
  6. Press Insert+6 on the numbers row to open Settings Center. Review the window and close it without saving changes.
  7. If JAWS speech seems out of date, press Insert+Escape to refresh the screen.
  8. If voice settings were changed accidentally, use the documented Restore Normal Voice Settings command for the installed keyboard layout.
  9. Practice this troubleshooting order: stop speech, identify the window, identify focus, refresh the screen, check help, then restart only the affected application if necessary.
  10. Create JAWS-Lesson-8.txt describing the problem-solving sequence and three help resources.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Goal

Document an accessible practice-application workflow.

Step-by-step instructions

  1. Prepare résumé, dates, and references before starting.
  2. Navigate fields with Tab and JAWS forms commands.
  3. Read every label, required state, and error message.
  4. Use consistent information and save progress when available.
  5. Review uploaded filename and application summary.
  6. Never submit a practice application to a real employer.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

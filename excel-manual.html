About this manual

This manual is written for Microsoft Excel in Microsoft 365 desktop on Windows. It focuses on keyboard use with JAWS, but most standard Excel shortcuts also work with other screen readers and magnification.

Excel is organized as workbooks containing worksheets. Each worksheet is a grid of columns, rows, and cells. A cell address combines its column letter and row number, such as B4. JAWS normally announces the active cell address, cell contents, and useful formatting or formula information.

Microsoft 365 changes over time. If a Ribbon KeyTip differs, press Alt+Q, type the command name, and choose it from Search. For JAWS command help, press Insert+Spacebar, then J to open JAWS Commands Search.

Accessible workbook practices

  • Use a short, unique header for every column and keep headers in one row.
  • Keep one kind of information in each column and one record in each row.
  • Avoid merged cells. Screen readers can repeat, skip, or misidentify merged content.
  • Avoid blank rows and columns inside a data table.
  • Use real number formats for currency, percentages, and dates instead of typing visual symbols as text.
  • Do not use color as the only way to communicate status or instructions. Include words or symbols with text equivalents.
  • Give worksheets meaningful names and remove unused blank worksheets before sharing.
  • For charts and other visual objects, add concise alternative text and keep the source data available in cells.
  • Use an Excel table when possible so headers and data boundaries are explicit.
  • Run Review, Check Accessibility before submitting or sharing a workbook.

Formula essentials

Every Excel formula begins with an equals sign. A formula can contain numbers, cell references, operators, and functions.

  • =B2*C2 multiplies the values in B2 and C2.
  • =SUM(D2:D10) adds the values from D2 through D10.
  • =AVERAGE(D2:D10) calculates the average.
  • =MIN(D2:D10) and =MAX(D2:D10) return the lowest and highest values.
  • =IF(B2>=C2,"Complete","Needs Training") returns text based on a condition.
  • =COUNTIF(D2:D10,"Complete") counts cells matching the word Complete.

Press F2 to edit and inspect the active cell's formula. When copying formulas, confirm that relative cell references changed as intended.

Tables, sorting, and filtering

Select a cell in a continuous data list and press Ctrl+T to create a table. Confirm the range and that the table has headers. On a table header, press Alt+Down Arrow to open sorting and filtering choices.

After filtering, remember that some rows are hidden. Clear filters before sharing unless the filtered view is intentional, and describe the active filter in a nearby cell or instructions worksheet.

Charts and nonvisual access

A chart should never be the only source of information. Keep the labeled source table, add useful alternative text, and include a short text summary of the important trend or conclusion. Avoid descriptions such as “chart” that do not explain its purpose.

Ten-lesson course sequence

  1. Lesson 1: Excel Basics: Workbooks, Worksheets, and Cells — Open Excel, understand the worksheet grid, enter a simple workplace contact list, and save a workbook.
  2. Lesson 2: Navigating, Editing, Finding, and Filling Data — Move efficiently through a worksheet, edit cells, find and replace information, and copy values without relying on a mouse.
  3. Lesson 3: Formulas, AutoSum, and Basic Calculations — Create a small expense worksheet and calculate totals and averages with formulas.
  4. Lesson 4: Accessible Formatting and Number Formats — Apply meaningful formatting and number formats while keeping the worksheet usable with screen readers and magnification.
  5. Lesson 5: Tables, Sorting, and Filtering — Convert data into an accessible Excel table and use keyboard commands to sort and filter records.
  6. Lesson 6: IF, COUNTIF, and Conditional Results — Use logical and counting functions to turn raw workplace data into useful status information.
  7. Lesson 7: Managing Worksheets and Cross-Sheet References — Organize related information across worksheets and create a summary that refers to another sheet.
  8. Lesson 8: Charts, Alternative Text, and Accessibility Checker — Create a simple chart, provide a text equivalent, and use Excel accessibility checks.
  9. Lesson 9: Data Validation, Consistent Entry, and Review — Create a reliable data-entry sheet with controlled choices and check it for common accessibility problems.
  10. Lesson 10: Final Employment Workbook Project — Independently build an accessible workbook that organizes, calculates, summarizes, and communicates workplace information.

Accessible Audio Recording and Editing

Record, navigate, edit, save, and export audio while protecting the original.

Record and stop in Audacity

Keyboard commands: R starts recording. Space starts or stops playback. P pauses or resumes.

  1. Confirm the microphone and recording device.
  2. Press R and speak a short fictional practice script.
  3. Press Space to stop, then return to the beginning and play it.

What you should hear: Recording or playback feedback and changing time position.

If that does not happen: Stop before repeating commands. Confirm focus, the selected audio device, and whether another application is using the microphone.

Navigate and select before editing

Keyboard commands: Home moves to the beginning; End moves to the end. Selection commands depend on the active Audacity context.

  1. Save a backup before editing.
  2. Move to a known time position.
  3. Create a small selection and verify its start and end.
  4. Delete or change audio only after the range is confirmed.

If that does not happen: Undo with Ctrl+Z and recheck the selection boundaries and active track.

Save the project and export audio

Keyboard commands: Ctrl+S saves the editable project. Export commands can change between Audacity versions, so use the current File menu labels.

  1. Save the project before exporting.
  2. Choose an output format appropriate for the assignment.
  3. Use a new filename for the listening copy.
  4. Verify the exported file's duration and playback.

If that does not happen: Do not overwrite the project. Check the destination, format, and export dialog for an error.

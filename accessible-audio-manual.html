Basic how-tos

Create and save a new project

What you will learn: Complete create and save a new project independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Ctrl+N creates a project. Ctrl+S saves it.

  1. Open Audacity and press Ctrl+N.
  2. Press Ctrl+S before recording.
  3. Choose a folder you can find again.
  4. Enter a descriptive project name and confirm Save.

What should happen: The project name in the Audacity window title.

If that does not happen: Use Alt+F and choose Save Project. Do not export yet; a project file and an audio file serve different purposes.

Practice: Repeat create and save a new project with a second safe practice item, then explain the commands you used.

Record and stop

What you will learn: Complete record and stop independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: R starts recording. Space stops recording or playback.

  1. Connect the microphone and reduce background noise.
  2. Press R once and speak a short practice sentence.
  3. Press Space to stop.
  4. Press Ctrl+S to save the project.

What should happen: Recording feedback and a changing time position.

If that does not happen: Stop before trying again. Check the selected input device and whether another application controls the microphone.

Practice: Repeat record and stop with a second safe practice item, then explain the commands you used.

Play and navigate

What you will learn: Complete play and navigate independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Space plays or stops. P pauses or resumes. Home moves to the track start. End moves to the track end.

  1. Press Home.
  2. Press Space and listen from the beginning.
  3. Press P to pause at a point you want to inspect.
  4. Press P again to continue or Space to stop.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Confirm that an audio track exists and the Audacity window is active.

Practice: Repeat play and navigate with a second safe practice item, then explain the commands you used.

Advanced how-tos

Select and delete unwanted audio

What you will learn: Complete select and delete unwanted audio independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Shift+Right Arrow or Shift+Left Arrow extends a selection in small steps. Delete removes the confirmed selection. Ctrl+Z undoes.

  1. Press Ctrl+S to protect the project.
  2. Move playback near the unwanted sound and stop.
  3. Hold Shift while using an arrow key to extend the selection.
  4. Use Audacity’s selection toolbar or screen-reader feedback to verify start and end times.
  5. Press Delete, then listen across the edit.
  6. Press Ctrl+Z immediately if the wrong audio was removed.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Undo and create a smaller selection. Never delete an unverified range.

Practice: Repeat select and delete unwanted audio with a second safe practice item, then explain the commands you used.

Record a second track

What you will learn: Complete record a second track independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: Shift+R starts recording on a new track in current Audacity versions.

  1. Save the project and move to the intended start time.
  2. Press Shift+R.
  3. Record the second part and press Space to stop.
  4. Use track navigation and Solo or Mute controls to review tracks separately.
  5. Save again.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Undo the new recording and confirm Audacity’s recording preference and active track.

Export an MP3 or WAV file

What you will learn: Complete export an mp3 or wav file independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Use Alt+F to open File, then choose Export Audio.

  1. Press Ctrl+S to save the editable project.
  2. Open File and choose Export Audio.
  3. Choose MP3 for a smaller listening copy or WAV for higher-quality uncompressed audio.
  4. Select the destination and enter a new filename.
  5. Review format settings and activate Export.
  6. Open the exported file and verify its duration and sound.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Keep the project open. Check the destination, filename, format, and any error dialog.

Practice: Repeat export an mp3 or wav file with a second safe practice item, then explain the commands you used.

Apply an effect safely

What you will learn: Complete apply an effect safely independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Select audio, open the Effect menu with Alt+C in many Audacity versions, and choose an effect by name.

  1. Save a backup project.
  2. Select only the audio that should change.
  3. Open the Effect menu and choose the effect.
  4. Preview it when available.
  5. Apply it, listen again, and use Ctrl+Z if the result is worse.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Cancel the dialog rather than accepting settings you do not understand.

Practice: Repeat apply an effect safely with a second safe practice item, then explain the commands you used.

Quick command list

  • R: Record
  • Shift+R: Record a new track
  • Space: Play or stop
  • P: Pause or resume
  • Home / End: Start / end
  • Ctrl+S: Save project
  • Ctrl+Z: Undo
  • Delete: Remove selected audio

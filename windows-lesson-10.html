Windows 11 Lesson 10

Final Workplace File and Window Management Project

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Combine Windows navigation, file organization, accessibility, security, and troubleshooting skills in one independent project.

Skills practiced

  • Plan and create a workplace folder structure.
  • Create, rename, copy, move, search, and verify files.
  • Manage multiple applications.
  • Document accessibility and security decisions.

Step-by-step instructions

  1. In Documents, create a folder named Workplace Project.
  2. Inside it, create folders named Incoming, Completed, and Archive.
  3. Create three fictional text files in Incoming: Schedule.txt, Contacts.txt, and Tasks.txt. Do not use real personal information.
  4. Add appropriate fictional content to each file and save all work.
  5. Rename Tasks.txt to Weekly-Tasks.txt.
  6. Copy Schedule.txt to Archive and move Weekly-Tasks.txt to Completed.
  7. Use File Explorer search to find every file containing the word Schedule in its name.
  8. Open Notepad and File Explorer together. Use Alt+Tab and a Snap command to organize the task.
  9. Review the project with keyboard navigation, confirm file names and locations, and use Properties on one file.
  10. Create Windows-Lesson-10.txt summarizing the folder structure, commands used, one accessibility choice, one security choice, and one troubleshooting step.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

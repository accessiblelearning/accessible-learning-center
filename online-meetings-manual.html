First-time keyboard guide

Use this short routine before following the Zoom, Microsoft Teams, and Google Meet Manual procedures. It explains exactly how the keyboard directions in this manual work.

Press a single key

  1. Find the named key without pressing it if possible.
  2. Press and release the key one time. Do not hold it unless the step specifically says to hold it.
  3. Stop and listen to the full screen-reader announcement before pressing another key.

Press a keyboard combination

  1. When a command contains a plus sign, such as Ctrl+S, hold down the first key.
  2. While continuing to hold the first key, press and release the final key once.
  3. Release the first key. The plus sign is not a key and should not be pressed.
  4. Listen for the expected result described in the procedure. If nothing changes, verify that the correct application or webpage has focus and try the command once more.

Press a sequence of keys

  1. When keys are separated by commas or the word “then,” press and release them in order instead of holding them together.
  2. After each key, listen for a menu, tab, control, or new screen before continuing.
  3. If the announcement does not match the step, press Escape once to close the current menu or dialog and restart that procedure.

Know which navigation key to try

  • Tab and Shift+Tab: move forward and backward among buttons, links, fields, and other controls.
  • Arrow keys: move inside menus, lists, groups of choices, text, and many screen-reader reading views.
  • Enter: opens the selected item or activates the focused command.
  • Space: activates many buttons and checks or clears checkboxes. In a text field, Space types a space.
  • Escape: cancels or closes the current menu, list, or dialog without intentionally accepting a change.

Verify before moving on

  1. Listen for the window, page, or application name so you know where focus is.
  2. Perform only one numbered step.
  3. Compare what the screen reader announces with the “What should happen” information in the procedure.
  4. If the result is wrong, stop. Use the procedure’s recovery directions, Escape to cancel, or Ctrl+Z to undo when that command is supported.
  5. Continue only after you can identify the result. Save completed work with Ctrl+S whenever the application supports saving.

Basic how-tos

Join a meeting safely

What you will learn: Complete join a meeting safely independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Tab and Shift+Tab move through join controls. Space changes a focused checkbox. Enter activates Join.

  1. Open the invitation and verify the organizer, date, and meeting link.
  2. Open the link and confirm the meeting application or browser tab.
  3. Tab through microphone, camera, name, and audio choices.
  4. Join muted unless instructed otherwise.
  5. Activate Join and wait for the meeting title or waiting-room announcement.

What should happen: Your microphone and camera states, followed by the meeting or waiting room.

If that does not happen: Do not press Join repeatedly. Check for a browser permission dialog or an “open application” prompt.

Practice: Repeat join a meeting safely with a second safe practice item, then explain the commands you used.

Mute or unmute

What you will learn: Complete mute or unmute independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Zoom: Alt+A. Teams: Ctrl+Shift+M. Google Meet: Ctrl+D.

  1. Confirm the correct meeting is active.
  2. Press the command once.
  3. Wait for a spoken or sound confirmation.
  4. When uncertain, Tab to the microphone button and read its state.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Do not toggle repeatedly. A host or organization may prevent unmuting.

Practice: Repeat mute or unmute with a second safe practice item, then explain the commands you used.

Open chat and send a message

What you will learn: Complete open chat and send a message independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: Zoom: Alt+H opens or closes meeting chat. In Teams and Meet, locate Chat by button navigation because shortcuts and layouts change.

  1. Open Chat and confirm its heading.
  2. Move to the message field.
  3. Type a short message and review it.
  4. Press Enter to send only when the application indicates Enter sends.
  5. Return to meeting controls after confirming the message appeared.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Check whether focus is in chat history, a recipient selector, or the message field.

Share a window safely

What you will learn: Complete share a window safely independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: Zoom: Alt+S starts or stops sharing when permitted. For Teams and Meet, activate the labeled Share control.

  1. Close private files, messages, and notifications.
  2. Open only the content you intend to share.
  3. Start sharing and choose a specific window rather than the entire screen.
  4. Read the selected window name before confirming.
  5. Describe visual content aloud and provide the source file or accessible alternative.
  6. Stop sharing and confirm that sharing ended.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Cancel the chooser. Never select a source whose name you cannot verify.

Practice: Repeat share a window safely with a second safe practice item, then explain the commands you used.

Leave without ending the meeting for everyone

What you will learn: Complete leave without ending the meeting for everyone independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Find Leave, then read the confirmation choices.

  1. Save anything needed from chat according to the meeting policy.
  2. Activate Leave.
  3. If you are the host, choose Leave meeting unless you truly intend to end it for everyone.
  4. Confirm that focus returns to the desktop or previous application.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Read the dialog carefully; do not choose End meeting for all by accident.

Practice: Repeat leave without ending the meeting for everyone with a second safe practice item, then explain the commands you used.

Your first meeting rehearsal from invitation to exit

Practice with a trusted person or a meeting you created for yourself before joining an important appointment.

  1. Open the invitation and read the meeting date, start time, platform, and organizer before activating any link.
  2. Move to the join link and press Enter. If the browser asks whether to open an application, use Tab to review every choice and select the intended application only.
  3. On the preview screen, use Tab and Shift+Tab to identify the microphone, camera, speaker, and Join controls. Listen for each control’s current state.
  4. Leave the microphone muted and the camera off for the first entry unless the organizer instructed otherwise.
  5. Activate Join and wait. If a waiting-room message is announced, do not repeatedly press Enter; wait for the host to admit you.
  6. After entry, use the platform’s keyboard shortcut to confirm or change microphone state. Say a short test sentence only after another participant confirms it is appropriate.
  7. Open chat, type a private practice message only if you can verify the recipient, or send a harmless greeting to everyone if the meeting is explicitly a rehearsal.
  8. Return focus to the main meeting controls. Practice raising and lowering your hand and turning captions on, listening for the state change after each command.
  9. Before sharing, choose a single safe application window rather than the entire screen. Read the selected window name aloud to yourself before activating Share.
  10. Stop sharing, locate Leave, and activate it. If offered Leave Meeting or End Meeting for All, choose Leave Meeting unless you are the host and intentionally want to end the session for everyone.

Success check: You entered with safe audio/video settings, located communication and accessibility controls, and left without ending the meeting for others.

Quick command list

  • Zoom Alt+A / Teams Ctrl+Shift+M / Meet Ctrl+D: microphone
  • Zoom Alt+V / Teams Ctrl+Shift+O / Meet Ctrl+E: camera
  • Zoom Alt+U: Participants
  • Zoom Alt+H: Chat
  • Zoom Alt+Y: Raise or lower hand
  • Zoom Alt+S: Start or stop sharing
  • Tab / Shift+Tab: next or previous control

Version note: Commands shown are for Windows. Web and desktop versions can differ.

Google Docs Lesson 3

Format Text and Paragraphs Accessibly

Google Docs manualAll Google Docs lessonsMy progress

Goal

Format a readable two-section workplace notice with true headings.

Step-by-step instructions

  1. Select the document title and apply the Title or Heading 1 style from the toolbar.
  2. Use Ctrl+B only for meaningful emphasis, not as the sole heading cue.
  3. Use Format, Align and indent to set paragraph alignment without spaces.
  4. Use Format, Line and paragraph spacing instead of blank lines.
  5. Avoid using color alone to communicate meaning.
  6. Download and inspect the DOCX copy.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Format a readable two-section workplace notice with true headings.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Docs-Lesson-3.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Google Docs Lesson 3.

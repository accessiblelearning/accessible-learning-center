Calendar Layout and Keyboard Navigation

Google Calendar manualAll Google Calendar lessonsMy progress

Goal

Create a command reference describing six Calendar controls.

Step-by-step instructions

  1. Open calendar.google.com in Chrome.
  2. Turn on keyboard shortcuts in Calendar settings if the account permits.
  3. Press C to open a new event and Esc to cancel.
  4. Use J and K to move through date ranges where supported.
  5. Use T to return to today.
  6. Use JAWS Insert+T and Insert+Tab to confirm context and focus.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

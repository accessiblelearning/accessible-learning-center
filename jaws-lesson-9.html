JAWS Lesson 9

JAWS AI: FSCompanion and Picture Smart AI

JAWS manual All JAWS lessons My progress

Goal

Use JAWS AI tools thoughtfully for command help and image descriptions while protecting privacy and verifying results.

Skills practiced

  • Ask FSCompanion a clear JAWS question.
  • Use Picture Smart AI only with appropriate, non-sensitive images.
  • Recognize that AI answers and descriptions can be incomplete or wrong.
  • Use official documentation and human verification as fallbacks.

Step-by-step instructions

  1. Confirm that the computer has internet access and an installed JAWS version that offers the AI feature. If the feature is unavailable, complete the documented fallback steps instead.
  2. Press Insert+Spacebar, then F1 to open FSCompanion, as listed on Freedom Scientific’s current JAWS Hotkeys page.
  3. Ask: How do I list headings on a web page in JAWS? Record the answer and compare the command with Freedom Scientific’s JAWS Hotkeys page.
  4. Ask a second specific question about the current application. Avoid including names, passwords, client records, health information, or confidential workplace content.
  5. Open JAWS Commands Search or official JAWS documentation and verify at least one command returned by FSCompanion.
  6. Choose a non-sensitive sample image. Do not use a client document, identification card, private photograph, medical image, or confidential work screen.
  7. Open Picture Smart AI from the current JAWS interface or Commands Search and request a description of the sample image. Exact options can vary by JAWS version.
  8. Record the description, then identify one detail that should be confirmed by another source or a sighted person.
  9. If Picture Smart AI is unavailable, read Freedom Scientific’s official Picture Smart AI information and write how the feature is intended to work.
  10. Create JAWS-Lesson-9.txt with both AI exercises, verification results, and the privacy rules followed.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

AI safety: JAWS AI features use online services and can make mistakes. Never send passwords, client information, medical details, identification documents, or confidential workplace content. Verify important results with official documentation or a trusted person.

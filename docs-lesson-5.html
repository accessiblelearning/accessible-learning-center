Google Docs Lesson 5

Bulleted and Numbered Lists

Google Docs manualAll Google Docs lessonsMy progress

Goal

Create a supply list and a five-step opening checklist.

Step-by-step instructions

  1. Type three short items on separate lines.
  2. Select them and apply a bulleted list.
  3. Create a separate numbered list for ordered steps.
  4. Use Tab and Shift+Tab only when a nested level is truly needed.
  5. Avoid manually typing bullets or numbers.
  6. Read the lists with JAWS and verify item boundaries.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Microsoft Word Lesson 6

Bulleted and Numbered Lists

Goal

Create structured bulleted and numbered lists that screen readers can recognize.

Instructions

  1. Create a blank Word document.
  2. Type the heading: Daily Technology Checklist
  3. Apply Heading 1.
  4. Press Enter and return to Normal style.
  5. Press Ctrl+Shift+L to begin a bulleted list.
  6. Enter: Check email
  7. Enter: Review calendar
  8. Enter: Complete assignments
  9. Enter: Save important files
  10. Press Enter twice to end the list.
  11. Type the heading: Steps for Saving a Document
  12. Apply Heading 2.
  13. Create a numbered list containing: Open the File menu, Choose Save As, Choose a folder, Enter a filename, and Choose Save.
  14. Save the file as Word-Lesson-6.docx.

Your Assignment

Submit Word-Lesson-6.docx.

Before Submitting

  • The document should contain one true bulleted list.
  • The document should contain one true numbered list.
  • Headings should use built-in heading styles.

Windows 11 Lesson 9

Safe Troubleshooting, Task Manager, and Getting Help

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Use reversible troubleshooting steps and know when to stop and request assistance.

Skills practiced

  • Identify the affected window and save work.
  • Restart only an unresponsive application when safe.
  • Review Task Manager without ending unfamiliar processes.
  • Use Windows Get Help and document a problem clearly.

Step-by-step instructions

  1. Practice describing a problem with five facts: application, task, expected result, actual result, and any exact error message.
  2. Press Ctrl+S in open documents before troubleshooting.
  3. Use Alt+Tab and Insert+T with JAWS to confirm whether the issue affects one application or the whole computer.
  4. Try Escape, then Alt+F4 only if closing the affected application is safe. Reopen it and test again.
  5. Press Ctrl+Shift+Escape to open Task Manager.
  6. Review running applications. Do not end system processes or unfamiliar tasks.
  7. If a clearly identified practice application is unresponsive, select only that application and use End task with instructor or workplace approval.
  8. Press the Windows key, type Get Help, and open the Microsoft Get Help app. Review it without entering confidential information.
  9. Write a concise support request using the five facts from step 1 and include steps already tried.
  10. Save the support request as Windows-Lesson-9.txt.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

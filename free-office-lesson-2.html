Free Office Suite Lesson 2

Check Accessibility before Choosing a Program

Goal

Test keyboard access, screen-reader labels, zoom, focus visibility, and help resources in two free programs.

Prepare safely

  • Use your selected free office suite or complete the written alternative if the program or account is unavailable.
  • Do not purchase software, begin a paid trial, or enter payment information.
  • Use fictional or public information only.
  • Create a practice folder and confirm the active account, filename, and location before saving.

Step-by-step instructions

  1. Read the Choosing a Free Office Suite manual sections on accessibility, screen readers, file formats, and compatibility.
  2. Open your selected free office suite and confirm the window title or browser tab, active file, and current account when applicable.
  3. Navigate the main controls using only the keyboard. Record the labels announced by JAWS, Narrator, or NVDA.
  4. Test keyboard access, screen-reader labels, zoom, focus visibility, and help resources in two free programs.
  5. Save frequently in the program’s preferred editable format. If working in a browser, confirm that changes are saved before closing.
  6. Review the work from the beginning using keyboard and screen-reader navigation. Correct unclear structure, labels, or data.
  7. Create a separate Microsoft-compatible or requested exchange copy. Do not overwrite the editable original.
  8. Open or re-import the exchange copy when possible and compare content, formatting, formulas, notes, links, and accessibility.
  9. Write a short compatibility report naming anything that changed and how it was corrected.
  10. Save the submission using the filename free-office-Lesson-2.txt.

Screen-reader help: Use Tab and Shift+Tab for controls and listen to the current accessible name. JAWS users can use Insert+Tab, NVDA users NVDA+Tab, and Narrator users Scan Mode commands when appropriate. Application and web-editor commands may differ after updates.

Your assignment

Test keyboard access, screen-reader labels, zoom, focus visibility, and help resources in two free programs.

Include the finished work and a brief accessibility and compatibility review. Save it as free-office-Lesson-2.txt.

Before submitting

  • No private or confidential information is included.
  • The file opens and contains the expected content.
  • Keyboard and screen-reader access were tested.
  • A separate exchange copy was reviewed when the lesson requires one.
  • The filename is free-office-Lesson-2.txt.

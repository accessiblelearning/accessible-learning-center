Microsoft Word Lesson 8

Links, Alt Text, and Accessibility

Goal

Practice creating meaningful links, working with images, and checking document accessibility.

Instructions

  1. Create a blank Word document.
  2. Type the heading: Accessible Documents
  3. Apply Heading 1.
  4. Type: Accessible documents can be used effectively by people with disabilities.
  5. Press Enter twice.
  6. Type the words Microsoft Accessibility.
  7. Select those words.
  8. Press Ctrl+K.
  9. Enter a Microsoft accessibility web address.
  10. Confirm that the visible link text remains Microsoft Accessibility instead of displaying only a raw URL.
  11. If you are able to insert an image, add one practice image.
  12. Add concise alt text describing the image's purpose.
  13. If the image is decorative, mark it decorative instead.
  14. Open Review and run Accessibility Checker or Accessibility Assistant.
  15. Correct any accessibility problems you can identify.
  16. Save as Word-Lesson-8.docx.

Your Assignment

Submit Word-Lesson-8.docx.

Before Submitting

  • The document should contain a real Heading 1.
  • The hyperlink should have meaningful text.
  • Any informative image should have alt text.
  • Accessibility Checker should have been reviewed.

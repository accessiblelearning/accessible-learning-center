First-time setup and success checks

Lesson goal in plain language: Move efficiently through a worksheet, edit cells, find and replace information, and copy values without relying on a mouse.

Prepare before step 1

  1. Open the correct application, website, or device screen and wait for its name to be announced.
  2. Open Excel manual and review the matching procedure if any command or term is unfamiliar.
  3. Use only fictional, public, disposable, or instructor-provided practice information. Make a copy before changing an important file.
  4. Read all numbered instructions once before performing them so you know the intended final result.

Commands used or referenced

Ctrl+Home, Ctrl+End, Ctrl+G,, Enter, F2, Ctrl+F,, Escape, Ctrl+H., Ctrl+C,, Shift+Down, Ctrl+V., Ctrl+Arrow, F12, Insert+Spacebar,

For a plus-sign command, hold the modifier key, press and release the final key, then release the modifier. For a sequence, press and release each key in order. Stop after every command and listen for the result.

Work and verify

  1. Perform one numbered instruction and stop. Identify the active window, focused control, selected item, cell, slide, message, field, or device area before continuing.
  2. Compare the result with the lesson goal. A sound alone is not enough; verify the name, state, value, location, permission, or content.
  3. If the result is wrong, press Escape once to leave an unexpected menu, identify focus again, and use Undo only when the change is safely reversible.
  4. Save or synchronize at natural stopping points. Use the required filename Excel-Lesson-2.xlsx.
  5. Complete the “Before submitting” checklist from top to bottom. Correct missing items before marking the lesson complete.
  6. Close and reopen the practice item, or return to it from the product’s main screen, to prove you can locate and verify the result independently.

Success standard: Explain what each major command did, show the finished result, and recover from one harmless focus or navigation error without another person naming the next key.

Goal

Move efficiently through a worksheet, edit cells, find and replace information, and copy values without relying on a mouse.

Skills practiced

  • Move to data boundaries with Ctrl+Arrow.
  • Use Ctrl+G to go directly to a cell.
  • Edit a cell with F2.
  • Use Find and Replace.
  • Copy and paste a value or formula.

Step-by-step instructions

  1. Open Excel-Lesson-1.xlsx.
  2. Press Ctrl+Home to move to A1. Press Ctrl+End to move to the last used cell.
  3. Press Ctrl+G, type B3, and press Enter to move directly to cell B3.
  4. Press F2, change the department in B3 to Customer Service, and press Enter.
  5. Press Ctrl+F, type Employment, and press Enter to locate that word. Press Escape to close Find.
  6. Press Ctrl+H. Replace Training with Learning Services, then close the dialog.
  7. Add a fourth column header in D1 named Status.
  8. Type Active in D2. Copy D2 with Ctrl+C, select D3 through the last employee row with Shift+Down Arrow, and press Ctrl+V.
  9. Review the list with Ctrl+Arrow and Arrow keys.
  10. Press F12 or use File, Save As, and save a copy as Excel-Lesson-2.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Your assignment

Update the contact list so one department is Customer Service, Training is replaced with Learning Services, and every employee has Active in the Status column.

Save the finished assignment as Excel-Lesson-2.xlsx.

Before submitting

  • The original headers remain present.
  • Customer Service and Learning Services appear in the Department column.
  • Every employee row has Active in the Status column.
  • The file is saved as Excel-Lesson-2.xlsx.

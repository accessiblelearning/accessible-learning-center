Google Chrome keyboard shortcuts

Purpose: This manual teaches Google Chrome from the beginning to a person using a screen reader. It explains what to press, what browser region or webpage element should receive focus, what your screen reader should announce, and how to recover when the result is different.

Reference platform: This manual focuses on current Google Chrome on Windows 11.

Screen readers: Core Chrome keyboard commands are taught first. Narrator, NVDA, and JAWS are covered separately so browser and screen-reader commands stay distinct.

How to Use This Manual

  • Learn Chrome itself before memorizing screen-reader quick-navigation keys.

  • Ctrl+L, Alt+D, or F6 can move focus to the address bar.

  • Ctrl+T opens a new tab. Ctrl+W closes the current tab. Ctrl+Shift+T reopens recently closed tabs.

  • F6 cycles focus through Chrome's major browser areas.

  • Tab and Shift+Tab move through clickable controls.

  • Screen-reader browse/scan modes are used for structural webpage navigation.

  • F7 turns Caret Browsing on or off.

  • Alt+Shift+R opens Chrome Reading Mode on Windows when supported.

  • Ctrl+J opens Downloads, Ctrl+H opens History, and Ctrl+Shift+O opens Bookmark Manager.

  • Verify the website domain before entering passwords or sensitive information.

Part 1 - What Google Chrome Is

Google Chrome is a web browser. It displays webpages, web applications, PDFs, downloads, settings, extensions, history, bookmarks, and account/profile features.

  • Omnibox/address bar: where you type a website address or web search.

  • Tab: one open webpage or browser task.

  • Tab strip: area containing open tabs and tab groups.

  • Toolbar: browser controls such as Back, Reload, bookmark, extensions, profile, and Chrome menu.

  • Web content: the current webpage.

  • Bookmarks: saved website shortcuts.

  • History: previously visited pages.

  • Downloads: files downloaded through Chrome.

  • Extensions: optional add-ons that can change Chrome behavior.

Part 2 - Open Chrome and Learn the Window

2.1 Open Google Chrome

What you will learn: Start Chrome without using a mouse.

Before you begin: Chrome must be installed.

Exactly how to do it

  1. Press the Windows key.

  2. Type Chrome.

  3. Press Enter on Google Chrome.

  4. Wait for Chrome to open.

  5. Press F6 once.

  6. Listen to the browser region announced.

  7. Continue pressing F6 to hear the tab strip, address bar/toolbar, and page area.

  8. Press Shift+F6 to move backward.

What should happen: Chrome opens and you can identify its major focus areas.

If that does not happen: If F6 does not move, press Escape to close an open menu or popup and try again.

Practice: Open Chrome, cycle focus through the main areas, then return to the webpage.

Part 3 - Address Bar and Search

Task Command
Focus address bar Ctrl+L, Alt+D, or F6
Search from anywhere Ctrl+K or Ctrl+E
Open typed search/address in new tab Alt+Enter

3.1 Open a Website

What you will learn: Go directly to a known address.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+L.

  2. Type the website address, for example google.com.

  3. Press Enter.

  4. Wait for the page to load.

  5. Use the screen reader to confirm the page title or main heading.

What should happen: The website opens in the current tab.

If that does not happen: If search results appear, verify the address you typed.

Practice: Open two known websites.

3.2 Search the Web

What you will learn: Use the Omnibox as a search box.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+L.

  2. Type a search phrase.

  3. Press Enter.

  4. Wait for results.

  5. Use screen-reader heading and link navigation to review results.

What should happen: Search results appear.

If that does not happen: If Chrome stays on the previous page, make sure the Omnibox received focus before typing.

Practice: Search for three topics.

Part 4 - Tabs, Windows, and Tab Groups

Move tab left/right Ctrl+Shift+Page Up / Ctrl+Shift+Page Down

4.1 Open and Switch Tabs

What you will learn: Work with several webpages at once.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+T.

  2. Open a site or search.

  3. Press Ctrl+T and open a second site.

  4. Press Ctrl+Tab to move forward through tabs.

  5. Press Ctrl+Shift+Tab to move backward.

  6. Listen to each page title.

What should happen: The active tab changes.

If that does not happen: If only one tab exists, Ctrl+Tab may appear to do nothing.

Practice: Open three tabs and cycle through all three.

4.2 Restore a Closed Tab

What you will learn: Recover a tab closed by mistake.

Before you begin: Close a non-important tab.

Exactly how to do it

  1. Press Ctrl+Shift+T.

  2. Wait for the restored tab.

  3. Listen to the page title.

What should happen: The most recently closed tab reopens.

If that does not happen: Press Ctrl+Shift+T again to restore earlier tabs when available.

Practice: Close and restore two tabs.

4.3 Reach Tab Groups with the Keyboard

What you will learn: Access group controls when your Chrome setup uses tab groups.

Before you begin: At least one tab group exists.

Exactly how to do it

  1. Press F6 until the tabs are in focus.

  2. Press Tab or Shift+Tab to move among tab and group items.

  3. Focus the tab group header.

  4. Press Spacebar or Enter to collapse or expand it.

  5. Press the Menu/Application key or Shift+F10 to open its context menu.

What should happen: The group expands/collapses and the menu can be reached without a mouse.

If that does not happen: If no group header is announced, the current window may not contain a tab group.

Practice: Create or use a practice tab group and collapse/expand it.

5.1 Use Back and Forward

What you will learn: Move through recent pages in one tab.

Before you begin: Follow at least one link from a starting page.

Exactly how to do it

  1. Press Alt+Left Arrow.

  2. Listen for the previous page.

  3. Press Alt+Right Arrow.

  4. Listen for the newer page.

What should happen: Chrome moves through the tab's history.

If that does not happen: If nothing happens, the tab has no backward/forward history.

Practice: Navigate three pages and move backward/forward.

Part 6 - Webpage Keyboard Navigation

6.1 Move Through Clickable Page Controls

What you will learn: Use only Chrome keyboard focus navigation.

Before you begin: Open a page with several links or form controls.

Exactly how to do it

  1. Press Tab.

  2. Listen to the focused link, button, field, or control.

  3. Press Tab again.

  4. Press Shift+Tab to move backward.

  5. Press Enter to activate a focused link or button when intended.

  6. Press Spacebar to toggle many checkboxes/buttons.

What should happen: Focus moves through interactive webpage elements.

If that does not happen: If Tab stays in Chrome controls, press F6 until focus reaches page content.

Practice: Move through ten controls without activating them.

Part 7 - Find on Page

Task Command
Find on page Ctrl+F
Next match Ctrl+G
Previous match Ctrl+Shift+G

7.1 Find Text on the Current Page

What you will learn: Locate visible text quickly.

Before you begin: Open a long webpage.

Exactly how to do it

  1. Press Ctrl+F.

  2. Type a word or phrase.

  3. Press Enter if needed.

  4. Press Ctrl+G to move to the next match.

  5. Press Ctrl+Shift+G to move to the previous match.

  6. Press Escape to close Find.

What should happen: Chrome identifies matching text on the page.

If that does not happen: If Chrome reports zero matches, shorten the phrase or check spelling.

Practice: Find a repeated word on one page.

8.1 Save a Bookmark

Before you begin: Open a safe webpage.

Exactly how to do it

  3. Change the name if needed.

  4. Choose a folder.

  5. Activate Done/Save.

What should happen: The page is bookmarked.

If that does not happen: If Ctrl+D opens an unexpected command, verify Chrome has focus.

Before you begin: Have at least one bookmark.

Exactly how to do it

  3. Locate a bookmark.

  4. Press Enter to open it.

What should happen: The selected bookmark opens.

If that does not happen: If Bookmark Manager opens in a new tab, use Ctrl+Tab to return afterward.

Practice: Open one bookmark and return.

Part 9 - History

9.1 Review Browsing History

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+H.

  2. Use screen-reader navigation through the History page.

  3. Use the History search box if available.

Part 10 - Downloads

10.1 Open the Downloads Page

What you will learn: Review recent download status and files.

Before you begin: Have at least one known download or open the page empty.

Exactly how to do it

  1. Press Ctrl+J.

  2. Use screen-reader navigation through the Downloads page.

  3. Listen for filename, source, and status.

  4. Use Show in folder or Open only for files you trust.

What should happen: The Downloads page opens in a tab.

Part 11 - Forms and Interactive Controls

11.1 Complete a Web Form

What you will learn: Enter text and choose options safely.

Before you begin: Use a non-sensitive practice form.

Exactly how to do it

  1. Use Tab or your screen reader's form navigation to reach the first edit field.

  2. Type text.

  3. Press Tab to the next field.

  4. Press Spacebar on a checkbox.

  5. Use Arrow keys in radio-button groups.

  6. Use Alt+Down Arrow on a combo box if needed, then arrows and Enter.

  7. Review all fields before activating Submit.

What should happen: The form contains the intended values.

If that does not happen: If letter keys navigate the page instead of typing, switch the screen reader into direct-interaction/focus/forms mode.

Practice: Complete a practice form without submitting sensitive information.

Part 12 - Links and Context Menus

12.1 Inspect a Link Before Opening It

What you will learn: Reduce the chance of following misleading links.

Before you begin: Focus a link.

Exactly how to do it

  1. Listen to the link text.

  2. Use your screen reader's link-details command if available.

  3. Press Shift+F10 to open the link context menu.

  4. Review options such as Open link in new tab, Copy link address, or Save link as.

  5. Press Escape if you do not want to act.

What should happen: You can inspect available link actions without immediately following it.

If that does not happen: If the destination is suspicious or unexpected, do not open it.

Practice: Inspect three links on a trusted site.

Part 13 - PDFs in Chrome

Chrome includes a built-in PDF viewer. Accessibility depends heavily on whether the PDF contains real text and usable structure.

13.1 Open and Read a PDF

What you will learn: Read a PDF in Chrome using your screen reader.

Before you begin: Open a known accessible PDF.

Exactly how to do it

  1. Open the PDF from a website or press Ctrl+O and choose a local PDF.

  2. Wait for the PDF viewer.

  3. Use Tab/F6 and your screen reader to reach document content.

  4. Use Ctrl+F to search for a word.

  5. Use screen-reader reading/navigation commands to read.

What should happen: Accessible PDF text is exposed to the screen reader.

If that does not happen: If only 'image' or very little text is announced, the PDF may be scanned/image-only or poorly structured.

Practice: Open an accessible PDF and find one word.

Important: The browser cannot repair a fundamentally inaccessible PDF. Obtain an accessible version or use appropriate OCR/accessibility tools when necessary.

Part 14 - Reading Mode

14.1 Open Chrome Reading Mode

What you will learn: Read supported content in a simplified side panel.

Before you begin: Open an article-style webpage.

Exactly how to do it

  1. Press Alt+Shift+R.

  2. Wait for Reading Mode to open.

  3. Use Up/Down Arrow or Alt+Up/Alt+Down Arrow on Windows to move through Reading Mode text when appropriate.

  4. Use the Reading Mode controls to adjust text size, theme, or highlighting if desired.

  5. Close the Reading Mode side panel when finished.

What should happen: A simplified reading version of the page appears.

If that does not happen: Reading Mode does not work on every site, especially highly interactive pages, forms, maps, login pages, payment pages, or some forums.

Practice: Open Reading Mode on two article pages.

Read Aloud in Reading Mode: Current Chrome Reading Mode can also provide read-aloud controls and Google natural voices for supported languages.

Part 15 - Caret Browsing

15.1 Turn Caret Browsing On and Off

What you will learn: Use a text cursor to move and select webpage text.

Before you begin: Open a text-heavy webpage.

Exactly how to do it

  1. Press F7.

  2. Confirm the Caret Browsing prompt if shown.

  3. Use Arrow keys to move the text cursor.

  4. Hold Shift with Arrow keys to select text.

  5. Press F7 again to turn Caret Browsing off.

What should happen: A text cursor can move through page text.

If that does not happen: If F7 controls a laptop hardware function, use Fn+F7.

Practice: Turn it on, select one word, then turn it off.

Part 16 - Accessibility Settings, Live Caption, and Live Translate

16.1 Open Chrome Accessibility Settings

What you will learn: Reach browser accessibility options.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Alt+F.

  2. Move to Settings and press Enter.

  3. Use the Settings search box or navigation to open Accessibility.

  4. Review available accessibility options.

What should happen: Chrome's Accessibility settings appear.

If that does not happen: If Accessibility is not visible, type accessibility in Settings search.

Practice: Open Accessibility and review each option.

16.2 Turn Live Caption On or Off

What you will learn: Generate captions for audio playing in Chrome.

Before you begin: Open Settings > Accessibility.

Exactly how to do it

  1. Find Live Caption.

  2. Turn it on.

  3. If prompted, allow Chrome to download the needed language files.

  4. Play media with speech.

  5. Listen for/observe the caption bubble if using visual support.

  6. Return to Accessibility settings to turn Live Caption off when desired.

What should happen: Chrome generates captions for supported audio; Google states Live Caption audio/captions are processed locally and not stored or sent away for caption generation.

If that does not happen: If captions do not appear, confirm audio is playing and the selected caption language is supported.

Practice: Enable Live Caption, test with a safe video, then decide whether to keep it enabled.

16.3 Review Live Translate

What you will learn: Translate generated captions when the feature is available.

Before you begin: Live Caption is available and Accessibility settings are open.

Exactly how to do it

  1. Find Live Translate.

  2. Turn it on if you want translated captions.

  3. Choose the target language.

  4. Play supported media and verify the translated caption behavior.

What should happen: Captions can be translated to the selected language when supported.

If that does not happen: Availability and supported languages can change; if the control is missing, your Chrome version, language, or platform may not support it.

Practice: Review the setting without relying on it for critical interpretation.

17.1 Change Page Zoom

What you will learn: Adjust visual size for residual vision.

Before you begin: Open any page.

Exactly how to do it

  1. Press Ctrl+Plus twice.

  2. Press Ctrl+Minus once.

Part 18 - Profiles, Sign-In, and Sync

18.1 Review Chrome Profile and Sync

What you will learn: Understand what Chrome can synchronize.

Before you begin: Chrome is open.

Exactly how to do it

  1. Use F6/Shift+Alt+T or Tab to reach the profile control.

  2. Open the profile menu.

  3. If signed out, review the Sign in option.

  4. If signed in, open sync/profile settings.

  5. Review categories such as bookmarks, passwords, history, tabs, settings, addresses, and payment information before enabling them.

What should happen: You understand what profile/sync data is being shared across signed-in Chrome devices.

If that does not happen: On a shared/public device, do not enable persistent sign-in or sync without understanding the privacy impact.

Part 19 - Incognito, Privacy, Cookies, and Passwords

19.1 Open an Incognito Window

What you will learn: Use a temporary browsing session that does not keep normal local history after closing.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+Shift+N.

  2. Listen for Incognito mode.

  3. Browse as needed.

  4. Close the Incognito window with Alt+F4.

What should happen: An Incognito window opens.

If that does not happen: Incognito does not make you anonymous to websites, networks, employers/schools, or internet providers.

Practice: Open and close one Incognito window.

19.2 Review Password Settings

What you will learn: Find Chrome password-management controls safely.

Before you begin: Open Chrome Settings.

Exactly how to do it

  1. Use Settings search for passwords.

  2. Open Google Password Manager or the password section available in your version.

  3. Review options for saving passwords, autofill, passkeys, and password checks.

  4. Do not reveal stored passwords while others can hear or see your screen.

What should happen: You can locate Chrome password controls.

If that does not happen: Chrome/Windows may require authentication before revealing a stored password.

Practice: Review settings without revealing a password.

Cookies and site permissions: Use Settings > Privacy and security and Site settings to control cookies, notifications, camera, microphone, location, pop-ups, and other permissions.

Part 20 - Extensions and Accessibility Extensions

20.1 Review Installed Extensions

What you will learn: Understand what browser add-ons are installed.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Alt+F.

  2. Move to Extensions and open Manage extensions.

  3. Use screen-reader navigation through installed extensions.

  4. Review each extension name, enabled/disabled status, and permissions.

  5. Disable or remove only extensions you recognize and intend to change.

What should happen: You can identify installed extensions.

If that does not happen: Do not remove organization-required extensions on a managed device without permission.

Practice: Review your installed extensions.

Accessibility extensions: Google points users to the Chrome Web Store for accessibility extensions, including tools for contrast, color enhancement, and keyboard/caret navigation. Extensions can read or change webpage data, so install only trusted extensions with permissions you understand.

20.2 Install an Accessibility Extension Safely

What you will learn: Evaluate permissions before adding an extension.

Before you begin: You have identified a trusted extension from a legitimate source.

Exactly how to do it

  1. Open the Chrome Web Store listing.

  2. Read the extension name, publisher, description, and permissions.

  3. Activate Add to Chrome.

  4. Read the confirmation prompt.

  5. Choose Add extension only if the requested permissions make sense for its function.

  6. Test the extension on a safe page.

What should happen: The extension installs and appears in Chrome's extensions controls.

If that does not happen: If the permissions are broader than expected, cancel installation.

Practice: Practice reviewing an extension listing without necessarily installing it.

Part 21 - Security and Phishing

  • Press Ctrl+L and verify the full domain before entering passwords, financial information, or verification codes.

  • Do not trust a site merely because it uses HTTPS.

  • Do not bypass Chrome security warnings unless you independently know the destination/file is safe.

  • Unexpected downloads should not be opened.

  • Never install an extension because a random webpage claims it is required to continue.

  • Use known addresses or trusted bookmarks for banking, email, government, healthcare, and work sites.

  • Be suspicious of urgent requests for passwords, money, gift cards, or authentication codes.

21.1 Verify a Site Before Signing In

What you will learn: Check the address before entering credentials.

Before you begin: A page requests a username/password.

Exactly how to do it

  1. Press Ctrl+L.

  2. Read the full domain.

  3. Confirm it matches the legitimate service.

  4. Press Escape to leave the address bar unchanged.

  5. Only then return to the sign-in fields.

What should happen: You verify the site before entering credentials.

If that does not happen: If the domain is misspelled, shortened, unfamiliar, or unexpected, do not sign in.

Practice: Check three known legitimate domains.

Part 22 - Narrator with Chrome

Narrator uses Scan Mode for structural webpage reading and direct interaction mode for typing.

Task Command
Toggle Scan Mode Narrator+Spacebar
Next/previous heading H / Shift+H in Scan Mode
Webpage summary Narrator+S
Image description Narrator+Ctrl+D
Start/stop Narrator Windows+Ctrl+Enter

22.1 Navigate a Webpage with Narrator

What you will learn: Move by page structure.

Before you begin: Narrator is running and Chrome has a webpage open.

Exactly how to do it

  1. Turn Scan Mode on with Narrator+Spacebar if needed.

  2. Press H to move through headings.

  3. Press Shift+H to move backward.

  4. Press Tab through focusable links and controls.

  5. Press Enter on a link.

What should happen: Narrator moves through webpage structure.

If that does not happen: If letters type into a field, focus is probably inside an edit field or Scan Mode is off.

Practice: Navigate a page by headings and links.

22.2 Type in a Form with Narrator

What you will learn: Switch from Scan Mode to direct typing.

Before you begin: Focus an edit field.

Exactly how to do it

  1. Press Enter or Tab into the field.

  2. If letters still navigate, press Narrator+Spacebar to turn Scan Mode off.

  3. Type the text.

  4. Press Tab to the next control.

  5. Turn Scan Mode on again when you return to reading.

What should happen: Typing goes into the field.

If that does not happen: If letters continue to navigate, verify the edit field has focus.

Practice: Complete a practice form.

Practice: Complete a practice form.

Part 25 - Braille Displays with Chrome

Braille output comes through Narrator, NVDA, or JAWS. Chrome exposes webpage and browser accessibility information to the screen reader.

  • Braille should follow the address bar, browser buttons, headings, links, form fields, and webpage text.

  • Routing keys can move the caret or activate controls depending on the screen reader and current mode.

  • Browse/Scan/Virtual versus Focus/Forms mode affects both speech and braille.

  • Long URLs and link text may require panning.

  • Poorly labeled website controls will also be poorly labeled in braille.

25.1 Test Braille with Chrome

What you will learn: Verify browser and webpage access.

Before you begin: Connect/configure the display through your screen reader.

Exactly how to do it

  1. Press Ctrl+L and confirm the address appears in braille.

  2. Open a webpage.

  3. Move to a heading and link.

  4. Move to an edit field.

  5. Type using braille input if supported.

  6. Use a routing key if supported.

What should happen: Braille follows Chrome and supports input according to the screen reader.

If that does not happen: If braille works in other apps but not Chrome, first check focus and screen-reader mode.

Practice: Test address bar, heading, link, and form field.

Part 26 - Troubleshooting

26.1 You Are Stuck in Browser Controls

What you will learn: Return to webpage content.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Escape to close menus/popups.

  2. Press F6 until the page content is announced.

  3. Use your screen reader's heading command to confirm.

What should happen: Focus returns to the webpage.

If that does not happen: If needed, continue F6/Shift+F6 through Chrome regions.

Practice: Move to toolbar and recover twice.

26.2 Letter Keys Type Instead of Navigating

What you will learn: Restore the screen-reader browsing mode.

Before you begin: A webpage is open.

Exactly how to do it

  1. Narrator: turn Scan Mode on.

  2. NVDA: enter Browse Mode.

  3. JAWS: leave Forms Mode/return to Virtual Cursor.

  4. Make sure focus is not inside an edit field.

  5. Press H.

What should happen: H moves to a heading if one exists.

If that does not happen: If the page has no headings, use another structural key or test another page.

Practice: Practice mode recovery.

26.3 Letter Keys Navigate Instead of Typing

What you will learn: Enter the screen-reader interaction mode.

Before you begin: Focus an edit field.

Exactly how to do it

  1. Narrator: turn Scan Mode off if necessary.

  2. NVDA: enter Focus Mode.

  3. JAWS: enter Forms Mode.

  4. Type a short word.

What should happen: Text appears in the field.

If that does not happen: If not, the edit field may not actually have focus.

Practice: Practice direct typing.

26.4 Chrome Looks or Behaves Differently

What you will learn: Check state before resetting settings.

Before you begin: Chrome is open.

Exactly how to do it

  1. Press Ctrl+0 to reset zoom.

  2. Press F11 to check full-screen state.

  3. Press F7 to check Caret Browsing.

  4. Close Reading Mode if it is open.

  5. Check the active Chrome profile.

  6. Review recently installed extensions.

What should happen: You identify a likely cause before resetting Chrome.

If that does not happen: Resetting all settings should be a last resort after checking these simpler states.

Practice: Identify zoom, full screen, Caret Browsing, and profile state.

26.5 A PDF Is Not Readable

What you will learn: Determine whether the PDF itself lacks accessible content.

Before you begin: Open the PDF.

Exactly how to do it

  1. Try Ctrl+F for a visible word.

  2. Use screen-reader reading commands.

  3. Compare with a known accessible PDF.

  4. If only image content is exposed, seek an accessible version or use appropriate OCR tools.

What should happen: You distinguish a browser issue from an inaccessible-document issue.

If that does not happen: If accessible PDFs work normally, the specific PDF is the likely problem.

Practice: Compare two PDFs if available.

26.6 Chrome Became Unstable After Installing an Extension

What you will learn: Test whether an extension is causing the problem.

Before you begin: The problem began after adding/changing an extension.

Exactly how to do it

  1. Open Manage extensions.

  2. Disable the recently added extension.

  3. Restart the affected tab or Chrome if needed.

  4. Test the behavior again.

  5. Remove the extension only if you no longer trust/need it.

What should happen: The problem improves if that extension caused it.

If that does not happen: On a managed device, some extensions may be required and cannot be disabled.

Practice: Practice locating extension controls.

Your goal

Keep instructions in one tab, find a manual in another, bookmark it, and locate a harmless downloaded file. Explain recovery from a closed tab and verify each saved item.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Work with two tabs

What you will learn: Keep your instructions available while opening another page.

Exactly how to do it

  1. Press Ctrl+T and open a second familiar website.
  2. Use Ctrl+Page Up or Ctrl+Page Down to move between adjacent tabs.
  3. Close the practice tab with Ctrl+W. Reopen it with Ctrl+Shift+T.

What should happen: You can return to both pages.

If that does not happen: Confirm the active tab before closing it; closing the final tab may close the window.

Practice: Describe which page you expect before switching, then verify the title.

Source: Mozilla tab shortcuts.

Save and return to a useful page

Start here: The page you want to keep, open in Firefox.

Step-by-step instructions

  1. Press Ctrl+D. If a bookmark editor appears, Tab through its controls and locate the Name field. Give the bookmark a recognizable name such as “Learning Center — Firefox.”
  2. Review the folder/location choice. Choose a location you will recognize, then activate Save. If the page was already bookmarked, the editor may offer editing instead of a new save.
  3. Open the bookmark Library with Ctrl+Shift+O. Tab to its Search Bookmarks field, enter part of your saved name, and move to the matching results.
  4. Select the intended bookmark with arrow keys and press Enter to open it. Confirm the page heading or address matches what you saved.
  5. To rename or remove a practice bookmark, select it in the Library and use Shift+F10 to explore its context menu. Read the selected action before activating it. Removing a bookmark removes your saved link, not the website.

Check your result

You can close the original tab and still return through the saved bookmark.

If something goes wrong

If there is no match, clear the search and check its spelling and saved location. A website’s own search box is not the bookmark Library search.

Try it yourself

Save two pages with distinct names, close their original tabs, and reopen each through the Library.

Documentation: Mozilla bookmarks.

Download a file and find the saved copy

Start here: A page offering a harmless document you recognize. Know whether you want to save it or only view it.

Step-by-step instructions

  1. Tab to the document’s download link and activate it. Some document links first open a viewer; if so, locate that viewer’s labeled download control.
  2. If a Save dialog appears, read its current folder and File name. Choose a destination you can find, such as Downloads, and keep a meaningful filename. Activate Save. If no dialog appears, the browser may use its configured default folder.
  3. Open the Downloads list with Ctrl+J. Select the expected item and check whether it is complete, still transferring, or failed.
  4. For a completed item, explore its available actions with Tab or its context menu. Use the action that opens the containing folder to see the saved file in File Explorer.
  5. Check the filename and extension before opening it. If Windows asks which application to use, identify the file type rather than selecting an unrelated program.
  6. Close the file and return to its folder independently. Explain where the local copy is stored. Clearing a browser download-history entry is different from deleting that file.

Check your result

You can locate the completed file after leaving its original web page.

If something goes wrong

Do not repeatedly download while an existing transfer is still in progress. A failed or blocked transfer needs its status examined. If a duplicate filename has a number added, verify which copy is the one you intend to use.

Try it yourself

Record the destination folder and filename, then locate the file without using the original website.

Documentation: Mozilla downloads and file actions.

Microsoft screen reader support for OneNote

Purpose: This manual teaches current Microsoft OneNote from the beginning to a person using a screen reader. It explains what to press, where focus should move, what should be announced, and how to recover when the result is different.

Reference version: The main procedures are written for the current OneNote desktop app included with Microsoft 365 on Windows. Separate sections cover OneNote for the web, macOS/VoiceOver, mobile, and braille.

Important version note: The former OneNote for Windows 10 app reached end of support in October 2025. This guide therefore focuses on the current desktop OneNote app rather than the retired Windows 10 app.

How to Use This Manual

  • Learn OneNote's structure first: notebook, section, page, page title, and content block.

  • Use Ctrl+G to move to the notebook picker, Ctrl+Shift+G to move to sections, and Ctrl+Alt+G to move to pages.

  • Press Ctrl+T to create a section and Ctrl+N to create a page in the current section.

  • Press Tab from a page title to move into the page content area.

  • OneNote pages can contain several independent note containers; screen readers may announce them as content blocks.

  • Use Ctrl+E to search all notebooks and Ctrl+F to search the current page.

  • Use Ctrl+1 through Ctrl+9 for common note tags; Ctrl+0 removes note tags from selected notes.

  • Use F9 to synchronize all shared notebooks and Shift+F9 to synchronize the current shared notebook.

  • Save is normally automatic because OneNote synchronizes notebook changes.

  • Before sharing, verify which notebook you are sharing and whether it contains private sections/pages.

Part 1 - What OneNote Is

OneNote is a digital notebook application. Information is organized in a hierarchy rather than as separate files for every note.

  • Notebook: the top-level collection of notes.

  • Section: a major category within a notebook.

  • Section group: an optional folder-like grouping of sections.

  • Page: one note page inside a section.

  • Subpage: a page visually/structurally nested beneath another page.

  • Page title: the page's name and a key navigation cue.

  • Content block: a note container on the page. One page can contain several.

  • Tag: a marker such as To Do, Important, Question, or Contact.

  • Shared notebook: a notebook stored where other authorized people can collaborate.

Part 2 - Open OneNote and Learn the Structure

2.1 Open OneNote

What you will learn: Start OneNote without using a mouse.

Before you begin: OneNote must be installed.

Exactly how to do it

  1. Press the Windows key.

  2. Type OneNote.

  3. Press Enter on Microsoft OneNote.

  4. Wait for the app to open.

  5. Press Ctrl+G.

  6. Listen for the current notebook.

  7. Press Ctrl+Shift+G.

  8. Listen for the current section.

  9. Press Ctrl+Alt+G.

  10. Listen for the current page.

What should happen: You can identify the notebook, section, and page layers.

If that does not happen: If one shortcut does not move focus, press Escape to close menus/dialogs and try again.

Practice: Open OneNote and identify notebook, section, and page.

Focus map: Notebook, section, page, page title, and page content are separate focus locations. When a command behaves unexpectedly, identify which layer currently has focus.

Part 3 - Switch Notebooks

3.1 Switch to Another Open Notebook

What you will learn: Move between notebooks without hunting through the interface.

Before you begin: Have more than one notebook open.

Exactly how to do it

  1. Press Ctrl+G.

  2. Use Up/Down Arrow through the notebook list.

  3. Listen to each notebook name.

  4. Press Spacebar on the notebook you want.

  5. Wait for its last visited page to open.

  6. Press Ctrl+Shift+G to verify its sections.

What should happen: The selected notebook becomes active.

If that does not happen: If only one notebook is listed, another notebook has not been opened/synced into this OneNote profile.

Practice: Switch between two notebooks and return.

Part 4 - Create and Navigate Sections

4.1 Create a Section

What you will learn: Add a major category to the current notebook.

Before you begin: Open the notebook where the section belongs.

Exactly how to do it

  1. Press Ctrl+T.

  2. Listen for the new section name text box.

  3. Type a descriptive section name.

  4. Press Enter.

What should happen: A new section is created and named.

If that does not happen: If a new page appears unexpectedly, confirm you pressed Ctrl+T rather than Ctrl+N.

Practice: Create a section named Practice.

4.2 Navigate Sections

What you will learn: Move directly through section tabs.

Before you begin: The notebook has multiple sections.

Exactly how to do it

  1. Press Ctrl+Shift+G.

  2. Use Up/Down Arrow through sections as announced in your current layout.

  3. Stop on the desired section.

  4. Press Spacebar or Enter if necessary to activate it.

  5. Press Ctrl+Alt+G to move to that section's pages.

What should happen: The selected section becomes active and its pages are available.

If that does not happen: If arrows move within page text, Ctrl+Shift+G did not move focus to sections.

Practice: Move through every section once.

Part 5 - Create and Navigate Pages

5.1 Create a Page

What you will learn: Add a new note page to the current section.

Before you begin: Select the correct section first.

Exactly how to do it

  1. Press Ctrl+N.

  2. Listen for a new untitled page and page-title field.

  3. Type a descriptive page title.

  4. Press Enter.

  5. Begin typing page content.

What should happen: A new page is created at the end of the current section.

If that does not happen: If a new application window opens, verify the OneNote window had focus.

Practice: Create pages named Meeting Notes and Ideas.

5.2 Navigate Pages

What you will learn: Move among pages without searching.

Before you begin: The section has several pages.

Exactly how to do it

  1. Press Ctrl+Alt+G.

  2. Use Up/Down Arrow through page titles.

  3. Press Spacebar or Enter on the desired page.

  4. Listen for the page title.

  5. Press Tab once to move into the content area.

What should happen: The desired page opens and you can reach its notes.

If that does not happen: If Ctrl+Alt+G does not move to pages, close any dialog and try again.

Practice: Move among five pages and return to the first.

Part 6 - Page Titles and Content Blocks

6.1 Jump to the Page Title

What you will learn: Rename or review the page's title.

Before you begin: A page is open.

Exactly how to do it

  1. Press Ctrl+Shift+T.

  2. Listen for the page title.

  3. Edit the title if needed.

  4. Press Enter.

  5. Press Tab to move into the page content.

What should happen: Focus moves to the page title and then back to content.

If that does not happen: If Ctrl+Shift+T affects selected text instead, make sure OneNote—not a browser—is active.

Practice: Rename a practice page and rename it back.

6.2 Move Between Content Blocks

What you will learn: Understand OneNote's free-form note containers.

Before you begin: A page contains more than one note container.

Exactly how to do it

  1. Press Ctrl+A three times to select all content blocks on the page.

  2. Press Tab to move among the selected content blocks.

  3. Press Shift+Tab to move backward.

  4. Press Escape to cancel the block selection when finished.

What should happen: Focus cycles among note containers rather than only within one line of text.

If that does not happen: If Ctrl+A selects only text, press it additional times as documented until page content blocks are selected.

Practice: Create two separate note containers and move between them.

Beginner recommendation: For predictable screen-reader reading order, keep most notes in one main vertical content block unless separate containers are truly useful.

7.1 Edit a Note

What you will learn: Correct existing text precisely.

Before you begin: Place the caret in page text.

Exactly how to do it

  1. Use Ctrl+Left/Right Arrow to move by word.

  2. Use Left/Right Arrow to move by character.

  3. Use Backspace or Delete to remove incorrect text.

  4. Type the correction.

  5. Press Ctrl+Z if the change occurs in the wrong location.

What should happen: Only the intended text changes.

If that does not happen: If arrow keys move between OneNote interface elements, return to the page content area with Tab/F6 as appropriate.

Practice: Create and correct three errors.

7.2 Apply Formatting

What you will learn: Format selected text without retyping it.

Before you begin: Select a practice phrase.

Exactly how to do it

  1. Press Ctrl+B.

  2. Move the caret into the formatted text.

  3. Use your screen reader's formatting-information command if available.

  4. Press Ctrl+B again to remove bold when desired.

What should happen: The selected text toggles bold formatting.

If that does not happen: If newly typed text stays bold unintentionally, press Ctrl+B once more to turn bold off.

Practice: Bold, italicize, and underline separate phrases.

Part 8 - Lists and Outlines

Task Command
Bulleted list Ctrl+Period
Numbered list Ctrl+Forward slash or Ctrl+Shift+O
Increase indent/outline level Tab
Decrease indent/outline level Shift+Tab
Move paragraph up/down Alt+Shift+Up / Alt+Shift+Down
Increase/decrease paragraph indent Alt+Shift+Right / Alt+Shift+Left

8.1 Create a Bulleted List

What you will learn: Create a structured list of related notes.

Before you begin: Place the caret on a blank line.

Exactly how to do it

  1. Press Ctrl+Period.

  2. Type the first item.

  3. Press Enter.

  4. Type the second item.

  5. Press Enter.

  6. Type the third item.

  7. Press Enter twice or toggle the list command off to leave the list.

What should happen: OneNote creates a bulleted list.

If that does not happen: If a period is typed instead of creating a list, confirm Ctrl is held with the Period key.

Practice: Create a three-item list.

8.2 Create an Outline

What you will learn: Build hierarchical notes.

Before you begin: Start a bulleted or plain-text outline.

Exactly how to do it

  1. Type a top-level item and press Enter.

  2. Press Tab to indent one level.

  3. Type a subordinate item.

  4. Press Enter.

  5. Press Shift+Tab to return one level.

  6. Use Alt+Shift+Up/Down to reorder selected paragraphs.

What should happen: The note structure gains levels that can be collapsed/expanded in supported contexts.

If that does not happen: If Tab inserts a tab character, place the caret at the beginning of the paragraph/list item.

Practice: Create a two-level outline.

Part 9 - Note Tags

9.1 Apply a To Do Tag

What you will learn: Turn a line into a trackable task marker.

Before you begin: Place the caret in a note line.

Exactly how to do it

  1. Press Ctrl+1.

  2. Listen for the tag/checkbox announcement if your screen reader reports it.

  3. Press Ctrl+1 again when you want to mark/select/clear the To Do state according to the current note context.

  4. Use Ctrl+0 when you need to remove tags from selected notes.

What should happen: The note is tagged as a To Do item.

If that does not happen: If the shortcut produces a literal number, the page content may not have focus.

Practice: Tag three action items.

Part 10 - Tables

10.1 Create a Quick Table

What you will learn: Turn typed text into a table with Tab.

Before you begin: Place the caret on a blank line.

Exactly how to do it

  1. Type the first cell text.

  2. Press Tab.

  3. Type the next cell.

  4. Press Tab.

  5. Continue entering cells.

  6. When the caret is in the last table cell, press Tab to create another cell/row.

  7. Use Ctrl+Enter inside a table cell when you intentionally want to insert a row below.

What should happen: OneNote creates and extends a table.

If that does not happen: If Tab simply indents text, the initial context may not be creating a table; use Insert > Table instead.

Practice: Create a 3-column table with two data rows.

Accessibility: Keep OneNote tables simple. Avoid using a complex table when headings or lists would communicate the information more clearly.

Part 11 - Links, Files, Pictures, and Alt Text

11.1 Insert a Hyperlink

What you will learn: Create useful linked text.

Before you begin: Select meaningful text.

Exactly how to do it

  1. Press Ctrl+K.

  2. Enter or paste the destination address.

  3. Press Enter.

  4. Read the linked phrase and confirm it describes the destination.

What should happen: The selected text becomes a hyperlink.

If that does not happen: If the visible text is only a long raw URL, replace it with descriptive text when the URL itself is not needed.

Practice: Create one descriptive link.

11.2 Add Alt Text to a Picture

What you will learn: Describe a meaningful image.

Before you begin: Insert or select a picture.

Exactly how to do it

  1. Open the picture's context menu with Shift+F10.

  2. Find the Alt Text or accessibility-related command available in your version.

  3. Enter a concise description of the image's purpose/content.

  4. Close the pane/dialog.

What should happen: The image has alternative text for screen-reader users.

If that does not happen: If Alt Text is not available in the context menu, use the Ribbon or Accessibility Checker to reach the control.

Practice: Add alt text to a practice image.

Embedded files: Microsoft accessibility guidance recommends alternative text for important visuals and embedded files, along with meaningful link text and descriptive section/page names.

Part 12 - Search OneNote

Task Command
Search all notebooks Ctrl+E
Search current page Ctrl+F

12.1 Search All Notebooks

What you will learn: Find a note even when you do not remember where it is stored.

Before you begin: Know one distinctive word or phrase.

Exactly how to do it

  1. Press Ctrl+E.

  2. Type the search term.

  3. Use Arrow keys through results.

  4. Listen for notebook/section/page context when announced.

  5. Press Enter on the desired result.

What should happen: OneNote opens the matching page/result.

If that does not happen: If results are too broad, type a more distinctive phrase or narrow the search scope from the search controls.

Practice: Search for one word across several notebooks.

12.2 Search the Current Page

What you will learn: Locate one phrase on a long page.

Before you begin: Open a page with several paragraphs.

Exactly how to do it

  1. Press Ctrl+F.

  2. Type the phrase.

  3. Move through matches.

  4. Press Escape when finished.

What should happen: OneNote highlights/navigates matching text on the current page.

If that does not happen: If the search finds results elsewhere, verify you used Ctrl+F rather than Ctrl+E.

Practice: Find three terms on one page.

Part 13 - Audio Notes

Task Command
Start a new audio recording Ctrl+Alt+A
Play selected audio Ctrl+Alt+P
Stop audio playback Ctrl+Alt+S
Back 10 seconds Ctrl+Alt+Y
Forward 10 seconds Ctrl+Alt+U

13.1 Record an Audio Note

What you will learn: Capture audio associated with a page.

Before you begin: Use a non-confidential practice notebook and confirm microphone permission.

Exactly how to do it

  1. Place the caret where the recording should be associated.

  2. Press Ctrl+Alt+A.

  3. Speak a short practice sentence.

  4. Use the recording controls to stop recording.

  5. Select the audio item.

  6. Press Ctrl+Alt+P to play it.

  7. Press Ctrl+Alt+S to stop playback.

What should happen: An audio recording is attached to the page and can be played.

If that does not happen: If recording does not start, check microphone permissions and whether another application is using the microphone.

Practice: Record and play a short harmless note.

Privacy: Audio recording can capture people who did not expect to be recorded. Follow consent, workplace, school, and local legal requirements.

Part 14 - Move, Copy, Rename, and Delete Pages/Sections

14.1 Move a Page Up or Down

What you will learn: Reorder pages in the current section.

Before you begin: Focus the page list.

Exactly how to do it

  1. Press Ctrl+Alt+G.

  2. Use Up/Down Arrow to select the page.

  3. Press Shift+Alt+Up or Shift+Alt+Down.

  4. Listen for the page's new position.

What should happen: The page moves within the section.

If that does not happen: If the text paragraph moves instead, focus is still in page content rather than the page list.

Practice: Move a practice page and move it back.

14.2 Delete a Page

What you will learn: Remove a page deliberately.

Before you begin: Focus the page in the page list.

Exactly how to do it

  1. Press Ctrl+Alt+G.

  2. Select the disposable page.

  3. Press Shift+F10.

  4. Move to Delete page.

  5. Activate it.

  6. Confirm if prompted.

What should happen: The page is removed.

If that does not happen: Always read the page title before deleting. Shared notebooks may affect other collaborators.

Practice: Create and delete a disposable page.

14.3 Move a Section

What you will learn: Reorder sections within a notebook.

Before you begin: Focus the sections pane.

Exactly how to do it

  1. Press Ctrl+Shift+G.

  2. Select the section.

  3. Press Shift+Alt+Up or Shift+Alt+Down.

  4. Listen for the new order.

What should happen: The section changes position.

If that does not happen: If the command changes a paragraph, return to the sections pane.

Practice: Move the Practice section and restore its position.

Part 15 - Section Groups

15.1 Create a Section Group

What you will learn: Group related sections in a large notebook.

Before you begin: Open a notebook with several sections.

Exactly how to do it

  1. Press Ctrl+Shift+G.

  2. Press Shift+F10.

  3. Move to New section group.

  4. Press Spacebar or Enter.

  5. Type a descriptive group name.

  6. Press Enter.

What should happen: A new section group is created.

If that does not happen: If the context menu opens for a page, press Ctrl+Shift+G before retrying.

Practice: Create a section group named Archive Practice.

15.2 Move a Section into a Section Group

What you will learn: Organize existing sections.

Before you begin: Focus the section.

Exactly how to do it

  1. Press Ctrl+Shift+G.

  2. Select the section.

  3. Press Shift+F10.

  4. Choose Move or Copy.

  5. Find the destination section group.

  6. Select it and complete the Move action.

What should happen: The section moves into the section group.

If that does not happen: If you need the section in both places, use Copy rather than Move when the dialog offers it.

Practice: Move a practice section and return it.

Part 16 - Sharing and Collaboration

16.1 Share a Notebook

What you will learn: Give another person access to a notebook rather than a single isolated page.

Before you begin: Use a notebook appropriate for sharing.

Exactly how to do it

  1. Open the Share command from the Ribbon/File area.

  2. Enter the recipient's email address.

  3. Review the permission level offered by your Microsoft 365/OneDrive/SharePoint environment.

  4. Read the notebook name again.

  5. Add a message if needed.

  6. Activate Send/Share.

What should happen: The recipient receives access according to the selected permission.

If that does not happen: OneNote sharing is generally notebook-based. Do not share a notebook that contains private sections just because one page is safe.

Practice: Inspect sharing controls on a practice notebook without sending.

Collaboration: Shared notebooks can synchronize other people's edits. Use descriptive page/section names so collaborators can navigate changes efficiently.

Part 17 - Sync and Offline Behavior

Task Command
Synchronize all shared notebooks F9
Synchronize current shared notebook Shift+F9

17.1 Force a Sync

What you will learn: Check whether recent changes synchronize.

Before you begin: Use a notebook stored in OneDrive or SharePoint.

Exactly how to do it

  1. Press Shift+F9 to sync the current shared notebook.

  2. Wait for any synchronization status message.

  3. Press F9 when you want to synchronize all shared notebooks.

  4. Check whether another device/web view reflects the updated page when practical.

What should happen: OneNote attempts to synchronize changes.

If that does not happen: If sync fails, check internet access, Microsoft account sign-in, storage, permissions, and any notebook sync error message.

Practice: Create a harmless test note and force a sync.

Offline behavior: OneNote can cache notes locally, but cloud collaboration depends on later synchronization. Avoid assuming another person has seen a change until sync completes.

Part 18 - Accessibility Checker and Accessible Notebook Design

  • Give notebooks, section groups, sections, and pages unique descriptive names.

  • Remove unused empty pages/sections that create navigation noise.

  • Add alt text to meaningful pictures and embedded files.

  • Use meaningful hyperlink text.

  • Do not use color alone to convey meaning.

  • Use readable contrast and formatting.

  • Keep tables simple.

  • Prefer one predictable vertical reading order rather than scattering many note containers around the canvas.

  • Run Accessibility Checker before sharing important notebook content.

  • Use Immersive Reader as an additional way to review how note text flows.

18.1 Run Accessibility Checker

What you will learn: Find common barriers before sharing.

Before you begin: Open a representative page/notebook.

Exactly how to do it

  1. Open Review or the accessibility controls available in your current OneNote version.

  2. Choose Check Accessibility.

  3. Move through issues in the accessibility pane.

  4. Read why each issue matters.

  5. Correct missing alt text, vague page names, poor links, or other issues.

  6. Recheck.

What should happen: The notebook has fewer accessibility barriers.

If that does not happen: If Accessibility Checker is unavailable in the current view/device, open the notebook in the full desktop or web OneNote version where Microsoft provides the checker.

Practice: Fix at least two practice issues.

19.1 Navigate OneNote with Narrator

What you will learn: Use OneNote focus shortcuts while Narrator announces context.

Before you begin: Narrator is on and OneNote is open.

Exactly how to do it

  1. Press Ctrl+G and choose a notebook.

  2. Press Ctrl+Shift+G and choose a section.

Part 20 - NVDA with OneNote

20.1 Navigate and Review with NVDA

What you will learn: Use standard OneNote focus while NVDA reports controls/text.

Before you begin: NVDA is running.

Exactly how to do it

  1. Press Ctrl+G to choose a notebook.

  2. Press Ctrl+Shift+G for sections.

  3. Press Ctrl+Alt+G for pages.

  4. Press NVDA+Tab when you want NVDA to repeat the focused control/item.

Part 21 - JAWS with OneNote

21.1 Navigate OneNote with JAWS

What you will learn: Use OneNote structure while JAWS provides speech/help.

Before you begin: JAWS is running.

Exactly how to do it

  1. Press Ctrl+G for notebooks.

  2. Press Ctrl+Shift+G for sections.

  3. Press Ctrl+Alt+G for pages.

  4. Press Insert+Tab to repeat the focused item when needed.

  5. Press Tab into the page content.

  6. Use Insert+H or Command Search when you need JAWS help.

What should happen: JAWS follows OneNote hierarchy and page content.

If that does not happen: If a JAWS command conflicts with OneNote, use JAWS help and OneNote's official shortcut list rather than guessing.

Practice: Navigate through two notebooks and several pages.

Part 22 - VoiceOver and OneNote for Mac

OneNote for Mac uses different shortcuts and VoiceOver interaction patterns. Microsoft documents VoiceOver-compatible navigation for the Mac app.

  • Use VoiceOver interaction commands to enter notebook, section, page, and content areas.

  • Microsoft documents Command+Control+G to move keyboard focus to the page list.

  • Microsoft documents Control+Shift+G to move keyboard focus to the section list.

  • Use Command+S to synchronize the current notebook and Command+Shift+S to synchronize all notebooks.

  • Use VoiceOver's VO+Tab pass-through when a OneNote shortcut conflicts with a VoiceOver command.

Practice: On Mac, identify notebook, section, page list, page title, and content using VoiceOver before relying on memorized Windows commands.

Part 23 - OneNote for the Web

OneNote for the web runs inside a browser. Microsoft recommends Microsoft Edge for the web version and notes that browser-based shortcuts differ from the desktop app.

  • Use Ctrl+F6 rather than desktop F6 to move among web application command regions.

  • Narrator is tested in Microsoft Edge; JAWS and NVDA are also tested in Chrome in Microsoft's accessibility documentation.

  • Browser shortcuts such as Ctrl+O and F1 apply to the browser rather than the OneNote desktop app.

  • Use the web version when you need access from a computer without the desktop OneNote app.

  • Expect some advanced features to be simplified compared with desktop OneNote.

Part 24 - Braille Displays

Braille output and input are provided through Narrator, NVDA, JAWS, or VoiceOver. OneNote exposes the notebook hierarchy, page text, tags, links, and controls to the screen reader.

24.1 Test Braille with OneNote

What you will learn: Verify output, input, and routing.

Before you begin: Configure the braille display in the active screen reader.

Exactly how to do it

  1. Press Ctrl+G and read notebook names in braille.

  2. Press Ctrl+Shift+G and read section names.

  3. Press Ctrl+Alt+G and read page titles.

  4. Open a page and Tab into its content.

  5. Type a short note using braille input if supported.

  6. Use a routing key inside the text if supported.

What should happen: Braille follows OneNote focus and page editing.

If that does not happen: If braille works in other apps but not OneNote, verify OneNote focus before changing braille settings.

Practice: Test notebook, section, page, text input, and routing.

Part 25 - iPhone/iPad and Android

25.1 iPhone/iPad with VoiceOver

  • Swipe right/left to move VoiceOver focus; double-tap to activate.

  • OneNote organizes notebooks into sections and pages; VoiceOver may announce page note containers as content blocks.

  • Use the Notebooks/Recent Notes areas to find content quickly.

  • Use the VoiceOver rotor for efficient text and control navigation.

  • Test sharing and deletion commands carefully because mobile menus can change with app updates.

25.2 Android with TalkBack

  • Swipe right/left to move TalkBack focus; double-tap to activate.

  • Use the notebook, section, and page lists to move through the hierarchy.

  • Use standard TalkBack text-editing gestures/keyboard commands in page content.

  • Microsoft recommends using the built-in TalkBack screen reader as one way to review notebook navigation order.

Part 26 - Security and Privacy

  • OneNote notebooks can contain highly sensitive information such as meeting notes, passwords copied by mistake, client/student information, or recordings.

  • Do not store passwords or authentication codes in ordinary notebook pages unless an approved secure process explicitly permits it.

  • Before sharing a notebook, inspect all sections—not only the page you intend the recipient to read.

  • Password-protected sections are not a substitute for organization-wide information-security policy.

  • Audio notes can record other people; follow consent and local/legal/workplace requirements.

  • Synced notebooks may exist on multiple devices and cloud services.

  • Delete or move sensitive content only when you understand how sync affects the cloud and collaborators.

Password-protected sections: Microsoft documents Ctrl+Alt+L to lock all password-protected sections. Remember that forgotten OneNote section passwords generally cannot simply be recovered by Microsoft.

Part 27 - Troubleshooting

27.1 You Are Typing in the Wrong Place

What you will learn: Return to the intended page content area.

Before you begin: OneNote is open.

Exactly how to do it

  1. Press Escape to close menus/dialogs.

  2. Press Ctrl+Alt+G and select the intended page.

  3. Press Tab once to enter page content.

  4. Type one test character.

  5. Undo with Ctrl+Z.

What should happen: Typing occurs on the intended page.

If that does not happen: If focus remains on the title, press Tab again.

Practice: Practice recovering from the page list.

27.2 You Cannot Find a Page

What you will learn: Search rather than scanning every section.

Before you begin: Know one distinctive word or phrase.

Exactly how to do it

  1. Press Ctrl+E.

  2. Type the search term.

  3. Review results.

  4. Open the matching page.

  5. If you only need the current page, use Ctrl+F instead.

What should happen: You locate the note through search.

If that does not happen: If results are stale, force sync and search again.

Practice: Find one page by text rather than page title.

27.3 Sync Is Stuck

What you will learn: Separate network/account problems from note-editing problems.

Before you begin: A cloud notebook is not updating.

Exactly how to do it

  1. Press Shift+F9.

  2. Listen for sync status/errors.

  3. Verify internet access.

  4. Verify the correct Microsoft account is signed in.

  5. Check whether the notebook is stored in OneDrive/SharePoint and you still have permission.

  6. Resolve any named sync conflict/error before creating duplicate notebooks.

What should happen: The cause becomes clearer or sync resumes.

If that does not happen: Avoid repeatedly copying the whole notebook as a troubleshooting step; this can create conflicting versions.

Practice: Force sync and inspect status.

27.4 A Page or Section Moved Unexpectedly

What you will learn: Use hierarchy shortcuts to reestablish location.

Before you begin: You feel lost after reorganizing.

Exactly how to do it

  1. Press Ctrl+G and confirm the notebook.

  2. Press Ctrl+Shift+G and review sections/section groups.

  3. Press Ctrl+Alt+G and review pages.

  4. Use Ctrl+E search if the item still cannot be found.

What should happen: You rebuild notebook context and find the item.

If that does not happen: If another collaborator moved content, check shared-notebook activity/version information where available.

Practice: Practice recovering after moving a practice page.

27.5 Content Blocks Read in a Confusing Order

What you will learn: Simplify free-form page layout.

Before you begin: A page has several scattered note containers.

Exactly how to do it

  1. Use Ctrl+A three times and Tab/Shift+Tab to inspect content blocks.

  2. Identify the intended reading sequence.

  3. Move important text into one main vertical note container where practical.

  4. Use headings/lists instead of visual spatial placement to express structure.

  5. Run Accessibility Checker again.

What should happen: The page becomes more predictable for screen-reader reading.

If that does not happen: Free-form spatial layouts can be visually useful but harder for assistive technology; prioritize logical order on shared accessible pages.

Practice: Simplify one practice page.

No-cost course rule

This course must not require a purchase, subscription, paid trial, payment card, or new paid service. LibreOffice is free and open source. Google Docs editors and Microsoft 365 for the web have free account-based options, but internet access, account rules, storage limits, and available features can differ.

Use an employer-approved program and account for workplace information. A free personal account is not automatically approved for client or organizational data.

Accessibility comes before feature count

Before choosing a program, test the actual work tasks with the learner’s preferred screen reader, Braille display, magnification, browser zoom, color settings, and keyboard. Confirm that focus is announced, controls have useful names, editing feedback is understandable, and essential tasks do not require a mouse.

  • Use descriptive headings, real lists, clear table headers, meaningful links, alternative text, sufficient contrast, and logical reading order.
  • Do not communicate meaning only through color or visual position.
  • Run the program’s accessibility checker when available, but also perform a keyboard and screen-reader review.
  • Keep an original editable file before exporting PDF or converting formats.

Native and exchange formats

LibreOffice native formats
ODT for Writer, ODS for Calc, and ODP for Impress preserve LibreOffice editing features.
Microsoft exchange formats
DOCX, XLSX, and PPTX are often required by employers or instructors using Microsoft 365.
Other formats
CSV carries plain spreadsheet data without formulas or formatting. PDF is useful for fixed-layout review but may be harder to edit and must be checked for accessibility.

Save the native version first. Then save or download a separate exchange copy and review it in the receiving program whenever possible.

JAWS, Narrator, and NVDA

Interfaces vary by program and update. Use Tab and Shift+Tab for controls, arrow keys within menus and lists, Enter or Space to activate, Alt or F10 for menus when supported, Ctrl+S to save, Ctrl+O to open, and Ctrl+Z to undo. Listen for the current control name and state instead of memorizing screen position.

  • JAWS: Use Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help.
  • NVDA: Use NVDA+T for the title, NVDA+Tab for focus, and NVDA+1 for Input Help.
  • Narrator: Use Caps Lock+T for the title and Caps Lock+1 for Input Learning. Toggle Scan Mode only when the application or webpage requires it.

Browser-based editors may have their own screen-reader-support setting and keyboard shortcuts. Read the current official help before changing screen-reader modes.

Compatibility review

  1. Keep an untouched native copy.
  2. Create a separate DOCX, XLSX, PPTX, CSV, or PDF copy.
  3. Read every heading, cell range, slide title, link, table, image description, formula result, note, and page or slide count.
  4. Check fonts, spacing, page breaks, charts, animations, formulas, comments, and accessibility metadata.
  5. Correct the native file and export again rather than repeatedly converting the same exchange copy.

Never promise perfect compatibility without testing the actual document in the receiving software.

Privacy, accounts, and sharing

Use fictional or public information in these lessons. Do not upload client records, medical or disability information, passwords, financial data, or confidential workplace material. For cloud tools, confirm the active account and sharing permission before entering content. For local tools, back up files to an approved location.

Basic procedure

1. Install Safely, Open Writer, and Identify the Window

What you will learn: Document the official download source, open Writer, and identify menus, toolbars, document area, and status information.

Before you begin: Open the application and a fictional, instructor-provided, or nonprivate practice file. Save a separate working copy before making major changes.

Exactly how to do it

  1. Read the LibreOffice Writer manual sections on accessibility, screen readers, file formats, and compatibility.
  2. Open LibreOffice Writer and confirm the window title or browser tab, active file, and current account when applicable.
  3. Navigate the main controls using only the keyboard. Record the labels announced by JAWS, Narrator, or NVDA.
  4. Document the official download source, open Writer, and identify menus, toolbars, document area, and status information.
  5. Save frequently in the program’s preferred editable format. If working in a browser, confirm that changes are saved before closing.
  6. Review the work from the beginning using keyboard and screen-reader navigation. Correct unclear structure, labels, or data.
  7. Create a separate Microsoft-compatible or requested exchange copy. Do not overwrite the editable original.
  8. Open or re-import the exchange copy when possible and compare content, formatting, formulas, notes, links, and accessibility.
  9. Write a short compatibility report naming anything that changed and how it was corrected.
  10. Save the submission using the filename libreoffice-writer-Lesson-1.odt.

Screen-reader help: Use Tab and Shift+Tab for controls and listen to the current accessible name. JAWS users can use Insert+Tab, NVDA users NVDA+Tab, and Narrator users Scan Mode commands when appropriate. Application and web-editor commands may differ after updates.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Document the official download source, open Writer, and identify menus, toolbars, document area, and status information.

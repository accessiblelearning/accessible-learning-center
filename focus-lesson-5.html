Goal

Create Focus-Lesson-5.txt or DOCX containing a short corrected workplace note.

Step-by-step instructions

  1. Confirm BrailleIn is enabled in JAWS for the Focus.
  2. Open a blank practice document and type a sentence with the Perkins-style keys.
  3. Enter a space, new line, punctuation, and a capital letter using the configured braille input table.
  4. Compare contracted and uncontracted input only if the instructor has enabled both.
  5. Use cursor routing and Backspace to correct an intentional error.
  6. Save the document with a descriptive filename and proofread it in braille.

JAWS and braille tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Focus commands vary by device generation, JAWS settings, application, and connection method; use the official guide linked from the manual when a command differs.

Your assignment

Create Focus-Lesson-5.txt or DOCX containing a short corrected workplace note.

Use fictional, public, instructor-provided, or redacted information only. Never submit passwords, pairing codes, serial numbers, protected books, or private workplace data.

Save your work with a clear filename beginning Focus-Lesson-5.

Before submitting

  • All requested steps are complete.
  • The file contains no credentials or sensitive information.
  • Commands are identified as Focus, JAWS, Windows, or application commands.
  • The filename identifies Focus 40 Blue Lesson 5.

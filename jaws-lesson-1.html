JAWS Lesson 1

Starting JAWS, Speech Control, and Keyboard Help

JAWS manual All JAWS lessons My progress

Goal

Start and identify JAWS, control speech safely, and use built-in keyboard help to learn commands.

Skills practiced

  • Identify the JAWS modifier key for desktop and laptop layouts.
  • Read the active window title and focused control.
  • Stop speech, start Say All, and adjust speech rate temporarily.
  • Use Keyboard Help without accidentally activating commands.

Step-by-step instructions

  1. Start JAWS from the Windows Start menu. Wait until JAWS announces that it is ready.
  2. Press Insert+T to hear the title of the active window. On a laptop layout, use Caps Lock as the JAWS key when required.
  3. Press Insert+Tab to hear the currently focused control and its prompt.
  4. Press Ctrl once to stop speech. This interrupts speech without closing JAWS.
  5. Press Insert+Down Arrow to begin Say All. Press Ctrl to stop.
  6. During Say All, press Page Up or Page Down to temporarily increase or decrease the reading rate.
  7. Press Insert+1 on the numbers row to turn Keyboard Help on.
  8. Press several keys, including Tab, F6, and Insert+T, and listen to their descriptions. Commands are described rather than performed while Keyboard Help is on.
  9. Press Insert+1 again to turn Keyboard Help off.
  10. Open Notepad and write a short skills log describing what each command did. Save it as JAWS-Lesson-1.txt.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

Your assignment

Create a skills log that names the JAWS modifier key you used and explains Insert+T, Insert+Tab, Ctrl, Insert+Down Arrow, and Insert+1.

Save the finished assignment as JAWS-Lesson-1.txt. DOCX, PDF, and BRF versions are also accepted.

Before submitting

  • The file names the keyboard layout used.
  • At least five commands are explained in the student’s own words.
  • The student confirms Keyboard Help was turned off.
  • The file is named JAWS-Lesson-1.txt.

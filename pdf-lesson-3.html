Accessible PDFs Lesson 3

Links, Bookmarks, Lists, and Tables

Accessible PDFs manualAll Accessible PDFs lessonsMy progress

Goal

Evaluate structure in a public PDF without changing it.

Step-by-step instructions

  1. Navigate links with Tab or JAWS link commands.
  2. Activate only a safe public link and return with Alt+Left Arrow.
  3. Use bookmarks to jump between major sections.
  4. Identify one real list and confirm item boundaries.
  5. Navigate a simple tagged table with JAWS table commands.
  6. Record any element that is not announced clearly.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Evaluate structure in a public PDF without changing it.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Pdf-Lesson-3.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Accessible PDFs Lesson 3.

Windows 11 Lesson 1

Desktop, Start Menu, Search, and Taskbar

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Navigate the Windows 11 desktop, launch applications, and identify taskbar areas without a mouse.

Skills practiced

  • Move to and review the desktop.
  • Search from Start and launch an application.
  • Navigate taskbar buttons and pinned applications.
  • Identify the active window before taking action.

Step-by-step instructions

  1. Press Windows+D to move to the desktop.
  2. Use Arrow keys to review desktop items. Press Home and End to move to the first and last item.
  3. Press the Windows key, type Notepad, and press Enter.
  4. Press Alt+Tab once and confirm the active application with Insert+T when using JAWS.
  5. Press Windows+T to move to the first taskbar button. Use Left and Right Arrow to review buttons.
  6. Press Shift+F10 on a taskbar item to open its context menu, then press Escape without changing anything.
  7. Press the Windows key and search for Calculator. Press Enter to open it.
  8. Use Alt+Tab to move among Notepad and Calculator.
  9. Return to Notepad and write the commands practiced and what each one did.
  10. Save the file as Windows-Lesson-1.txt.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

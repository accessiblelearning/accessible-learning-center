Your goal

Open a practice document, record current magnification and speech settings, and switch between it and the product controls without losing the document.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Prepare a usable setup before changing preferences

Start here: Windows with the licensed product installed. Keep your existing access method available while checking a new setup.

Step-by-step instructions

  1. Identify the installed application by its name in Windows Start: ZoomText or Fusion. If neither is installed, use the official ZoomText downloads or your organization’s approved Fusion installer. Installation and activation may need an administrator.
  2. Launch only the intended product for this exercise. In its interface, open Help or About using the keyboard-accessible menu and record the name and version. Record whether you have magnification only, Magnifier/Reader, or Fusion.
  3. For Fusion, identify the configured JAWS keyboard layout before using the two-column command table below. If you do not know it, use the labeled toolbar controls while you check the installed help or ask the person who configured the device.
  4. Open a short, non-sensitive text document with a heading and two paragraphs. Put these instructions in a separate window so you can switch back using Alt+Tab.
  5. Write down the current magnification level and speech setting before making changes. Change one setting, inspect the result, and restore it if it makes the exercise harder.

Check your result

You have a known product, a practice document, and a recorded baseline to return to.

If something goes wrong

If two programs speak simultaneously, identify which products are running before closing either one. Do not shut down the only tool providing access to the screen. Ask for setup help if the product or layout remains unclear.

Try it yourself

State your product, its speech capability, and the starting magnification level before continuing.

Documentation: ZoomText getting started · Fusion getting started.

Start Fusion and locate its controls

What you will learn: Reach the application without relying on a tiny mouse target.

Exactly how to do it

  1. With Fusion installed, locate its desktop shortcut using the keyboard and press Enter.
  2. Inspect the Fusion interface: Magnifier, Reader, and Tools tabs provide its controls.
  3. On the Reader tab, locate Voice and Rate. Adjust one setting, then return to your practice document.

What should happen: Magnification and speech are available together.

If that does not happen: If Fusion does not start, report the exact launch or licensing message; do not repeatedly start additional copies.

Practice: Locate the magnification and speech controls separately. Change only one and describe the effect.

Source: Getting started with Fusion.

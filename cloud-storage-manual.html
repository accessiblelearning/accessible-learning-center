Cloud file skills

OneDrive, Dropbox, and Cloud Sharing

Manage synchronized files, ownership, links, and permissions safely.

Identify a synchronized folder

Keyboard commands: Windows+E opens File Explorer. Alt+D focuses its address bar.

  1. Open File Explorer and navigate to OneDrive or Dropbox.
  2. Read the current location.
  3. Confirm the active account and synchronization status.

What you should hear: The service name and current folder or file.

If that does not happen: Use the navigation tree and address bar. A similarly named local folder may not be synchronized.

Rename, copy, or move a cloud file

Keyboard commands: F2 renames; Ctrl+C copies; Ctrl+X cuts; Ctrl+V pastes.

  1. Select one practice file and read its complete name.
  2. Copy when the original must remain. Cut only when you intend to move it.
  3. Verify the destination before pasting.
  4. Wait for synchronization and confirm the result.

If that does not happen: Stop before repeating Paste. Check the source and destination for duplicates or conflicts.

Choose a sharing permission

Keyboard command: Shift+F10 or the Application key opens the selected file's context menu in many Windows configurations.

  1. Confirm the selected file and owner.
  2. Find Share using the current menu labels.
  3. Choose named people when possible.
  4. Select View or Edit deliberately and review recipients.

If that does not happen: Cancel and verify the selected item. Sharing may be available only through the service's web interface.

Use version history carefully

Keyboard approach: Locate Version history in the service's current context menu or web actions.

  1. Confirm the file and owner.
  2. Review version dates and editors.
  3. Preview or download an earlier version when possible.
  4. Restore only after confirming what will be replaced.

If that does not happen: Keep the current file. Ask the owner or administrator whether version history is available.

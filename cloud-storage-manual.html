Basic how-tos

Find your synchronized folder

What you will learn: Complete find your synchronized folder independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Windows+E opens File Explorer. Alt+D focuses the address bar. Alt+Up Arrow moves to the parent folder.

  1. Press Windows+E.
  2. Use the navigation pane or address bar to open OneDrive or Dropbox.
  3. Press Alt+D and have the screen reader read the location.
  4. Press Escape to return to the file list.
  5. Select a file and hear its complete name and status.

What should happen: OneDrive or Dropbox in the current path.

If that does not happen: A similarly named local folder may not synchronize. Confirm the service is signed in before saving important work there.

Practice: Repeat find your synchronized folder with a second safe practice item, then explain the commands you used.

Create a folder and save a file in it

What you will learn: Complete create a folder and save a file in it independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Ctrl+Shift+N creates a folder in File Explorer. F2 renames it.

  1. Open the correct OneDrive or Dropbox location.
  2. Press Ctrl+Shift+N.
  3. Type a descriptive folder name and press Enter.
  4. Open the folder and save or paste a practice file into it.
  5. Wait for synchronization, then verify the file is listed.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Press Escape, recheck the current path, and confirm you have permission to create folders.

Copy or move a file

What you will learn: Complete copy or move a file independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: Ctrl+C copies, Ctrl+X moves, and Ctrl+V pastes.

  1. Select one file and read its name.
  2. Press Ctrl+C to keep the original, or Ctrl+X to move it.
  3. Open the destination and confirm its path.
  4. Press Ctrl+V once.
  5. Verify the result and wait for synchronization.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Do not paste repeatedly. Check both locations for duplicates, conflicts, or a permission alert.

Share a file with named people

What you will learn: Complete share a file with named people independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard command: Shift+F10 or the Application key opens a context menu in many Windows configurations.

  1. Select the file and verify its name and owner.
  2. Press Shift+F10 and choose Share.
  3. Enter the intended email addresses.
  4. Choose Can view or Can edit.
  5. Review recipients and permission before sending.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Cancel and use the service’s labeled Share command. Sharing may open a web dialog.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard approach: Select the file, open its context menu, and find Version history.

  2. Open Version history and review dates, times, and editors.
  3. Preview or download the older version when possible.
  4. Make a backup of the current version.
  5. Restore only after confirming what will be replaced.

Resolve a synchronization conflict

What you will learn: Complete resolve a synchronization conflict independently with keyboard or screen-reader feedback.

Before you begin: Open the relevant application or device screen and use a fictional, public, or nonprivate practice item.

Exactly how to do it

Keyboard commands: F2 renames a selected file; Alt+Enter opens Properties.

  1. Stop editing both copies.
  2. Compare filenames, modified dates, sizes, and locations.
  3. Rename each copy clearly instead of overwriting either one.
  4. Open and compare their content.
  5. Keep the correct copy, then archive or delete the other only after verification.

What should happen: The intended item, setting, or result is available and can be verified before you continue.

If that does not happen: Preserve both copies and ask for help. Never guess which conflict copy is current.

Practice: Repeat resolve a synchronization conflict with a second safe practice item, then explain the commands you used.

Quick command list

  • Windows+E: File Explorer
  • Alt+D: Address bar
  • Ctrl+Shift+N: New folder
  • F2: Rename
  • Ctrl+C / Ctrl+X / Ctrl+V: Copy / move / paste
  • Shift+F10: Context menu
  • Alt+Enter: Properties
  • Ctrl+Z: Undo the most recent supported file action

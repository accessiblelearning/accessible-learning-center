Google Docs Lesson 4

Headings, Outline, and Document Structure

Google Docs manualAll Google Docs lessonsMy progress

Goal

Build a structured procedure with four logical sections.

Step-by-step instructions

  1. Create one Heading 1 and at least three Heading 2 sections.
  2. Open View, Show outline to expose the document outline.
  3. Use JAWS heading navigation in the editing surface where supported.
  4. Check that heading levels do not skip for visual size alone.
  5. Move a section by selecting its heading and related text.
  6. Confirm the outline matches the intended reading order.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Accessible PDFs Lesson 9

Export, Print, and Document Security

Accessible PDFs manualAll Accessible PDFs lessonsMy progress

Goal

Write a file-handling plan for a fictional PDF workflow.

Step-by-step instructions

  1. Use Save As to preserve the original PDF.
  2. Review Export options without purchasing or starting a trial.
  3. Open Print and review page range, printer, and copies before canceling.
  4. Inspect security properties and recognize restricted actions.
  5. Never remove protections or signatures without authorization.
  6. Record the safest format for the recipient’s accessibility needs.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Write a file-handling plan for a fictional PDF workflow.

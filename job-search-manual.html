Independent Self-Study Guide for Finding and Applying for Work

All manuals Table of contents Start of manual

Purpose: This manual teaches an independent, accessible workflow for finding jobs, evaluating postings, preparing resumes, completing online applications, requesting application-process accommodations when needed, and interviewing with common digital tools.

Platforms: The main desktop examples use Windows with JAWS, NVDA, or Narrator, but the workflow also applies to VoiceOver and TalkBack. Dedicated sections cover LinkedIn and Indeed, while company career sites are treated as variable third-party systems.

Legal scope: The accommodation section provides general U.S. employment-access information and practical communication guidance, not individualized legal advice.

How to Use This Manual

  • Build your resume and reusable application information before starting a live application.

  • Open every job posting in a separate tab or save the link so you can return to it while applying.

  • Read the entire job description before investing time in the application.

  • Keep a private application tracker with employer, role, date, link, status, contact, and next action.

  • Use headings, landmarks, form controls, and browser Find rather than only Tab through long pages.

  • When an application is inaccessible, document the barrier and use the employer accommodation/contact route rather than repeatedly fighting the same control.

  • Never pay an employer or recruiter to apply, receive equipment, cash a check, buy gift cards, or release a job offer.

  • Before interviews, test the meeting platform, microphone, camera if used, screen reader, headphones, and any requested accommodation.

Part 1 - Build a Job-Search Workspace

  • Create a folder named Job Search with subfolders for Resume, Cover Letters, Applications, and Interview Notes.

  • Keep one master resume and create role-specific copies from it.

  • Keep a plain-text file with frequently requested information: employment dates, supervisor names, addresses, phone numbers, education dates, certifications, and references.

  • Keep a private application tracker. Do not store Social Security numbers, passwords, full banking details, or identity documents in the tracker.

  • Use a professional email address that you check regularly.

1.1 Create an Application Tracker

What you will learn: Track jobs so you know what you applied to and what comes next.

Before you begin: Open Excel, Google Sheets, or another accessible spreadsheet.

Exactly how to do it

  1. Create columns for Employer, Job title, Job ID, Location, Date found, Date applied, Source/link, Contact, Status, Follow-up date, and Notes.
  2. Enter one practice job.
  3. Save the tracker in your Job Search folder.
  4. After every application, update the status immediately.

What should happen: You can answer “What have I applied to?” without searching your email.

If that does not happen: If a spreadsheet is cumbersome, use a simple Word table or structured text list instead.

Practice: Track three practice postings.

Part 2 - Prepare an Accessible Resume

  • Use real Word headings for major sections such as Summary, Skills, Experience, and Education.

  • Use simple one-column reading order.

  • Prefer standard fonts and ordinary text over text boxes, floating shapes, icons, charts, or infographic skill bars.

  • Use actual bullet lists for achievements.

  • Write employer, job title, dates, and accomplishments as text that reads logically linearly.

  • Do not use color alone to communicate meaning.

  • Use meaningful link text for LinkedIn/portfolio links.

  • Run Word Accessibility Checker before exporting.

2.1 Check Resume Reading Order

What you will learn: Make sure the resume reads correctly from top to bottom.

Before you begin: Open the resume in Word.

Exactly how to do it

  1. Press Ctrl+Home.
  2. Use Ctrl+Down Arrow or your screen reader reading commands to move through the document.
  3. Listen for each section in the intended order.
  4. Use the screen reader heading list to verify section headings.
  5. Use Tab to identify hyperlinks and confirm their text is meaningful.
  6. Run Review > Check Accessibility and fix relevant issues.

What should happen: The resume makes sense without visual position cues.

If that does not happen: If information is announced out of order, remove text boxes/columns and rebuild that area in normal paragraphs or a simple table.

Practice: Read your resume from top to bottom without using sighted layout cues.

Part 3 - Resume File Formats and Uploads

Task How
DOCX Usually best when the employer explicitly requests Word or when an ATS parses Word documents well.
PDF Useful when you want layout preserved; export from an accessible source and verify the PDF has real selectable/tagged text.
Plain text Useful as a fallback for copy/paste fields; not usually the primary polished resume.
Image/scanned PDF Avoid. It may be unreadable and difficult for ATS/screen readers.

3.1 Upload a Resume Reliably

What you will learn: Use a file-upload control without losing your place.

Before you begin: Keep the resume in a known folder with a clear filename.

Exactly how to do it

  1. Focus the Upload resume or Choose file button.
  2. Press Enter or Space.
  3. In the file chooser, press Ctrl+L if needed to type the folder path, or use the normal File Explorer navigation.
  4. Find the resume filename.
  5. Press Enter.
  6. Return to the application and listen for the uploaded filename or success message.
  7. If the site parsed your resume into fields, review every parsed field before submission.

What should happen: The correct filename is attached and the application recognizes it.

If that does not happen: If the filename is not announced, inspect nearby status text or re-focus the upload control. Do not assume the upload worked.

Practice: Upload a disposable resume copy to a safe form or practice environment.

Part 4 - Read a Job Posting Efficiently

4.1 Build a Posting Summary

What you will learn: Extract the facts you need before applying.

Before you begin: Open the job posting.

Exactly how to do it

  1. Use H or your screen reader heading-navigation command to find the job title and major sections.
  2. Use browser Find (Ctrl+F) for terms such as salary, location, remote, qualifications, required, preferred, schedule, travel, clearance, license, benefits, and accommodation.
  3. Read the entire Responsibilities and Qualifications sections.
  4. Write down the job ID/requisition number.
  5. Copy the posting link into your tracker.
  6. Note the closing date if one is listed.

What should happen: You can summarize the job without rereading the entire page.

If that does not happen: If headings are poor, use browser Find and landmarks/form controls instead.

Practice: Summarize one posting in five lines.

Part 5 - Evaluate Qualifications and Essential Functions

  • Separate clearly required qualifications from preferred qualifications.

  • Do not automatically reject yourself because you do not meet every preferred item.

  • Focus on whether you can perform the job’s essential functions, with or without reasonable accommodation where applicable.

  • Distinguish a true job function from one particular way an employer currently performs it.

  • Prepare examples that demonstrate transferable skills.

U.S. access principle: Department of Labor guidance emphasizes evaluating whether a qualified applicant can perform essential functions with or without reasonable accommodation, and recognizes that there are often multiple ways to accomplish the same task.

Part 6 - Search on LinkedIn with a Screen Reader

6.1 Search LinkedIn Jobs

What you will learn: Use LinkedIn’s current accessible job-search flow.

Before you begin: Sign in to LinkedIn in a supported browser.

Exactly how to do it

  1. Activate Jobs from the LinkedIn navigation.
  2. Move backward from the Jobs link or navigate to the job-search input near the top of the page.
  3. Type the role, skills, location, or natural-language search you want.
  4. Use Up/Down Arrow through suggestions when LinkedIn announces them.
  5. Tab to the Search button and press Enter or Space.
  6. Navigate by headings to the heading that represents your search.
  7. Move into the result list and open a job with Enter.
  8. Read the job details before applying.

What should happen: LinkedIn displays the result list and screen reader focus can move into job details.

If that does not happen: LinkedIn changes dynamically; if focus becomes confusing, return to the Jobs heading/search field and rebuild context rather than tabbing endlessly.

Practice: Search for two roles and open one job detail page.

LinkedIn current guidance: LinkedIn publishes a dedicated “Find jobs on LinkedIn - Best practices for users with a screen reader” article and supports screen-reader navigation of search suggestions, results, details, and application flows.

Part 7 - Apply on LinkedIn

7.1 Complete a LinkedIn Application

What you will learn: Distinguish LinkedIn-hosted applications from external company applications.

Before you begin: Open a LinkedIn job detail page.

Exactly how to do it

  1. Find the Apply now or Apply button.
  2. Activate it.
  3. If LinkedIn opens an in-site application dialog, review the profile-sharing option, then Continue.
  4. Move through each form field with Tab/Shift+Tab and form-field navigation.
  5. Upload the correct resume.
  6. Answer screening questions.
  7. Use the Review step if offered.
  8. Read name, email, phone, resume filename, and critical answers one final time.
  9. Activate Submit application.
  10. Listen for confirmation and update your tracker.

What should happen: The application is submitted and confirmation is available.

If that does not happen: If Apply opens the company’s external site, treat it as a new application system and use Part 9.

Practice: Complete a practice review without submitting, where possible.

7.2 Set Open to Work Carefully

What you will learn: Control who can see your job-search status.

Before you begin: Be signed in to LinkedIn.

Exactly how to do it

  1. Open your profile.
  2. Find Open to.
  3. Choose Finding a new job.
  4. Enter desired titles, workplaces, locations, start date, and job types.
  5. Find Choose who sees you’re open.
  6. Review All LinkedIn members versus Recruiters only.
  7. Select the privacy level you intend.
  8. Save/Add to profile.

What should happen: LinkedIn stores the job preferences with the visibility choice you selected.

If that does not happen: Do not assume “Open to Work” is private unless you explicitly review who can see it.

Practice: Inspect the visibility control and decide which option fits your situation.

Part 8 - Search and Apply on Indeed

Current supported combinations: Indeed currently lists JAWS with Chrome and NVDA with Chrome on Windows, VoiceOver with Safari on Mac/iOS, and TalkBack with Chrome on Android among its supported assistive-technology combinations.

8.1 Search Indeed

What you will learn: Find jobs and preserve a predictable browser workflow.

Before you begin: Open Indeed and sign in if you use an account.

Exactly how to do it

  1. Navigate to the job-title/keyword search field.
  2. Enter a role, skill, or employer.
  3. Move to the location field and enter a location or remote preference.
  4. Activate Search.
  5. Use headings and links to review results.
  6. Open a promising result in a new tab when practical so the result list remains available.
  7. Read the entire description and application instructions.

What should happen: You can compare multiple jobs without losing the search page.

If that does not happen: If a result opens a company site, note that you have left Indeed and the accessibility behavior may change.

Practice: Open three results in separate tabs and compare them.

8.2 Apply Through Indeed

What you will learn: Complete Indeed-hosted forms and recognize employer-controlled steps.

Before you begin: Open a suitable job.

Exactly how to do it

  1. Activate Apply now when available.
  2. Confirm whether the application remains on Indeed or redirects elsewhere.
  3. Review contact/profile information.
  4. Upload or select the intended resume.
  5. Answer employer screening questions.
  6. Review before submission.
  7. Submit and save confirmation information.

What should happen: The application is recorded and your tracker is updated.

If that does not happen: If a screening step is inaccessible, use the accommodation/contact option where provided rather than guessing answers or asking someone to answer for you.

Practice: Walk through a noncritical application up to the review step.

Indeed accommodation note: Indeed’s current disability-inclusion FAQ states that job seekers who require alternatives in searching, applying, interviewing, or hiring can seek assistance; the employer remains responsible for its own application and screening content.

Part 9 - Company Career Sites and ATS Systems

Company career sites may use systems such as Workday, Taleo, iCIMS, Greenhouse, Lever, SuccessFactors, or custom portals. The exact labels vary, so use a structure-first workflow rather than memorizing one site.

9.1 Orient to an Unfamiliar Application System

What you will learn: Find the important regions before typing data.

Before you begin: Open the application in a desktop browser.

Exactly how to do it

  1. Press H repeatedly to review headings.
  2. Use landmarks/regions to find Main, Search, or Application content.
  3. Use F or your screen reader form-control list to identify text boxes, combo boxes, checkboxes, and buttons.
  4. Find Save, Next, Back, Review, and Submit controls before filling the entire page.
  5. Identify whether the site autosaves or provides Save and continue later.
  6. Only then begin entering data.

What should happen: You understand the page structure and recovery options before investing time.

If that does not happen: If there is no reliable structure, use Tab while taking notes on field order and save frequently.

Practice: Map one unfamiliar application page without submitting.

Part 10 - Online Application Forms

10.1 Complete Forms Systematically

What you will learn: Prevent skipped fields and accidental submissions.

Before you begin: Have your reusable information file available.

Exactly how to do it

  1. Start at the first field.
  2. Read the label before typing.
  3. Enter only the information requested.
  4. Use Tab to move forward and Shift+Tab to recheck the previous field.
  5. For checkboxes, listen for checked/not checked before pressing Space.
  6. For radio buttons, use Arrow keys within the group.
  7. Before Next/Submit, use your screen reader form-field list or Shift+Tab review to confirm required fields.
  8. Use Save/Continue later when available.

What should happen: Required information is entered into the intended controls.

If that does not happen: If a label is missing, use surrounding text, screen-reader object information, or request an accessible alternative rather than guessing sensitive information.

Practice: Complete a practice form with text boxes, checkboxes, and radio buttons.

Part 11 - Dropdowns, Date Pickers, Autocomplete, and Custom Controls

Task How
Native combo box Enter/Alt+Down to open when needed; Arrow keys; Enter to choose.
Autocomplete edit field Type part of the value, then use Arrow keys through announced suggestions and Enter to select.
Date field Prefer typing the documented date format when allowed; otherwise use keyboard navigation in the date picker.
Custom listbox Listen for expanded/collapsed and selected state; Arrow keys usually move within the list.
Slider Arrow keys usually adjust the value; listen for the numeric state.
Toggle/switch Space or Enter; verify on/off state afterward.

Recovery habit: After choosing a custom control, Shift+Tab back once and listen to the selected value. Dynamic applications sometimes accept focus movement without actually saving the selection.

Part 12 - Resume Parsing and Re-entering Work History

  • ATS resume parsing is not proof that every field was interpreted correctly.

  • Check employer names, job titles, dates, degree names, phone/email, and location carefully.

  • Re-enter information manually when required even if it duplicates the resume.

  • Do not write “see resume” unless the application explicitly permits it.

  • Keep dates in one consistent format to reduce parsing errors.

12.1 Audit Parsed Resume Fields

What you will learn: Correct ATS errors before submission.

Before you begin: Resume upload has completed.

Exactly how to do it

  1. Move to the first parsed field.
  2. Compare it with your master resume.
  3. Correct any split employer/job-title lines.
  4. Check month/year dates.
  5. Check that bullet accomplishments were not placed into employer/title fields.
  6. Review education and certifications.
  7. Save before leaving the page.

What should happen: The application data matches the resume.

If that does not happen: If parsing is severely broken, upload a simpler one-column resume version and try again if the site allows replacement.

Practice: Audit one parsed application profile.

Part 13 - Cover Letters and Application Questions

  • Answer the question actually asked; do not paste a generic paragraph everywhere.

  • Use plain language and concrete examples.

  • For “Why are you interested?” connect the role, organization, and your relevant experience.

  • For “Describe a challenge” use a short Situation-Action-Result structure.

  • Keep a library of reusable examples, but tailor each final answer.

  • Do not disclose private medical information simply because a question asks about challenges or strengths.

13.1 Paste Long Answers Safely

What you will learn: Avoid losing text in unstable web forms.

Before you begin: Draft the answer in Word or a plain text editor first.

Exactly how to do it

  1. Write and proofread the answer outside the application.
  2. Copy it.
  3. Return to the correct application field.
  4. Confirm the label.
  5. Paste.
  6. Use Ctrl+A inside that field only if you need to verify length/content, then cancel selection as appropriate.
  7. Save the application page.

What should happen: You keep a backup copy and reduce the risk of losing work.

If that does not happen: If the site has a character limit, shorten the answer in the external editor before pasting again.

Practice: Draft and paste one 150-word answer.

Part 14 - Assessments and Timed Tests

  • Read the instructions before starting the timer.

  • Check whether the test requires video, drag-and-drop, visual pattern recognition, a specific browser, or locked-down software.

  • Test keyboard and screen-reader behavior before the timed portion if a practice item is available.

  • If the assessment is inaccessible or extra time/another format is needed because of disability, request accommodation before starting when possible.

  • Do not ask another person to take an assessment for you.

Current platform note: Indeed announced the discontinuation of its own Assessments product, but employers may still send third-party pre-employment tests or screening systems.

Part 15 - Requesting an Application Accommodation

General U.S. principle: U.S. Department of Labor guidance states that qualified applicants may need reasonable accommodations to participate in the application process. Examples can include alternate formats or adjustments to inaccessible recruiting/application technology.

15.1 Request an Accessible Application Method

What you will learn: Ask for a practical alternative when a barrier prevents equal participation.

Before you begin: Document the barrier before contacting the employer.

Exactly how to do it

  1. Write down the employer, job title, job ID, application URL, date, and exact inaccessible step.
  2. Find the accommodation, HR, recruiting, or applicant-support contact listed in the posting/application.
  3. Explain that you are an applicant and identify the job.
  4. Describe the barrier functionally, such as “the required assessment cannot be operated with my screen reader.”
  5. State the accommodation or alternative you need, such as an accessible version, extra time when appropriate, a keyboard-operable format, or another way to submit the same information.
  6. Ask how the employer wants you to proceed.
  7. Keep a copy of the request and response.

What should happen: The employer has enough information to address access to the hiring process.

If that does not happen: If the posting has no contact, use the company careers/HR contact or accessibility channel. For legal questions about rights, consult EEOC/JAN or qualified counsel rather than relying on a recruiter for legal interpretation.

Practice: Write a practice accommodation request for an inaccessible timed assessment.

Part 16 - Disability Disclosure and Interview Boundaries

  • You do not need to put disability information on a resume unless you choose to and it is relevant to your goals.

  • An accommodation request may require enough information to explain the need, but it does not require sharing unrelated medical history.

  • In the U.S., pre-offer disability-related questions are restricted; employers may generally ask whether you can perform job functions and may discuss accommodation in appropriate circumstances.

  • Keep the conversation focused on job functions, access needs, and effective accommodations.

EEOC guidance: EEOC states that an employer generally may not ask a job applicant disability-related questions before a job offer, though it may ask whether the applicant can perform the job and how the applicant would perform it, with or without reasonable accommodation.

Part 17 - Job-Search Scams

  • Never pay to receive a legitimate job offer.

  • Be suspicious of interviews conducted only by text/chat with immediate offers and no normal hiring process.

  • Never deposit a check and send part of the money back for “equipment.”

  • Never buy gift cards or cryptocurrency for an employer/recruiter.

  • Check the recruiter’s email domain and the employer’s real careers site.

  • Compare the job posting with the company’s official careers page.

  • Be cautious when a recruiter moves the conversation to Telegram, WhatsApp, Signal, or another private channel immediately.

  • Never provide banking information or identity documents before you understand why they are needed and have verified the employer.

17.1 Verify a Recruiter

What you will learn: Confirm identity through an independent path.

Before you begin: A recruiter contacts you unexpectedly.

Exactly how to do it

  1. Read the full email address/domain.
  2. Find the employer’s official website by a known or independently typed address.
  3. Locate the job on the official careers site if possible.
  4. Check whether the recruiter appears on the company site or LinkedIn profile, but do not rely on profile existence alone.
  5. Call or email the company through its official contact if the request involves sensitive information or money.

What should happen: You know whether the recruiting contact is plausible before sharing sensitive data.

If that does not happen: If the employer cannot verify the recruiter, stop the process.

Practice: Verify a legitimate recruiter or staffing agency using public contact information.

Part 18 - Email and Recruiter Communication

  • Use clear subject lines: “Application - Data Analyst - Job 12345 - Your Name.”

  • Keep replies concise and answer every scheduling/action question.

  • Read the full recipient address before sending sensitive documents.

  • Do not send Social Security cards, driver’s licenses, bank details, or tax documents during ordinary early recruiting unless you have verified a legitimate onboarding process after an offer.

  • Keep copies of important recruiter emails in an application folder.

Part 19 - Interview Scheduling

19.1 Confirm an Interview

What you will learn: Record all logistics accessibly.

Before you begin: You receive an interview invitation.

Exactly how to do it

  1. Read the date, time, time zone, platform, interviewer names, and meeting link.
  2. Add the event to your calendar.
  3. Add the job description or posting link to the calendar notes.
  4. If you need an interview accommodation, request it before the interview with enough lead time when possible.
  5. Reply confirming attendance.
  6. One day before, reopen the meeting link only far enough to test the platform/device—not to join unexpectedly if that would be inappropriate.

What should happen: You have one reliable calendar record with all interview details.

If that does not happen: If the invitation lacks time zone or platform, ask before the interview day.

Practice: Create a practice calendar event from a sample invitation.

Part 20 - Zoom, Teams, and Video Interviews

Task How
Zoom Test at zoom.us/test; know mute, camera, participants/chat, and leave controls.
Microsoft Teams Use the pre-join screen to verify microphone/camera; know mute, camera, chat, participants, and leave.
Google Meet Verify microphone/camera and know captions, chat, people, and leave controls.

20.1 Prepare a Video Interview Setup

What you will learn: Prevent platform navigation from becoming the interview itself.

Before you begin: Know the platform.

Exactly how to do it

  1. Update the app/browser before interview day.
  2. Connect headphones/headset if you use them.
  3. Test microphone and speakers.
  4. If camera is expected and you choose/use video, test camera framing with a trusted person or built-in preview.
  5. Practice mute/unmute without searching menus.
  6. Practice opening chat and participants, then return focus to the main meeting.
  7. Know the Leave command/control.
  8. Close unrelated apps and silence nonessential notifications.

What should happen: You can manage meeting controls without losing conversational focus.

If that does not happen: If the platform is inaccessible, request an alternative or accommodation before the interview rather than improvising under time pressure.

Practice: Run a ten-minute mock interview call.

Part 21 - Interview Preparation with a Screen Reader

  • Keep the job description in a separate document with headings for Responsibilities, Required, Preferred, Questions, and Your Examples.

  • Prepare five to eight short stories demonstrating skills using Situation-Action-Result.

  • Use concise braille or text notes rather than a long script you must search during the interview.

  • Keep questions for the employer in a short numbered list.

  • If using speech, use headphones so interviewers do not hear screen-reader output.

  • If using braille, position the display so routing/typing noises do not interfere with the microphone.

21.1 Build Interview Notes

What you will learn: Create notes you can retrieve quickly while listening.

Before you begin: Open Word or a plain-text editor.

Exactly how to do it

  1. Create headings: Role, Company, Three priorities, Five examples, Questions, Closing.
  2. Under each heading, use short bullet phrases rather than paragraphs.
  3. Practice moving by heading with your screen reader.
  4. Try answering one mock question while locating a note without long silence.

What should happen: You can find a prompt quickly without reading a script word-for-word.

If that does not happen: If note navigation is slow, reduce the notes until each section fits in a few lines.

Practice: Run five mock questions using the notes.

Part 22 - After the Interview

  • Immediately write down interviewer names, questions, commitments, and follow-up dates.

  • Send a concise thank-you email when appropriate.

  • If you promised a portfolio/sample, send exactly what was requested through a verified address/link.

  • Do not assume silence means rejection; follow the stated timeline and then follow up once professionally.

Part 23 - Application Tracking and Follow-Up

23.1 Update Status After Every Contact

What you will learn: Keep the search organized across many employers.

Before you begin: Open your tracker.

Exactly how to do it

  1. Find the employer/job row.
  2. Update Status: Saved, Applied, Recruiter screen, Interview, Assessment, Offer, Rejected, Withdrawn, or other meaningful state.
  3. Enter the date of the latest contact.
  4. Enter the next follow-up date.
  5. Add a short note with the person/contact and next action.

What should happen: You can prioritize follow-ups instead of relying on memory.

If that does not happen: If the tracker becomes large, sort/filter by next follow-up date or active status.

Practice: Update five sample applications.

Part 24 - Mobile Job Search

  • LinkedIn and Indeed mobile apps can be useful for searching and notifications, but long application forms are often easier on desktop with a physical keyboard.

  • VoiceOver: use swipe navigation, rotor headings/forms, and double-tap to activate.

  • TalkBack: use swipe navigation, reading controls, and double-tap to activate.

  • Keep the resume in Files/Drive/OneDrive so it is available to mobile upload controls.

  • For a complex inaccessible mobile form, switch to desktop before deciding the application cannot be completed.

Part 25 - Troubleshooting Inaccessible Applications

25.1 You Are Tabbing Forever

What you will learn: Switch from linear Tab navigation to structure navigation.

Before you begin: A page has many controls.

Exactly how to do it

  1. Press H to inspect headings.
  2. Use landmarks/regions.
  3. Use the screen reader forms list or F/form-control navigation.
  4. Use browser Find for “submit,” “next,” “resume,” or the question text.
  5. Return to Tab only when you are near the intended control.

What should happen: Navigation becomes shorter and more predictable.

If that does not happen: If the site exposes no useful structure, document the barrier and use the accommodation route.

Practice: Navigate a long form without tabbing through every link.

25.2 Focus Jumps After You Choose a Dropdown

What you will learn: Reconfirm the selected value and your new focus location.

Before you begin: A dynamic control refreshed the page.

Exactly how to do it

  1. Press Shift+Tab once.
  2. Listen to the selected value/control label.
  3. Press Tab forward again.
  4. If focus returned to the top, use headings/forms navigation to return to the next required field.
  5. Save if the application offers Save.

What should happen: You verify the choice before continuing.

If that does not happen: If the selected value repeatedly disappears, capture the exact control label/problem and contact applicant support/accommodation.

Practice: Practice on a country/state autocomplete field.

25.3 CAPTCHA Blocks Submission

What you will learn: Use the site’s accessible CAPTCHA or employer alternative.

Before you begin: A CAPTCHA appears.

Exactly how to do it

  1. Look for an audio or accessibility alternative.
  2. Use the provider’s accessibility sign-in/cookie option if offered.
  3. Refresh only if the alternative failed—not repeatedly.
  4. If no accessible challenge exists, contact application support or request an alternative submission method.

What should happen: You complete the human-verification step without asking another person to submit the application for you.

If that does not happen: A sighted helper describing one inaccessible image may solve a one-time barrier, but a required inaccessible hiring process should still be reported/requested as an accommodation where appropriate.

Practice: Identify the accessible alternative on a practice CAPTCHA page if available.

25.4 Resume Upload Works but Fields Are Blank/Wrong

What you will learn: Treat upload and parsing as separate tasks.

Before you begin: The filename is attached.

Exactly how to do it

  1. Confirm the uploaded filename.
  2. Move through every parsed field.
  3. Correct missing/wrong information manually.
  4. If replacement is allowed, try the simpler accessible resume version.
  5. Save before proceeding.

What should happen: The application contains accurate data even if parsing was imperfect.

If that does not happen: Do not submit based only on seeing/hearing the resume filename.

Practice: Audit one parsed profile.

25.5 Timed Assessment Is Not Accessible

What you will learn: Stop before consuming the timer when possible.

Before you begin: You discover a barrier before or at the beginning of the test.

Exactly how to do it

  1. Do not continue guessing through inaccessible questions.
  2. Document the exact barrier and test name.
  3. Use the employer/test provider accommodation contact.
  4. Request an accessible version or appropriate modification.
  5. Keep the confirmation of your request.

What should happen: The employer/provider can address access before the assessment is completed.

If that does not happen: If the timer has already started, contact support immediately and document that the barrier occurred during the timed attempt.

Practice: Write a sample barrier description.

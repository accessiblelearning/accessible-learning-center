Purpose and setup

This manual supports independent practice with Accessible Job Search on Windows. Use the exact software version, device model, account permissions, and workplace policy available to you. Commands and labels can change after updates.

  • Start JAWS before opening the application or connecting a braille device.
  • Use Insert+T for the window title, Insert+Tab for focus, and Insert+1 for Keyboard Help.
  • Practice with fictional, public, instructor-provided, or redacted information only.
  • Never submit passwords, recovery codes, government identifiers, protected books, or private workplace data.
  • Save a backup before changing, deleting, converting, or remediating a file.

Ten-lesson learning path

  1. Lesson 1: Set a Career Goal and Search Keywords — Create a one-page career target and keyword list.
  2. Lesson 2: Build a Clear Résumé — Create a fictional or redacted résumé draft.
  3. Lesson 3: Check Résumé Accessibility — Submit an accessibility review of a fictional or redacted résumé.
  4. Lesson 4: Search Trusted Job Sites — Create a search log for three public postings.
  5. Lesson 5: Analyze a Posting and Check for Scams — Analyze one public posting or an instructor-provided fictional posting.
  6. Lesson 6: Complete Online Applications Accessibly — Document an accessible practice-application workflow.
  7. Lesson 7: Write a Targeted Cover Letter — Create a fictional or redacted targeted cover letter.
  8. Lesson 8: Networking and Professional Email — Submit a networking email draft using fictional contact information.
  9. Lesson 9: Interview and Accommodation Planning — Create an interview and accommodation preparation checklist.
  10. Lesson 10: Final Accessible Application Package — Submit a complete accessible fictional application package.

Accessible working routine

  1. Confirm the window, document, device, or webpage title.
  2. Identify keyboard focus before typing or activating a control.
  3. Navigate by real structure—headings, lists, fields, tables, or menus—when available.
  4. Review the result with JAWS or a braille display from beginning to end.
  5. Verify the destination and filename before saving, uploading, sharing, or deleting.
  6. Use the course’s private assignment uploader only for the requested practice file.

Important: These course controls complement, and do not replace, browser, operating-system, screen-reader, braille-display, or other assistive-technology settings.

Screen-Reader Troubleshooting and Recovery

Separate focus, mode, application, and computer problems before restarting.

Identify the active window

Keyboard commands: JAWS: Insert+T. NVDA: NVDA+T. Narrator: Narrator key+T.

  1. Pause typing.
  2. Request the active window title.
  3. Compare it with the application you expected.
  4. Use Alt+Tab only after identifying where focus is.

What you should hear: A useful window or document title.

If that does not happen: Test whether the screen reader speaks in another safe window before closing anything.

Identify the focused control

Keyboard commands: JAWS: Insert+Tab. NVDA: NVDA+Tab. Narrator users can request information about the current item with the current Narrator item-reading command.

  1. Request focused-control information.
  2. Decide whether focus is in text, a button, a list, a dialog, or browser content.
  3. Use Tab or Shift+Tab once and compare the result.

If that does not happen: Check for a modal dialog or a screen-reader mode that is intercepting keys.

Use keyboard help without performing commands

Keyboard commands: JAWS: Insert+1. NVDA: NVDA+1. Narrator provides input learning from its settings and command help.

  1. Turn keyboard or input help on.
  2. Press the uncertain command.
  3. Listen to its description.
  4. Turn help off before returning to work.

What you should hear: A command description without the command being performed.

If that does not happen: Stop and use the product's current Commands or Help documentation.

Escalate in a safe order

  1. Protect unsaved work.
  2. Confirm window, focus, and screen-reader mode.
  3. Try one reversible check.
  4. Test another application only when it will provide evidence.
  5. Restart the application, screen reader, or computer in that order when appropriate.
  6. Repair or reinstall only after simpler checks fail and files are backed up.

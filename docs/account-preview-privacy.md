# Prelaunch account privacy

Owner request: October 4, 2026, Indianapolis time (October 5 UTC).

The unfinished learner/admin previews and their account source are withdrawn from the current public website/repository. Development continues in a private archive and a local folder outside the public checkout. The public site no longer contains the preview HTML, scripts/styles, account API/schema/registry or account-specific test fixtures. The un-deployed Worker integration hook has been removed from public source as well.

All work was preserved before withdrawal, including WPM/accuracy reporting, hand-path separation, prepared backend code, migrations and tests. Login remains off. No services, costs, billing, credentials, users or production data changes were introduced. Public learning, existing anonymous progress and private Braille remain unchanged.

Public boundary tests now reject those files or links if they are accidentally reintroduced. Gitignore patterns are a convenience, not access control. Private archives and new account changes must never be published through Pages before explicit release approval.

## Important limit

These designs had already been published. Earlier copies may remain in GitHub commit history, caches, downloads or other copies. Withdrawal removes current hosting; it does not retroactively make the old snapshots private or erase them. Only fictional data was present, and no live account backend or learner credential data was exposed by these previews. No Git history rewriting was performed.

## Future review and launch

The owner can review locally or receive private review artifacts. There is no hosted private account-preview URL in this arrangement. If a remotely accessible preview is later needed, select a genuinely protected approach and obtain the owner's approval before provisioning or activation. Keep additional cost at $0. Do not substitute noindex or an obscure URL for security.

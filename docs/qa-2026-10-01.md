## One-hand courses

The starting main branch already contained the rebuilt movable-hand curriculum in `keyboarding-one-hand.js`. This pass verified that implementation rather than replacing it with a duplicate curriculum. Both paths have 50 distinct lessons, cover both sides of the keyboard with the selected hand, introduce the complete alphabet by lesson 12, and eventually cover all 95 printable US keyboard characters. Guidance describes moving the hand and forearm and using a comfortable stronger finger for distant keys. Practice draws on learned characters. Each hand has separate saved progress. Default one-hand speed requirement is zero; accuracy remains required.

All 150 lessons across regular, left-hand, and right-hand paths passed the production-controller completion tests. Settings now explicitly label each one-hand choice “whole keyboard.” Physical usability of the finger suggestions still needs a one-handed learner's assessment.

## Punctuation follow-up from learner testing

The learner's screenshot requested Control+[ (one-point font decrease) while they tried the comma/less-than key. Those are different keys; that attempt should remain incorrect. Prompts and feedback now say “left square bracket” / “right square bracket” and provide a brief location beside P. Verified the shortcut distinction against Microsoft's “Use a screen reader to insert and change text in Word,” https://support.microsoft.com/en-us/accessibility/word/use-a-screen-reader-to-insert-and-change-text-in-word (October 1, 2026).

Investigation also reproduced a separate real defect: native `Comma`/`Period` key codes were compared with semantic “Less Than”/“Greater Than” names. Correct shifted commands were rejected, and separated-key Alt/Shift exercises could not finish using the actual comma/period keys. Matching now uses the shared physical punctuation key while continuing to require the specified modifiers. Separated-key instructions ask for comma/period after the Shift step; the short explanation identifies the shared symbol. Square brackets remain distinct.

Three new regressions cover bracket/comma distinction, shifted font-size commands in Word and Presentations, and separated-key Alt/Shift exercises. Updated the old simulated key helper to emit real punctuation instead of invented key names. All 123 regression tests and the site validator pass. Native Chromium keyboard checks passed for Control+[, Control+Shift+Comma/Period, and separated Alt, Shift, Comma/Period with no page errors; inspected the rendered bracket hint. This is browser verification, not a new claim of JAWS or VoiceOver testing.

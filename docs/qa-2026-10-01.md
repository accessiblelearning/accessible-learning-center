# Learning-center QA checkpoint — October 1, 2026

User scope: full-keyboard Left-Hand Only and Right-Hand Only courses, 50 lessons per path; then regular Keyboarding, Mission Control, Braille, assessments, certificates, navigation, speech, contrast, keyboard access, and curriculum gaps.

## One-hand courses

The starting main branch already contained the rebuilt movable-hand curriculum in `keyboarding-one-hand.js`. This pass verified that implementation rather than replacing it with a duplicate curriculum. Both paths have 50 distinct lessons, cover both sides of the keyboard with the selected hand, introduce the complete alphabet by lesson 12, and eventually cover all 95 printable US keyboard characters. Guidance describes moving the hand and forearm and using a comfortable stronger finger for distant keys. Practice draws on learned characters. Each hand has separate saved progress. Default one-hand speed requirement is zero; accuracy remains required.

All 150 lessons across regular, left-hand, and right-hand paths passed the production-controller completion tests. Settings now explicitly label each one-hand choice “whole keyboard.” Physical usability of the finger suggestions still needs a one-handed learner's assessment.

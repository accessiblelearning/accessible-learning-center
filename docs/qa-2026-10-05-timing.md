## Reproduced issue and fix

The practice keyboard handler and free-typing beforeinput handler finish an expired test before accepting another entry. Existing Escape behavior still leaves practice. This is elapsed-time timing, not a new pause/resume feature; time away still counts. A suspended page displays results when it resumes execution.

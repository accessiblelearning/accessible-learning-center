Cybersecurity Lesson 2

Strong Passwords and Password Managers

Cybersecurity manualAll Cybersecurity lessonsMy progress

Goal

Create a password-policy checklist using examples that are not real passwords.

Step-by-step instructions

  1. Use a unique long password for every account.
  2. Prefer a reputable organization-approved password manager.
  3. Never place passwords in assignment files or chat messages.
  4. Review password-manager autofill before approving it.
  5. Change a password promptly after a confirmed compromise.
  6. Store recovery codes in an approved secure location.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

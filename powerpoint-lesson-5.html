PowerPoint Lesson 5

Reading Order and Keyboard Navigation

PowerPoint manual All PowerPoint lessons My progress

Goal

Arrange slide objects so a screen reader encounters them in a logical order.

Skills practiced

  • Understand object reading order.
  • Use the Reading Order pane.
  • Test slides with Tab and Shift+Tab.
  • Keep slide titles first in the logical sequence.

Step-by-step instructions

  1. Open PowerPoint-Lesson-4.pptx.
  2. Choose a slide containing a title, text, and image.
  3. Press Alt+Q, type Reading Order, and open the Reading Order pane or use the Accessibility Checker recommendation.
  4. Review the listed objects. The title should be read before the main content, and supporting objects should follow logically.
  5. Use the pane's Move Up and Move Down controls to correct the sequence if needed.
  6. Mark decorative objects decorative rather than leaving them unnamed.
  7. Close the pane and return to the slide.
  8. Press Tab repeatedly to test the object sequence. Use Shift+Tab to move backward.
  9. Repeat the test on every slide.
  10. Run Check Accessibility and resolve reading-order warnings that apply.
  11. Save the presentation as PowerPoint-Lesson-5.pptx.

Keyboard help: Press Alt+Q to search PowerPoint commands when Ribbon KeyTips differ. For JAWS help, press Insert+Spacebar, then J, and search for the task.

  • Titles occur before related slide content in reading order.

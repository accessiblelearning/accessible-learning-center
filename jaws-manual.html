Use one primary screen reader at a time. Running several simultaneously can produce overlapping speech and conflicting commands. An instructor may demonstrate a second product after the student can safely start, stop, and recover the primary choice.

What stays the same

Windows and application commands such as Tab, Shift+Tab, Arrow keys, Enter, Spacebar, Ctrl+C, Ctrl+V, Alt+Tab, and Windows+L usually stay the same. Screen-reader commands differ when you request information, change reading modes, open element lists, adjust speech, or use product settings.

Equivalent concepts with different names

  • Screen-reader key: JAWS key, Narrator key, or NVDA key.
  • Web-reading mode: JAWS Virtual Cursor, Narrator Scan Mode, or NVDA Browse Mode.
  • Typing in forms: JAWS Forms Mode, Narrator with Scan Mode off, or NVDA Focus Mode.
  • Command discovery: JAWS Keyboard Help, Narrator Input Learning, or NVDA Input Help.

Basic procedure

1. Choose, Start, and Stop a Screen Reader

What you will learn: Choose JAWS, Narrator, or NVDA and start and stop it safely.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Choose one primary screen reader for this course. Do not run multiple screen readers at the same time unless an instructor directs you.
  2. Confirm that the computer’s speakers or headset are connected and the volume is safe.
  3. Start the selected screen reader using its method in the comparison table.
  4. Open Notepad and type one short sentence.
  5. Confirm the screen reader announces the application, focus, and typed text.
  6. Save the note and stop the screen reader using its documented method.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a one-page choice report naming the selected screen reader, why it fits the practice computer, and how to start and stop it.

Basic procedure

2. Keyboard Help, Speech Control, and Basic Information

What you will learn: Use keyboard help and control speech without losing focus.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open the screen reader selected in Lesson 1.
  2. Use its keyboard-help command and press several harmless keys to hear their descriptions.
  3. Exit keyboard help before returning to work.
  4. Press Ctrl while speech is talking to stop speech.
  5. Use the current-focus command to identify the selected control.
  6. Use the window-title command to confirm the active application.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a command card for keyboard help, stopping speech, current focus, and window title.

3. Read by Character, Word, Line, Paragraph, and Continuously

What you will learn: Read and review text at several levels with the chosen screen reader.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open an instructor-provided text document and move to the beginning with Ctrl+Home.
  2. Use Left and Right Arrow to review characters in editable text.
  3. Use Ctrl+Left Arrow and Ctrl+Right Arrow to move by word.
  4. Use Up and Down Arrow to move by line or paragraph as supported by the application.
  5. Use the screen reader’s continuous-reading command.
  6. Stop speech with Ctrl and summarize the passage.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Submit a reading log showing how you read one passage by character, word, line, and continuously.

Basic procedure

4. Navigate Windows, Dialogs, and Controls

What you will learn: Move reliably through Windows applications and identify focus.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open the Start menu and search for Settings.
  2. Use Tab and Shift+Tab to move between controls.
  3. Use Arrow keys within lists, menus, and groups.
  4. Press Spacebar to toggle a checkbox and Enter to activate a button when appropriate.
  5. Press Alt+Tab to switch applications and use the screen-reader focus command.
  6. Press Esc to close a menu or cancel a practice dialog without changing important settings.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a control-navigation report covering a button, checkbox, edit field, list, and dialog.

5. Browse Webpages by Headings, Links, Lists, and Landmarks

What you will learn: Navigate structured webpages efficiently with the selected screen reader.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open Chrome and visit the Accessible Learning Center.
  2. Move to the top with Ctrl+Home.
  3. Turn on or confirm the screen reader’s web-reading mode.
  4. Press H and Shift+H to move among headings.
  5. Press K and Shift+K to move among links where supported; Tab also moves through interactive controls.
  6. Navigate a list and landmark or region, then return to the page heading.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a web-navigation log identifying headings, links, lists, and landmarks on a public page.

6. Complete Forms and Manage Input Modes

What you will learn: Enter fictional information in web forms while controlling reading and typing modes.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open an instructor-approved practice form.
  2. Navigate to the first field with F or Tab.
  3. Listen for the label, field type, required state, and instructions.
  4. Enter fictional data only.
  5. Move through radio buttons, checkboxes, lists, and buttons using standard form controls.
  6. Review all entries before leaving the page without submitting to an external organization.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Document a fictional form practice, including how your screen reader enters and leaves its typing mode.

7. Navigate Tables, Lists, and Structured Information

What you will learn: Read relationships in tables and lists without losing row or column context.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open a page containing a simple accessible table.

  3. Read the caption and column headers before the data.
  4. Use the selected screen reader’s table commands to move one cell at a time.
  5. Move out of the table and locate a list.
  6. Read list boundaries, item count when announced, and each item.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

8. Read, Edit, and Review Workplace Documents

What you will learn: Use shared editing commands and screen-reader feedback in Word or another document editor.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open a practice document and press Ctrl+Home.
  2. Use Ctrl+F to locate a required phrase.
  3. Select text with Shift plus navigation keys.
  4. Use Ctrl+X, Ctrl+C, and Ctrl+V to move or copy text.
  5. Use Ctrl+Z to undo an intentional edit.
  6. Navigate true headings and lists with the chosen screen reader, then save a copy.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Revise an instructor-provided workplace memo and submit a command log plus the corrected copy.

Advanced procedure

9. Help, Settings, Updates, Braille, and JAWS AI

What you will learn: Find trustworthy help, make reversible settings changes, and understand product-specific advanced features.

Before you begin: Open a harmless practice document or webpage. Confirm which screen reader is running and save open work before changing settings.

Exactly how to do it

  1. Open the selected screen reader’s settings or menu.
  2. Locate speech, verbosity, keyboard-layout, and braille options without changing unrelated settings.
  3. Change one instructor-approved reversible setting, test it, and restore the original.
  4. Open the official help or current command reference.
  5. Record the installed screen-reader version without including device serial numbers or license information.
  6. Review the JAWS-only AI note and do not assume the same feature exists in Narrator or NVDA.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Create a comparison explaining official help, settings, updates, braille support, and which AI features are JAWS-only.

  4. Complete a practice form with fictional data without submitting it externally.
  5. Edit and save a short workplace document with a verified filename.
  6. Troubleshoot one simulated focus, speech, or reading-mode problem using official help.

What should happen: You can complete the procedure and verify the result using the keyboard, your screen reader, or your braille display.

If that does not happen: Press Escape to leave an unexpected menu or dialog, confirm the active window and keyboard focus, then repeat one step at a time. Use Undo when a reversible content change occurred.

Practice: Submit a final report naming the selected screen reader, the commands used, completed tasks, and one troubleshooting solution.

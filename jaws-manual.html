Getting started with JAWS

JAWS is a screen reader for Windows. It speaks text, controls, status information, and application content. This manual uses the desktop keyboard layout unless a step says otherwise.

The JAWS key

Many commands begin with the JAWS modifier key. Insert is normally the JAWS key in desktop layout. Caps Lock is commonly the JAWS key in laptop layout. Do not memorize a command that does not match the installed layout—use Keyboard Help or Commands Search to confirm it.

  • Stop speech: Ctrl.
  • Window title: Insert+T.
  • Focused control and prompt: Insert+Tab.
  • Keyboard Help: Insert+1 on the numbers row.
  • JAWS window: Insert+J.
  • Exit JAWS: Insert+F4. Use this only when you intend to close the screen reader.

Practice safely: Keyboard Help describes keys without performing their normal actions. Toggle it off with Insert+1 when practice is finished.

Reading and reviewing text

Use standard Arrow keys for characters and lines, JAWS commands for words and spoken context, and Windows editing keys to move through documents.

  • Left Arrow and Right Arrow read the prior or next character.
  • Insert+Left Arrow and Insert+Right Arrow read the prior or next word.
  • Up Arrow and Down Arrow read the prior or next line.
  • Ctrl+Up Arrow and Ctrl+Down Arrow move by paragraph.
  • Insert+Down Arrow begins Say All. Ctrl stops speech.
  • Insert+Shift+Down Arrow reads selected text.
  • Ctrl+Home and Ctrl+End move to the beginning and end in many documents.

Commands can vary between desktop and laptop layouts. The official JAWS Keystrokes reference lists both layouts.

Windows and application navigation

  • Desktop: Windows+D.
  • Start search: Press the Windows key, type an application or file name, and press Enter.
  • Switch applications: Alt+Tab.
  • Taskbar: Windows+T.
  • JAWS Window List: Insert+F10.
  • System tray icons: Insert+F11.
  • Close the current window: Alt+F4.

Before typing or activating a command, press Insert+T and Insert+Tab when you are unsure which window and control have focus.

Understanding JAWS cursors

PC Cursor

The PC Cursor follows keyboard focus in applications. In desktop layout, Num Pad Plus returns to the PC Cursor.

Virtual Cursor

The Virtual Cursor presents supported web pages and PDF content like a text document. It enables headings, links, lists, forms, tables, and Navigation Quick Keys. Insert+Z toggles the Virtual Cursor.

JAWS Cursor

The JAWS Cursor can inspect screen content that does not take keyboard focus. In desktop layout, Num Pad Minus activates it. Return to the PC Cursor when finished.

Web pages and Navigation Quick Keys

With the Virtual Cursor on, use these single-letter commands. Add Shift to move backward.

  • H: heading
  • P: paragraph
  • L: list
  • I: list item
  • T: table
  • F: form field
  • B: button
  • C: combo box, list box, or tree view

Insert+F6 opens the Headings List, Insert+F7 opens the Links List, and Insert+F5 opens the Form Fields List. Tab moves among focusable controls.

Forms Mode

Press Enter on an edit field or other interactive control to enter Forms Mode. In desktop layout, Num Pad Plus exits Forms Mode. Listen for mode announcements and review field labels with Insert+Tab before entering information.

Tables

Use T to locate a table and Ctrl+Alt+Arrow keys to move among cells. Good tables announce meaningful row and column headers. If context disappears, return to the start of the table or use a table list before continuing.

Built-in help and troubleshooting

  • Screen-sensitive help: Insert+F1.
  • Hot Key Help: Insert+H.
  • Windows Key Help: Insert+W.
  • JAWS Commands Search: Insert+Spacebar, then J.
  • Quick Settings: Insert+V.
  • Settings Center: Insert+6 on the numbers row.
  • Refresh screen: Insert+Escape.

Start with reversible steps: stop speech, identify the window and focus, refresh the screen, check built-in help, and restart only the affected application. Do not change unfamiliar settings on a shared or workplace computer.

JAWS AI: FSCompanion and Picture Smart AI

FSCompanion

FSCompanion is Freedom Scientific’s AI-powered assistant for questions about JAWS and supported applications. Freedom Scientific’s current Hotkeys page lists Insert+Spacebar, then F1 to open it. Ask one specific task question at a time, such as “How do I list headings on a webpage?”

Picture Smart AI

Picture Smart AI analyzes images and returns detailed descriptions. Depending on the installed JAWS version, it can describe supported images from webpages, email, files, or screenshots. Use JAWS Commands Search or the current JAWS interface to locate the available Picture Smart AI command because options may change by version.

Responsible use

  • AI features use online services and may be unavailable in secure or offline installations.
  • Never send passwords, client records, identification documents, medical information, private photographs, or confidential work screens.
  • AI can omit details or describe something incorrectly. Verify important commands with official documentation and important visual details with another reliable source.
  • If AI is unavailable, use Keyboard Help, JAWS Commands Search, official documentation, or a trusted instructor.

Important: JAWS AI is a learning and access aid, not a replacement for professional judgment, privacy rules, official instructions, or human verification.

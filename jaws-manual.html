Screen readerBest reason to choose it for this courseImportant note
JAWSChoose JAWS when it is installed and licensed by you, your school, or your workplace.Includes JAWS-specific tools such as FSCompanion and Picture Smart AI when available.
Windows NarratorChoose Narrator when you need the screen reader built into Windows 11.Start or stop it with Windows+Ctrl+Enter. Its Scan Mode and views differ from JAWS.
NVDAChoose NVDA when it is already installed or your organization approves the free, open-source Windows screen reader.Its Browse Mode and NVDA modifier commands differ from JAWS and Narrator.

Use one primary screen reader at a time. Running several simultaneously can produce overlapping speech and conflicting commands. An instructor may demonstrate a second product after the student can safely start, stop, and recover the primary choice.

What stays the same

Windows and application commands such as Tab, Shift+Tab, Arrow keys, Enter, Spacebar, Ctrl+C, Ctrl+V, Alt+Tab, and Windows+L usually stay the same. Screen-reader commands differ when you request information, change reading modes, open element lists, adjust speech, or use product settings.

Equivalent concepts with different names

  • Screen-reader key: JAWS key, Narrator key, or NVDA key.
  • Web-reading mode: JAWS Virtual Cursor, Narrator Scan Mode, or NVDA Browse Mode.
  • Typing in forms: JAWS Forms Mode, Narrator with Scan Mode off, or NVDA Focus Mode.
  • Command discovery: JAWS Keyboard Help, Narrator Input Learning, or NVDA Input Help.

Ten-lesson learning path

  1. Lesson 1: Choose, Start, and Stop a Screen Reader — Choose JAWS, Narrator, or NVDA and start and stop it safely.
  2. Lesson 2: Keyboard Help, Speech Control, and Basic Information — Use keyboard help and control speech without losing focus.
  3. Lesson 3: Read by Character, Word, Line, Paragraph, and Continuously — Read and review text at several levels with the chosen screen reader.
  4. Lesson 4: Navigate Windows, Dialogs, and Controls — Move reliably through Windows applications and identify focus.
  5. Lesson 5: Browse Webpages by Headings, Links, Lists, and Landmarks — Navigate structured webpages efficiently with the selected screen reader.
  6. Lesson 6: Complete Forms and Manage Input Modes — Enter fictional information in web forms while controlling reading and typing modes.
  7. Lesson 7: Navigate Tables, Lists, and Structured Information — Read relationships in tables and lists without losing row or column context.
  8. Lesson 8: Read, Edit, and Review Workplace Documents — Use shared editing commands and screen-reader feedback in Word or another document editor.
  9. Lesson 9: Help, Settings, Updates, Braille, and JAWS AI — Find trustworthy help, make reversible settings changes, and understand product-specific advanced features.
  10. Lesson 10: Final Screen-Reader Workplace Project — Complete a realistic Windows, web, form, document, and troubleshooting workflow with the chosen screen reader.

Cybersecurity Lesson 8

Public Wi-Fi and Remote Work

Cybersecurity manualAll Cybersecurity lessonsMy progress

Goal

Write a secure remote-work plan for a fictional trip.

Step-by-step instructions

  1. Prefer a trusted network or approved hotspot.
  2. Confirm the network name with staff rather than guessing.
  3. Avoid sensitive work on unknown public networks.
  4. Use the organization’s approved VPN when required.
  5. Disable unnecessary sharing and Bluetooth discovery.
  6. Lock and physically protect devices in public.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Goal

Describe the accessibility of a practice form and save a local copy if allowed.

Step-by-step instructions

  1. Open a trusted fillable practice form.
  2. Press Tab and Shift+Tab through fields and buttons.
  3. Listen for each field label, type, and required state.
  4. Enter fictional data only.
  5. Review the completed fields before saving a copy.
  6. Do not submit the form to an external organization.

JAWS and keyboard tip: Use Insert+T to confirm the window title, Insert+Tab to identify focus, and Insert+1 for Keyboard Help. Commands can vary by software version and device model; use the official manual linked from the course manual when a control differs.

Your assignment

Describe the accessibility of a practice form and save a local copy if allowed.

Use fictional, public, or redacted information only. Never submit passwords, account codes, private NLS books, financial details, or other sensitive information.

Save your work with a clear filename beginning Pdf-Lesson-4.

Before submitting

  • All requested steps are complete.
  • The file contains no private credentials or sensitive personal information.
  • The content is organized with clear headings or labels.
  • The filename identifies Accessible PDFs Lesson 4.

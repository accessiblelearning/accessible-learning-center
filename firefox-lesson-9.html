Recover when navigation feels wrong

What you will learn: Identify focus before changing browser settings.

Exactly how to do it

  1. Name the problem: wrong page, wrong tab, wrong field, or unexpected reading behavior.
  2. If an unwanted Find bar is active, close it with Escape. If you closed the wrong tab, reopen it using the command above.
  3. If arrow keys move a text cursor through the page, check whether Caret Browsing was enabled with F7. Read its prompt before changing it.

What should happen: You can explain what changed and take one targeted recovery step.

If that does not happen: Check your screen reader’s current mode. Do not reset the browser or delete your profile to solve an unidentified focus problem.

Practice: Ask an instructor to move focus to the address bar. Identify the change before entering any text.

Source: Mozilla Caret Browsing guidance.

Troubleshooting by symptom

The wrong page opened.
Read its address and title. Return to the known starting address if necessary. A similar-looking search result is not proof that it is the official site.
The page looks cut off after zooming.
Reduce browser zoom one step and check whether a menu has collapsed into a menu button. If screen magnification is also active, identify which zoom you changed.
My text vanished.
Check the active tab and focused field before retyping. A form may have navigated away. Use its saved-draft feature where provided; browser history is not a reliable backup of form text.
A keyboard command does nothing.
Check for an open menu, dialog, screen-reader command conflict, or laptop function-key behavior. Return focus to the intended control and try once. Record the command and what happened if the problem continues.
I hear two voices.
Identify whether the website or a media player is speaking alongside your screen reader. Pause that player through its controls before changing the screen reader you rely on for navigation.

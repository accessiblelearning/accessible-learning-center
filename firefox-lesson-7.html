Your goal

Use a harmless search form twice, replacing the query deliberately. Identify the edit field, submit button, and resulting heading or validation message.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Fill in a web form without losing your place

Start here: A familiar website with a harmless search form. Do not practice with a checkout or application that submits real information.

Step-by-step instructions

  1. Read the form’s heading and instructions first. Use Tab to reach its search edit field. Listen for the field’s label and whether it is required.
  2. Type a distinctive topic such as Firefox. If existing text needs replacing, confirm focus remains inside the edit field, press Ctrl+A, and type the replacement.
  3. Tab to the Search button and press Enter. Some forms submit when you press Enter in a text field, so use the labeled button when you are learning the layout.
  4. On a form with a checkbox, listen to its current checked state, then use Space only if you intend to change it. For a list of options, use its arrow-key choices and confirm the selected value before leaving it.
  5. After submitting, read the new heading, result count, or validation error. If a field is rejected, return to that labeled field and correct only the indicated value.
  6. When finished, leave the form through its ordinary navigation. Do not assume Escape undoes a submission or that the browser Back command will preserve unsaved text.

Check your result

The intended form action occurs once, and you can identify its result or error message.

If something goes wrong

If a single letter moves to a heading instead of appearing in the field, your screen reader may still be reading the page. Re-identify the editable field and use your reader’s interaction instructions. If audio or a dialog interrupts you, identify it before continuing.

Try it yourself

Search for a manual, replace the search word with another topic, and describe which field changed.

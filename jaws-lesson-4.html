JAWS Lesson 4

Dialogs, Controls, the PC Cursor, and Keyboard Focus

JAWS manual All JAWS lessons My progress

Goal

Recognize common controls, navigate dialogs, and understand where keyboard focus is located.

Skills practiced

  • Move through controls with Tab and Shift+Tab.
  • Operate buttons, check boxes, edit fields, and combo boxes.
  • Use Insert+Tab and Insert+B for context.
  • Return to the PC Cursor when another cursor is active.

Step-by-step instructions

  1. Open Notepad and press Ctrl+Shift+S to open Save As.
  2. Press Tab and Shift+Tab through the dialog. Listen for edit fields, buttons, combo boxes, and the file list.
  3. At each unfamiliar control, press Insert+Tab to hear its name, type, and state.
  4. Open a combo box with Alt+Down Arrow, review choices with Arrow keys, and press Escape without changing the selection.
  5. Press Insert+B to have JAWS read the current dialog from top to bottom.
  6. Press Num Pad Minus to activate the JAWS Cursor, then press Num Pad Plus to return to the PC Cursor. Laptop layouts may use different commands.
  7. Type JAWS-Lesson-4.txt in the file name field and choose a familiar folder.
  8. Press Enter on the Save button and respond to any confirmation dialog with the keyboard.
  9. Reopen the file with Ctrl+O and practice identifying the File name field and Open button.
  10. Write what focus means and why the PC Cursor normally follows keyboard focus.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

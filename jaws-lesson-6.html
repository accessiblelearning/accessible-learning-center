JAWS Lesson 6

Forms Mode and Completing Web Forms

JAWS manual All JAWS lessons My progress

Goal

Complete web forms while understanding the difference between Virtual Cursor navigation and Forms Mode interaction.

Skills practiced

  • Locate form fields with quick keys and element lists.
  • Enter and leave Forms Mode.
  • Complete edit fields, check boxes, radio buttons, combo boxes, and buttons.
  • Review entries before submitting.

Step-by-step instructions

  1. Open a safe practice form or the Accessible Learning Center Student ID page. Do not enter private information.
  2. With the Virtual Cursor on, press F and Shift+F to move among form fields.
  3. Press Insert+F5 to open the Form Fields List. Review the available controls and press Escape.
  4. Move to an edit field and press Enter to activate Forms Mode.
  5. Type fictional practice information. Press Tab to move to the next field.
  6. For a check box, press Spacebar to change its state. For radio buttons, use Arrow keys. For a combo box, use Alt+Down Arrow and Arrow keys.
  7. Press Num Pad Plus to leave Forms Mode when using the desktop layout. Confirm that JAWS announces the mode change.
  8. Use the Virtual Cursor to review nearby instructions and required-field messages.
  9. Return to each field, verify the value with Insert+Tab, and do not send real or sensitive information.
  10. Create JAWS-Lesson-6.txt describing the form controls practiced, the keys used, and how the student protected personal information.

Keyboard help: JAWS commands below use the desktop keyboard layout unless noted. Insert is the JAWS key in desktop layout; Caps Lock is commonly used in laptop layout. Press Insert+1 to toggle Keyboard Help, or use JAWS Commands Search to confirm the command for the installed layout.

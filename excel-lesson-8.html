Excel Lesson 8

Charts, Alternative Text, and Accessibility Checker

Excel manual All Excel lessons My progress

Goal

Create a simple chart, provide a text equivalent, and use Excel accessibility checks.

Skills practiced

  • Create a chart from a small data table.
  • Add meaningful alternative text.
  • Provide the same key information in worksheet cells.
  • Run the Accessibility Checker.

Step-by-step instructions

  1. Create a two-column table with Month and Completed Trainings.
  2. Enter January through June and fictional completion totals.
  3. Select the table, including headers.
  4. Press Alt+F1 to create a chart on the current worksheet.
  5. Use F6 to move focus among the worksheet, ribbon, and chart objects until JAWS announces the chart.
  6. Open the chart context menu with Shift+F10. Use Format Chart Area or Alt Text options to add a description.
  7. Write concise alt text that explains the chart's purpose and important trend, not every visual detail.
  8. Keep the source data table in the workbook so screen-reader users can inspect exact values.
  9. Add a cell below the table containing a short text summary of the trend.
  10. Press Alt+Q, type Check Accessibility, and run the Accessibility Checker.
  11. Review and resolve issues that apply. Do not remove the source table.
  12. Save the workbook as Excel-Lesson-8.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Your assignment

Create a six-month training-completion chart, add meaningful alternative text, retain the source data, and include a plain-text trend summary.

Save the finished assignment as Excel-Lesson-8.xlsx.

Before submitting

  • The chart is based on a clearly labeled data table.
  • The chart has useful alternative text.
  • A text summary identifies the main trend.
  • The Accessibility Checker was reviewed.
  • The file is saved as Excel-Lesson-8.xlsx.

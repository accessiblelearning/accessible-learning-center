Windows 11 Lesson 2

Managing Windows, Switching Apps, Snap, and Virtual Desktops

Windows 11 manualAll Windows 11 lessonsMy progress

Goal

Organize multiple workplace applications and move among windows efficiently.

Skills practiced

  • Switch and cycle among applications.
  • Minimize, maximize, restore, and close windows.
  • Use keyboard Snap commands.
  • Create and switch virtual desktops.

Step-by-step instructions

  1. Open Notepad, Calculator, and File Explorer.
  2. Press Alt+Tab repeatedly and release Alt when the desired application is announced.
  3. Press Alt+Escape to cycle through open windows in their opening order.
  4. Use Windows+Up Arrow to maximize the active window and Windows+Down Arrow to restore or minimize it.
  5. Use Windows+Left Arrow or Windows+Right Arrow to snap the active window. Press Escape if Windows offers a Snap group you do not want.
  6. Press Windows+Tab to open Task View and review open windows.
  7. Press Windows+Ctrl+D to create a new virtual desktop.
  8. Press Windows+Ctrl+Left Arrow and Windows+Ctrl+Right Arrow to switch desktops.
  9. Return applications to a known desktop and press Windows+Ctrl+F4 only when ready to close the extra virtual desktop.
  10. Write a comparison of Alt+Tab, Windows+Tab, Snap, and virtual desktops in Windows-Lesson-2.txt.

Screen-reader help: These lessons work with JAWS and other screen readers. With JAWS, press Insert+T to confirm the active window, Insert+Tab to hear the focused control, and Insert+1 to toggle Keyboard Help. Windows features and labels can vary slightly after updates.

Your goal

Move between a document and browser, identify each window, pause competing media if present, and return to the same paragraph.

Before starting

Use your own authorized practice account or a harmless practice document. Identify the active application and the focused control before each command. Keep these instructions in a separate window. Never include passwords or private messages in your learning notes.

Follow the product and device version named in each procedure. A plus sign means hold the modifier while pressing the final key; “then” means release before continuing. These procedures are documentation-based and have not been tested here with the actual assistive software or signed-in reading accounts.

Manage speech while switching between applications

Start here: Your practice document and a browser are open. Use the product-specific speech section above to set a comfortable rate.

Step-by-step instructions

  1. Read one paragraph, then stop the current speech before switching windows. This lets you hear the next window’s title instead of overlapping explanations.
  2. Use Alt+Tab to switch. Identify the destination application, active document or page, and focused control before using a command.
  3. If a web page or audiobook also plays audio, pause that media player through its own labeled control. Keep the access tool you need to navigate available.
  4. Return to the document and locate your last passage using a heading, distinctive phrase, or your recorded place. Read a short portion to confirm context.
  5. For ZoomText Magnifier/Reader, inspect its Reader settings if character or mouse announcements are distracting. Change one echo setting and test typing or pointer movement separately. For Fusion, use the corresponding JAWS controls rather than assuming those ZoomText speech settings apply.

Check your result

You can tell which source is speaking and switch tasks without losing your place.

If something goes wrong

If everything is silent, check volume, output device, and the product’s voice setting separately. Plugging in headphones can change the output device. A moving highlight alone does not prove that audio is reaching your speakers.

Try it yourself

Recover by identifying the symptom

I cannot see the whole window.
Compare the full-screen view using the matching 1x toggle, then return to a lower working magnification if needed. Find the window and focused control before changing more settings.
A highlight follows the wrong thing.
Check whether it is the pointer, text cursor, or keyboard focus. Test only the corresponding enhancement. A mouse highlight will not tell you where typed text goes.
The same key behaves differently on another computer.
Compare the product, version, and configured keyboard layout. Copying someone else’s command list without matching these details can produce another action.
A document image has no readable text.
A scanned page may need text recognition, often called OCR. Fusion can support recognition workflows, including supported scanned-PDF workflows. Follow the recognition prompt or installed help; recognition output must be checked for errors, especially numbers and names.
The program does not start after Windows sign-in.
Open it through Start first. Then review its startup preference with the person managing the computer. Do not enable multiple overlapping access tools automatically without checking the resulting startup experience.

When requesting help, provide the product/version, keyboard layout, application, exact command, expected result, and actual result. Do not include private document text.

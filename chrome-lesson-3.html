Chrome Lesson 3

JAWS Web Navigation in Chrome

Chrome manualAll Chrome lessonsMy progress

Goal

Use the JAWS Virtual Cursor, Navigation Quick Keys, and element lists in Chrome.

Step-by-step instructions

  1. Open the Accessible Learning Center home page.
  2. Confirm the Virtual Cursor is on with Insert+Z; turn it back on if needed.
  3. Press Ctrl+Home, then H and Shift+H to move by heading.
  4. Use P for paragraphs, L for lists, and I for list items.
  5. Press Tab and Shift+Tab to move among links and controls.
  6. Press Insert+F6 to open the Headings List.
  7. Press Insert+F7 to open the Links List.
  8. Use Insert+Ctrl+F for JAWS Find and compare it with Chrome Find using Ctrl+F.
  9. Open one lesson link, then use Alt+Left Arrow to return.
  10. Write the commands and one accessibility observation in Chrome-Lesson-3.txt.

Screen-reader help: With JAWS, press Insert+T for the window title, Insert+Tab for focused-control information, and Insert+1 for Keyboard Help. Chrome controls and labels can change after browser updates.

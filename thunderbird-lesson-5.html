Address a message: To, Cc, and Bcc

Start here: A new composition window. Use only your own address for the first practice.

Step-by-step instructions

  1. Tab to the To field. Type your complete email address and press Enter. The address becomes a recipient item. Review its spelling; an accepted-looking item is not proof that the address belongs to the intended person.
  2. To add another recipient, enter their address in the same row and confirm with Enter. To move onward after the last recipient, press Enter again or Tab and identify the next field.
  3. To correct an existing recipient, use the arrow keys in the recipient row to select that item. Press Enter to edit it, make the correction, and press Enter again. Delete removes a selected recipient item.
  4. If you need Cc or Bcc, reach the corresponding control above the address row with Tab or Shift+Tab and activate it. Cc recipients are visible to the other recipients. Bcc conceals the Bcc recipient list from them.
  5. Before sending, review every recipient row, not only To. In a practice draft, remove added recipients and save without sending.

Check your result

Each intended address is a distinct recipient item, and you know which address row it is in.

If something goes wrong

If a field is absent, activate its Cc or Bcc control first. If deleting removes message text instead of an address, stop: focus is in the body. Return to the recipient row before trying again.

Try it yourself

Explain who should see a copy of a hypothetical meeting invitation, then choose To or Cc. Do not test privacy by mailing real groups.

PowerPoint Lesson 3

Text, Bullets, and Clear Slide Content

PowerPoint manual All PowerPoint lessons My progress

Goal

Create concise, structured slide text that works for screen-reader users and visual audiences.

Skills practiced

  • Enter text in placeholders.
  • Create bulleted and numbered lists.
  • Change bullet levels with Tab and Shift+Tab.
  • Keep slide language concise and meaningful.

Step-by-step instructions

  1. Create a new presentation with the title Accessible Customer Service.
  2. Add a slide titled Greeting a Customer.
  3. Enter three bullets: Introduce yourself, Ask how you can help, and Listen before responding.
  4. With focus in the second bullet, press Tab to create a sub-bullet and type Clarify the request. Press Shift+Tab if you need to return it to the main level.
  5. Add a slide titled Resolving a Request.
  6. Create a numbered list with four steps: Identify the problem, Confirm the desired result, Complete the action, and Verify satisfaction.
  7. Avoid long paragraphs. Keep each bullet to one clear idea.
  8. Use Ctrl+B only when emphasis adds meaning; do not rely on bold alone to communicate status.
  9. Review each text object by pressing Tab through the slide, then F2 or Enter to edit its text.
  10. Save the presentation as PowerPoint-Lesson-3.pptx.

Keyboard help: Press Alt+Q to search PowerPoint commands when Ribbon KeyTips differ. For JAWS help, press Insert+Spacebar, then J, and search for the task.

Understand saved passwords and sign-in

Start here: Firefox on your own trusted device. Use a practice account if you are learning password controls.

Step-by-step instructions

  1. Open Firefox’s application menu and activate Passwords, or type about:logins in the address bar and press Enter. This opens Firefox’s saved-login manager, not a website’s password-reset page.
  2. Tab to its search field and search for a site you recognize. Select the matching entry and review its website and username.
  3. Do not reveal or copy a password merely to identify the entry. If you intentionally request a protected action, Windows may ask you to authenticate.
  4. If you edit a saved entry, understand that you are changing Firefox’s stored copy. To change the actual account password, follow that website’s own account-recovery or security process, then update the saved copy as appropriate.
  5. Close the login-manager tab when finished. On shared devices, follow the device owner’s sign-in and password-storage policy.

Check your result

You can distinguish a stored credential from the website account itself.

If something goes wrong

A rejected login may be an old saved password, a different account, or a site-specific access problem. Verify the website address and username before requesting recovery. Do not repeatedly guess passwords.

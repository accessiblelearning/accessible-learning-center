Set a comfortable listening pace

What you will learn: Use the correct speech controls for your product.

Exactly how to do it

  1. In ZoomText Magnifier/Reader, Caps Lock+Alt+Up or Down changes voice rate. Control briefly quiets speech.
  2. In Fusion, use the Reader tab’s Voice and Rate controls. JAWS supplies speech; ZoomText reading hotkeys are not interchangeable with Fusion speech commands.
  3. Listen to one short passage, adjust one step, and compare comprehension.

What should happen: You can understand the spoken material without repeatedly losing your place.

If that does not happen: Check the product edition, audio output, and voice setting before increasing volume. If another screen reader is also speaking, identify it before changing anything.

Practice: Summarize a short paragraph at two rates. Keep the rate at which you understand and navigate comfortably.

Read with Fusion: separate JAWS speech from magnification

Start here: Fusion is running, its JAWS keyboard layout is known, and a short document is active.

Step-by-step instructions

  1. Use the command table below to choose the correct Desktop or Laptop command. Do not borrow a ZoomText reader command just because its name sounds similar: Fusion uses JAWS speech.
  2. For continuous reading in Desktop layout, use Insert+Down Arrow. In Laptop layout, use Caps Lock+Down Arrow. Hold the modifier while pressing the arrow; release both after the command.
  3. Press Control to interrupt speech. Check where the reading or editing position is before moving to another passage.
  4. For the current line, Desktop layout uses Insert+Up Arrow; Laptop layout uses Caps Lock+I. Read the line once, then move deliberately to the next passage using the document’s navigation.
  5. To adjust speed without guessing another product’s shortcut, return to Fusion’s Reader controls and locate Rate. Change it a small amount, return to the same paragraph, and compare.
  6. When reading is done, leave speech at a useful setting. Stopping the current utterance is different from disabling ongoing speech feedback.

Check your result

You can start reading, stop it, and hear the current line using commands appropriate to your configured Fusion layout.

If something goes wrong

If a command magnifies instead of speaking, recheck the configured layout. Caps Lock combinations have different meanings in these products and layouts. If there is no speech, inspect the Reader voice control and Windows audio output before reinstalling anything.

Try it yourself

Read a paragraph, interrupt halfway, then request the current line. Describe where you are before resuming.

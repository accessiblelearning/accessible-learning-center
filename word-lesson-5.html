Microsoft Word Lesson 5

Headings, Styles, and Document Navigation

Goal

Learn to create a properly structured document using Word's built-in heading styles.

Instructions

  1. Create a blank Word document.
  2. Type: My Technology Training Plan
  3. Apply Heading 1 using Ctrl+Alt+1.
  4. Press Enter and type: Microsoft Word
  5. Apply Heading 2 using Ctrl+Alt+2.
  6. Press Enter and apply Normal style using Ctrl+Shift+N.
  7. Type one sentence about learning Microsoft Word.
  8. Press Enter twice and type: Internet Skills
  9. Apply Heading 2.
  10. Press Enter and return to Normal style.
  11. Type one sentence about learning Internet skills.
  12. Press Ctrl+F.
  13. Move to the Headings section of the Navigation Pane.
  14. Verify that your headings appear.
  15. Navigate between the headings.
  16. Save as Word-Lesson-5.docx.

Your Assignment

Submit Word-Lesson-5.docx.

Before Submitting

  • The main title should use Heading 1.
  • Microsoft Word should use Heading 2.
  • Internet Skills should use Heading 2.
  • Body text should use Normal style.

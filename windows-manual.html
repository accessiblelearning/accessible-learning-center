Desktop, Start, taskbar, and windows

Windows 11 can be operated efficiently with the keyboard and a screen reader. Confirm the active window and focused control before typing or activating an unfamiliar command.

  • Desktop: Windows+D.
  • Start and search: Press the Windows key and type an app, setting, or file name.
  • Taskbar: Windows+T, then Arrow keys.
  • Switch applications: Alt+Tab.
  • Task View: Windows+Tab.
  • Settings: Windows+I.
  • File Explorer: Windows+E.
  • Quick Settings: Windows+A.
  • Notifications: Windows+N.
  • Close active window: Alt+F4.

Window management

Windows+Up Arrow maximizes, Windows+Down Arrow restores or minimizes, and Windows+Left Arrow or Windows+Right Arrow snaps the active window. Alt+Tab changes applications; Windows+Tab opens Task View. Virtual desktops can separate tasks, but close an extra desktop only after confirming where its applications will move.

File Explorer and file organization

Press Windows+E to open File Explorer. F6 moves among major areas, Ctrl+L moves to the address bar, and Ctrl+F moves to search. Alt+Left Arrow and Alt+Right Arrow move through location history; Alt+Up Arrow moves to the containing folder.

  • New folder: Ctrl+Shift+N.
  • Rename: F2.
  • Copy: Ctrl+C.
  • Cut for moving: Ctrl+X.
  • Paste: Ctrl+V.
  • Properties: Alt+Enter.
  • Delete to Recycle Bin: Delete. Confirm the selection first.

Protect files: Never approve an overwrite, delete a large selection, or empty the Recycle Bin until names, locations, and backups are confirmed.

Selection, search, and location awareness

Arrow keys move the current item. Shift+Arrow extends a continuous selection, Ctrl+Spacebar can change one item’s selection state, and Ctrl+A selects all. Before copying, moving, or deleting, confirm what is selected and which folder is open.

Search within a specific folder for faster, safer results. Review file name, extension, type, date, and location before opening downloaded content.

Built-in accessibility features

Press Windows+I and search for Accessibility. Windows includes text-size controls, Magnifier, contrast themes, color filters, Narrator, live captions, mono audio, voice access, and keyboard options. Each learner should choose settings based on individual needs.

  • Start Magnifier: Windows+Plus.
  • Close Magnifier: Windows+Escape.
  • Start or stop Narrator: Windows+Ctrl+Enter on supported Windows 11 systems.

Do not change another person’s accessibility setup or shared workplace settings without permission. Website accessibility controls complement—not replace—Windows, browser, screen-reader, and device settings.

Quick Settings, notifications, and audio

Windows+A opens Quick Settings for network, Bluetooth, volume, battery, and other device controls. Windows+N opens Notification Center. Review state before changing it. Toggling airplane mode, Wi-Fi, Bluetooth, microphones, or audio output can interrupt assistive technology, meetings, or workplace connections.

Security, privacy, and updates

  • Install or pause updates on a workplace computer only with authorization.
  • When User Account Control requests administrator approval, stop and confirm the intended action.
  • Do not run unexpected downloads or files with misleading extensions.
  • Never enter passwords after following an unexpected message link.
  • Keep personal and client information out of practice assignments.
  • Report suspicious prompts with the exact wording, application, time, and steps that led to them.

Windows 11 receives security and quality updates. Save work and follow organizational restart procedures when an update requires a restart.

Safe troubleshooting and help

Use reversible steps first: save work, confirm the active application, read the focused control, press Escape, retry once, close only the affected application if safe, and reopen it. Ctrl+Shift+Escape opens Task Manager, but do not end unfamiliar processes.

A useful support request includes the application, task, expected result, actual result, exact error, and steps already tried. Use Microsoft Get Help or authorized workplace support without sharing confidential information unnecessarily.

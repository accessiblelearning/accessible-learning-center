Purpose: This manual teaches the built-in accessibility features of Windows 11. It is designed to stand alone and assumes no previous experience with Windows accessibility settings.

Scope: This guide focuses on accessibility features built into current Windows 11: Magnifier, text and pointer settings, color filters, contrast themes, Narrator overview, Live Captions, audio accessibility, hearing devices, Voice Access, voice typing, On-Screen Keyboard, Sticky/Filter/Toggle Keys, Mouse Keys, eye control, focus and notification settings, and accessibility shortcuts.

Core shortcut: Press Windows+U at any time to open Settings > Accessibility.

How to Use This Manual

  • Change one accessibility setting at a time, test it, and then decide whether to keep it.

  • Press Windows+U to return to the Accessibility settings hub.

  • Use Tab and Shift+Tab to move among controls; use Arrow keys in lists and Spacebar to toggle many switches.

  • Keep a written record of settings that make the computer easier to use.

  • Some features depend on hardware, language, Windows edition, or device capability.

  • Built-in accessibility features can be combined; for example, Magnifier can be used with Narrator, and Sticky Keys can be used with keyboard shortcuts.

  • Do not disable an accessibility feature that another person depends on without their permission.

  • If a shortcut triggers something unexpected, press Escape and return to Windows+U before changing more settings.

Part 1 - Windows 11 Accessibility Overview

Windows 11 groups accessibility settings into broad areas for vision, hearing, and interaction. Microsoft also provides tools for focus and cognitive accessibility.

  • Vision: text size, visual effects, mouse pointer and touch, text cursor, Magnifier, color filters, contrast themes, and Narrator.

  • Hearing: audio settings, visual alternatives to sounds, captions, and hearing-device support.

  • Interaction: speech, keyboard, mouse, and eye control.

  • Focus: notification timing, reduced animation, taskbar simplification, and other distraction-reduction settings.

Part 2 - Open and Navigate Accessibility Settings

2.1 Open Accessibility Settings

What you will learn: Reach the central Windows accessibility hub quickly.

Before you begin: Windows 11 is running.

Exactly how to do it

  1. Press Windows+U.
  2. Wait for Settings to open.
  3. Press Tab once or more until the Accessibility categories/settings are announced or visibly focused.
  4. Use Up/Down Arrow through available accessibility pages when focus is in the navigation list.
  5. Press Enter on the category you want.
  6. Press Shift+Tab or Alt+Left Arrow to return when needed.

What should happen: Settings > Accessibility opens.

If that does not happen: If another app receives U instead, make sure the Windows key is held down.

Practice: Open Accessibility, enter Magnifier, return, then enter Keyboard.

Search alternative: Press Windows, type the name of a feature such as 'Live Captions' or 'Magnifier settings,' then press Enter on the matching Settings result.

Part 3 - Text Size and Visual Effects

3.1 Increase Text Size Without Enlarging Everything

What you will learn: Make text easier to read while keeping overall screen layout similar.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Text size.
  2. Move to the Text size slider.
  3. Increase the percentage gradually.
  4. Use the preview area to judge the result.
  5. Activate Apply.
  6. Wait for Windows to update text.

What should happen: Text becomes larger across supported Windows interfaces without applying full-screen magnification.

If that does not happen: If controls become crowded, reduce the percentage and reapply.

Practice: Try one moderate increase and restore it if not useful.

3.2 Reduce Animation and Transparency

What you will learn: Reduce motion and visual distraction.

Before you begin: Open Accessibility > Visual effects.

Exactly how to do it

  1. Find Animation effects.
  2. Turn it off if movement is distracting.
  3. Find Transparency effects.
  4. Turn it off if translucent backgrounds reduce readability.
  5. Review notification-dismiss timing on the same page when available.

What should happen: Windows uses fewer animations and/or more solid backgrounds.

If that does not happen: Some apps have their own animation settings and may not follow every Windows preference.

Practice: Toggle each setting and compare.

Part 4 - Mouse Pointer and Touch

4.1 Make the Mouse Pointer Easier to See

What you will learn: Increase pointer size or use a more visible pointer style.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Mouse pointer and touch.
  2. Move to the pointer-size slider.
  3. Increase size gradually.
  4. Move to Mouse pointer style.
  5. Choose White, Black, Inverted, or another visible style.
  6. If offered, choose a custom pointer color.

What should happen: The pointer becomes easier to locate.

If that does not happen: If the pointer is too large and covers controls, reduce its size.

Practice: Try two sizes and two pointer styles.

Touch indicator: On touch-capable devices, Windows can show a visual touch indicator so finger contact is easier to see.

Part 5 - Text Cursor

5.1 Make the Text Cursor Easier to Find

What you will learn: Add a visible indicator around the insertion caret.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Text cursor.
  2. Turn Text cursor indicator on.
  3. Adjust the indicator size.
  4. Choose a high-visibility color.
  5. Adjust text cursor thickness if needed.
  6. Open Notepad and type a sentence to test the caret.

What should happen: The insertion point is easier to locate in supported text fields.

If that does not happen: If the indicator is distracting, reduce size or turn it off while retaining a thicker cursor.

Practice: Test in Notepad and a browser edit field.

Part 6 - Magnifier

Task Command / Path
Turn Magnifier on Windows+Plus
Turn Magnifier off Windows+Escape
Zoom in / out Windows+Plus / Windows+Minus
Open Magnifier settings Windows+Ctrl+M
Pan Ctrl+Alt+Arrow keys
Invert colors Ctrl+Alt+I

6.1 Start and Control Magnifier

What you will learn: Enlarge screen content quickly.

Before you begin: Windows is running.

Exactly how to do it

  1. Press Windows+Plus.
  2. Press Windows+Plus again to increase magnification.
  3. Press Windows+Minus to reduce magnification.
  4. Use Ctrl+Alt+Arrow keys to pan if your current Magnifier view supports it.
  5. Press Windows+Escape to turn Magnifier off.

What should happen: The screen enlarges and then returns to normal.

If that does not happen: If the keyboard has a layout where Plus requires Shift, hold Windows and press the key that produces Plus.

Practice: Turn Magnifier on, change zoom twice, then turn it off.

6.2 Choose a Magnifier View

What you will learn: Select the magnification style that fits the task.

Before you begin: Magnifier is on.

Exactly how to do it

  1. Press Windows+Ctrl+M.
  2. Move to View.
  3. Choose Full screen, Lens, or Docked when available.
  4. Return to the application and test navigation.
  5. Open settings again to choose another view.

What should happen: Magnification behaves according to the selected view.

If that does not happen: Multi-monitor and app behavior can differ; choose the view that keeps orientation easiest.

Practice: Test all available views.

Part 7 - Magnifier Reading

7.1 Have Magnifier Read Text Aloud

What you will learn: Combine visual magnification with spoken reading.

Before you begin: Magnifier is on.

Exactly how to do it

  1. Press Ctrl+Alt+Enter using the default Magnifier reading modifier.
  2. Listen as Magnifier begins reading.
  3. Press any key to stop.
  4. Press Ctrl+Alt+K for the next sentence.
  5. Press Ctrl+Alt+H for the previous sentence.

What should happen: Magnifier reads text aloud while magnifying it.

If that does not happen: The reading modifier can be changed in Magnifier settings. If you also use Narrator, avoid assigning conflicting modifier keys.

Practice: Read a short paragraph and move by sentence.

Mouse reading: With the default modifier, Ctrl+Alt plus a left mouse click can start reading from the clicked location.

Part 8 - Color Filters

8.1 Turn On a Color Filter

What you will learn: Adjust color presentation for color-vision or sensitivity needs.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Color filters.
  2. Turn Color filters on.
  3. Choose a filter that improves distinction or comfort.
  4. Open a familiar image or webpage and compare.
  5. Return to Color filters to choose another filter or turn the feature off.

What should happen: Windows changes displayed colors without changing the underlying files.

If that does not happen: If screenshots are used for color-critical work, remember the filter changes what you see, not the source content.

Practice: Compare two filters.

Shortcut: When enabled in settings, Windows+Ctrl+C can toggle color filters.

Part 9 - Contrast Themes

9.1 Apply a Contrast Theme

What you will learn: Increase separation between foreground and background elements.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Contrast themes.
  2. Open the theme list.
  3. Choose a theme such as Aquatic, Desert, Dusk, or Night sky when available.
  4. Activate Apply.
  5. Wait for Windows to redraw.
  6. Open several apps to test readability.

What should happen: Windows uses a high-contrast color scheme across supported apps.

If that does not happen: Some websites/apps may need their own contrast settings. If text becomes harder to distinguish, choose another theme or None.

Practice: Apply one theme and then return to your original setting.

Keyboard shortcut: Left Alt+Left Shift+Print Screen toggles contrast/high-contrast behavior on supported systems when the shortcut is enabled.

Part 10 - Narrator Overview

Narrator is Windows 11's built-in screen reader. This manual gives an overview; a separate Narrator-focused manual can teach the complete command set.

Task Command / Path
Start/stop Narrator Windows+Ctrl+Enter
Narrator settings Windows+Ctrl+N
Input learning Narrator+1
Toggle Scan Mode Narrator+Space

10.1 Start Narrator from Windows

What you will learn: Use built-in speech access without installing another screen reader.

Before you begin: Windows is running.

Exactly how to do it

  1. Press Windows+Ctrl+Enter.
  2. Wait for Narrator to speak.
  3. Press Narrator+1 to enter Input Learning.
  4. Press a few harmless keys to hear their functions.
  5. Press Narrator+1 again to leave Input Learning.
  6. Press Windows+Ctrl+Enter to stop Narrator.

What should happen: Narrator starts and stops without changing your files.

If that does not happen: If the shortcut is disabled by policy or hardware, open Windows+U > Narrator and turn it on there.

Practice: Start, practice, and stop Narrator.

Part 11 - Live Captions

11.1 Turn On Live Captions

What you will learn: Create on-screen captions for audio playing through the PC.

Before you begin: Open Windows 11 with an internet connection available for initial language setup if required.

Exactly how to do it

  1. Press Windows+Ctrl+L.
  2. Wait for the Live Captions window/bar.
  3. If prompted, choose/download the caption language package.
  4. Play a video or other speech audio.
  5. Read the captions.
  6. Open caption settings to choose position/style if desired.
  7. Close Live Captions when finished.

What should happen: Windows displays automated captions for supported audio.

If that does not happen: Captions may be inaccurate and depend on language/support. Do not treat automated captions as a certified transcript.

Practice: Caption a short known video and compare accuracy.

Privacy: Current Windows Live Captions processing is designed to run on-device for supported scenarios after required language components are installed, but feature behavior can vary by device/version.

Part 12 - Audio, Mono Audio, and Visual Alerts

12.1 Turn On Mono Audio

What you will learn: Send left and right audio channels into one combined channel.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Open Audio.
  2. Find Mono audio.
  3. Turn it on.
  4. Play stereo audio and listen through one ear/headphone channel if appropriate.
  5. Turn Mono audio off if stereo separation is preferred.

What should happen: Both channels are combined so information from either side is not lost when listening with one channel.

If that does not happen: If the sound seems less spatial, that is expected; mono removes stereo separation.

Practice: Compare stereo and mono.

12.2 Flash the Screen for Audio Notifications

What you will learn: Add a visual alert when Windows plays notification sounds.

Before you begin: Open Accessibility > Audio.

Exactly how to do it

  1. Find Flash my screen during audio notifications.
  2. Open the choice list.
  3. Choose title bar, active window, entire screen, or another offered option.
  4. Trigger a safe Windows notification to test.

What should happen: A visual flash accompanies supported audio notifications.

If that does not happen: If the flash is uncomfortable, choose a smaller visual area or turn it off.

Practice: Test one flash option.

12.3 Make Notifications Stay Visible Longer

What you will learn: Increase reading time for temporary notifications.

Before you begin: Open Accessibility > Visual effects.

Exactly how to do it

  1. Find Dismiss notifications after this amount of time.
  2. Open the list.
  3. Choose a longer duration.
  4. Trigger a safe notification and observe how long it remains.

What should happen: Notifications stay on screen longer.

If that does not happen: Very long durations can increase clutter; choose the minimum that works.

Practice: Compare two durations.

Part 13 - Hearing Devices

Windows 11 can support compatible hearing devices and Bluetooth audio devices. Available controls depend on the PC's Bluetooth hardware, Windows version, and the hearing device.

13.1 Look for Hearing Device Settings

What you will learn: Determine whether Windows exposes dedicated hearing-device controls.

Before you begin: Open Windows+U.

Exactly how to do it

  1. Look for Hearing devices under the Hearing section.
  2. Open it if present.
  3. Review detected/supported device options.
  4. If the page is absent, open Settings > Bluetooth & devices and check normal Bluetooth audio pairing.
  5. Follow the hearing-device manufacturer's current pairing procedure.

What should happen: Compatible hardware can be paired/configured where supported.

If that does not happen: Not every PC or hearing device supports every Windows hearing-device feature.

Practice: Locate the settings without changing a working configuration.

Part 14 - Voice Access

Voice Access lets you control Windows and dictate text by voice. Microsoft documents that it works without an internet connection after the required speech language is installed.

14.1 Start Voice Access

What you will learn: Control Windows using spoken commands.

Before you begin: Use a working microphone.

Exactly how to do it

  1. Press Windows+U.
  2. Open Speech.
  3. Turn Voice access on, or search Start for Voice access.
  4. If this is the first run, complete the language/speech-model setup.
  5. Follow the Voice Access guide/tutorial.
  6. Say 'Voice access wake up' when the microphone is in the listening state if supported.
  7. Use basic commands such as 'Open Start,' 'Open Settings,' or 'Click <control name>'.

What should happen: Windows responds to supported spoken commands.

If that does not happen: If recognition is poor, check microphone selection, ambient noise, and selected voice-access language.

Practice: Open and close one app entirely by voice.

14.2 Use Numbers/Grid When a Control Has No Easy Name

What you will learn: Select controls visually by voice.

Before you begin: Voice Access is listening.

Exactly how to do it

  1. Say 'Show numbers' to label clickable items when supported.
  2. Say the number shown on the intended control.
  3. If a target cannot be selected reliably, say 'Show grid'.
  4. Narrow the grid by speaking the numbered region until the target is reached.
  5. Say 'Click' or the displayed number as instructed.

What should happen: Voice Access activates otherwise hard-to-name controls.

If that does not happen: Exact wording can vary with current Voice Access command grammar; use the built-in command guide.

Practice: Use number overlays on a safe Settings page.

Voice shortcuts: Current Voice Access supports custom voice shortcuts for frequently repeated tasks in supported configurations.

Part 15 - Voice Typing

15.1 Dictate Text with Voice Typing

What you will learn: Enter text by speech without controlling the whole computer.

Before you begin: Place the caret in an edit field.

Exactly how to do it

  1. Press Windows+H.
  2. Wait for the voice typing panel to indicate listening.
  3. Speak a short sentence.
  4. Say punctuation explicitly if automatic punctuation is not enabled.
  5. Press Windows+H again or activate the microphone control to stop.

What should happen: Speech is converted to text in the active field.

If that does not happen: Voice typing normally needs an appropriate speech service/network configuration, unlike Voice Access's offline control capability.

Practice: Dictate two sentences and correct errors by keyboard.

Difference: Voice Access controls the PC and can also author text. Voice typing is primarily for dictation into the active text field.

Part 16 - On-Screen Keyboard

Task Command / Path
Turn On-Screen Keyboard on/off Windows+Ctrl+O
Settings path Windows+U > Keyboard > On-Screen Keyboard

16.1 Use the On-Screen Keyboard

What you will learn: Type without relying on a full physical keyboard.

Before you begin: Open a safe text field.

Exactly how to do it

  1. Press Windows+Ctrl+O.
  2. Wait for the OSK to appear.
  3. Use a mouse, pointing device, touch, or scanning/switch method to choose letters.
  4. Type a short word.
  5. Press Windows+Ctrl+O again to close the OSK.

What should happen: A visual keyboard allows input through alternate pointing/switch methods.

If that does not happen: The touch keyboard is a separate feature from the Accessibility On-Screen Keyboard.

Practice: Type your name or a practice phrase.

Part 17 - Sticky Keys, Filter Keys, and Toggle Keys

17.1 Turn On Sticky Keys

What you will learn: Press multi-key shortcuts one key at a time.

Before you begin: Open Windows+U > Keyboard.

Exactly how to do it

  1. Turn Sticky keys on.
  2. Open its options.
  3. Decide whether to allow the Shift-key shortcut and sounds/indicator.
  4. Test Ctrl+S by pressing Ctrl, releasing it, then pressing S.
  5. Turn Sticky Keys off if you do not need it.

What should happen: Windows holds modifier keys logically so simultaneous keypresses are not required.

If that does not happen: If Sticky Keys turns on unexpectedly after pressing Shift five times, change its shortcut option.

Practice: Use one three-key shortcut one key at a time.

17.2 Use Filter Keys

What you will learn: Ignore brief or repeated accidental keypresses.

Before you begin: Open Accessibility > Keyboard.

Exactly how to do it

  1. Turn Filter keys on.
  2. Open its detailed settings.
  3. Review options such as Slow Keys, Bounce Keys, and Repeat Keys.
  4. Change only one timing value at a time.
  5. Test typing in Notepad.
  6. Adjust or turn the feature off if typing becomes too slow.

What should happen: Windows filters keystrokes according to the selected sensitivity/timing.

If that does not happen: Aggressive settings can make the keyboard seem unresponsive; return to Windows+U and reduce delays.

Practice: Test with a disposable text document.

17.3 Use Toggle Keys

What you will learn: Hear feedback when lock keys change state.

Before you begin: Open Accessibility > Keyboard.

Exactly how to do it

  1. Turn Toggle keys on.
  2. Press Caps Lock.
  3. Listen for the state-change sound.
  4. Press Num Lock if the keyboard has it.
  5. Return to the desired lock state.

What should happen: Windows provides an audio cue for supported lock keys.

If that does not happen: If audio is muted or unavailable, use another status method.

Practice: Toggle Caps Lock twice.

Part 18 - Mouse Keys

18.1 Control the Pointer with the Numeric Keypad

What you will learn: Move/click the mouse pointer without moving a physical mouse.

Before you begin: A keyboard with numeric keypad is available.

Exactly how to do it

  1. Press Windows+U.
  2. Open Mouse.
  3. Turn Mouse keys on.
  4. Review speed and acceleration settings.
  5. Use the numeric keypad to move the pointer according to the Windows Mouse Keys layout.
  6. Use the Mouse Keys click/select controls to activate a safe desktop item.
  7. Turn Mouse Keys off if not needed.

What should happen: The numeric keypad controls the pointer.

If that does not happen: Laptop keyboards without a separate numeric keypad may not provide a convenient Mouse Keys layout.

Practice: Move the pointer to four screen quadrants and return.

Part 19 - Touch and Pen Accessibility

Touch-capable Windows devices can expose touch indicators, touch keyboard controls, and pen settings. Availability depends on hardware.

  • Use Mouse pointer and touch settings to make touch contact easier to see.

  • Use Settings > Bluetooth & devices > Pen & Windows Ink for pen behavior on supported devices.

  • Touch gestures can replace some mouse actions, but accessibility features such as Narrator also have their own touch gesture sets.

  • Do not confuse the Windows touch keyboard with the Accessibility On-Screen Keyboard.

Part 20 - Eye Control

Eye control lets compatible eye-tracking hardware control Windows and type without a conventional mouse/keyboard.

20.1 Find Eye Control Settings

What you will learn: Determine whether your system supports eye control.

Before you begin: A compatible eye tracker must be installed/configured.

Exactly how to do it

  1. Press Windows+U.
  2. Open Eye control.
  3. If the control is available, turn it on.
  4. Follow the hardware calibration/setup steps.
  5. Use the eye-control launchpad to practice pointer selection and typing.

What should happen: Windows exposes eye-controlled pointer/keyboard features when supported hardware is detected.

If that does not happen: If Eye control is unavailable, verify that the tracker model and drivers support current Windows 11 eye control.

Practice: Locate the page and read the setup requirements.

Part 21 - Focus, Notifications, and Visual Clutter

21.1 Reduce Visual Distraction

What you will learn: Simplify the Windows desktop/taskbar and reduce motion.

Before you begin: Open Settings.

Exactly how to do it

  1. Open Accessibility > Visual effects and turn off Animation effects if helpful.
  2. Increase notification duration only if needed.
  3. Open Personalization > Taskbar.
  4. Hide taskbar items you do not use, such as Widgets or Task view if appropriate.
  5. Review taskbar flashing/badges and automatic hiding.
  6. Keep only settings that improve focus.

What should happen: The desktop presents fewer competing visual cues.

If that does not happen: Hiding a feature does not uninstall it; restore items later if needed.

Practice: Reduce one source of clutter and assess the effect.

21.2 Use Do Not Disturb / Focus

What you will learn: Reduce interruptions during concentrated work.

Before you begin: Open Settings > System > Notifications or search for Do not disturb/Focus.

Exactly how to do it

  1. Turn on Do not disturb for a short test period.
  2. Review which priority notifications can still appear.
  3. Open Focus if available and start a short focus session.
  4. End the session and restore normal notifications.

What should happen: Nonpriority interruptions are reduced during the chosen period.

If that does not happen: Do not suppress safety-critical/work-required notifications without understanding the consequences.

Practice: Run one short test session.

Part 22 - Accessibility Flyout and Sign-In Screen

22.1 Open Quick Accessibility Controls

What you will learn: Reach common accessibility features quickly.

Before you begin: Windows is running.

Exactly how to do it

  1. Press Windows+A to open Quick Settings.
  2. Move to Accessibility.
  3. Press Enter.
  4. Review the available quick toggles such as Narrator, Magnifier, Live Captions, Sticky Keys, or Color Filters depending on configuration.
  5. Press Escape to close.

What should happen: Common accessibility features can be toggled without opening the full Settings app.

If that does not happen: The exact flyout choices can vary by Windows version and configuration.

Practice: Open and close the Accessibility flyout.

Sign-in screen: Windows also provides an Accessibility button on the sign-in screen so supported features can be enabled before signing in.

Part 23 - Windows Hello and Easier Sign-In

Windows Hello can reduce reliance on repeatedly typing a password by using a PIN, fingerprint, or face recognition when supported.

23.1 Review Sign-In Options

What you will learn: Choose an accessible authentication method without weakening account security.

Before you begin: Open Settings.

Exactly how to do it

  1. Open Accounts > Sign-in options.
  2. Review Windows Hello Face, Fingerprint, PIN, security key, and other available methods.
  3. Choose only hardware-supported options you can use reliably.
  4. Keep account recovery information current.

What should happen: You understand the available sign-in methods.

If that does not happen: Do not remove the only sign-in/recovery method until a replacement has been tested.

Practice: Inspect available options without changing them.

Part 24 - Combining Features Safely

  • Magnifier + Narrator: useful when both enlarged visuals and speech are needed.

  • Magnifier + contrast theme: can increase visual clarity but may be too intense for some users.

  • Sticky Keys + keyboard shortcuts: lets modifier combinations be entered sequentially.

  • Live Captions + mono audio: combines text access with simplified audio routing.

  • Voice Access + On-Screen Keyboard: offers alternative interaction methods if speech or pointing becomes temporarily difficult.

  • Color Filters + contrast themes can interact strongly; test them separately before combining.

  • Do not assign the same modifier shortcut to two assistive technologies if it causes conflicts.

24.1 Build a Personal Accessibility Profile

What you will learn: Create a repeatable set of settings that work together.

Before you begin: Choose two or three features relevant to your access needs.

Exactly how to do it

  1. Write down the starting settings.
  2. Enable the first feature and test for five minutes.
  3. Enable the second and test again.
  4. Note any shortcut or visual conflicts.
  5. Keep the combination only if it improves access.
  6. Record how to turn each feature off.

What should happen: You have a controlled, reversible combination rather than a collection of accidental settings.

If that does not happen: If the computer becomes difficult to use, disable the most recently changed feature first.

Practice: Create one two-feature profile.

Part 25 - Privacy and Security

  • Voice features use microphone access; verify which apps/services have microphone permission.

  • Live captions and speech recognition can expose sensitive spoken content on screen.

  • Screen-reader speech may be overheard in public settings.

  • Windows Hello biometric data and sign-in methods should be protected like other authentication credentials.

  • Do not enable remote-assistance or third-party accessibility software merely because a pop-up claims it is required.

  • Accessibility settings are not a substitute for account security, device encryption, backups, and software updates.

  • On shared computers, restore accessibility settings only if doing so will not remove another person's needed access.

Part 26 - Troubleshooting

26.1 The Screen Suddenly Looks Very Large

What you will learn: Check Magnifier before changing display resolution.

Before you begin: Everything is enlarged.

Exactly how to do it

  1. Press Windows+Escape.
  2. If Magnifier closes, stop troubleshooting.
  3. If not, press Windows+U and open Magnifier.
  4. Verify Magnifier is off.
  5. Only then inspect display scaling/resolution.

What should happen: Accidental Magnifier activation is ruled out quickly.

If that does not happen: Do not immediately lower Windows display scaling if Magnifier caused the enlargement.

Practice: Practice turning Magnifier on and recovering.

26.2 Colors Look Wrong

What you will learn: Check accessibility color features first.

Before you begin: Colors suddenly look inverted or unusual.

Exactly how to do it

  1. Press Windows+Ctrl+C if the Color Filter shortcut is enabled.
  2. Press Ctrl+Alt+I if Magnifier is on to check inversion.
  3. Press Windows+U and inspect Color filters.
  4. Inspect Contrast themes.
  5. Return each to the intended state.

What should happen: The source of the color change is identified.

If that does not happen: If colors remain wrong, inspect display-driver/hardware settings only after accessibility features are ruled out.

Practice: Practice toggling and restoring a filter.

26.3 Keyboard Seems to Ignore or Delay Keys

What you will learn: Check Filter/Sticky Keys before assuming hardware failure.

Before you begin: Typing feels delayed or modifiers stick.

Exactly how to do it

  1. Press Windows+U.
  2. Open Keyboard.
  3. Check Filter keys and Sticky keys.
  4. Turn off the recently enabled feature or reduce its timing.
  5. Test in Notepad.

What should happen: Normal keyboard response returns if an accessibility timing feature caused the issue.

If that does not happen: If the problem persists with both features off, test another keyboard/application.

Practice: Practice identifying Filter Keys.

26.4 No Audio from One Side

What you will learn: Check Mono Audio and output device.

Before you begin: Important audio seems missing through one ear/channel.

Exactly how to do it

  1. Press Windows+U.
  2. Open Audio.
  3. Turn Mono audio on temporarily.
  4. Replay the content.
  5. If still missing, check speaker/headphone connection and Settings > System > Sound output.

What should happen: Stereo information is combined into one channel when Mono Audio is on.

If that does not happen: Mono cannot fix a physically failed headset/speaker, but it can prevent left/right-only content from disappearing.

Practice: Compare mono and stereo.

26.5 Voice Access Does Not Understand Commands

What you will learn: Check listening state, microphone, and language.

Before you begin: Voice Access is open.

Exactly how to do it

  1. Confirm Voice Access is listening rather than sleeping/muted.
  2. Open Voice Access settings and confirm the selected microphone/language.
  3. Reduce background noise.
  4. Speak one simple built-in command.
  5. Open the Voice Access command guide.

What should happen: Recognition improves or the cause is isolated.

If that does not happen: A language/model mismatch or poor microphone can make commands unreliable.

Practice: Use three simple commands in a quiet room.

26.6 Live Captions Do Not Appear

What you will learn: Check language setup and audio source.

Before you begin: Live Captions is open.

Exactly how to do it

  1. Press Windows+Ctrl+L.
  2. Confirm the caption window/bar is visible.
  3. Check that the required language package finished installing.
  4. Play clearly audible speech.
  5. Check caption language/settings.
  6. Restart Live Captions.

What should happen: Captions appear for supported audio.

If that does not happen: Not every language, device, or feature combination has identical support.

Practice: Test with a clear recorded voice.

26.7 Accessibility Shortcut Was Triggered Accidentally

What you will learn: Identify and disable only the shortcut if needed.

Before you begin: A feature keeps turning on unexpectedly.

Exactly how to do it

  1. Open Windows+U.
  2. Open the feature's detailed settings.
  3. Find its keyboard shortcut option.
  4. Turn off only the shortcut if you still want the feature available manually.
  5. Test the previously troublesome key sequence.

What should happen: Accidental activation stops while the feature remains available.

If that does not happen: Do not disable the entire accessibility feature if only its shortcut is the problem.

Practice: Review Sticky Keys and Color Filter shortcut options.

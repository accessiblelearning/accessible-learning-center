Excel Lesson 4

Accessible Formatting and Number Formats

Excel manual All Excel lessons My progress

Goal

Apply meaningful formatting and number formats while keeping the worksheet usable with screen readers and magnification.

Skills practiced

  • Open Format Cells with Ctrl+1.
  • Apply currency, percentage, date, and text formats.
  • Use bold and clear headers.
  • Avoid merged cells and color-only meaning.

Step-by-step instructions

  1. Open Excel-Lesson-3.xlsx.
  2. Select the header row from A1 through D1 and press Ctrl+B.
  3. Select the Unit Cost and Line Total values. Press Ctrl+1 to open Format Cells.
  4. Choose Currency or Accounting with two decimal places, then press Enter.
  5. Add a Discount column in E1. Enter percentages such as 5%, 10%, and 0% in E2 through E6.
  6. Use Ctrl+1 to confirm the Discount cells use Percentage format.
  7. Add a Purchase Date column in F1 and enter valid dates for each item.
  8. Use Ctrl+1 to apply a clear date format.
  9. Do not merge cells. Keep one header for every column and one record per row.
  10. If you use color, also include text such as Approved or Review so color is not the only cue.
  11. Run Review, Check Accessibility by pressing Alt+Q, typing Check Accessibility, and choosing the command.
  12. Save the workbook as Excel-Lesson-4.xlsx.

JAWS help: Press Insert+Spacebar, then J, to search JAWS commands when you forget a keystroke. Ribbon KeyTips can differ slightly by Microsoft 365 update, so Alt+Q search is included where useful.

Your assignment

Format the expense worksheet with bold headers, currency, percentage, and date formats. Keep the structure accessible and do not merge cells.

Save the finished assignment as Excel-Lesson-4.xlsx.

Before submitting

  • Headers are bold and descriptive.
  • Money, percentages, and dates use appropriate number formats.
  • No cells are merged.
  • Color is not the only way information is communicated.
  • The file is saved as Excel-Lesson-4.xlsx.

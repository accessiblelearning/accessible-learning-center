Final quiz

Choose one best answer for each question based on the course material. There are two questions from each lesson and four choices per question. Question and answer order changes each time. There is no time limit. After grading, read the explanations and use the lesson links to review before retaking the quiz.

2. A colleague asks for the workbook, but you have only described the active worksheet. What distinction matters?
3. You need to change part of B3's existing text while preserving the rest. Which sequence fits?
4. You copied Active from D2 to several rows. Which review checks the intended result?
5. B2 contains 3 and C2 contains 12. What result should =B2*C2 produce?

7. A cell stores 0.1 and should display as 10 percent. What should you change?
8. Red cells mean Needs Review, but no status words are present. What is the best improvement?
9. After filtering Training Status to Not Started, several employees disappear. How should you restore the full list?
10. You are converting a list with column labels into a table. What must be verified in the creation dialog?
11. B2 is 8 and C2 is 8. What does =IF(B2>=C2,"Complete","Needs Training") return?

13. Summary!B1 contains =January!B8. January!B8 changes from 50 to 65. Under normal automatic calculation, what should Summary!B1 show?
14. You want January, February, and Summary in one saved file. Which organization fits?
15. A chart has good alt text, but a reader needs the exact monthly values. What should remain available?

18. You added a validation list for Status. What practical check should follow?

20. The final budget has totals and a chart but no source values accessible to readers. What is missing?

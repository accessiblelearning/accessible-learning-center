Purpose: This manual teaches the HumanWare Brailliant BI X series from the beginning. It covers the BI 20X and BI 40X, including physical orientation, KeySoft Lite, reading and editing, online libraries, terminal mode, connections to computers and mobile devices, troubleshooting, practice, and quick-reference commands.

Current reference: HumanWare's current support pages list User Guide version 2.6 and firmware version 2.6.0 build 5120 for the BI 20X and BI 40X.

Model difference: The BI 20X has 20 braille cells and no six-key command cluster. The BI 40X has 40 braille cells plus six configurable command keys, three on each side of the display.

How to Use This Manual

  • Place the device flat with the braille cells closest to you.

  • Use Previous and Next thumb keys to move through menus.

  • Use Left and Right thumb keys to pan braille.

  • Press Enter (dot 8) or any routing key to activate the selected item.

  • Press Space+E to go back.

  • Press Home or Space+dots 1-2-3-4-5-6 to return to Main Menu.

  • Press Space+H for help and Space+M for the context menu.

  • Use first-letter navigation in KeySoft Lite lists and menus.

  • Terminal mode is different from KeySoft Lite: once connected to a host screen reader, host-screen-reader commands take precedence.

  • Connection rule: pair/connect first, configure the host screen reader second, then test OUTPUT, INPUT, and ROUTING.

  • Before removing USB/SD storage, use Enter+E to eject it safely.

Part 1 - What the Brailliant BI X Is

The Brailliant BI X series is a family of smart refreshable braille displays. The devices work independently with KeySoft Lite applications and can also become external braille displays for computers, phones, and tablets.

  • BI 20X: 20 braille cells, Perkins-style input keyboard, four thumb keys plus Home, onboard Wi-Fi, Bluetooth/USB host connections, rear SD-card slot.

  • BI 40X: 40 braille cells, Perkins-style input keyboard, four thumb keys plus Home, six command keys, onboard Wi-Fi, Bluetooth/USB host connections.

  • KeySoft Lite: HumanWare's onboard menu/app environment.

  • Terminal mode: host-device braille display mode.

  • KeyPad: text editor.

  • KeyBRF: braille-file editor.

  • Victor Reader: reading app for text and audio books.

  • KeyFiles: file manager.

  • Online services: NLS BARD, Bookshare, NFB-NEWSLINE and DAISY Online accounts where eligible.

Part 2 - Physical Orientation

2.1 Top Face - Both Models

  • Place the Brailliant flat with the braille cells closest to you.

  • The front section of the top face contains the 20 or 40 braille cells.

  • Immediately above each cell is a routing key. In text editing, a routing key moves the cursor to that cell. In menus, a routing key activates the selected item.

  • Two Space bars are positioned for the thumbs.

  • Farther away from you is the Perkins-style braille keyboard.

  • Under the left hand: dots 1, 2, 3 and Backspace (dot 7). Dot 1 is under the left index finger; Backspace is under the left little finger.

  • Under the right hand: dots 4, 5, 6 and Enter (dot 8). Dot 4 is under the right index finger; Enter is under the right little finger.

2.2 BI 40X Command Keys

  • Only the BI 40X has six command keys around the braille display.

  • Left side of the display, from back to front: C1, C2, C3.

  • Right side of the display, from back to front: C4, C5, C6.

  • Current default functions include C1 previous item, C2 pan left, C3 next item, C4 switch language profile, C5 pan right, and C6 start auto-scroll.

  • These command keys can be reassigned in User Settings.

2.5 Right Edge - Front to Back

  • Volume buttons.

  • 3.5 mm audio jack.

  • On the BI 40X, the right edge/top area also includes speaker hardware; audio features depend on current firmware/function.

2.6 BI 20X Rear Edge

  • The BI 20X has an SD-card slot on the rear edge near the left side.

  • The BI 40X does not use this BI 20X rear SD-card layout.

Part 3 - Charging, Power, and Battery

3.1 Charge the Brailliant

What you will learn: Connect power without forcing the connector.

Before you begin: Use the included USB-C cable and a suitable USB power adapter.

Exactly how to do it

  1. Locate the USB-C port at the back end of the left edge.
  2. Insert the USB-C plug gently.
  3. Connect the other end to the power adapter.
  4. Plug the adapter into AC power.
  5. Allow the battery to charge.

What should happen: The status LED/braille status indicates charging.

If that does not happen: If the device does not charge, try the included cable/adapter and a different outlet.

Practice: Locate USB-C and connect/disconnect it correctly.

3.2 Power On and Check Battery

What you will learn: Start the device and verify charge.

Before you begin: Battery has some charge.

Exactly how to do it

  1. Press and hold the Power button for about two seconds.
  2. Wait for KeySoft Lite to start.
  3. Press Enter+P.
  4. Read/listen to the battery level.

What should happen: Main Menu appears and the battery percentage/status is reported.

If that does not happen: If nothing happens, connect power and retry.

Practice: Power on and report battery level.

Firmware update warning: HumanWare states that units still on firmware 1.x must first install version 2.0 manually before updating to later firmware.

What you will learn: Move around without memorizing app order.

Before you begin: Device is on.

Exactly how to do it

  1. Press Home.
  2. Press Next thumb repeatedly.
  3. Read each app/item.

What should happen: The selected app opens.

If that does not happen: If letters enter text, you are in an edit field rather than a menu; press Space+E and return Home.

6.1 Change Braille Grade Safely

What you will learn: Switch between configured braille grades.

Before you begin: Open ordinary text where the difference is easy to recognize.

Exactly how to do it

  1. Press Backspace+G.
  2. Read the same text again.
  3. Press Backspace+G again if you want to restore the prior grade.

What should happen: Braille translation changes without changing the underlying file.

If that does not happen: If the result is unexpected, inspect the active language/braille profile in Options.

Practice: Toggle grade and identify which grade is active.

Computer braille note: HumanWare notes that commands containing Enter or Backspace may require adding Space when computer braille input is selected.

7.1 Create and Save a Text File

What you will learn: Write a basic note in KeyPad.

Before you begin: Open KeyPad.

Exactly how to do it

  1. Press Backspace+N.
  2. Enter a filename if prompted.
  3. Press Enter to enter edit mode.
  4. Type a short paragraph.
  5. Press Space+S.
  6. Press Space+E to leave edit mode/file when finished.

What should happen: The text file is saved and can be reopened.

If that does not happen: If the file remains unnamed, use Backspace+S for Save As.

Practice: Create, save, close, and reopen a practice note.

7.2 Use Bookmarks in KeyPad

What you will learn: Mark important positions inside a file.

Before you begin: Open a longer file.

Exactly how to do it

  1. Move to the desired location.
  2. Press Enter+M for Bookmark menu, or Enter+B for a quick bookmark.
  3. Assign a number if requested.
  4. Move elsewhere.
  5. Press Enter+J.
  6. Enter the bookmark number and press Enter.

What should happen: The cursor returns to the saved position.

If that does not happen: Use unique bookmark numbers.

Practice: Create two bookmarks and jump between them.

9.1 Read a Text Book

What you will learn: Navigate structure rather than only panning.

Before you begin: Open a supported text/DAISY title.

Exactly how to do it

  1. Press Space+T.
  2. Choose a navigation level.
  3. Press Next thumb to move forward at that level.
  4. Press Previous thumb to move backward.
  5. Press Space+G for read-all speech if desired.
  6. Press Backspace+Enter to stop.

What should happen: The book moves by the selected structure.

If that does not happen: A book without headings/pages cannot provide those levels.

Practice: Navigate by two different levels.

9.2 Read an Audiobook

What you will learn: Play, pause, rewind, and fast-forward.

Before you begin: Open an audio title.

Exactly how to do it

  1. Press Space+G to play.
  2. Single-press Left thumb to rewind about five seconds.
  3. Single-press Right thumb to fast-forward about five seconds.
  4. Press and hold Left/Right thumb for larger time movement.
  5. Press Backspace+Enter to stop.

What should happen: Playback responds without leaving your current book.

If that does not happen: If thumb keys move structural elements instead, verify the title is in audio playback mode.

Practice: Practice five-second and long jumps.

Part 10 - KeyFiles and External Storage

10.1 Browse and Manage Files

What you will learn: Find files without connecting to a computer.

Before you begin: Open KeyFiles with Backspace+Enter+F.

Exactly how to do it

  1. Use Previous/Next through storage locations and folders.
  2. Press Enter to open a folder.
  3. Use first-letter navigation for a known filename.
  4. Press Space+M for available actions.
  5. Press Space+E to go back.

What should happen: You can browse internal and removable storage.

If that does not happen: If removable media is absent, it will not appear.

Practice: Find one text file and one book file.

10.2 Eject USB or SD Media

What you will learn: Avoid data corruption.

Before you begin: USB storage or BI20X SD card is connected.

Exactly how to do it

  1. Press Enter+E.
  2. Select the removable device.
  3. Press Enter.
  4. Wait for confirmation.
  5. Remove the storage physically.

What should happen: The device is safely unmounted.

If that does not happen: Do not remove media while files are being saved or copied.

Practice: Practice reaching Eject without removing media.

Part 15 - Terminal Mode

Terminal mode makes the BI X an external braille display/controller for a host device running a screen reader.

Task Command / Control
Open Terminal Backspace+Enter+T
Exit Terminal Home
Connections supported Up to five Bluetooth hosts plus one USB host

15.1 Use the Correct Connection Sequence

What you will learn: Avoid mixing BI X and host screen-reader problems.

Before you begin: Host device and BI X are ready.

Exactly how to do it

  1. Open Terminal.
  2. Choose or establish Bluetooth/USB connection.
  3. Complete pairing/USB connection on the host.
  4. Open the host screen reader's braille settings.
  5. Select/configure the HumanWare/Brailliant display if required.
  6. Test braille OUTPUT from the host.
  7. Test braille INPUT from the BI X.
  8. Test a routing key.
  9. Only after all three tests should you begin learning host commands.

What should happen: The BI X mirrors and controls the host screen reader.

If that does not happen: If output works but input/routing does not, the Bluetooth/USB pairing itself is probably not the whole problem; inspect screen-reader braille settings/driver commands.

Practice: Perform output, input, and routing tests.

Part 16 - iPhone and iPad with VoiceOver

16.1 Pair with VoiceOver

What you will learn: Use the BI X as an Apple braille display.

Before you begin: Bluetooth is enabled and Terminal is ready.

Exactly how to do it

  1. Open Terminal on the BI X.
  2. Choose Bluetooth and make the intended BI X connection available.
  3. On iPhone/iPad open Settings > Accessibility > VoiceOver > Braille.
  4. Move to detected braille displays.
  5. Choose the Brailliant BI X entry.
  6. Confirm pairing if prompted.
  7. Open a normal iPhone/iPad app.
  8. Confirm VoiceOver output appears on the BI X.
  9. Type from the BI X.
  10. Test a routing key.

What should happen: VoiceOver uses the BI X for braille output/input.

If that does not happen: If the display does not appear, forget stale pairings only after verifying Bluetooth and Terminal mode.

Practice: Test output, input, and routing.

Part 17 - Windows with JAWS

17.1 Configure JAWS

What you will learn: Use HumanWare's JAWS-supported Brailliant driver workflow.

Before you begin: BI X is paired by Bluetooth or connected by USB.

Exactly how to do it

  1. Start JAWS.
  2. Open JAWS braille/display settings.
  3. Add/select a Brailliant/HumanWare display.
  4. Choose the correct USB/Bluetooth/COM connection when asked.
  5. Apply settings.
  6. Move through Windows text and controls.
  7. Confirm braille output.
  8. Type and test routing.

What should happen: JAWS uses the BI X as a braille display/controller.

If that does not happen: If the device is paired but JAWS has no braille, the JAWS display configuration may be incomplete.

Practice: Test output/input/routing and one JAWS braille command.

Part 18 - Windows with NVDA and Narrator

18.1 NVDA

  • Pair/connect the BI X first.

  • Open NVDA Settings > Braille.

  • Select the detected/appropriate HumanWare braille display or automatic detection when supported.

  • Confirm output, then input, then routing.

  • Once Terminal is active, use NVDA's current braille commands rather than KeySoft Lite commands.

18.2 Narrator

  • HumanWare provides current instructions for using HumanWare braille displays with Narrator.

  • Connect the BI X, then configure Narrator's braille settings/driver as currently documented.

  • Verify output/input/routing before troubleshooting individual commands.

  • Narrator commands may differ significantly from JAWS and NVDA.

Part 19 - Mac with VoiceOver

  • Open Terminal and use the connection method supported by current HumanWare/macOS documentation.

  • Open VoiceOver Utility or current macOS braille-display settings.

  • Add/select the detected Brailliant.

  • Test output/input/routing.

  • Use VoiceOver braille commands while Terminal is active; Home returns to BI X Main Menu.

20.1 Pair with TalkBack

What you will learn: Use the BI X with Android's current braille-display support.

Before you begin: TalkBack is current and Bluetooth is enabled.

Exactly how to do it

  2. On Android open TalkBack braille-display settings.

Part 21 - Bluetooth and Multiple Host Devices

The BI X can maintain multiple host connections: HumanWare documents up to five Bluetooth devices plus one USB device.

  • Give paired devices recognizable names on the host when possible.

  • Do not assume the BI X is controlling the host you last touched; verify the active Terminal connection.

  • If keystrokes affect the wrong host, return Home, reopen Terminal, and choose the intended connection.

  • Remove stale pairings only after simpler reconnection attempts fail.

Part 22 - Terminal Clipboard

Current BI X firmware includes a Terminal Clipboard workflow for moving text between the host-device terminal session and KeySoft Lite contexts.

Learning strategy: Because clipboard commands can change with firmware and host screen reader, open Space+H or the built-in User Guide while in Terminal Clipboard and practice with non-sensitive text before using it for passwords, account information, or confidential content.

22.1 Practice Clipboard Safely

What you will learn: Learn the concept without risking private information.

Before you begin: Use a short practice sentence.

Exactly how to do it

  1. Copy a harmless sentence on the host using the host screen reader's normal clipboard command.
  2. Open the BI X Terminal Clipboard workflow according to current Help/User Guide.
  3. Confirm the clipboard text.
  4. Paste or transfer it only into a practice KeySoft Lite file.
  5. Reverse the process with another harmless phrase if supported.

What should happen: Text transfers without exposing sensitive information.

If that does not happen: If the clipboard workflow differs from this manual, use current firmware Help/User Guide rather than guessing commands.

Practice: Practice only with disposable text.

Part 23 - User Settings and One-Handed Mode

  • Space+O opens Options.

  • User Settings can customize thumb-key mapping.

  • BI 40X User Settings can customize C1-C6 command keys.

  • One-handed mode allows braille dots to be entered sequentially and confirmed with Space.

  • Start in Terminal can make the BI X open Terminal automatically at startup.

  • Word wrap, condensed blank lines, confirmation prompts, vibration, beeps, wireless notifications, and other settings are available.

23.1 Enable One-Handed Mode

What you will learn: Enter braille one dot at a time.

Before you begin: Use this only when needed.

Exactly how to do it

  1. Press Space+O.
  2. Open User Settings.
  3. Find One-handed mode.
  4. Turn it On.
  5. Enter a test braille character by pressing/releasing its dots one at a time.
  6. Press Space to confirm the dot combination.
  7. Return to User Settings and turn the mode Off when finished if you do not need it.

What should happen: The character is entered after Space confirms the collected dots.

If that does not happen: If normal chorded braille behaves strangely, check whether One-handed mode was left enabled.

Practice: Enable, type a few letters, then disable.

Part 24 - Software Updates

24.1 Check for Current Firmware

What you will learn: Keep KeySoft Lite current.

Before you begin: Use stable Wi-Fi and adequate battery/AC power.

Exactly how to do it

  1. Open Space+O Options.
  2. Find Software Update / update settings.
  3. Check for updates.
  4. Follow spoken/braille prompts.
  5. Do not disconnect power or storage during installation.
  6. After restart, press Space+I to review version information.

What should happen: The BI X reports current firmware or installs the update.

If that does not happen: If you are still on version 1.x, HumanWare requires a manual update to 2.0 before later versions.

Practice: Check the installed version.

Current support listing: At the time this manual was prepared, HumanWare listed firmware 2.6.0 build 5120 and User Guide 2.6 for BI 20X and BI 40X.

Part 25 - Security and Privacy

  • Online-library passwords entered on the braille keyboard are account credentials; protect them like passwords entered on a computer.

  • Terminal mode can display confidential host-device text. Anyone reading the braille display may see that content.

  • Remove or lock sensitive files before lending the BI X.

  • Safely eject USB/SD media before removal.

  • Do not pair with an unfamiliar Bluetooth device.

  • On shared computers/phones, remove or disconnect the BI X after use if persistent pairing is not appropriate.

  • Update firmware from HumanWare's official support sources.

Part 26 - Troubleshooting

26.1 You Are Lost in KeySoft Lite

What you will learn: Return to a known location.

Before you begin: The device is responsive.

Exactly how to do it

  1. Press Space+H and read contextual Help.
  2. Press Space+E one or more times.
  3. Press Home.
  4. Use first-letter navigation from Main Menu.

What should happen: You return to a predictable app/menu location.

If that does not happen: If Home does not respond, inspect battery/power before performing a restart.

Practice: Practice recovery from three apps.

26.2 Braille Does Not Change

What you will learn: Separate a frozen app from a display/host issue.

Before you begin: The device is on.

Exactly how to do it

  1. Press Home.
  2. Press Next thumb repeatedly.
  3. See whether the cells update through Main Menu.
  4. If Main Menu works, the problem is likely app/Terminal-specific.
  5. If in Terminal, test host-screen-reader output and reconnect the host.
  6. Restart the BI X only after these checks.

What should happen: The failure is narrowed to KeySoft Lite, Terminal/host, or device hardware.

If that does not happen: If cells never change even in Main Menu, contact HumanWare support.

Practice: Practice the diagnostic order.

26.3 Terminal Pairing Exists but No Braille Appears

What you will learn: Check screen-reader configuration.

Before you begin: Host says Bluetooth/USB is connected.

Exactly how to do it

  1. Confirm Terminal is open on the BI X.
  2. Confirm the intended host connection is selected.
  3. Open the host screen reader's braille settings.
  4. Verify the HumanWare/Brailliant display is selected.
  5. Test OUTPUT.
  6. Then test INPUT and ROUTING.

What should happen: The missing configuration stage becomes clear.

If that does not happen: Do not repeatedly delete Bluetooth pairing if the screen reader is simply not configured for braille.

Practice: Practice explaining pairing versus screen-reader configuration.

26.4 Online Library Will Not Log In

What you will learn: Check Wi-Fi and credentials separately.

Before you begin: An eligible library account exists.

Exactly how to do it

  1. Confirm Wi-Fi is connected.
  2. Verify the account credentials on the provider's own website/app if possible.
  3. Return to Online Services.
  4. Edit the account only if credentials changed.
  5. Check storage space if login works but downloads fail.

What should happen: You identify network, account, service, or storage as the cause.

If that does not happen: Avoid repeated password guesses that could lock an account.

Practice: Run the diagnostic sequence.

26.5 A File Will Not Open

What you will learn: Check type, location, and app.

Before you begin: The file is present in KeyFiles.

Exactly how to do it

  1. Read the full filename/extension.
  2. Use Space+M and choose Open with / appropriate app if available.
  3. Copy the file to internal storage if removable-media access is unreliable.
  4. Try KeyPad, KeyBRF, or Victor Reader according to file type.

What should happen: A compatible app opens the file or the unsupported format becomes clear.

If that does not happen: Do not rename an extension merely to force compatibility.

Practice: Test with TXT, BRF, and a supported book file.
